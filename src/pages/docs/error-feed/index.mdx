Every failing trace in your app is evidence of something broken, but scrolling through them one at a time doesn't tell you what's actually wrong. Error Feed pulls the failing ones out of an Observe project, groups the matching failures together, and gives you a queue you work down instead of a pile you scroll through.

## What is Error Feed?

Error Feed lives in the sidebar under **Observe**. It's where hallucinations, eval failures, and pipeline issues, the kinds of failure plain trace search doesn't surface on its own, turn into something you can act on.

When traces from an Observe project fail, Error Feed groups the matching ones into a single **issue**: a row you triage like a ticket, not a trace you read line by line. Every issue carries a severity, a status, an assignee, and an optional link to a Linear ticket, and it points at the fix layer, the part of your system the fix actually belongs in.

Error Feed sits behind an Enterprise or Cloud license. Without one, the page shows an upgrade prompt instead of a feed, and the API declines every request the same way.

Licensed doesn't mean scanning. Every Observe project ships with its scanner sampling rate at 0, so nothing gets scanned, and no issues appear, until you raise it yourself. See [Turn on Error Feed](/docs/error-feed/guides/turn-on-error-feed).
