---
title: "Run a root cause analysis"
description: "Turn one issue into a written root cause and a proposed fix"
---

An issue in the feed groups a batch of failing traces together, but it doesn't tell you why they're failing. The **Fix** tab does: sub-agents sample representative calls from the issue, compare them against a passing baseline trace, and synthesise a written root cause and a proposed fix.

<Steps>
  <Step title="Open the issue's Fix tab">
    From the issue's detail page, click into the **Fix** tab.
  </Step>
  <Step title="Start the analysis">
    If nothing has run yet, the tab shows an empty state: click **Analyze this cluster**. You can also kick it off from the issue's headline card, whose button reads **Debug this cluster** before a run exists.
  </Step>
  <Step title="Wait for it to finish">
    The analysis runs in the background. Give it a few minutes.
  </Step>
  <Step title="Read the synthesis">
    The result lands as a written thread: the root cause and the proposed fix.
  </Step>
  <Step title="Ask a follow-up">
    Type into the composer at the bottom (its placeholder reads "Ask Falcon a follow-up…") to probe the reasoning further.
  </Step>
  <Step title="Re-run once the issue has moved on">
    If the cluster has picked up new traces since the last run, click **Re-run** in the tab's header to analyze it against its current state.
  </Step>
</Steps>

## Cost

A run and a re-run each cost one credit. Future AGI checks and deducts the credit before the run starts, and refunds it automatically if the run fails, so a failed run doesn't cost you anything.

## Timing

Clicking **Analyze this cluster** or **Re-run** returns immediately, it doesn't block the page. The tab polls in the background and updates the moment the run flips from running to done or failed. A run is capped at one hour; if it hasn't landed by then, it ends as failed rather than hanging indefinitely.

## If it fails

Two messages cover the failure cases you'll actually see:

- **"Couldn't start the analysis. Please try again."** The request to start the run didn't go through.
- **"Couldn't connect to the server. Please try again."** The connection dropped partway through a run that had already started.

Either way, re-running is safe. Since the credit is refunded on failure, a re-run after either message doesn't double-charge you.
