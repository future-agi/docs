When an [Error Feed](/docs/error-feed) issue needs engineering work, send it to the right Linear team without retyping the title. The issue keeps a permanent link to one ticket, but its status does not follow changes in Linear.

<Prerequisites title="Before you start">
- An Error Feed issue and a Linear team for the ticket.
- A [Linear integration](/docs/admin-settings/integrations) connected under **Settings > Integrations**. An organization Owner or Admin can configure it with a Linear personal API key with **Issues: Write** permission; workspace admins and members can view configured integrations.
</Prerequisites>

## Create the ticket

1. Open the issue from the Feed.
2. Find **Integrations** in the [metadata sidebar](/docs/error-feed/guides/investigate-an-issue).

   If a ticket already exists, the Linear row reads **View** followed by its ID; there is no second ticket slot.

3. Select **Create issue** in the Linear row.

   You should see **Create Linear Issue**, with “Select a team to create the issue in.” above the team list.

<Warning>
Selecting a team immediately creates the ticket. There is no confirmation button and you cannot remove the link from Error Feed. Check the team name before selecting it.
</Warning>

4. Select the team that should own the ticket.

   Look for “Created” followed by the issue ID; the Linear row should change to **View** followed by the same ID.

The ticket uses the Error Feed title, truncated at 200 characters. When a root cause analysis already exists, the **Cluster Analysis** card on **Overview** also offers **Create Linear issue**.

## Verify the link

1. Select **View** in the Linear row.
2. Compare the ID of the ticket in Linear with the ID on the Error Feed issue.

   The IDs should match even if the title in Linear was shortened.

Creating the ticket is one-directional. Closing, resolving or editing the Linear ticket does not update the [issue status](/docs/error-feed/concepts/severity-and-status): the issue keeps whatever status it had when you created the ticket. Once the fix lands, resolve the issue in Error Feed yourself.

## If you don't see a team or ticket

<div class="sdk-ref-table max-sm:[&_td]:px-1.5! max-sm:[&_th]:px-1.5!">

| What you see | What to do |
| --- | --- |
| “Loading teams” | Wait for the list to load. |
| “Couldn't reach Linear. Check the integration in Settings and try again.” | Check the connection under **Settings > Integrations** before retrying. |
| “Linear isn't connected for this workspace. Connect it in Settings > Integrations.” | Have an organization Owner or Admin connect Linear under **Settings > Integrations**. |
| “No teams found in your Linear workspace.” | Add a team in Linear before creating the ticket. |
| “Failed to create Linear issue” | The row stays on **Create issue** so you can retry. |

</div>
