---
title: "Create a Linear issue"
description: "Push an Error Feed issue into Linear so the fix lands in your engineering backlog."
---

Once an issue is worth fixing, you don't have to leave Error Feed to open a ticket for it. Create a Linear issue right from the issue page, and it stays linked so anyone can jump between the two.

## Before you start

Linear needs to be connected for your workspace under **Settings > Integrations**.

## Create the issue

<Steps>
  <Step title="Open the issue">
    Go to the Error Feed issue you want to send to Linear.
  </Step>
  <Step title="Find the Linear row">
    In the metadata sidebar, scroll to the Integrations section. The Linear row shows a **Create issue** button.
  </Step>
  <Step title="Press Create issue">
    The Create Linear Issue dialog opens and lists the teams in your Linear workspace.
  </Step>
  <Step title="Pick a team">
    Select the team to create the issue in.
  </Step>
  <Step title="Confirm">
    The Linear row now reads **View {'{issueId}'}**. Click it any time to open the ticket in Linear.
  </Step>
</Steps>

<Note>
The ticket title is truncated at 200 characters, so a long cluster title gets clipped.
</Note>

## If the picker won't cooperate

The Create Linear Issue dialog can land in a few states before it shows you a team to pick:

| State | What you'll see |
|-------|-----------|
| Teams loading | "Loading teams…" |
| Linear unreachable | "Couldn't reach Linear. Check the integration in Settings and try again." |
| Linear not connected | "Linear isn't connected for this workspace. Connect it in Settings > Integrations." |
| No teams found | "No teams found in your Linear workspace." |
