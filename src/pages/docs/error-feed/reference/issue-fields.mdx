## Feed filters

Controls on the feed's filter bar, with the exact set of options each one offers.

| Filter | Options |
|---|---|
| Time range | `24h`, `7d`, `14d`, `30d`, `90d` |
| Status | `escalating`, `for_review`, `acknowledged`, `resolved` |
| Severity | `critical`, `high`, `medium`, `low` |
| Fix layer | `Tools`, `Prompt`, `Orchestration`, `Guardrails` |
