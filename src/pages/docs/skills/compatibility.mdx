## Availability contract

**Pilot preview.** These pages describe the supported-subset pilot contract. They do not establish deployment enablement, released package versions, native client certification, or a measured 10x result. Before using a new surface, require the exact deployment capability, API contract, package version/hash, and qualification evidence for the selected host/runtime.

No new SDK package release or live native profile is verified by this documentation change. Installation examples for unreleased methods are intentionally withheld. Existing Skills documentation describes its earlier release and does not certify the new context paths.

## Who the pilot fits

A Python application that can retain its current tracing/regression pipeline, use one managed AGENTS entrypoint with same-workspace leaf skills, reconstruct historical state, and run a qualified actual-entrypoint adapter with controlled model/tool spending and business-action idempotency.

A new Deep Agents demo is not evidence that an existing LangGraph application is compatible. Adapter construction, configuration, local policy review, and recovery work are part of setup—not hidden prerequisites excluded from measurements.

## Content limits

All limits apply to the **whole compiled tree**, including generated descriptor and prefixed linked files:

| Limit | Maximum |
| --- | --- |
| Linked leaf skills | 20 |
| Total files | 200 |
| One UTF-8 file | 512 KiB |
| Complete release | 2 MiB |
| Path length | 255 characters |
| Path depth | 8 segments |

A 200-file child cannot fit beside a new root and descriptor. Reject overflow with a contribution breakdown; do not truncate or import a surviving subset silently. Existing upload/ZIP safety budgets still apply. Nonempty `AGENTS.md` is required. Binary/multimodal files, recursive contexts/subagents, cross-workspace links, and managed nested entrypoints are unsupported.

Owned files cannot collide with generated `.futureagi/**`, mounted `skills/**`, or host-control destinations. Stored executable text is reviewed as content; import does not execute it or grant its declared permissions.

## Host precedence is part of compatibility

- **Codex:** project-root AGENTS, ancestor/override/fallback instructions, working directory, skill locations, and context byte budget all affect the result. Do not install standing instructions under a skill-only directory.
- **Claude Code:** direct AGENTS loading depends on the exact version and settings/ancestor conditions. Existing CLAUDE files may change precedence. A reviewed CLAUDE import is a separate adapter output, not an implicit setting change. Direct AGENTS loading may lack an InstructionsLoaded hook, so model self-report alone is insufficient evidence.
- **Python application:** the approved context/source mount is read-only; checkpoint state, conversation history, and large tool results remain writable elsewhere. Custom subagents are not implicitly configured.
- **Other clients/scopes:** Cursor, Gemini, Copilot, global/personal installs, plugins/cloud destinations, native JavaScript, and managed monorepo/nested semantics remain unqualified until their own exact matrix passes.

Existing local/nested instructions are preserved and exposed as additional context, not silently folded into behavioral evidence.

## Deliberately unavailable in the pilot

Multi-repository campaigns and rollout credentials; service-owned proposals; isolated Context-token MCP ingress; broad external evidence import; paid assistance unless its separate original-operation recovery/non-destructive apply journey is qualified; automatic repair/optimization; automatic promotion; offline authorization/cache mode; inherited mandatory evidence policies; autonomous Git writes/merge; and broad hosted private-source connectors.

Their enforcement foundations may exist without an enabled user feature. Existing protection, revocation, and quarantine must still hold.

## Commercial, privacy, and evidence boundaries

Provider estimates are not invoices. Confirm permitted workspace connections, explicit period/run limits, known and unknown reservations, and any separately disclosed Simulation/platform charges. No new monetary default or billing decision is established here. An unqualified common spending bridge means paid native execution is unavailable.

Private payloads cannot escape through ordinary Simulation lists/counts, artifacts, traces, exports, or guest logs. Explicit sharing changes only the declared audience and never silently extends expiry. Expired detailed payloads lose inspectability even when non-content receipts survive.

Qualification uses the exact committed build, released package hashes, runtime/template pins, fixtures, and real observation path. Unit-green, fake-provider/Git orchestration, a text pass, an installed lock, or a screenshot is not full customer qualification. Existing experiment CI and incident detection remain authoritative.

## What would justify an improvement claim

Measure complete jobs: reversible trial/update/exit; historical failure to verified repair; shared-policy correction; author-to-reviewer exact release; repository adoption/update/recovery; and qualified application recovery. Include setup, scripts, wrapper code, failed attempts, review, waits, handoffs, and local reconciliation. Separate cold and configured work.

A claim of **10x fewer operator actions** requires `10 × our actions ≤ best applicable competitor actions` for that job, with the required outcomes preserved. Documentation bullet counts are candidate scripts, not measured denominators. Do not average across jobs or turn a zero/missing baseline into a win.

Human active time, elapsed time, comprehension, success, and known/unknown expense require a separate preregistered study. Missing competitor access, customer state, or live native observation is **Not measured / Not qualified**. None of these docs claims an overall 10x launch.
