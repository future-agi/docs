## About

Skills stores versioned instructions and supporting text in a workspace library. A **skill** has a `SKILL.md` root for an on-demand procedure. An **agent context** has an `AGENTS.md` root for standing instructions and can link published skills. Each context release records the exact accepted child versions rather than resolving those children again on every fetch.

The library is under **Build → Skills**. Its **Agent contexts** and **Reviews** tabs separate context authoring from release decisions. Source imports, drafts, published versions, and production labels are different states; importing or saving a draft does not authorize a production change.

## Choose the right resource

| Resource | Contents | Update behavior |
| --- | --- | --- |
| Skill | `SKILL.md`, frontmatter, and supporting UTF-8 files | A publication creates an immutable file set. |
| Agent context | `AGENTS.md`, purpose, owned files, and explicitly linked same-workspace leaf skills | A publication includes the accepted dependency lock. A following child label offers an update; it does not rewrite a published context. |
| Label | A mutable pointer such as `production` | Moving it affects future resolutions, not existing locks or conversations. |
| Binding | An explicitly declared repository or runtime consumer | Observations distinguish resolved, installed, discovered, and delivered states. |

## Review before release

Static checks inspect structure, paths, detected secrets, and portability. They do not execute imported scripts or certify behavioral correctness. [Tests and evidence](/docs/skills/tests) distinguish text comparisons from native application evidence. [Reviewed releases](/docs/skills/reviewed-releases) bind decisions to an exact candidate and label transition.

A publication, approval, production pointer, installation receipt, and model-delivery observation are separate facts. Missing observations remain unknown.

## Availability in this build

The documented source baseline is product commit `12576311b77d22f00c8ca1471c7f051eed96889a`. API registration alone is not feature enablement. The retained product screenshots show agent-context editing, accepted dependency locks, retained migration, and exact release receipts. They also show **Repository rollouts (unavailable)** and disabled context testing controls. These boundaries are preserved in the guides.

[Compatibility](/docs/skills/compatibility) describes deployment and package prerequisites. No SDK package release, native client certification, automatic promotion, or measured 10x result is established by these pages. Binary assets, recursive context links, cross-workspace links, and skill renaming are outside this content model.

## How Skills connects to other features

- [Prompts](/docs/prompt) hold prompt templates; their default-version rules do not replace Skills labels and locks.
- [MCP tools](/docs/skills/mcp-tools) expose authorized discovery and file reads. Reading a resource does not install or execute it.
- [Application consumption](/docs/skills/use-in-agents) retrieves immutable content; [safe installation](/docs/skills/safe-installation) covers managed destinations, authentication, and recovery.
- Existing tracing and experiment pipelines remain authoritative for application outcomes. [Migration](/docs/skills/migration) preserves source identity and does not replace those pipelines.
