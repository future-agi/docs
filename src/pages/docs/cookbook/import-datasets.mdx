## About

The optimizer takes a Python list of dictionaries, not a filename. Load a Ridgeline Outfitters support export into that shape, keep the reference queue out of the prompt, and score two variations of a ticket router.

| Time | Difficulty | Package |
|---|---|---|
| 15 min | Beginner | `agent-learning-kit==0.3.7` |

## Set up Python

Use a fresh Python 3.12 environment. In Bash, enter an OpenRouter API key when prompted. The model calls use that key; the exact-match metric runs locally without Future AGI credentials.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7
read -rsp 'OpenRouter API key: ' OPENROUTER_API_KEY; printf '\n'
export OPENROUTER_API_KEY
```

## Load and validate a ticket export

| Format | What the file must contain for this loader |
|---|---|
| CSV | A header with `ticket` and `queue`, then one ticket per row. |
| JSON | One array of objects, each with a `ticket` and a `queue`. |
| JSONL | One complete ticket object per nonblank line; no outer array. |

For example, the same two records appear in each file in this recipe:

| `ticket` | `queue` |
|---|---|
| My new boots don't fit. Can I send them back? | `RETURNS` |
| Can you fix a broken buckle on my pack? | `REPAIRS` |

Save as `import_tickets.py` and run `python import_tickets.py`. With no arguments the script makes two labeled tickets in memory, writes temporary exports, and reads all three back. The optimizer uses the rows loaded from the last file. To use your own file instead, pass its path, for example `python import_tickets.py my-tickets.csv`.

<CodeGroup titles={["Python"]}>

```python
import csv
import json
import sys
from pathlib import Path
from tempfile import TemporaryDirectory

from fi.evals.metrics import Equals
from fi.opt.base import Evaluator
from fi.opt.datamappers import BasicDataMapper
from fi.opt.generators import LiteLLMGenerator
from fi.opt.optimizers import RandomSearchOptimizer


def load_rows(path):
    with path.open(encoding="utf-8", newline="") as file:
        if path.suffix == ".csv":
            rows = list(csv.DictReader(file))
        elif path.suffix == ".json":
            rows = json.load(file)
        elif path.suffix == ".jsonl":
            rows = [json.loads(line) for line in file if line.strip()]
        else:
            raise ValueError("Use CSV, JSON, or JSONL")
    if not isinstance(rows, list) or not rows:
        raise ValueError("Expected a nonempty list of tickets")
    tickets = []
    for n, row in enumerate(rows, start=1):
        if (
            not isinstance(row, dict)
            or not isinstance(row.get("ticket"), str)
            or not row["ticket"].strip()
            or row.get("queue") not in ("REPAIRS", "RETURNS")
        ):
            raise ValueError(f"Check ticket and queue on row {n}")
        tickets.append({"ticket": row["ticket"], "queue": row["queue"]})
    return tickets


examples = [
    {"ticket": "My new boots don't fit. Can I send them back?", "queue": "RETURNS"},
    {"ticket": "Can you fix a broken buckle on my pack?", "queue": "REPAIRS"},
]

if len(sys.argv) > 1:
    train = load_rows(Path(sys.argv[1]))
    print(f"Loaded {len(train)} tickets from {sys.argv[1]}")
else:
    # Demonstrate all three formats without requiring an existing export.
    with TemporaryDirectory() as folder:
        root = Path(folder)
        with (root / "tickets.csv").open("w", encoding="utf-8", newline="") as file:
            writer = csv.DictWriter(file, fieldnames=["ticket", "queue"])
            writer.writeheader()
            writer.writerows(examples)
        (root / "tickets.json").write_text(json.dumps(examples), encoding="utf-8")
        (root / "tickets.jsonl").write_text(
            "\n".join(map(json.dumps, examples)), encoding="utf-8"
        )
        for suffix in ("csv", "json", "jsonl"):
            train = load_rows(root / f"tickets.{suffix}")
            assert train == examples
            print(f"{suffix}: {len(train)} tickets")

MODEL = "openrouter/openai/gpt-4o-mini"
seed = "Ticket: {ticket}\nQueue (RETURNS or REPAIRS):"
mapper = BasicDataMapper({
    "response": "generated_output",
    "expected_response": "queue",
})
evaluator = Evaluator(metric=Equals(config={"case_sensitive": True}))


class TicketGenerator(LiteLLMGenerator):
    def generate(self, row):
        # A rewrite must not be able to insert the answer key into its prompt.
        return super().generate({"ticket": row["ticket"]})


generator = TicketGenerator(MODEL, seed)
optimizer = RandomSearchOptimizer(
    generator=generator, teacher_model=MODEL, num_variations=2
)
result = optimizer.optimize(evaluator=evaluator, data_mapper=mapper, dataset=train)
print(f"Best variation: {result.final_score:.0%} exact matches")
```

</CodeGroup>

## Read the result

The three counts should match because the exports contain the same tickets. The final score is the fraction of generated replies matching the reference queue exactly. Example output:

```text
csv: 2 tickets
json: 2 tickets
jsonl: 2 tickets
Best variation: 0% exact matches
```

The three loaders agreed on the inputs. The zero is a routing score, not an import failure: neither output from the best variation exactly matched its label.

## Limits and troubleshooting

- A JSONL file is not a single JSON document. Choose the extension that matches the actual format; renaming an array to `.jsonl` does not split it into records.
- `BasicDataMapper` silently omits a mapping if the source key is absent. Validate `ticket` and `queue` **before** you make model calls so a missing label cannot look like a bad prompt.
- If a variation asks for `{queue}`, generation stops with `KeyError` rather than giving the routing model the answer. Use only ticket text you can send to your model provider.
- With a large export, choose a representative subset before calling `optimize()`. Reserve different tickets for testing; each additional training row adds a generation per variation.
