<TLDR>
Trace a four-agent research crew as it turns a Ridgeline Outfitters field brief into a recommendation. Inspect the report writer's inputs in Observe before you decide which spans to evaluate.
</TLDR>

<Prerequisites>
- A Future AGI account with `FI_API_KEY` and `FI_SECRET_KEY` (see [Get your API keys](/docs/admin-settings))
- An OpenAI API key
- Python 3.12
</Prerequisites>

## Install

Run these commands in an empty directory. Save all three Python files below in that directory.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install crewai==1.15.44 traceai-crewai==0.1.11 fi-instrumentation-otel==1.5.1
```

```bash
export OPENAI_API_KEY="your-openai-api-key"
export FI_API_KEY="your-futureagi-api-key"
export FI_SECRET_KEY="your-futureagi-secret-key"
export CREWAI_DISABLE_TELEMETRY=true
export CREWAI_TRACING_ENABLED=false
```

Only if you self-host, set `export FI_TRACES_URL=https://your-collector.example.com` to the base URL of your trace collector.

## Tutorial

<Steps>
<Step title="Register the trace provider and instrument CrewAI">

Save this as `crew_tracing.py`. The instrumentor wraps `Crew.kickoff` and task execution. Register it before running the crew.

```python
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from traceai_crewai import CrewAIInstrumentor

provider = register(
    project_name="crewai-research-team",
    project_type=ProjectType.OBSERVE,
    verbose=False,
)
CrewAIInstrumentor().instrument(tracer_provider=provider)
```

</Step>
<Step title="Define the research team and its sources">

Save this as `research_team.py`. Each specialist uses the same model. The two labeled notes are the crew's entire evidence base; no search account or embeddings are needed.

```python
from crewai import Agent, LLM, Task

llm = LLM(model="gpt-4o-mini", temperature=0)

def specialist(role, goal):
    return Agent(role=role, goal=goal, backstory="You advise Ridgeline Outfitters. Cite only the supplied notes.",
                 llm=llm, allow_delegation=False)

researcher = specialist("Market researcher", "Identify what shoppers asked for.")
analyst = specialist("Competitive analyst", "Identify differences between the two offers.")
writer = specialist("Report writer", "Recommend one action supported by the evidence.")
reviewer = specialist("Quality analyst", "Flag unsupported claims in the recommendation.")

brief = (
    "Note A: In 40 Ridgeline store interviews, 19 shoppers asked for a lighter daypack. "
    "Note B: Ridgeline's pack weighs 680 g; the comparison pack weighs 560 g. "
    "No sales or pricing data was collected."
)
market = Task(agent=researcher, description=f"Summarize demand using only this brief: {brief}",
              expected_output="One sentence citing Note A.")
competition = Task(agent=analyst, description=f"Compare pack weights using only this brief: {brief}",
                   expected_output="One sentence citing Note B.")
report = Task(agent=writer, description="Use both findings to recommend a next step. Name one unknown.",
              expected_output="A two-sentence recommendation with note labels.", context=[market, competition])
review = Task(agent=reviewer, description=f"Check the report against this brief: {brief}",
              expected_output="A pass/fail verdict and a reason.", context=[report])
```

`context=[market, competition]` explicitly selects the findings the writer receives. It does not guarantee a grounded answer; compare the recommendation with those findings.

</Step>
<Step title="Run the crew and locate its trace">

Save this as `run_crew.py` and run `python run_crew.py`. The outer span gives you one trace ID for the entire crew. The crew's final output is the quality review, not the report, so print the report task's output separately.

```python
from uuid import UUID
from crewai import Crew, Process
from crew_tracing import provider
from research_team import researcher, analyst, writer, reviewer, market, competition, report, review

crew = Crew(agents=[researcher, analyst, writer, reviewer], tasks=[market, competition, report, review],
            process=Process.sequential, memory=False)
with provider.get_tracer(__name__).start_as_current_span("daypack research") as span:
    result = crew.kickoff()
    trace_id = UUID(int=span.get_span_context().trace_id)
print("Recommendation:", report.output.raw)
print("Quality review:", result.raw)
provider.force_flush()
print(trace_id)
```

</Step>
<Step title="Inspect the report and configure an Eval Task">

In **Observe**, open `crewai-research-team` and the trace matching the printed ID. Expand the kickoff span and inspect the third task: its input contains the task description and the upstream context; its output contains the recommendation.

<img src="/images/docs/cookbook-crewai-research-team/image2.png" alt="Example of a CrewAI trace tree in Observe" style={{ borderRadius: '5px' }} />

For future runs, configure an **Eval Task** on the matching agent spans. Choose a [built-in eval](/docs/evaluation/builtin) whose required fields you can map. For groundedness, supply both the actual evidence and the generated answer; a topic string alone is not evidence. Rerun `python run_crew.py` after enabling the task and inspect the matching spans for scores when evaluation finishes.

</Step>
</Steps>

## Troubleshooting

| Symptom | What to check |
|---|---|
| No crew spans appear | Check the project and credentials. For self-hosted installs, `FI_TRACES_URL` must point to the collector, not the dashboard. |
| The report contains unsupported numbers | Inspect the writer's captured input. Compare its output with the two notes, not just with the quality agent's verdict. |
| A span has no score | Confirm the task is enabled, the span matches its filters, and the required eval inputs are mapped. |
