<TLDR>
Trace the same question twice: once when a Ridgeline Outfitters agent cannot look up a policy, and once when it must. Compare the recorded model and tool calls rather than guessing from the final answer whether retrieval happened.
</TLDR>

## Install

Use Bash, Python 3.12, an OpenAI API key and a pair of [Future AGI API keys](/docs/admin-settings).

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install fi-instrumentation-otel==1.5.1 traceai-langchain==0.1.12 langgraph==1.0.1 langchain-openai==0.3.35 langchain-core==0.3.86
```

Replace the example values with your credentials. For self-hosting, use your HTTP trace collector as `FI_TRACES_URL`.

```bash
export FI_API_KEY="your-api-key"
export FI_SECRET_KEY="your-secret-key"
export OPENAI_API_KEY="your-openai-api-key"
export FI_TRACES_URL="https://api.futureagi.com"
```

## Instrument the model and tool

Save this as `policy_agent.py`. Register the provider before enabling LangChain instrumentation. A local tool returns the store's written policy; you don't need a search-service account.

```python
from uuid import UUID

from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from langchain_core.messages import HumanMessage, SystemMessage, ToolMessage
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI
from langgraph.graph import END, MessagesState, StateGraph
from traceai_langchain import LangChainInstrumentor

provider = register(project_type=ProjectType.OBSERVE, project_name="ridgeline-policy-agent",
                    set_global_tracer_provider=True, verbose=False)
LangChainInstrumentor().instrument(tracer_provider=provider)
tracer = provider.get_tracer(__name__)
model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

@tool
def repair_policy() -> str:
    """Look up Ridgeline Outfitters' current buckle repair policy."""
    return "Buckle repairs are free within 45 days of delivery."

lookup_model = model.bind_tools([repair_policy], tool_choice="repair_policy")
```

## Assemble the graph

Save this block as `policy_graph.py` in the same directory. For a controlled comparison, the first model call either has no tools or must call `repair_policy`. After a lookup, a plain model reads the tool result and answers. Returning just the new messages lets `MessagesState` append them to the conversation.

```python
from policy_agent import (HumanMessage, ToolMessage, MessagesState, StateGraph, END,
                          model, lookup_model, repair_policy)


class State(MessagesState):
    use_lookup: bool


def agent_node(state):
    messages = state["messages"]
    first_turn = isinstance(messages[-1], HumanMessage)
    llm = lookup_model if state["use_lookup"] and first_turn else model
    return {"messages": [llm.invoke(messages)]}


def tool_node(state):
    replies = []
    for call in state["messages"][-1].tool_calls:
        result = repair_policy.invoke(call["args"])
        replies.append(ToolMessage(content=result, tool_call_id=call["id"]))
    return {"messages": replies}


def route(state):
    return "tool" if state["messages"][-1].tool_calls else END


graph = StateGraph(State)
graph.add_node("agent", agent_node)
graph.add_node("tool", tool_node)
graph.set_entry_point("agent")
graph.add_conditional_edges("agent", route, {"tool": "tool", END: END})
graph.add_edge("tool", "agent")
app = graph.compile()
```

## Run the comparison

Save the following as `compare_policy.py` alongside `policy_agent.py`, then run `python compare_policy.py`. Each outer span groups all the nodes from one graph invocation under a single trace ID.

```python
from policy_agent import UUID, HumanMessage, SystemMessage, ToolMessage, provider, tracer
from policy_graph import app

question = "Within how many days does Ridgeline offer free buckle repairs?"
ids = []
for use_lookup in (False, True):
    label = "with-lookup" if use_lookup else "without-lookup"
    with tracer.start_as_current_span(label) as span:
        result = app.invoke({"use_lookup": use_lookup, "messages": [
            SystemMessage(content="Answer from the written policy. If you have no policy, say you don't know."),
            HumanMessage(content=question),
        ]})
        answer = result["messages"][-1].content
        calls = sum(isinstance(msg, ToolMessage) for msg in result["messages"])
        print(f"{label}: {calls} tool replies; {answer}")
        span.set_attribute("raw.input", question)
        span.set_attribute("raw.output", answer)
        ids.append(str(UUID(int=span.get_span_context().trace_id)))
provider.force_flush()
print(*ids)
```

## Read the traces

Open **Observe** and select `ridgeline-policy-agent`. Look up the two printed trace IDs in order. The first run has no tool reply. In the second run, expand the `repair_policy` call and compare its output (45 days) with the final model response. Wording varies. A tool span proves a lookup ran; it does not prove the model used the returned policy correctly.

For ongoing quality scores rather than a manual check, [configure an Observe Eval Task](/docs/cookbook/observe-langgraph-agent-and-obtain-insights). Registering this Observe project does not by itself schedule evaluations.

## Troubleshooting

- **No tool span:** Check that you opened `with-lookup` and that `LangChainInstrumentor().instrument()` ran before the graph was invoked.
- **No traces:** Check both Future AGI credentials and the collector URL. Flush the provider before exiting a short script.
- **`traceai_langchain` not found:** Check that the active Python environment has `traceai-langchain` installed; the import name uses an underscore.
