<TLDR>
Can your support agent tell a caller how to reset a password before ending the call? Run both sides in a LiveKit room, read the transcript, then score the agent's words rather than the caller's. The report, score, and audio stay on your machine; the speech and model providers process the call.
</TLDR>

<Prerequisites>
- Python 3.12 and a running LiveKit server. For a local server, follow the [LiveKit local setup guide](https://docs.livekit.io/transport/self-hosting/local/). Keep the server running in its own terminal.
- OpenAI, Deepgram, and Cartesia API keys. Use synthetic caller details; this example records the call.
</Prerequisites>

## Install

Create a new directory for the scripts below, then install the Agent Learning Kit with its LiveKit plugins:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install "agent-learning-kit[livekit]==0.3.7"
```

## Tutorial

<Steps>
<Step title="Set environment variables">

Use the WebSocket URL and credentials for your own LiveKit server. No Future AGI keys are required for the local run or the transcript check.

```bash
export LIVEKIT_URL="ws://127.0.0.1:7880"
export LIVEKIT_API_KEY="your-livekit-api-key"
export LIVEKIT_API_SECRET="your-livekit-api-secret"
export OPENAI_API_KEY="your-openai-api-key"
export DEEPGRAM_API_KEY="your-deepgram-api-key"
export CARTESIA_API_KEY="your-cartesia-api-key"
```

</Step>
<Step title="Connect the support agent">

Save this as `support_voice.py`. The target joins as `ridgeline-support`. Deepgram listens to the customer, OpenAI writes the reply, and Cartesia speaks it back into the room.

```python
import os
from contextlib import asynccontextmanager

import aiohttp
from livekit import rtc
from livekit.api import AccessToken, VideoGrants
from livekit.agents import Agent, AgentSession
from livekit.plugins import cartesia, deepgram, openai, silero

INSTRUCTIONS = (
    "You work for Ridgeline Outfitters. When a caller cannot sign in, say: "
    "Select Forgot password on the sign-in page, then check your email for a reset link. "
    "Never ask for the password. When the caller thanks you, say goodbye. Keep replies short."
)

@asynccontextmanager
async def support_in(room_name):
    token = (AccessToken(os.environ["LIVEKIT_API_KEY"], os.environ["LIVEKIT_API_SECRET"])
             .with_identity("ridgeline-support")
             .with_grants(VideoGrants(room_join=True, room=room_name)).to_jwt())
    room = rtc.Room()
    await room.connect(os.environ["LIVEKIT_URL"], token)
    try:
        async with aiohttp.ClientSession() as http:
            session = AgentSession(
                stt=deepgram.STT(model="nova-3", http_session=http),
                llm=openai.LLM(model="gpt-4o-mini"),
                tts=cartesia.TTS(model="sonic-3", http_session=http),
                vad=silero.VAD.load(),
            )
            try:
                await session.start(agent=Agent(instructions=INSTRUCTIONS), room=room)
                yield
            finally:
                await session.aclose()
    finally:
        await room.disconnect()
```

</Step>
<Step title="Run one caller through the room">

Save this as `simulate_voice.py` and run `python simulate_voice.py`. A unique room name keeps each call separate. Use `room_mode="external"` because your target has already joined the room. `AgentDefinition` describes that target; `SimulatorAgentDefinition` configures the simulated caller's own speech and model providers.

```python
import asyncio
import os
from pathlib import Path
from uuid import uuid4

from fi.simulate import (AgentDefinition, LiveKitSimulatorRuntime, LLMConfig, Persona,
                         Scenario, SimulatorAgentDefinition, STTConfig, TTSConfig, TestRunner)
from support_voice import INSTRUCTIONS, support_in

async def main():
    room_name = f"ridgeline-reset-{uuid4().hex}"
    scenario = Scenario(name="password-reset", dataset=[Persona(
        persona={"name": "Casey"}, situation="I cannot sign in to my Ridgeline account.",
        outcome="Find out how to reset my password, thank the agent, and end the call.",
    )])
    async with support_in(room_name):
        report = await TestRunner().run_test(
            agent_definition=AgentDefinition(name="support", system_prompt=INSTRUCTIONS,
                                            target_participant_identity="ridgeline-support"),
            livekit_runtime=LiveKitSimulatorRuntime(url=os.environ["LIVEKIT_URL"],
                                                    room_name=room_name, room_mode="external"),
            scenario=scenario,
            simulator=SimulatorAgentDefinition(
                llm=LLMConfig(model="gpt-4o-mini"),
                stt=STTConfig(provider="deepgram", model="nova-3"),
                tts=TTSConfig(provider="cartesia", model="sonic-3",
                              voice="f786b574-daa5-4673-aa0c-cbe3e8534c02"),
            ),
            min_turn_messages=2, max_seconds=90, record_audio=True,
        )
    case = report.results[0]
    Path("voice-report.json").write_text(report.model_dump_json(indent=2))
    print("Call status:", case.metadata["status"])
    print(case.transcript)
    print("Mixed recording:", case.audio_combined_path)

if __name__ == "__main__":
    asyncio.run(main())
```

A completed call has `user` turns from the caller and `assistant` turns from your support agent. Listen to the mixed WAV at the printed path to check pacing and interruptions. If the status is not `completed`, inspect `results[0].metadata.failure` in `voice-report.json` before scoring it.

</Step>
<Step title="Score the instructions in the transcript">

Save this as `score_voice.py` and run `python score_voice.py` after the call. This local check looks for the reset action and email step only in the agent's replies. It does not prove that the caller received an email or regained access.

```python
from pathlib import Path
from fi.evals.metrics.heuristics.string_metrics import ContainsAll
from fi.evals.types import TextMetricInput
from fi.simulate import TestReport

report = TestReport.model_validate_json(Path("voice-report.json").read_text())
case = report.results[0]
if case.metadata["status"] != "completed":
    raise RuntimeError(f"Call did not complete: {case.metadata['status']}")
agent_text = " ".join(m["content"] for m in case.messages if m["role"] == "assistant")
metric = ContainsAll({"keywords": ["forgot password", "email"]})
result = metric.compute_one(TextMetricInput(response=agent_text))
print("Reset instructions:", result["output"], result["reason"])
```

A score of `1.0` means both phrases were present; `0.0` means at least one was missing. If the caller thanks the agent but the score is zero, read the actual reply: the agent may have skipped a step, or it may have used a synonym the literal check doesn't recognize.

</Step>
</Steps>

## Troubleshooting

| Symptom | What to check |
|---|---|
| No LiveKit plugin modules | Activate the virtual environment where you installed the `livekit` extra. |
| Room connection fails | Use the server's `ws://` or `wss://` URL and its matching LiveKit key pair. |
| No reply or one-sided transcript | Check the provider credentials, the call failure code, and whether both participants joined the same room. |
| No mixed WAV | Check that recording is enabled and both participants published audio; an incomplete call can have a partial report. |

For local text and LiveKit execution modes, see the [Simulation SDK reference](/docs/sdk/simulate). For hosted simulations, see [Environments](/docs/environments).
