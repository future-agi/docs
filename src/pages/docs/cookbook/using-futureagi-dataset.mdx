<TLDR>
Create a dataset for Ridgeline Outfitters support tickets, add two rows, and download them as a CSV. You can open the same dataset in your Future AGI account.
</TLDR>

| Time | Difficulty | Package |
|---|---|---|
| 15 minutes | Beginner | `futureagi` |

<Prerequisites>
- A Future AGI account with an API key and secret key (see [Get your API keys](/docs/admin-settings))
- Python 3.11 or later
</Prerequisites>

## Install

Install the platform SDK in a virtual environment. If you also use Agent Learning Kit, keep it in a separate virtual environment: both packages install modules under `fi`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install futureagi==0.8.0
```

```bash
export FI_API_KEY="<your_api_key>"
export FI_SECRET_KEY="<your_api_secret>"
```

## Tutorial

Run the following Python blocks in order in one Python session or notebook.

<Steps>
<Step title="Create a dataset">

```python
from uuid import uuid4
from fi.datasets import Dataset, DatasetConfig
from fi.datasets.types import ModelTypes

config = DatasetConfig(
    name=f"ridgeline-support-{uuid4().hex}",
    model_type=ModelTypes.GENERATIVE_LLM,
)
dataset = Dataset(dataset_config=config).create()
print(dataset.get_config().name, dataset.get_config().id)
```

Use the printed name to find the dataset in **Datasets**. The suffix gives each run its own dataset. The SDK reads your keys from the environment.

</Step>

<Step title="Define the columns">

```python
from fi.datasets.types import Column, DataTypeChoices

columns = [
    Column(name="ticket_text", data_type=DataTypeChoices.TEXT),
    Column(name="priority", data_type=DataTypeChoices.INTEGER),
    Column(name="order_ref", data_type=DataTypeChoices.TEXT),
]
dataset.add_columns(columns=columns)
```

</Step>

<Step title="Add rows">

Use the platform client from the same package to add rows by dataset ID. Each cell needs just its column name and value.

```python
from fi.platform import Client

rows = [
    {"cells": [
        {"column_name": "ticket_text", "value": "Refund missing for returned hiking boots"},
        {"column_name": "priority", "value": 1},
        {"column_name": "order_ref", "value": "RG-1042"},
    ]},
    {"cells": [
        {"column_name": "ticket_text", "value": "Need a return label for a rain jacket"},
        {"column_name": "priority", "value": 2},
        {"column_name": "order_ref", "value": "RG-1051"},
    ]},
]
Client().datasets.rows.add(str(dataset.get_config().id), rows=rows)
```

Open the dataset in your account to see the two support tickets with their priorities and order references.

</Step>

<Step title="Download the dataset">

```python
from pathlib import Path

file_path = Path(f"{dataset.get_config().name}.csv")
dataset.download(file_path=str(file_path))
print(file_path.read_text(encoding="utf-8"))
```

The CSV contains a header and the two tickets. Use a fresh path if you download again: the SDK appends to an existing CSV.

</Step>

<Step title="Clean up (optional)">

Keep the dataset if you plan to use it for evaluations. When you no longer need it, call `dataset.delete()` in the same Python session to remove this dataset from your account. That leaves the downloaded CSV alone; use `file_path.unlink()` if you also want to remove your local copy.

</Step>
</Steps>

## Troubleshooting

| Symptom | Fix |
|---|---|
| You cannot import `ModelTypes`, `Column`, `Row`, or `Cell` from `fi.datasets` | Import them from `fi.datasets.types`. |
| `401 Unauthorized` on `dataset.create()` | Re-export both keys from your account's API keys page and retry. |
| `add_columns()` reports a duplicate column name | Add each column once. If you already ran this step for this dataset, continue to **Add rows**. |
| `create()` reports that the dataset already exists | Start with a new dataset name rather than deleting an existing dataset. |
