## About

Choose a recipe for the task in front of you: trace a request, evaluate a reply, prepare examples, or test a prompt change. For Python prompt optimization, start with [Basic Prompt Optimization](/docs/cookbook/basic-optimization), which installs Agent Learning Kit and uses its `fi.opt` module.
