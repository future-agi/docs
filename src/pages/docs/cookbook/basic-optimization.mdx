## About

Ridgeline Outfitters needs to send a support ticket to `RETURNS` or `REPAIRS`. Use random search to find out whether changing the wording of the routing prompt improves the fraction of tickets that receive exactly the right label.

| Time | Difficulty | Package |
|---|---|---|
| 15 min | Beginner | `agent-learning-kit==0.3.7` |

## Set up Python

If you previously installed `agent-opt`, install Agent Learning Kit instead in a fresh Python 3.12 environment. Your optimizer imports still start with `fi.opt`. In Bash, enter an OpenRouter API key when prompted. The model calls use that key; the exact-match metric runs locally without Future AGI credentials.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7
read -rsp 'OpenRouter API key: ' OPENROUTER_API_KEY; printf '\n'
export OPENROUTER_API_KEY
```

## Score the original prompt and two variations

1. Give each ticket a reference queue. The prompt uses only `ticket`; `queue` is the answer key.
2. Score the original generator before starting the search. `BasicDataMapper` puts the model's text in `response` and the reference queue in `expected_response`. `generated_output` is a special mapper value, not a column you need to create.
3. Ask the teacher model for two variations. The optimizer generates a reply for each ticket with each variation, averages the row scores, and returns the best variation as a generator.

Save as `basic.py` and run `python basic.py` in the activated environment.

<CodeGroup titles={["Python"]}>

```python
from fi.evals.metrics import Equals
from fi.opt.base import Evaluator
from fi.opt.datamappers import BasicDataMapper
from fi.opt.generators import LiteLLMGenerator
from fi.opt.optimizers import RandomSearchOptimizer

MODEL = "openrouter/openai/gpt-4o-mini"
seed = "Ticket: {ticket}\nQueue (RETURNS or REPAIRS):"
train = [
    {"ticket": "My new boots don't fit. Can I send them back?", "queue": "RETURNS"},
    {"ticket": "Can you fix a broken buckle on my pack?", "queue": "REPAIRS"},
]
mapper = BasicDataMapper({
    "response": "generated_output",
    "expected_response": "queue",
})
evaluator = Evaluator(metric=Equals(config={"case_sensitive": True}))


def accuracy(generator, rows):
    inputs = []
    for row in rows:
        reply = generator.generate({"ticket": row["ticket"]})
        if not reply:
            raise RuntimeError("No reply from the generator")
        inputs.append(mapper.map(reply, row))
    scores = evaluator.evaluate(inputs)
    return sum(item.score for item in scores) / len(rows)


generator = LiteLLMGenerator(model=MODEL, prompt_template=seed)
baseline = accuracy(generator, train)
optimizer = RandomSearchOptimizer(
    generator=generator, teacher_model=MODEL, num_variations=2
)
result = optimizer.optimize(evaluator=evaluator, data_mapper=mapper, dataset=train)
print(f"Baseline: {baseline:.0%}")
for n, item in enumerate(result.history, start=1):
    print(f"Variation {n}: {item.average_score:.0%}")
print("Best variation:", result.best_generator.get_prompt_template())
```

## Read the result

Example output from one run. On two tickets, one exact match counts for 50 percentage points. The best *variation* need not beat the original prompt.

```text
Baseline: 100%
Variation 1: 0%
Variation 2: 0%
Best variation: Help us resolve the following issue: Ticket Number: {ticket}. Please indicate whether it pertains to RETURNS or REPAIRS.
```

Keep the original in this run: both rewrites scored below it. Asking for more variations would buy more attempts, not a guarantee of improvement.

## Limits and troubleshooting

- If an answer says “This belongs in RETURNS,” the model identified the queue but the router cannot use the whole sentence as a label. The case-sensitive `Equals` metric scores it as a miss.
- If a rewritten template fails to format, check that it still uses `{ticket}` and hasn't introduced a field your rows don't supply.
- Two tickets make it easy to inspect a run, not to decide what to deploy. Score the original and the selected variation on new tickets before replacing the prompt.
