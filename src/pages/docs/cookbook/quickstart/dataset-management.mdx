## Prepare the sample rows

Save this as `rag-eval-rows.csv`. Each row contains a support question, the reply a customer saw, the policy the reply should follow, and a reference answer. The first reply adds a promise of free return shipping that isn't in the policy.

```csv
input,output,context,expected_answer
"Can I return my headlamp?","You have 30 days with a receipt. Shipping is free on all returns.","Headlamps may be returned within 30 days with a receipt and original packaging.","30 days with a receipt and original packaging."
"Do you ship hiking poles overseas?","Yes. Standard delivery takes 7 to 14 business days.","International shipping is available. Standard delivery takes 7 to 14 business days.","Yes. Allow 7 to 14 business days."
"How do I reset my password?","Select Forgot password on the sign-in page.","Select Forgot password on the sign-in page. The reset link expires in 24 hours.","Select Forgot password and follow the email link."
"Can I pay with PayPal?","Yes. PayPal is accepted.","We accept Visa, Mastercard and PayPal.","Yes."
"Can I cancel my boot order?","You can cancel within two hours of placing the order.","Orders can be cancelled within two hours of placement.","Yes, within two hours."
"When do reward points expire?","Points expire after twelve months.","Customers earn one point per dollar spent. Points expire after twelve months.","After twelve months."
```

## Tutorial

<Steps>
<Step title="Create a dataset from the CSV">

Open **Dataset**, select **Add Dataset**, then **Upload a file (JSON, CSV)**. Choose `rag-eval-rows.csv`, name the dataset `ridgeline-support-policy`, and submit the upload. Use a new name if you already have a dataset with that name. Open the table when the import finishes: you should see six rows and the four columns from the header.

If you prefer to enter the rows yourself, select **Add datasets Manually**, request six rows and four columns, and name the columns `input`, `output`, `context` and `expected_answer`. Fill the cells with the values above instead of uploading the file. To append rows to an existing table later, use **Add Row** and the file upload option; match the CSV headers to the existing column names.

</Step>
<Step title="Run groundedness on the replies">

In the dataset's evaluation controls, add the `groundedness` template. Map `input`, `output` and `context` to their namesake columns. You don't need to map `expected_answer`: groundedness checks whether the reply is supported by the supplied context, not whether it matches a reference answer. Name the check `policy-grounding` and run it on the six rows.

Open the result for the headlamp return. The 30-day window is supported, but free shipping isn't. Read the judge's reason before changing the reply. A negative verdict here is useful: it points to a promise the customer shouldn't receive.

</Step>
<Step title="Export the scored table">

Wait for the evaluation to finish. Download the dataset as CSV from the table toolbar. Check that the six support replies and their verdicts are present before sharing the file.

</Step>
</Steps>

## Optional: import and score the same file from Python

Use this instead of the dashboard steps if you want a repeatable import. It creates a new dataset each time. Use a platform SDK environment with Python 3.12 and your [workspace API keys](/docs/admin-settings).

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install futureagi==0.7.0
export FI_API_KEY="your-api-key"
export FI_SECRET_KEY="your-secret-key"
```

Save this as `manage_dataset.py` next to the CSV and run `python manage_dataset.py`. It prints the dataset ID and saves the scored rows locally.

```python
import csv
import time
from uuid import uuid4
from fi.platform import Client

with Client() as client:
    dataset = client.datasets.create_from_file(
        file="rag-eval-rows.csv", new_dataset_name=f"ridgeline-support-{uuid4().hex[:8]}",
        model_type="GenerativeLLM",
    )
    dataset_id = dataset.dataset_id
    print("Dataset:", dataset_id)
    for _ in range(120):
        table = client.datasets.get(dataset_id)
        if len(table.table or []) == 6 and not table.is_processing_data:
            break
        time.sleep(1)
    else:
        raise TimeoutError(f"Upload not ready: {dataset_id}")

    columns = {c.name: c.id for c in table.column_config}
    templates = client.evals.templates.list(owner_filter="system", search="groundedness")
    template = next(t for t in templates.items if t.name == "groundedness")
    check = "policy-grounding"
    client.datasets.evals.add(
        dataset_id, template_id=template.id, name=check,
        config={"mapping": {k: columns[k] for k in ("input", "output", "context")}}, run=True,
    )
    for _ in range(150):
        evaluations = client.datasets.evals.list(dataset_id, eval_type="user").evals
        state = next(e["status"] for e in evaluations if e["name"] == check)
        if state == "Completed":
            break
        if state not in {"NotStarted", "Queued", "Running"}:
            raise RuntimeError(f"{check}: {state}")
        time.sleep(2)
    else:
        raise TimeoutError(f"Evaluation is not finished: {dataset_id}")

    table = client.datasets.get(dataset_id)
    columns = {c.name: c.id for c in table.column_config}
    fields = ["input", "output", "context", "expected_answer", check]
    path = f"ridgeline-{dataset_id}-scored.csv"
    with open(path, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=fields)
        writer.writeheader()
        for row in table.table:
            cells = row.model_dump()
            record = {k: cells[columns[k]]["cell_value"] for k in fields}
            if record[check] not in ("Passed", "Failed"):
                raise ValueError(f"Missing groundedness verdict in row {row.row_id}")
            writer.writerow(record)
    print(path)
```

## Troubleshooting

| Symptom | What to check |
|---|---|
| A value ends up in the wrong CSV column | Quote fields containing commas, and keep the same four headers. |
| Scores are missing | Check the three required mappings, wait for the run to finish, and inspect the row's error or reason. |
| The verdict differs from your expectation | Compare every claim in the reply with the context. The reference answer is not an input to groundedness. |
