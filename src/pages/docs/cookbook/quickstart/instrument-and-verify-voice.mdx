A voice call needs a root span of kind `CONVERSATION`. A trace with only STT, LLM and TTS spans can appear in Traces without appearing as a call. You will send one synthetic support call, check its transcript and span tree with `fi_verify_voice.py`, then open the same trace in the Voice tab.
</TLDR>

## What a verified integration means

The collector accepting a batch does not prove you can find a call. The Voice tab selects a conversation root in the selected project and time window. Call details then read attributes on that root, including the transcript and turn count. The checker compares your export with these requirements:

| Gate | Holds when | Step |
|---|---|---|
| V1 | the keys and route are accepted, and the collector took a conversation-shaped span | 1 |
| V2 | the resource has a project name; the checker also displays its type | 2 |
| V3 | exactly one conversation span, and it has no parent | 3 |
| V4 | one call is one trace, one root, no orphans | 3 |
| V5 | `session.id` and `user.id` are on the conversation span | 3 |
| V6 | `call.duration` is a number | 4 |
| V7 | `call.total_turns` and `call.talk_ratio` are numbers | 4 |
| V8 | the transcript is present in all three shapes the product reads | 4 |
| V9 | the call names its voice provider | 4 |
| V10 | recording URLs are strings under an alias evals can resolve, or their absence is acknowledged | 4 |
| V11 | every LLM span carries a model, and at least one carries a prompt and a completion | 5 |
| V12 | no scanned environment credential value occurs in the captured attributes | 6 |

The delivery receipt records the exporter's result, not an app readback. Use the trace ID printed by the agent to check the stored call in the final step. V12 is a limited check for matching secret values, not a general redaction guarantee.

## Tutorial

<Steps>
<Step title="Check your collector route">

```bash
python fi_verify_voice.py preflight
```

This sends a conversation-shaped probe to your project and checks that invalid credentials, missing credentials and an incorrect path are refused. Expect `PASS V1`. A `401` on the valid send points to the key pair; a `404` usually points to the collector URL. The probe is separate from the actual call below.

</Step>
<Step title="Configure one tracing provider">

Save **only the file for your track**. Both providers expose an OpenTelemetry tracer. The agent sets the span kinds and fields explicitly, so neither track needs to modify the LiveKit exporter or alias any `lk.pii.*` attributes.

<Tabs>
<Tab title="Future AGI SDK">

Save as `setup_sdk.py`.

```python
import os

from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType

provider = register(project_name=os.environ["FI_PROJECT_NAME"],
                    project_type=ProjectType.OBSERVE, verbose=False)
tracer = provider.get_tracer("voice-agent")
```

</Tab>
<Tab title="OpenTelemetry">

Save as `setup_otel.py`.

```python
import os

from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.resources import Resource
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

provider = TracerProvider(resource=Resource.create({
    "project_name": os.environ["FI_PROJECT_NAME"], "project_type": "observe",
}))
provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter(
    endpoint=os.environ["FI_ENDPOINT"],
    headers={"X-Api-Key": os.environ["FI_API_KEY"],
             "X-Secret-Key": os.environ["FI_SECRET_KEY"]},
)))
tracer = provider.get_tracer("voice-agent")
```

</Tab>
</Tabs>

</Step>
<Step title="Give each call one root and a caller">

Save as `call_scope.py`. An empty OpenTelemetry context starts a **new** trace even when your call handler runs inside a dispatch span. Set `session.id` and a pseudonymous `user.id` on this root. Open it before starting the voice session, and close it when the call ends.

```python
from contextlib import contextmanager
from opentelemetry.context import Context


@contextmanager
def conversation(tracer, session_id, user_id):
    with tracer.start_as_current_span("voice.call", context=Context(), attributes={
        "fi.span.kind": "CONVERSATION", "session.id": session_id, "user.id": user_id,
    }) as span:
        yield span
```

</Step>
<Step title="Write what the Voice tab reads">

Save as `voice_spans.py`. The call drawer reads `fi.conversation.transcript`; the single JSON transcript and numbered message fields make the same turns available to evals and trace panels. Durations are seconds. Here the talk ratio is agent speech seconds divided by caller speech seconds. A ratio of 2 means the agent spoke twice as long as the caller.

```python
import json
from uuid import uuid4


def finish(span, turns, elapsed):
    # Each turn is (role, text, audio duration in seconds).
    rendered = [{"id": uuid4().hex, "role": role, "content": text, "duration": duration}
                for role, text, duration in turns]
    messages = [{"role": role, "content": text} for role, text, _ in turns]
    span.set_attribute("fi.conversation.transcript", json.dumps(rendered))
    span.set_attribute("conversation.transcript", json.dumps(messages))
    for i, (role, text, _) in enumerate(turns):
        span.set_attribute(f"conversation.transcript.{i}.message.role", role)
        span.set_attribute(f"conversation.transcript.{i}.message.content", text)
    caller = sum(duration for role, _, duration in turns if role == "user")
    agent = sum(duration for role, _, duration in turns if role == "assistant")
    span.set_attributes({"call.duration": elapsed, "call.total_turns": len(turns),
                         "call.talk_ratio": agent / caller, "call.status": "completed",
                         "gen_ai.system": "livekit", "input.value": turns[0][1],
                         "output.value": turns[-1][1]})
```

The synthetic call never saves its audio. If your deployment records calls, protect the audio, supply an authorized recording URL such as `conversation.recording.mono.combined`, and unset `FI_VOICE_NO_RECORDING`. A transcript alone is not input for an audio eval.

</Step>
<Step title="Run a real voice exchange">

Save as `agent.py`. Cartesia supplies audio for the synthetic caller, Deepgram transcribes it and a roomless LiveKit session passes that text to OpenAI. The script synthesizes the reply and measures both audio frames; it does not play or record them. The LLM span covers the turn that generated the reply, and shares its trace ID with the conversation root.

```python
import asyncio
import sys
import time
from uuid import uuid4

import aiohttp
from livekit.agents import Agent, AgentSession
from livekit.plugins import cartesia, deepgram, openai

import fi_verify_voice
from call_scope import conversation
from voice_spans import finish

if sys.argv[1:] == ["sdk"]:
    from setup_sdk import provider, tracer
elif sys.argv[1:] == ["otel"]:
    from setup_otel import provider, tracer
else:
    raise SystemExit("Choose a tracing track: sdk or otel")


async def main():
    fi_verify_voice.attach(provider)
    model = "gpt-4o-mini"
    async with (aiohttp.ClientSession() as http,
                cartesia.TTS(http_session=http) as tts,
                deepgram.STT(http_session=http) as stt):
        with conversation(tracer, f"call-{uuid4().hex}", "shopper-demo") as call:
            started = time.monotonic()
            session = AgentSession(llm=openai.LLM(model=model), stt=stt)
            await session.start(agent=Agent(instructions=(
                "You work at an outdoor gear shop. Unused tents can be returned within "
                "30 days. Answer the caller in one short sentence."
            )), record=False)
            try:
                caller_audio = await tts.synthesize("Can I return an unused tent?").collect()
                event = await stt.recognize(caller_audio)
                question = event.alternatives[0].text.strip()
                if not question:
                    raise ValueError("The caller's speech produced no transcript")
                with tracer.start_as_current_span("support.reply", attributes={
                    "fi.span.kind": "LLM", "gen_ai.request.model": model, "input.value": question,
                }) as llm_span:
                    await session.run(user_input=question, input_modality="text")
                    reply = next(m.text_content for m in reversed(session.history.items)
                                 if getattr(m, "role", None) == "assistant" and m.text_content)
                    llm_span.set_attribute("output.value", reply)
                reply_audio = await tts.synthesize(reply).collect()
                turns = [("user", question, caller_audio.duration),
                         ("assistant", reply, reply_audio.duration)]
                finish(call, turns, time.monotonic() - started)
                trace_id = f"{call.get_span_context().trace_id:032x}"
            finally:
                await session.aclose()
    provider.force_flush()
    print(f"Trace ID: {trace_id}")


if __name__ == "__main__":
    asyncio.run(main())
```

For the SDK track run `python agent.py sdk`. For plain OpenTelemetry run `python agent.py otel`. Both print the trace ID for the call you just made.

</Step>
<Step title="Check the export and find this call in the app">

```bash
python fi_verify_voice.py check
```

Expect twelve `PASS` rows followed by `GREEN LIGHT achieved`. Open your Observe project, select the Voice tab and find the `voice.call` trace with the ID the script printed. The transcript should contain two messages: the recognized question about an unused tent and the assistant's reply. Unlike the preflight probe, this call has nonzero duration and two turns.

## If your calls come from a managed provider

If Vapi or Retell hosts the call, use the provider integration instead of creating a second conversation root. After a call finishes, check the project's Voice tab for the provider's call and inspect its transcript and recording availability.

## Troubleshooting

| Symptom | What to check |
|---|---|
| A trace appears but there is no call | The root must be of kind `CONVERSATION`. Check V3, the project and the time window. |
| No spans captured | Run `preflight`, the agent and `check` in one directory. Attach the checker before creating spans; flush after the call closes. |
| A transcript is missing from the drawer | Put `fi.conversation.transcript` on the conversation root, not on the model span. |
| Duration or turns is blank | Set numeric `call.duration` and `call.total_turns` attributes before ending the root. Per-turn playback timing is separate from elapsed wall time. |
| The model span is empty | Set `gen_ai.request.model`, `input.value` and `output.value` around the actual generation. Do not enable content capture for sensitive calls without a suitable consent and redaction policy. |

For non-voice agents, see [Instrument and Verify](/docs/cookbook/quickstart/instrument-and-verify).
