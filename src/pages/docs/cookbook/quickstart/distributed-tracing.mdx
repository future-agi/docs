## About

Ridgeline Outfitters’ Node.js support gateway asks a Java returns service whether a customer can return an unused tent. To see the answer as part of the gateway request, you need to carry the gateway's trace ID **and** its span ID across the network. The Node adapter writes them to the W3C `traceparent` header. The Java agent uses that parent for the servlet's model call. Neither adapter adds a span just for the HTTP hop.

## 1. Start the Java returns service

You need a JDK (17 or later), Node.js 20.6 or later, npm, cURL and a pair of [Future AGI API keys](/docs/admin-settings/api-keys). Set `FI_API_KEY` and `FI_SECRET_KEY` in your shell. Use the same `FI_PROJECT_NAME` so you can see both services in one project. The `traceparent` header, not the project name, connects the spans.

Set the collector URL for this example. If you host Future AGI yourself, replace the URL with your trace collector (for example, `http://localhost:4318`).

```bash
export COLLECTOR_URL=https://api.futureagi.com
```

For an existing Jakarta or Javax servlet that makes an instrumented AI call on the request thread, add `-javaagent:/path/to/traceai-javaagent-1.4.0.jar` to your Java command **before** `-jar` or the main class. You don't need to add a servlet filter or call `extract()` yourself.

For a standalone example, save this as `ReturnsServlet.java` in an empty directory. The servlet listens on loopback. Its `/return-policy` handler uses the JDK HTTP client to call a local chat-completions fixture, so you don't need a model account.

```java
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.file.Files;
import org.apache.catalina.Context;
import org.apache.catalina.startup.Tomcat;

// A loopback-only servlet and a fixed chat-completions response for the cookbook.
public class ReturnsServlet {
    public static void main(String[] args) throws Exception {
        var tomcat = new Tomcat();
        tomcat.setBaseDir(Files.createTempDirectory("ridgeline-tomcat").toString());
        tomcat.setPort(5101);
        tomcat.getConnector().setProperty("address", "127.0.0.1");
        Context app = tomcat.addContext("", Files.createTempDirectory("ridgeline-web").toString());
        var client = HttpClient.newHttpClient();

        Tomcat.addServlet(app, "policy", new HttpServlet() {
            @Override protected void doGet(HttpServletRequest req, HttpServletResponse res) throws IOException {
                var query = HttpRequest.newBuilder(URI.create("http://127.0.0.1:5101/v1/chat/completions"))
                    .header("Content-Type", "application/json")
                    .POST(HttpRequest.BodyPublishers.ofString("""
                        {"model":"returns-fixture","messages":[{"role":"user","content":"Can I return an unused tent?"}]}
                        """)).build();
                try {
                    var reply = client.send(query, HttpResponse.BodyHandlers.ofString());
                    res.setStatus(reply.statusCode());
                    res.setContentType("text/plain");
                    res.getWriter().println("Servlet received: " + req.getHeader("traceparent"));
                    res.getWriter().println(reply.body());
                } catch (InterruptedException err) {
                    Thread.currentThread().interrupt();
                    res.sendError(503);
                }
            }
        });
        app.addServletMappingDecoded("/return-policy", "policy");

        Tomcat.addServlet(app, "model", new HttpServlet() {
            @Override protected void doPost(HttpServletRequest req, HttpServletResponse res) throws IOException {
                req.getInputStream().readAllBytes();
                res.setContentType("application/json");
                res.getWriter().print("""
                    {"id":"ridgeline-demo","object":"chat.completion","model":"returns-fixture","choices":[{"index":0,"message":{"role":"assistant","content":"Yes, within 30 days."},"finish_reason":"stop"}]}
                    """);
            }
        });
        app.addServletMappingDecoded("/v1/chat/completions", "model");
        tomcat.start();
        tomcat.getServer().await();
    }
}
```

## 2. Enable propagation in the Node gateway

In the same directory and shell, create an npm project. Opt in to the experimental native HTTP/HTTPS adapter and allow the servlet host. In an application, replace `127.0.0.1` with the hostname of your downstream service, not a URL or `host:port`.

```bash
npm init -y
npm install @traceai/auto@0.4.0 @opentelemetry/api@1.9.0 @opentelemetry/sdk-trace-node@2.0.1
export FI_PROJECT_NAME=ridgeline-returns
export TRACEAI_PROPAGATE_OUTGOING_ADAPTERS=true
export TRACEAI_PROPAGATE_HOSTS='+127.0.0.1'
```

Save this as `gateway.cjs`. Registering the Node tracer provider gives the application a context manager. Initialize the adapter **before** starting the gateway span, so it can observe the start and find the active parent when `http.get()` sends the headers. If your app already registers a provider, keep it and its shutdown lifecycle rather than creating another provider for the adapter.

```js
const { randomBytes } = require('node:crypto');
const { context, ROOT_CONTEXT, trace, TraceFlags } = require('@opentelemetry/api');
const { NodeTracerProvider } = require('@opentelemetry/sdk-trace-node');
const { init, shutdown } = require('@traceai/auto');

const provider = new NodeTracerProvider();
provider.register();
init({ forwardApplicationSpans: true });
const http = require('node:http');

function askReturns() {
  const { traceId, spanId } = trace.getSpan(context.active()).spanContext();
  console.log(`Gateway trace: ${traceId}, parent: ${spanId}`);
  return new Promise((resolve, reject) => {
    http.get('http://127.0.0.1:5101/return-policy', res => {
      res.setEncoding('utf8');
      let body = '';
      res.on('data', chunk => { body += chunk; });
      res.on('error', reject);
      res.on('end', () => res.statusCode === 200 ? resolve(body) : reject(Error(`HTTP ${res.statusCode}`)));
    }).on('error', reject);
  });
}

async function main() {
  try {
    if (process.argv[2] === 'unsampled') {
      // Stand in for a valid parent received from an upstream service.
      const upstream = trace.setSpanContext(ROOT_CONTEXT, {
        traceId: randomBytes(16).toString('hex'), spanId: randomBytes(8).toString('hex'),
        isRemote: true, traceFlags: TraceFlags.NONE,
      });
      console.log(await context.with(upstream, askReturns));
      console.log(`Trace: ${trace.getSpanContext(upstream).traceId}`);
    } else {
      await trace.getTracer('support-gateway').startActiveSpan('Check return policy', async span => {
        try {
          console.log(await askReturns());
          console.log(`Trace: ${span.spanContext().traceId}`);
        } finally { span.end(); }
      });
    }
  } finally {
    await shutdown();
    await provider.shutdown();
  }
}
main().catch(err => { console.error(err.message); process.exitCode = 1; });
```

`forwardApplicationSpans: true` exports the gateway's application span to Future AGI so you can see the parent alongside the Java child. Leave it off if application spans should stay with your existing exporter. Forwarding and HTTP header propagation are separate settings.

## 3. Compare a sampled and an unsampled request

With the servlet still running, run each command from the example directory. The third command bypasses the gateway so you can see what happens without an incoming parent.

<CodeGroup titles={["Sampled", "Unsampled", "No parent"]}>

```bash
FI_BASE_URL="$COLLECTOR_URL" node gateway.cjs
```

```bash
FI_BASE_URL="$COLLECTOR_URL" node gateway.cjs unsampled
```

```bash
curl -fsS http://127.0.0.1:5101/return-policy
```

</CodeGroup>

All three requests should return the fixture's answer, `Yes, within 30 days.` Compare the IDs printed by the gateway with `Servlet received: 00-<trace ID>-<parent span ID>-<flags>` in each gateway response. Both IDs should match for that request. The direct cURL request prints `Servlet received: null`. In the [dashboard](https://app.futureagi.com), open **Tracing**, select `ridgeline-returns` and inspect the sampled trace. The sampling flag changes what gets recorded, not whether the servlet runs.

| Request | Header at the servlet | What to look for in `ridgeline-returns` |
| --- | --- | --- |
| Sampled | Ends in `-01` | Open the trace for `Check return policy`. The `chat returns-fixture` span has the gateway span as its direct parent. There is no intervening HTTP CLIENT or servlet SERVER span. |
| Unsampled upstream parent | Ends in `-00` | With the default parent-based Java sampler, the AI call exports no span. There should be no separate root trace for that call. |
| No valid `traceparent` | Missing or invalid | With no active application span, Java makes a local root sampling decision. The call does not join the gateway trace. |

![An abbreviated trace ID appears above the tree. Directly under “Check return policy,” the selected “chat returns-fixture” span shows “Can I return an unused tent?” and the reply “Yes, within 30 days.”](/images/docs/cookbook/distributed-tracing/sampled-returns-trace.png)

To isolate the Java side from the Node adapter, send a valid sampled parent directly with cURL and OpenSSL. Here `traceparent` marks this particular request as sampled. The `tracestate` entry describes the upstream sampling probability, not a second decision about this request. Java inherits the valid `fi=r:0.5` entry and records `fi.sampling.ratio` as `0.5` on the AI span. When the Java sampler *adds or updates* its own `fi` entry, it places it first; adding it to a full 32-member list removes the rightmost member. The command below supplies a parent ID but does not export a span for that parent.

```bash
curl -fsS http://127.0.0.1:5101/return-policy \
  -H "traceparent: 00-$(openssl rand -hex 16)-$(openssl rand -hex 8)-01" \
  -H 'tracestate: fi=r:0.5'
```

Stop the example servlet when you finish: `kill "$SERVLET_PID"`.

## Choose which destinations receive context

| Node environment variable | `init()` option | Behavior |
| --- | --- | --- |
| `TRACEAI_PROPAGATE_OUTGOING_ADAPTERS` | `propagateOutgoingAdapters` | Off by default. Use the exact string `true` in the environment, or boolean `true` in code. Setting a policy alone doesn't enable it. |
| `TRACEAI_PROPAGATE_OUTGOING` | `propagateOutgoing` | `default` allows eligible native HTTP(S) destinations. `none` adds nothing. `all` has the same exclusions as `default`. |
| `TRACEAI_PROPAGATE_HOSTS` | `propagateHosts` | No explicit host rules by default. Use a comma-separated list in the environment or an array of strings in code. |

For example, `+*.ridgeline.internal,-payments.ridgeline.internal` allows subdomains but not the bare domain or the payments service. Any positive rule excludes unlisted hosts; denies win. A positive rule cannot override known provider-host and provider-port exclusions, such as Ollama's port `11434`. Allow only the services you control: an unrecognized model proxy is not automatically excluded.

On eligible requests, the adapter can add `traceparent`, `tracestate` and existing W3C baggage after privacy filtering. The host policy applies only to headers the adapter adds, not to headers your application sets itself. The adapter never creates a root or overwrites application headers. If it observes a redirect to another origin, it stops adding headers to that chain, even if a later redirect returns to the original host.

## Alternative: inject and extract the parent yourself

On other transports the same rule applies: inject while the sender's span is active, then extract **before** the receiver starts its span. For example, if the returns service reads jobs from a queue instead of HTTP, put the headers in the job envelope and extract from that envelope in the worker. Don't rely on process-local context surviving the handoff.

| If you use… | On the caller | On the receiver |
| --- | --- | --- |
| Node `fetch` with OpenTelemetry | With a registered W3C propagator, call `propagation.inject(context.active(), headers)` and pass those headers on that request. | Use `propagation.extract()` on the incoming headers and run the work inside `context.with()` using the extracted context. |
| Java without a servlet | Use the application's `TextMapPropagator.inject()` when building the outgoing request. | Call `TextMapPropagator.extract()` with a case-insensitive header getter. Make the returned context current in a try-with-resources scope around the AI call. |
| ASP.NET Core and `HttpClient` | Use OpenTelemetry `AddHttpClientInstrumentation()` rather than adding a second `traceparent`. | `AddAspNetCoreInstrumentation()` makes the incoming request activity available as `Activity.Current`. Start the backend work inside it. |

<Accordion title="Run both services in Python without the Node or Java agents">

This version uses a Python HTTP server and a local policy lookup instead of a model. In a Python environment with `FI_API_KEY` and `FI_SECRET_KEY` set, install the tracing SDK:

```bash
python3 -m venv .returns-venv
. .returns-venv/bin/activate
python -m pip install fi-instrumentation-otel==1.5.0
```

Save the following as `returns.py`. Use the same collector URL and credentials as above. The server handles one request and exits.

```python
import os
import sys
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.request import Request, urlopen

from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from opentelemetry.trace.propagation.tracecontext import TraceContextTextMapPropagator

provider = register(project_name=os.environ.get("FI_PROJECT_NAME", "ridgeline-returns"),
                    project_type=ProjectType.OBSERVE, verbose=False)
tracer = provider.get_tracer("ridgeline-returns")
w3c = TraceContextTextMapPropagator()


class Returns(BaseHTTPRequestHandler):
    def do_GET(self):
        parent = w3c.extract({k.lower(): v for k, v in self.headers.items()})
        with tracer.start_as_current_span("Look up tent policy", context=parent):
            self.send_response(200)
            self.end_headers()
            self.wfile.write(b"Yes, within 30 days.")


try:
    if sys.argv[1:] == ["serve"]:
        with HTTPServer(("127.0.0.1", 5102), Returns) as server:
            print("Ready", flush=True)
            server.handle_request()
    elif sys.argv[1:] == ["ask"]:
        with tracer.start_as_current_span("Check tent return") as span:
            headers = {}
            w3c.inject(headers)
            req = Request("http://127.0.0.1:5102/return-policy", headers=headers)
            with urlopen(req, timeout=10) as res:
                print(res.read().decode(), f"Trace: {span.get_span_context().trace_id:032x}")
    else:
        raise SystemExit("Use: python returns.py serve | ask")
finally:
    provider.shutdown()
```

Start the server, wait for it to bind, then send the request:

```bash
FI_TRACES_URL="$COLLECTOR_URL" python returns.py serve >returns.log 2>&1 &
server_pid=$!
while ! grep -qx Ready returns.log; do kill -0 "$server_pid" || exit 1; sleep 0.2; done
FI_TRACES_URL="$COLLECTOR_URL" python returns.py ask
wait "$server_pid"
```

Open the printed trace. `Look up tent policy` should be a child of `Check tent return`.

</Accordion>

## If the spans don't join

- **The servlet receives no header.** Check that you use `node:http` or `node:https`, the flag is on, the host is allowed, and the request runs in an active context. No headers are added for an unobserved local span, an observed active CLIENT span or a request that already has `traceparent` (even an invalid one). Check `outgoing-http` in `report()` from `@traceai/auto`: `disabled` means the opt-in is off or the policy disables additions, `pending` means the adapter is waiting for its first header write, and `instrumented` means it has added headers on at least one request.
- **Your gateway uses `fetch` or Undici.** The adapter doesn't inject into global `fetch`, `undici.fetch` or `undici.request`. Capturing a model call made with `fetch` doesn't imply that a call to your own backend carries context. Use native HTTP(S) for this recipe or [inject and extract W3C headers explicitly](/docs/sdk/tracing/advanced-tracing-examples).
- **Java starts a new trace despite a valid header.** Use the Java agent on `javax.servlet.http.HttpServlet` or `jakarta.servlet.http.HttpServlet`, including servlet-based Spring MVC. It scopes the parent to `service()` on the request thread and restores the previous context on return or exception. Filters before the servlet, work you hand to another thread, reactive servers and gRPC are outside this hook. An application span already active at the AI call takes precedence.
- **You already instrument incoming Java requests.** Set `FI_DISABLED_INSTRUMENTATIONS=servlet` on the Java process to opt out of servlet extraction. Beside the OpenTelemetry Java agent, the traceAI servlet hook is off automatically. Check which agent supplies and exports your parent before looking for a missing SERVER span.
