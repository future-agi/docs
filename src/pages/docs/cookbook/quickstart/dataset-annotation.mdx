<TLDR>
Turn a Ridgeline Outfitters support reply into a review item. You create a dataset, attach three labels to an annotation queue, then record a review against the row. You don't need a tracing project or a span ID.
</TLDR>

| Time | Difficulty | Package |
|------|------------|---------|
| 15 min | Intermediate | `futureagi` |

<Prerequisites>
- Python 3.12
- A workspace where you can create datasets, annotation queues and labels
- `FI_API_KEY` and `FI_SECRET_KEY` from [Settings](/docs/admin-settings)
</Prerequisites>

## Tutorial

<Steps>
<Step title="Create a dataset row to review">

Run the Python blocks in order in one session. Put the customer's question and the agent's reply in separate columns so a reviewer can compare them. File imports run asynchronously; wait for the actual row ID rather than using its position in the CSV.

```python
import json
import time
from pathlib import Path
from uuid import uuid4
from fi.platform import Client

client = Client()
queues = client.annotation_queues
suffix = uuid4().hex[:8]
source = b"question,reply\nHow do I return my hiking boots?,Start a return from your order page for a prepaid label.\n"
dataset = client.datasets.create_from_file(
    file=("returns.csv", source),
    new_dataset_name=f"ridgeline-review-{suffix}", model_type="GenerativeLLM",
)
for _ in range(60):
    table = client.datasets.get(dataset.dataset_id)
    if table.table and not table.is_processing_data:
        break
    time.sleep(1)
else:
    raise TimeoutError("The return example is not ready to review.")
row_id = table.table[0].row_id
```

</Step>
<Step title="Define the labels">

Use a category for tone, a numeric scale for relevance, and text for the reviewer's explanation. Attaching each label to the queue makes it part of this review.

```python
tone = client.annotations.labels.create(
    name=f"Tone {suffix}", type="categorical", description="Tone of the reply",
    settings={"options": [{"label": x} for x in ("Positive", "Neutral", "Negative")],
              "multi_choice": False, "rule_prompt": "", "auto_annotate": False, "strategy": None},
)
relevance = client.annotations.labels.create(
    name=f"Relevance {suffix}", type="numeric", description="How directly the reply addresses the question",
    settings={"min": 1, "max": 5, "step_size": 1, "display_type": "slider"},
)
comment = client.annotations.labels.create(
    name=f"Reviewer note {suffix}", type="text", description="Reason for your rating",
    settings={"placeholder": "Explain your rating", "min_length": 0, "max_length": 500},
)
```

</Step>
<Step title="Set up the review queue">

Create the queue with the three label IDs. To assign reviewers at creation, you can also pass their workspace user IDs in `annotator_ids`.

```python
queue = queues.create(
    name=f"Boot returns review {suffix}", label_ids=[tone.id, relevance.id, comment.id],
    instructions="Read the question and reply. Rate the tone and relevance, then explain your judgment.",
)
print(queue.name)
```

</Step>
<Step title="Add the reply and record a review">

Use `dataset_row` as the source type. Once the row is in the queue, submit the judgments against the **queue item ID**, not the dataset row ID. These example ratings reflect one reviewer's reading: the reply gives a specific next step without expressing a strong sentiment.

```python
added = queues.items.add(queue.id, items=[{"source_type": "dataset_row", "source_id": row_id}])
if added.added != 1:
    raise RuntimeError(f"Could not add the row: {added.errors}")
queues.update_status(queue.id, status="active")
item, = queues.items.list(queue.id)  # The new queue contains just this row.
detail = queues.items.annotate_detail(queue.id, item.id, reserve=True)
print(detail.item["source_content"]["fields"])
queues.items.submit(queue.id, item.id, annotations=[
    {"label_id": tone.id, "value": "Neutral"},
    {"label_id": relevance.id, "value": 5},
    {"label_id": comment.id, "value": "The reply tells the customer exactly where to get a return label."},
])
queues.items.complete(queue.id, item.id)
```

</Step>
<Step title="Read the review back">

Open **Annotations** and find the printed queue name, or fetch the scores by item ID. Save the IDs to reopen this review in a later session.

```python
scores = queues.items.list_annotations(queue.id, item.id)
for score in scores:
    print(score.label_name, score.value)
Path("returns-review.json").write_text(json.dumps({
    "dataset": dataset.dataset_id, "row": row_id, "queue": queue.id, "item": item.id,
    "labels": [tone.id, relevance.id, comment.id],
}))
```

</Step>
</Steps>

## Troubleshooting

| Symptom | What to check |
|---|---|
| The queue is empty | Creating a queue does not enqueue every row. Use `queues.items.add` with the row ID. |
| A rating is rejected | Check the label ID, categorical option spelling, and numeric range. |
| A reviewer cannot find the item | Make sure they are in the same workspace and have access to the active queue. |
