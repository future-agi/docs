## Tutorial

<Steps>
<Step title="Set up the Evaluator">

Start in an empty directory and run the Python blocks in order in one session. Each call to `evaluate()` uses a hosted evaluator and can consume credits. Keep the evaluation IDs if you want to retrieve the results later.

```python
import base64
import io
import json
import subprocess
from pathlib import Path

from PIL import Image, ImageDraw
from fi.evals import Evaluator

evaluator = Evaluator()
judgments = []

def media_uri(mime, content):
    return f"data:{mime};base64," + base64.b64encode(content).decode("ascii")

def score(template, inputs, model):
    batch = evaluator.evaluate(eval_templates=template, inputs=inputs, model_name=model)
    row = batch.eval_results[0]
    if row is None or row.output is None or not row.eval_id:
        raise RuntimeError(row.reason if row else "No judgment returned")
    judgments.append({"name": template, "eval_id": row.eval_id, "verdict": row.output})
    print(f"{template}: {row.output}\nReason: {row.reason}")
```

</Step>
<Step title="Detect caption hallucination">

Create a sample product icon: a red triangle on a white background. Score a caption that matches the icon.

```python
icon = Image.new("RGB", (192, 192), "white")
ImageDraw.Draw(icon).polygon([(96, 20), (26, 162), (166, 162)], fill="red")
buffer = io.BytesIO()
icon.save(buffer, format="PNG")
image = media_uri("image/png", buffer.getvalue())
score("caption_hallucination", {"image": image, "caption": "A red triangle on a white background."}, "turing_small")
```

Keep the image fixed and change only the caption:

```python
score("caption_hallucination", {"image": image, "caption": "A blue bicycle leaning against a tree."}, "turing_small")
```

Look for `Passed` on the matching caption and `Failed` on the invented bicycle. Read the reason to see which details the judge used.

</Step>
<Step title="Detect synthetic images">

Use the same icon to estimate whether the image was synthetically produced. The score expresses the judge's assessment, not proof of how an image was made.

```python
score("synthetic_image_evaluator", {"image": image}, "turing_small")
```

</Step>
<Step title="Evaluate audio quality">

Generate a short WAV file with synthesized speech, then score its clarity, noise, and naturalness. The audio-quality template uses a normalized score, not a listener panel's 1-to-5 MOS rating.

```python
text = "Unused gear can be returned within thirty days."
subprocess.run([
    "ffmpeg", "-v", "error", "-f", "lavfi", "-i", f"flite=text={text}:voice=slt",
    "-ac", "1", "-ar", "16000", "returns.wav",
], check=True)
audio = media_uri("audio/wav", Path("returns.wav").read_bytes())
score("audio_quality", {"input_audio": audio}, "turing_large")
```

</Step>
<Step title="Evaluate text-to-speech accuracy">

Does the clip say what the return policy actually says? Pass both the audio and its original script to the TTS evaluator. Unlike the previous audio-only check, this one also considers pronunciation and delivery against the text.

```python
score("TTS_accuracy", {"text": text, "generated_audio": audio}, "turing_large")
```

</Step>
<Step title="Evaluate OCR output against a PDF">

Build a one-page sample packing slip for Ridgeline Outfitters. Supply the PDF and the fields you extracted, not just the extracted text.

```python
slip = Image.new("RGB", (850, 1100), "white")
ImageDraw.Draw(slip).multiline_text(
    (50, 60), "Ridgeline Outfitters\nPacking slip: RO-1042\nItem: Trail mug\nQuantity: 2",
    fill="black", font_size=36, spacing=12,
)
buffer = io.BytesIO()
slip.save(buffer, format="PDF", resolution=100)
score("ocr_evaluation", {
    "input_pdf": media_uri("application/pdf", buffer.getvalue()),
    "json_content": json.dumps({"packing_slip": "RO-1042", "item": "Trail mug", "quantity": 2}),
}, "turing_large")
Path("multimodal-results.json").write_text(json.dumps(judgments, indent=2), encoding="utf-8")
```

The reason should explain which JSON values are supported by the source. `multimodal-results.json` records each template, evaluation ID, and verdict from this session.

</Step>
<Step title="Run multimodal evals from the dashboard">

You can also run these evals directly from the Future AGI platform without writing any code.

1. Go to **Datasets** and create or open a dataset
2. Add columns for your multimodal inputs, for example an `image` column with image URLs, or an `audio` column with audio URLs
3. Click **Add Evaluation** and select a multimodal eval, for example `caption_hallucination` or `audio_quality`
4. Map the eval's required keys to your dataset columns, for example `image` to your image column and `caption` to your caption column
5. Choose a Turing model and click **Run**
6. View scores alongside each row in the dataset

This is the same approach shown in the [Dataset SDK cookbook](/docs/cookbook/quickstart/batch-eval), but with multimodal columns instead of text-only.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `Evaluator()` raises a missing-credentials error | `FI_API_KEY` or `FI_SECRET_KEY` isn't exported before the script runs | Export both keys, or pass `fi_api_key`/`fi_secret_key` directly to `Evaluator()` |
| `audio_quality` or `ocr_evaluation` returns an unsupported-model error | Called with `model_name="turing_small"` instead of `turing_large` | Use `model_name="turing_large"` for these evals |
| `caption_hallucination` or `synthetic_image_evaluator` comes back empty or errors | The image URL isn't publicly reachable, for example a private bucket or an expired signed URL | Use a publicly accessible URL, or pass the image as base64 |
| `ocr_evaluation` scores low even on a correct extraction | `json_content` isn't valid JSON, for example a trailing comma or an unescaped quote | Validate the string with `json.loads()` before passing it in |
| `TTS_accuracy` or `audio_quality` times out on a long clip | The input audio runs several minutes and the evaluation model processes it in full | Trim the clip to the relevant segment before scoring |
| `result.eval_results[0]` is `None` | That row failed to evaluate, usually a bad input URL or an unsupported file type | Check the entry for `None` before reading `.output` or `.reason`, and re-check the input for that row |
