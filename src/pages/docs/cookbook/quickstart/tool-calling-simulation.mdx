<TLDR>
**What you'll build:** A simulated Ridgeline Outfitters order inquiry that runs locally. You inspect the tool request, the mock lookup, and the final OpenAI response as children of the same agent turn in Tracing.
</TLDR>

## The problem

A support agent can say it checked an order without using the carrier or tracking number that the lookup returned. A convincing final reply isn't enough: you need the tool result and the reply from the same turn.

## What you'll build

A local simulation of one order inquiry, traced so that the tool request, the mock lookup and the final reply sit under the same agent turn in one [trace](/docs/observe/concepts/traces).

You'll:

1. Instrument OpenAI and create a tracer.
2. Define a mock order lookup and an agent callback that records each tool call as a span.
3. Run one simulated customer through the agent with Agent Learning Kit.
4. Find the lookup between the two model calls in the trace.

<Prerequisites title="Before you start">
- Python 3.12 and an OpenAI API key
- A Future AGI account with [API keys](/docs/admin-settings/api-keys) for the trace export
</Prerequisites>

## Build and trace the simulated inquiry

<Steps>
<Step title="Set up tracing">

Save this as `tracing_setup.py`. Instrument OpenAI before creating the client so both chat completions become [spans](/docs/observe/concepts/spans).

```python
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from traceai_openai import OpenAIInstrumentor

provider = register(project_name="tool-calling-simulation", project_type=ProjectType.OBSERVE,
                    set_global_tracer_provider=True, verbose=False)
OpenAIInstrumentor().instrument(tracer_provider=provider)
tracer = provider.get_tracer("ridgeline.support")
```

</Step>
<Step title="Define tools and mock execution">

Save this as `order_tools.py`. Both tools return synthetic data; neither looks up a real shipment or issues a real refund.

```python
import json

TOOLS = [
    {
        "type": "function",
        "function": {
            "name": "check_order_status",
            "description": "Look up the current status of a customer order.",
            "parameters": {
                "type": "object",
                "properties": {
                    "order_id": {
                        "type": "string",
                        "description": "The unique order identifier, e.g. 'ORD-12345'.",
                    }
                },
                "required": ["order_id"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "initiate_refund",
            "description": "Start a refund for a customer order.",
            "parameters": {
                "type": "object",
                "properties": {
                    "order_id": {
                        "type": "string",
                        "description": "The unique order identifier to refund.",
                    },
                    "reason": {
                        "type": "string",
                        "description": "The reason for the refund.",
                    },
                },
                "required": ["order_id", "reason"],
            },
        },
    },
]


def execute_tool(tool_name: str, arguments: dict) -> str:
    if tool_name == "check_order_status":
        return json.dumps({
            "order_id": arguments.get("order_id", "UNKNOWN"),
            "status": "shipped",
            "carrier": "FedEx",
            "tracking_number": "FX-9988776655",
            "estimated_delivery": "2026-03-06",
        })
    elif tool_name == "initiate_refund":
        return json.dumps({
            "order_id": arguments.get("order_id", "UNKNOWN"),
            "refund_id": "REF-554433",
            "status": "approved",
            "amount": "$149.99",
            "timeline": "3-5 business days",
        })
    else:
        return json.dumps({"error": f"Unknown tool: {tool_name}"})
```

</Step>
<Step title="Write the agent callback">

Save this as `support_agent.py`. For this order inquiry, request a lookup explicitly. Append the assistant's tool call and the matching tool result before asking the model for its final reply. Return only the reply to the simulator; keep the tool exchange inside this turn.

```python
import json
from fi.simulate import AgentInput
from openai import AsyncOpenAI
from order_tools import TOOLS, execute_tool
from tracing_setup import tracer

client = AsyncOpenAI()

async def agent_callback(turn: AgentInput) -> str:
    with tracer.start_as_current_span("agent-turn") as span:
        span.set_attribute("thread_id", turn.thread_id)
        messages = [{"role": "system", "content": "You help Ridgeline Outfitters customers track orders. Give the carrier and tracking number from the lookup."}]
        messages.extend({"role": m["role"], "content": m["content"]} for m in turn.messages)
        request = await client.chat.completions.create(
            model="gpt-4o-mini", messages=messages, tools=TOOLS,
            tool_choice={"type": "function", "function": {"name": "check_order_status"}},
        )
        assistant = request.choices[0].message
        messages.append(assistant)
        for call in assistant.tool_calls or []:
            with tracer.start_as_current_span(f"execute: {call.function.name}") as tool_span:
                tool_span.set_attribute("gen_ai.span.kind", "TOOL")
                tool_span.set_attribute("tool.name", call.function.name)
                tool_span.set_attribute("tool.parameters", call.function.arguments)
                result = execute_tool(call.function.name, json.loads(call.function.arguments))
                tool_span.set_attribute("tool.result", result)
            messages.append({"role": "tool", "tool_call_id": call.id, "content": result})

        reply = await client.chat.completions.create(model="gpt-4o-mini", messages=messages)
        return reply.choices[0].message.content or ""
```

</Step>
<Step title="Run the simulation">

Save the following as `simulate_order.py`. The scenario contains one customer. Setting both turn limits to one exercises the lookup once. The simulation report stays local; the tracing provider sends spans to your Observe project.

```python
import asyncio
from fi.simulate import Persona, Scenario, TestRunner
from support_agent import agent_callback
from tracing_setup import provider, tracer

scenario = Scenario(name="track-order", dataset=[Persona(
    persona={"name": "Casey"}, situation="Where is my order ORD-12345?",
    outcome="Learn the carrier and tracking number.",
)])

async def main():
    with tracer.start_as_current_span("order-inquiry") as root:
        report = await TestRunner().run_test(scenario=scenario, agent_callback=agent_callback,
                                             min_turns=1, max_turns=1)
        print(report.results[0].transcript)
        trace_id = root.get_span_context().trace_id
    provider.force_flush()
    print(f"Trace ID: {trace_id:032x}")

if __name__ == "__main__":
    asyncio.run(main())
```

Run `python simulate_order.py`. The transcript should contain the synthetic tracking number `FX-9988776655`. The response wording and trace ID vary.

</Step>
<Step title="Inspect the trace">

1. Open the `tool-calling-simulation` project in **Tracing**.
2. Find the printed trace ID.
3. Expand `order-inquiry`.
4. Open `agent-turn`.

   You should see the lookup between the two model calls:

```text
agent-turn
├── OpenAI chat (requests the lookup)
├── execute: check_order_status (stores the arguments and mock result)
└── OpenAI chat (writes the reply)
```

## Test your own agent in a hosted environment

This example runs on your machine against a mock lookup, and the simulation report stays local. To test your own agent with its real tools, [build an environment](/docs/environments/guides/build-an-environment) from its repository, a code upload, or a hosted platform. [Environments and Simulations](/docs/environments) then runs scenarios against the agent as calls and grades each call against the scenario's sub-goals. [Add evaluations](/docs/environments/guides/add-evaluations) to grade on more than those.

For a first check, run one scenario that needs the order lookup, with **Repeats** at **1×**. Then find the exchange in **Transcript** and compare the tool arguments with what the customer asked for. The guides under **Next** cover both steps.

## Troubleshooting

| Symptom | What to check |
|---|---|
| OpenAI rejects a tool message | Each result must follow the assistant message containing its `tool_call_id`. |
| The transcript prints but you cannot find the trace | Check the Future AGI key pair and collector URL, and select the Observe project named in `register()`. |
| The tool span appears but the two model calls do not | Instrument OpenAI before making either request and pass the same provider to the instrumentor. |
