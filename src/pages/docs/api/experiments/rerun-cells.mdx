---
title: "Rerun Experiment Cells"
description: "Rerun selected result cells, configuration output columns, or evaluation metrics in an experiment."
---

`POST /model-hub/experiments/v2/{experiment_id}/rerun-cells/`

Replace the example experiment, column, and row UUIDs and API credentials with your own values.

### cURL

```bash
curl --request POST 'https://api.futureagi.com/model-hub/experiments/v2/4b626c23-2a8f-41fd-9660-43b43c42dc02/rerun-cells/' \
  --header 'X-Api-Key: YOUR_API_KEY' \
  --header 'X-Secret-Key: YOUR_SECRET_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "cells": [{
      "column_id": "5fbab3a6-26b0-4389-8687-3bd22f368e3c",
      "row_id": "d60bf486-7d1a-4c67-97f3-a053a1c44123"
    }],
    "failed_only": false
  }'
```

### Python

```python
import requests

response = requests.post(
    "https://api.futureagi.com/model-hub/experiments/v2/4b626c23-2a8f-41fd-9660-43b43c42dc02/rerun-cells/",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Secret-Key": "YOUR_SECRET_KEY",
    },
    json={
        "cells": [{
            "column_id": "5fbab3a6-26b0-4389-8687-3bd22f368e3c",
            "row_id": "d60bf486-7d1a-4c67-97f3-a053a1c44123",
        }],
        "failed_only": False,
    },
)
response.raise_for_status()
print(response.json())
```

  <ParamField name="X-Api-Key" type="API Key" required>Your Future AGI API key.</ParamField>
  <ParamField name="X-Secret-Key" type="Secret Key" required>Your Future AGI secret key.</ParamField>
</ApiSection>

<ApiSection title="Request body">
  <ParamField body="cells" type="object[]" optional>
    Result cells to rerun. Each entry requires `column_id` and `row_id` UUIDs from the experiment's result dataset. The column source determines whether the request reruns output generation or evaluation.
  </ParamField>
  <ParamField body="source_ids" type="UUID[]" optional>
    Experiment configuration dataset IDs for a full output-column rerun across rows. These are not column IDs or original input dataset IDs.
  </ParamField>
  <ParamField body="user_eval_metric_ids" type="UUID[]" optional>
    IDs of the experiment's configured evaluation metrics to rerun without regenerating outputs. Use metric IDs, not evaluation template IDs.
  </ParamField>
  <ParamField body="failed_only" type="boolean" optional>
    Restrict the rerun to failed cells within the selected scope. Defaults to `false`. This is not a selector by itself.
  </ParamField>
</ApiSection>

At least one of `cells`, `source_ids`, or `user_eval_metric_ids` must be **nonempty**. `user_eval_metric_ids` cannot be combined with `source_ids`. For a targeted request, use one selector family at a time.

## Select the right identifiers

Read [experiment details and result rows](/docs/api/experiments/read-experiments) before constructing the request:

- `cells` uses the `column_id` and `row_id` of the experiment result cells. It does not use a `source_id` key inside each cell entry.
- `source_ids` identifies the experiment's prompt/agent configuration datasets, also represented by output column metadata. It selects whole configuration outputs.
- `user_eval_metric_ids` comes from the experiment's `user_eval_metrics` entries.

A result column rerun can also rerun its dependent evaluations. An evaluation-only request reruns evaluations without regenerating the model output.

## Rerun failed outputs for a configuration

```json
{
  "source_ids": ["6371210f-c797-4583-a0da-107fed74f384"],
  "failed_only": true
}
```

## Rerun an evaluation

```json
{
  "user_eval_metric_ids": ["79e5cf56-9f30-47b6-b391-07ce7a07c207"]
}
```

<ApiSection title="Response" status={200} statusText="OK">
  <ResponseField name="status" type="boolean">`true` on success.</ResponseField>
  <ResponseField name="result.message" type="string">Acknowledgment for the selected rerun operation.</ResponseField>
  <ResponseField name="result.workflow_id" type="string">Identifier for the rerun workflow.</ResponseField>
</ApiSection>

```json
{
  "status": true,
  "result": {
    "message": "Cell rerun has started.",
    "workflow_id": "workflow-id"
```

Read the experiment status and rows to track completion. For a whole-experiment rerun, use [Rerun Experiments](/docs/api/experiments/rerun-experiments).

  <ParamField name="403" type="Forbidden">The selected target cannot be executed by the request.</ParamField>
</ApiSection>
