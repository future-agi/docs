<ApiSection title="Authentication">
  <ParamField name="X-Api-Key" type="API Key" required>Your Future AGI API key.</ParamField>
  <ParamField name="X-Secret-Key" type="Secret Key" required>Your Future AGI secret key.</ParamField>
</ApiSection>

<ApiSection title="Request body">
  <ParamField body="experiment_ids" type="UUID[]" required>A nonempty list of experiment IDs to rerun.</ParamField>
</ApiSection>

Use this endpoint for a whole-experiment rerun. To select individual result cells, configuration outputs, or evaluation metrics, use [Rerun Experiment Cells](/docs/api/experiments/rerun-cells).

<ApiSection title="Response" status={200} statusText="OK">
  <ResponseField name="status" type="boolean">`true` when the start is confirmed.</ResponseField>
  <ResponseField name="result" type="string">`Re-Run has started for the experiments.`</ResponseField>
</ApiSection>

The acknowledgment is not a completion result. [Read the experiment status and rows](/docs/api/experiments/read-experiments) after submitting the request. If the request fails, do not assume that no execution started; check status and follow the returned error guidance before retrying.

<ApiSection title="Errors">
  <ParamField name="400" type="Bad Request">Missing or invalid experiment IDs.</ParamField>
  <ParamField name="403" type="Forbidden">The request cannot execute a configured target.</ParamField>
  <ParamField name="404" type="Not Found">An experiment in the request is unavailable in the request scope.</ParamField>
</ApiSection>

Return to the [Experiments API](/docs/api/experiments).
