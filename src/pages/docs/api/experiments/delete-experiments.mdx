---
title: "Delete Experiments"
description: "Delete one or more experiments by ID."
---

`DELETE /model-hub/experiments/v2/delete/`

Replace the example experiment ID and API credentials with your own values.

### cURL

```bash
curl --request DELETE 'https://api.futureagi.com/model-hub/experiments/v2/delete/' \
  --header 'X-Api-Key: YOUR_API_KEY' \
  --header 'X-Secret-Key: YOUR_SECRET_KEY' \
  --header 'Content-Type: application/json' \
  --data '{"experiment_ids":["4b626c23-2a8f-41fd-9660-43b43c42dc02"]}'
```

### Python

```python
import requests

response = requests.delete(
    "https://api.futureagi.com/model-hub/experiments/v2/delete/",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Secret-Key": "YOUR_SECRET_KEY",
    },
    json={"experiment_ids": ["4b626c23-2a8f-41fd-9660-43b43c42dc02"]},
)
response.raise_for_status()
print(response.json())
```

<ApiSection title="Authentication">
  <ParamField name="X-Api-Key" type="API Key" required>Your Future AGI API key.</ParamField>
  <ParamField name="X-Secret-Key" type="Secret Key" required>Your Future AGI secret key.</ParamField>
</ApiSection>

<ApiSection title="Request body">
  <ParamField body="experiment_ids" type="UUID[]" required>A nonempty list of experiment IDs to delete. Send the list in the JSON body of the DELETE request.</ParamField>
</ApiSection>

The operation deletes matching experiments in the request scope and returns the number deleted. Use [Stop Experiment](/docs/api/experiments/stop-experiment) instead if you only want to cancel execution.

<ApiSection title="Response" status={200} statusText="OK">
  <ResponseField name="status" type="boolean">`true` on success.</ResponseField>
  <ResponseField name="result.message" type="string">Confirmation message with the number deleted.</ResponseField>
  <ResponseField name="result.deleted_count" type="integer">Number of matching experiments deleted.</ResponseField>
</ApiSection>

```json
{
  "status": true,
  "result": {
    "message": "1 experiments deleted successfully",
    "deleted_count": 1
  }
}
```

<ApiSection title="Errors">
  <ParamField name="400" type="Bad Request">No experiment IDs supplied, or the delete request could not be processed.</ParamField>
  <ParamField name="404" type="Not Found">No matching experiments were found in the request scope.</ParamField>
</ApiSection>

Return to the [Experiments API](/docs/api/experiments).
