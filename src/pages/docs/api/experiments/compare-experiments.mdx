Despite its route name, `compare-experiments/` compares the configuration outputs **within the experiment identified in the path**. It does not take a list of separate experiment IDs.

## Calculate comparisons

`POST /model-hub/experiments/v2/{experiment_id}/compare-experiments/`

<ParamField body="weights" type="object" optional>
  Comparison weights. The `completion_tokens`, `total_tokens`, and `response_time` weights each default to `1`. Send `{}` to use the defaults.
</ParamField>

The endpoint calculates comparisons for the experiment's prompt/agent configuration outputs and its base column when present. It saves the calculated comparisons for later retrieval.

<ApiSection title="Response" status={200} statusText="OK">
  <ResponseField name="status" type="boolean">`true` on success.</ResponseField>
  <ResponseField name="result.experiment_id" type="UUID">The experiment being compared.</ResponseField>
  <ResponseField name="result.experiment_name" type="string">Experiment name.</ResponseField>
  <ResponseField name="result.total_datasets" type="integer">Number of output datasets or base-column results included.</ResponseField>
  <ResponseField name="result.dataset_comparisons" type="object[]">Calculated comparison results. Empty when there are no comparable metrics.</ResponseField>
  <ResponseField name="result.weights_applied" type="object">Weights used when comparison results are present.</ResponseField>
</ApiSection>

## Read saved comparisons

`GET /model-hub/experiments/v2/{experiment_id}/comparisons/`

This returns the latest saved comparisons, ordered by rank. It does not calculate new comparisons.

The response has `status: true` and a `result` with:

| Field | Description |
|-------|-------------|
| `experiment_id` | Experiment UUID |
| `total_comparisons` | Number of saved comparison entries returned |
| `comparisons` | Entries containing `experiment_dataset_id`, `rank`, `rank_suffix`, raw and normalized `metrics`, `weights`, and `overall_rating` |

For the aggregate result table without calculating comparisons, use [Statistics](/docs/api/experiments/read-experiments#statistics). Return to the [Experiments API](/docs/api/experiments) for all routes.
