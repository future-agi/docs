Use the Experiments API to run prompt/model or agent configurations against a dataset with evaluation metrics. Start with [Create Experiment](/docs/api/experiments/create-experiment), then [read the experiment and its results](/docs/api/experiments/read-experiments).

## Authentication

Send `X-Api-Key` and `X-Secret-Key` with each request. The base URL is `https://api.futureagi.com`. Replace path placeholders with IDs accessible to your organization and workspace.

## Route map

All paths below are relative to `/model-hub/experiments/v2/`.

| Method | Path | Reference |
|--------|------|-----------|
| `POST` | `/` | [Create experiment](/docs/api/experiments/create-experiment) |
| `GET` | `list/` | [List experiments](/docs/api/experiments/read-experiments#list-experiments) |
| `GET` | `{experiment_id}/` | [Read experiment details](/docs/api/experiments/read-experiments#experiment-details) |
| `GET` | `{experiment_id}/rows/` | [Read result rows](/docs/api/experiments/read-experiments#result-rows) |
| `GET` | `{experiment_id}/stats/` | [Read aggregate statistics](/docs/api/experiments/read-experiments#statistics) |
| `PUT` | `{experiment_id}/` | [Update configuration](/docs/api/experiments/update-experiment) |
| `POST` | `re-run/` | [Rerun experiments](/docs/api/experiments/rerun-experiments) |
| `POST` | `{experiment_id}/rerun-cells/` | [Rerun cells or evaluations](/docs/api/experiments/rerun-cells) |
| `POST` | `{experiment_id}/stop/` | [Stop an experiment](/docs/api/experiments/stop-experiment) |
| `DELETE` | `delete/` | [Delete experiments](/docs/api/experiments/delete-experiments) |
| `POST` | `{experiment_id}/compare-experiments/` | [Calculate comparisons](/docs/api/experiments/compare-experiments) |
| `GET` | `{experiment_id}/comparisons/` | [Read saved comparisons](/docs/api/experiments/compare-experiments#read-saved-comparisons) |

The create route is `/model-hub/experiments/v2/` itself.

## Request and response conventions

- Request bodies use JSON and `Content-Type: application/json`.
- Create requires a name, dataset ID, at least one configuration, and at least one evaluation metric.
- The REST `experiment_type` enum accepts `llm`, `tts`, `stt`, and `image`; it is not limited to the LLM creation workflow shown in the dashboard.
- Most endpoints return a boolean `status` and a `result`. The list endpoint instead returns a paginated `results` array.
- Create returns the experiment ID **inside a result string**, not `result.id`.
- A successful create or rerun acknowledges execution starting, not completion. Read the experiment's status and results afterward.

For input data, see [Create Dataset](/docs/api/datasets/create-dataset). To select the union of live dataset subsets at creation, see [Dataset Splits](/docs/api/datasets/splits) and the create request's `split_ids` field.
