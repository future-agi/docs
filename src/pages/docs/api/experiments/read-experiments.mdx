## List experiments

`GET /model-hub/experiments/v2/list/`

| Query parameter | Description |
|-----------------|-------------|
| `dataset_id` | Filter by dataset UUID |
| `status` | Filter by experiment status |
| `search` | Search experiment names |
| `ordering` | `created_at` or `name`; prefix with `-` for descending order. Defaults to `-created_at`. |
| `page` | One-based page number |
| `limit` | Results per page; defaults to 10 |

The response has `count`, `next`, `previous`, `results`, `total_pages`, and `current_page`. It does **not** use the `status`/`result` envelope.

Each result includes `id`, `name`, `status`, `experiment_type`, `dataset`, `created_at`, `models_count`, `agents_count`, and `eval_templates_count`.

## Experiment details

`GET /model-hub/experiments/v2/{experiment_id}/`

Returns `status: true` and a `result` object with experiment details, including:

- `id`, `name`, `dataset_id`, `experiment_type`, `status`, and `created_at`
- `column_id` and `snapshot_dataset_id`
- `prompt_configs`, `agent_configs`, and `user_eval_metrics`

The read response uses the plural `prompt_configs` and `agent_configs`, while [create](/docs/api/experiments/create-experiment) and [update](/docs/api/experiments/update-experiment) use a unified `prompt_config` list. Keep the returned configuration and evaluation IDs when editing existing entries.

## Result rows

`GET /model-hub/experiments/v2/{experiment_id}/rows/`

| Query parameter | Type | Description |
|-----------------|------|-------------|
| `page_size` | integer | 1–100 rows per page; defaults to 10 |
| `current_page_index` | integer | Zero-based page index; defaults to 0 |
| `column_config_only` | boolean | Return column configuration without the row table; defaults to `false` |
| `get_diff` | boolean | Request diff information; defaults to `false` |
| `search` | string | Search text, up to 512 characters |

The normal response has `status: true` with a `result` containing `column_config`, `table`, `metadata`, `output_format`, and the experiment's `status`. Metadata includes `total_rows`, `total_pages`, `dataset`, and `dataset_name`.

With `column_config_only=true`, the result contains `column_config`, `output_format`, and the experiment's `status`, without the table or pagination metadata.

You can also retrieve a specific row with `GET /model-hub/experiments/v2/{experiment_id}/rows/{row_id}/`. Use the experiment result row IDs, not IDs copied from the original dataset, when [rerunning cells](/docs/api/experiments/rerun-cells).

<Note>
List pagination uses `page` and `limit`. Result-row pagination uses `current_page_index` and `page_size`. The former is one-based; the latter is zero-based.
</Note>

## Statistics

`GET /model-hub/experiments/v2/{experiment_id}/stats/`

Returns `status: true` with `result.column_config`, `result.table_data`, and `result.metadata`. These describe the experiment's aggregate result table. Use [Compare Experiment Configurations](/docs/api/experiments/compare-experiments) to calculate and retrieve comparisons.

For all operations and lifecycle actions, see the [Experiments API](/docs/api/experiments).
