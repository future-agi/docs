## Request body

Send an empty JSON object, `{}`, to stop the whole experiment. This reference covers the whole-experiment action, without a run selection.

<ApiSection title="Response" status={200} statusText="OK">
  <ResponseField name="status" type="boolean">`true` when the stop request succeeds.</ResponseField>
  <ResponseField name="result.message" type="string">`Experiment stopped.`</ResponseField>
  <ResponseField name="result.experiment_id" type="UUID">The affected experiment.</ResponseField>
  <ResponseField name="result.workflows_cancelled" type="object">Cancellation results for the main execution and rerun work.</ResponseField>
</ApiSection>

A request for an experiment that is not running can be rejected with its current status. [Read the experiment](/docs/api/experiments/read-experiments) to check its state. Stopping is separate from [deleting the experiment](/docs/api/experiments/delete-experiments).

Return to the [Experiments API](/docs/api/experiments).
