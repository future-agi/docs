Splits group existing rows within a dataset. Membership changes save immediately. These endpoints read and write **live memberships**, not immutable version membership.

An active organization and workspace are required. Writes require workspace write access. Every row and split ID must belong to the specified dataset.

## Routes

All paths below are relative to `/model-hub/datasets/{dataset_id}/`.

| Method | Path | Operation |
|--------|------|-----------|
| `GET` | `splits/` | List splits and their live row counts |
| `POST` | `splits/` | Create a split |
| `PATCH` | `splits/{split_id}/` | Change a split's name, color, or description |
| `DELETE` | `splits/{split_id}/` | Delete a split |
| `GET` | `splits/membership/?row_id={row_id}` | Read one row's memberships |
| `POST` | `splits/membership/` | Add or remove memberships for existing rows |
| `GET` | `splits/export/?split_id={split_id}` | Export the split's live rows as JSON |

## Create and update a split

<ApiSection title="Request body">
  <ParamField body="name" type="string" required>
    Required on creation; optional on PATCH. Use 1–30 lowercase letters, digits, dots, dashes, or underscores. The first character must be a letter or digit. The name `none` is reserved, and names must be unique within the dataset.
  </ParamField>
  <ParamField body="color" type="string" optional>
    One of `info`, `secondary`, `error`, `warning`, `success`, `primary`, `grey`, or `dark`. Defaults to `info` on creation.
  </ParamField>
  <ParamField body="description" type="string" optional>
    Up to 500 characters. Defaults to an empty string on creation.
  </ParamField>
</ApiSection>

A dataset supports at most **100 splits**. PATCH requires at least one of the fields above. Create and PATCH return `status: true` with a `result` object containing `id`, `name`, `color`, `description`, and `row_count`.

GET `splits/` returns `result.splits` (the split objects) and `result.no_split_count` (live rows that belong to no split).

DELETE returns `result.deleted`, the deleted split ID. If a saved view references the split, remove that reference before deleting it.

## Read row membership

GET `splits/membership/` requires the `row_id` query parameter. A row can belong to more than one split.

```json
{
  "status": true,
  "result": {
    "row_id": "d60bf486-7d1a-4c67-97f3-a053a1c44123",
    "split_ids": ["8a9ed777-63dc-43e1-91bf-724c606c1e32"]
  }
}
```

## Change row membership

POST `splits/membership/` accepts:

<ParamField body="row_ids" type="UUID[]" required>Between 1 and 1,000 existing row IDs.</ParamField>
<ParamField body="add" type="UUID[]" optional>Up to 100 split IDs to add to each selected row. Defaults to an empty list.</ParamField>
<ParamField body="remove" type="UUID[]" optional>Up to 100 split IDs to remove from each selected row. Defaults to an empty list.</ParamField>

At least one of `add` or `remove` must be nonempty. The same split cannot appear in both lists.

```json
{
  "row_ids": ["d60bf486-7d1a-4c67-97f3-a053a1c44123"],
  "add": ["8a9ed777-63dc-43e1-91bf-724c606c1e32"],
  "remove": []
}
```

The response is `{"status": true, "result": {"updated": 1}}`, where `updated` counts the distinct selected rows. The change is saved by this request; there is no separate save step.

## Export a split

GET `splits/export/` requires the `split_id` query parameter. The response is **JSON, not a downloadable CSV**:

```json
{
  "status": true,
  "result": {
    "dataset_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "split": {
      "id": "8a9ed777-63dc-43e1-91bf-724c606c1e32",
      "name": "test",
      "color": "info",
      "description": "Test examples",
      "row_count": 1
    },
    "rows": [
      {
        "row_id": "d60bf486-7d1a-4c67-97f3-a053a1c44123",
        "fields": { "question": "Where is my order?", "reference_answer": null }
      }
    ]
  }
}
```

Each row has a `row_id` and a `fields` object keyed by column name. Values are stored strings or `null`. Column names must be unique for export.

The endpoint refuses an export that exceeds any of these limits:

- **5,000 rows**
- **200 columns**
- **100,000 cells** (rows multiplied by columns)
- **16 MiB** of cell-value data or serialized result data

<ApiSection title="Errors">
  <ParamField name="400" type="Bad Request">Invalid fields, unknown membership IDs, conflicting add/remove lists, a split limit, or duplicate column names on export.</ParamField>
  <ParamField name="403" type="Forbidden">Missing workspace access or insufficient permission to write.</ParamField>
  <ParamField name="404" type="Not Found">The requested dataset, split, or row is not available in the request scope.</ParamField>
  <ParamField name="409" type="Conflict">A split with that name already exists.</ParamField>
  <ParamField name="413" type="Content Too Large">The export exceeds a row, column, cell, or byte limit. Choose a smaller split.</ParamField>
</ApiSection>
