## Named columns and schema-only creation

Each entry in `columns` supports:

| Field | Accepted values | Default |
|-------|-----------------|---------|
| `name` | A nonempty column name | Required |
| `type` | `text`, `integer`, `float`, `boolean`, `json`, `array`, `datetime` | `text` |
| `role` | `input`, `expected`, `metadata` | `metadata` |

To create a schema without any rows, send `number_of_rows: 0` with a nonempty named `columns` list:

```json
{
  "dataset_name": "Support evaluation",
  "number_of_rows": 0,
  "columns": [
    { "name": "question", "type": "text", "role": "input" },
    { "name": "reference_answer", "type": "text", "role": "expected" },
    { "name": "category", "type": "text", "role": "metadata" }
  ]
}
```

This request creates three columns and no rows. For dashboard instructions, see [Create a dataset](/docs/dataset/guides/create-a-dataset).
