<ApiSection title="Request body">
  <ParamField body="agent_definition_id" type="UUID" optional>
    UUID of the agent definition to test. The test run switches to that agent's latest version.
  </ParamField>
  <ParamField body="version" type="UUID" optional>
    UUID of the agent version to pin. It must belong to the test run's agent definition, including one set by `agent_definition_id` in the same request.
  </ParamField>
  <ParamField body="simulator_agent_id" type="UUID" optional>
    UUID of the simulator agent that plays the customer.
  </ParamField>
  <ParamField body="scenarios" type="array of UUID" optional>
    Scenario UUIDs to run, each listed once. The list replaces the test run's current scenarios. Send an empty array to remove them all.
  </ParamField>
  <ParamField body="enable_tool_evaluation" type="boolean" optional>
    Turns tool call evaluation on or off. While it is on, the test run's agent version must have an API key and an assistant ID for voice agents.
  </ParamField>
</ApiSection>

Send only the fields you want to change. A field not listed above is rejected with `400`.
