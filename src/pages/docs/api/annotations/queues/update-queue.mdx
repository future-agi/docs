<Note>
On PUT, `name` and `label_ids` are required, and `annotator_ids` defaults to an empty list: a PUT without it removes every member, the creator included. Other fields you leave out keep their values. A `PATCH` to the same URL applies no defaults, so members stay unless you send `annotator_ids`. Only a queue manager, or an admin of its organization or workspace, can update it. `status` is not changed here: use [Update queue status](/docs/api/annotations/queues/update-status).
</Note>
