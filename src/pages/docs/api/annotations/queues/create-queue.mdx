<Note>
This endpoint does not link the queue to a project, dataset or agent definition. It does not apply `project_id`, `dataset_id` or `agent_definition_id`, so `project`, `dataset` and `agent_definition` come back `null`. To get the queue for one of them, use [Get or create default queue](/docs/api/annotations/queues/get-or-create-default).
</Note>
