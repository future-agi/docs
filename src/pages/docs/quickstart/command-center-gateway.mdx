<TLDR>
Send your first chat completion through Agent Command Center, then match the reply to its [gateway request log](/docs/command-center/features/observability) instead of relying on the reply alone.
</TLDR>

## The problem

A client pointed at OpenAI and one pointed at the gateway can both answer a question about the capital of France. The answer alone does not tell you which provider served it or whether the request passed through your gateway.

## What you'll build

A chat request you can follow from the client to its entry in Agent Command Center.

<Mermaid chart={`

You'll:

1. Send a chat completion using your gateway key.
2. Match a request ID, provider and model between the response and log.
3. Try another configured provider or stream a reply.

<Prerequisites title="Before you start">
- A Future AGI account. Sign up at [app.futureagi.com](https://app.futureagi.com).
- An Agent Command Center API key from **Settings > API Keys**. Keys start with `sk-agentcc-`.
- At least one [configured provider](/docs/command-center/features/providers), such as OpenAI, Anthropic or Google, with the model you plan to request.
</Prerequisites>

## Send one request

Point your existing OpenAI SDK at Agent Command Center by changing two lines: `base_url` and `api_key`. All providers work through the same API. No new SDK required.

Pick your client and send one chat completion to a model your provider exposes. [Route your first LLM request](/docs/get-started/route-your-first-llm-request) walks through the same request with screenshots of the key and provider setup.

```python
from agentcc import AgentCC

client = AgentCC(
    api_key="sk-agentcc-your-api-key-here",
    base_url="https://gateway.futureagi.com/v1",
)

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
)

print(response.choices[0].message.content)
# Output: Paris
```

## Match a response to a log entry

Use the Python OpenAI SDK client from the preceding section for this check. The raw-response call sends a **new** request with the message `Hello`; match that request, not the earlier one. The [response headers](/docs/command-center/api/headers#response-headers) identify the provider, elapsed milliseconds and model used.

```python
# Using the OpenAI SDK client from Step 1
response = client.chat.completions.with_raw_response.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello"}],
)

print(f"Provider:  {response.headers.get('x-agentcc-provider')}")
print(f"Latency:   {response.headers.get('x-agentcc-latency-ms')}ms")
print(f"Cost:      ${response.headers.get('x-agentcc-cost')}")
print(f"Cache:     {response.headers.get('x-agentcc-cache')}")
print(f"Model:     {response.headers.get('x-agentcc-model-used')}")

# Parse the actual response
completion = response.parse()
print(f"Response:  {completion.choices[0].message.content}")
```

Example output:

```
Provider:  openai
Latency:   423ms
Cost:      $0.000045
Cache:     miss
Model:     gpt-4o-mini
Response:  Hello! How can I help you today?
```

Then find the same request in the log:

1. Read `x-agentcc-request-id` from that same raw response.
2. Open **Agent Command Center > Logs**.
3. Locate the entry with the matching request ID.

   Compare the resolved model and provider with the headers. Read latency in milliseconds and [estimated cost](/docs/command-center/features/cost-tracking) in USD when model pricing is available. The cache header applies when [caching](/docs/command-center/features/caching) is enabled.

## Switch providers

Change the model name to route to a different provider. Reuse the same client:

```python
# OpenAI
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello"}]
)

# Anthropic
response = client.chat.completions.create(
    model="claude-sonnet-4-6",
    messages=[{"role": "user", "content": "Hello"}]
)

# Google Gemini
response = client.chat.completions.create(
    model="gemini-2.0-flash",
    messages=[{"role": "user", "content": "Hello"}]
)
```

Agent Command Center translates the request to each provider's native format. Your code doesn't change.

## Try streaming

Stream responses to show output as it arrives. Reuse the client for your chosen SDK. The key strings in these examples are placeholders, so keep your real key out of source control.

<Tabs items={["Python (Agent Command Center SDK)", "Python (OpenAI SDK)", "LiteLLM", "cURL"]}>

<Tab title="Python (Agent Command Center SDK)">

```python
stream = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Write a short poem about AI"}],
    stream=True,
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

## Use a framework client

Agent Command Center works with any OpenAI-compatible client. If you use LangChain, LlamaIndex, or any other framework that supports custom base URLs, just point it at `https://gateway.futureagi.com/v1` with your Agent Command Center key.

---

## Troubleshooting

- **The gateway rejects the key.** Check that the key is the Agent Command Center key from **Settings > API Keys** (prefix `sk-agentcc-`), not a provider key. Retry against the gateway URL and check for a request ID on the successful response.
- **The provider or model is unavailable.** Check that the provider is configured and exposes the requested model, then retry the same request.
