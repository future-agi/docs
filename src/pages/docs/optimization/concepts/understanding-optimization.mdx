## About

A customer writes, “The rain jacket is too small. Can I exchange it?” A helpful paragraph might answer the question, but Ridgeline Outfitters' routing software needs the single label `RETURNS`. Prompt optimization compares instructions by scoring **what the model produces**, not by judging how the instructions read.

| Instruction to the model | Example output | Exact-label score |
|---|---|---|
| Reply to the customer | Yes, we can help you exchange your jacket. | 0 |
| Return only the queue name | RETURNS | 1 |

## When to use

- You have a prompt that works on some inputs but fails repeatedly on others, such as exchanges that the router sends to shipping.
- You can say what a better answer looks like. For a queue name, an exact comparison with an expected label is enough. For a customer-facing reply, you'd need a different evaluation.
- You want to compare a rewrite with the prompt you already use before replacing it.

## A trial is one candidate prompt, scored row by row

In a dashboard dataset, the **baseline** is the original prompt from your chosen column. A **trial** runs a candidate prompt against dataset rows and scores the outputs with the evaluations attached to that column. The optimizer proposes candidates; the evaluations determine which candidates score well. The model can produce better prose without improving a routing score at all.

The dashboard lists the variations in trial order and flags the one with the highest average score. The baseline is a comparison point, not a contender for that flag. If every variation scores below the baseline, the best trial is still a regression. Compare it with the baseline before adopting it.

## Which examples count?

A dashboard dataset run takes up to the **first 50 rows in dataset order**. If those rows are all return requests, a prompt that always says `RETURNS` can look perfect. Include shipping and return requests in those rows, and keep separate tickets for a final check.

With Agent Learning Kit in Python, you supply the rows directly to `optimize()`. Each algorithm selects its evaluation data according to its own settings. For example, Meta-Prompt samples up to `eval_subset_size` rows each round. The dashboard's 50-row limit doesn't apply to that Python list.

## Where the results live

| If you start from... | What you compare |
|---|---|
| A dataset's **Optimization** tab | A completed run has a baseline, per-eval scores across trials, prompt differences, and row-level trial items. |
| Agent Learning Kit (`fi.alk.optimize`) | The call returns an `OptimizationResult` to your script. Inspect `history` for scored candidates and get the selected prompt from `best_generator`. Whether the starting prompt is itself scored depends on the algorithm. |

For an agent evaluated through environment runs rather than dataset rows, start with [Environments](/docs/environments).
