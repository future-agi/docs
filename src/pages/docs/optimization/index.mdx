## What is Optimization?

A run points at a prompt column, scores rewrites against the evals you pick, and keeps the winner. Reach for it when a prompt is scoring badly and manual tweaking isn't converging.

A run takes three things: the [prompt column](/docs/dataset/features/run-prompt) and the [evals](/docs/evaluation) you pick to define what "good" means, plus the optimizer algorithm you run them with.

Six optimizer algorithms can run a given prompt column and eval set. They're interchangeable in setup, but each searches for the new prompt differently, which is why [choosing an optimizer](/docs/optimization/concepts/choosing-an-optimizer) is worth doing deliberately.

The same engine also runs from inside Simulation, where it optimizes an agent's prompt using results from a simulation test run instead of a dataset column. See [optimization in Simulation](/docs/simulation/concepts/optimization) for that path.
