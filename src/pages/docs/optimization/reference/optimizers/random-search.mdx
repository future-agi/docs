## About

Random Search asks a teacher model for several ways to word the same instruction, then runs each variation on every row. Use it when you want to know whether rephrasing an instruction changes the answers, without using one candidate's score to write the next.

## Compare two ways to handle a return

Ridgeline Outfitters wants its agent to ask for an order number before starting a return. Give the candidate generator the original instruction and set `teacher_model` separately: changing the generator's model does not change the teacher.

In a Python 3.10 or later environment, install Agent Learning Kit:

```bash
python -m pip install agent-learning-kit==0.3.7
```

Set `OPENROUTER_API_KEY` in the shell where you run the script. OpenRouter generates the text. The local `Contains` metric gives a reply `1` if it includes “order number” (case-insensitive) and `0` otherwise. You do not need Future AGI keys for this example.

<CodeGroup titles={["Python"]}>

```python
from fi.evals.metrics.heuristics.string_metrics import Contains
from fi.opt.base.evaluator import Evaluator
from fi.opt.datamappers import BasicDataMapper
from fi.opt.generators import LiteLLMGenerator
from fi.opt.optimizers import RandomSearchOptimizer

model = "openrouter/openai/gpt-4o-mini"
tickets = [
    {"message": "The rain shell is too big. Can I send it back?"},
    {"message": "I would like to return my unused headlamp."},
]
prompt = (
    "You work at Ridgeline Outfitters. Ask for the detail you need before "
    "starting a return. Customer message: {message}"
)
evaluator = Evaluator(metric=Contains(config={"keyword": "order number"}))
mapper = BasicDataMapper(key_map={"response": "generated_output"})

generator = LiteLLMGenerator(model=model, prompt_template=prompt)
optimizer = RandomSearchOptimizer(
    generator=generator, teacher_model=model, num_variations=2,
)
result = optimizer.optimize(
    evaluator=evaluator,
    data_mapper=mapper,
    dataset=tickets,
)
print(f"Score: {result.final_score:.2f}")
print(result.best_generator.get_prompt_template())
```

</CodeGroup>

The script prints the highest mean score among the scored variations, then the selected template. Here `0.50` would mean one of the two replies contained “order number”. The original instruction is not automatically included as a scored baseline.

## Parameters

| `RandomSearchOptimizer(...)` argument | SDK default | What it controls |
|---|---|---|
| `generator` | Required | A `BaseGenerator` such as `LiteLLMGenerator`. Supplies the starting template and runs each candidate. |
| `teacher_model` | `"gpt-5"` | LiteLLM model asked to propose the variations. |
| `num_variations` | `5` | Number of variations requested from the teacher in one call. The optimizer scores the list the teacher actually returns. |
| `teacher_model_kwargs` | `{}` | Extra completion options for the teacher. The optimizer sets the response format to a JSON object. |
| `eval_template`, `eval_model_name` | `"summary_quality"`, `"turing_flash"` | Accepted by the constructor but not used to score variations. Configure the `evaluator` passed to `optimize()` instead. |

`optimize(evaluator, data_mapper, dataset, early_stopping=None)` returns an `OptimizationResult`. It sets the supplied generator's template to the selected prompt. There is no separate `initial_prompts` argument to configure.

## Limits and troubleshooting

- Each extra variation adds one task-model call per row. The example uses a local metric, so scoring the generated text does not need a second model.
- If the teacher call fails or its JSON cannot be parsed, the optimizer tries the original instruction with ` Be creative.` appended. A one-entry `result.history` may be a fallback, not a comparison of the requested variations.
- With early stopping, the variation that triggers the stop is recorded in `history` before the optimizer updates its best score. If the first variation triggers the stop, `final_score` remains `-1.0` and `best_generator` retains the original instruction. Compare `average_score` in the history entries to find the best scored variation.
