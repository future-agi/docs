## About

Meta-Prompt rewrites one instruction at a time. Each round scores the current prompt, then gives a teacher the row data, scores, evaluator reasons and earlier attempts. Use it when you can describe what the reply should do and want the teacher to revise the whole instruction.

## Score a prompt and its first rewrite

Ridgeline Outfitters wants its agent to ask for the order number before starting a return. Use `{message}` in the task prompt to insert each ticket. Give the teacher a different template, `{prompt}`: the optimizer uses this placeholder to send the full rewrite request.

With Python 3.12, install Agent Learning Kit in a virtual environment:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7
```

Set `OPENAI_API_KEY` in the shell where you run the script. Save the example as `meta_prompt.py` and run `python meta_prompt.py`. The local `Contains` metric gives a reply `1` if it includes “order number” (case-insensitive) and `0` otherwise. You do not need Future AGI keys for this example.

<CodeGroup titles={["Python"]}>

```python
from fi.evals.metrics.heuristics.string_metrics import Contains
from fi.opt.base.evaluator import Evaluator
from fi.opt.datamappers import BasicDataMapper
from fi.opt.generators import LiteLLMGenerator
from fi.opt.optimizers import MetaPromptOptimizer

model = "gpt-4o-mini"
tickets = [
    {"message": "The rain shell is too big. Can I send it back?"},
    {"message": "I would like to return my unused headlamp."},
]
prompt = (
    "You work at Ridgeline Outfitters. Ask for the detail you need before "
    "starting a return. Customer message: {message}"
)
evaluator = Evaluator(metric=Contains(config={"keyword": "order number"}))
mapper = BasicDataMapper(key_map={"response": "generated_output"})

teacher = LiteLLMGenerator(model=model, prompt_template="{prompt}")
optimizer = MetaPromptOptimizer(teacher_generator=teacher)
result = optimizer.optimize(
    evaluator=evaluator,
    data_mapper=mapper,
    dataset=tickets,
    initial_prompts=[prompt],
    task_description="Ask for the order number and keep the {message} placeholder.",
    num_rounds=2,
)
print(f"Score: {result.final_score:.2f}")
print(result.best_generator.get_prompt_template())
```

</CodeGroup>

The first round scores the starting instruction; the second scores the teacher's first rewrite. The script prints the best **scored** template and its mean score, not necessarily the newest rewrite. If the starting instruction ties its rewrite, the earlier prompt wins.

## Parameters

| Where | Argument | SDK default | Purpose |
|---|---|---|---|
| Constructor | `teacher_generator` | Required | `LiteLLMGenerator` that receives the rewrite request through `{prompt}`. |
| Constructor | `task_model` | `None` | LiteLLM model that answers tickets during scoring. If omitted, uses the teacher's model. |
| `optimize()` | `evaluator`, `data_mapper`, `dataset` | Required | Metric wrapper, evaluator input mapping, and rows to sample. |
| `optimize()` | `initial_prompts` | Required | List of starting templates; only the first is used. |
| `optimize()` | `task_description` | `"I want to improve my prompt."` | Objective shown to the teacher along with the evaluation results. |
| `optimize()` | `num_rounds` | `5` | Number of score-and-rewrite cycles. Use at least two to score a rewrite. |
| `optimize()` | `eval_subset_size` | `40` | Rows sampled without replacement each round, capped at the dataset size. |
| `optimize()` | `early_stopping` | `None` | Optional `EarlyStoppingConfig`, checked after scoring and before rewriting. |

## Limits and troubleshooting

An empty `initial_prompts` raises `ValueError`. If the teacher returns invalid rewrite JSON, the current prompt stays in place for the next round. Read `result.history` on the returned `OptimizationResult` to see what was actually scored.

If you used a separate `task_model`, the returned `best_generator` is configured with the teacher's model. To run the selected prompt on your task model, initialize a `LiteLLMGenerator` with that model and `result.best_generator.get_prompt_template()`.
