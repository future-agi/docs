## About

GEPA uses one model to run the prompt and a reflection model to propose changes. The reflection model sees what went into a candidate, what came out, and why the evaluator scored it that way. Use GEPA when the reasons for low scores can tell the model how to revise an instruction.

## Run a search with a metric-call budget

Ridgeline Outfitters' starting prompt asks why the customer wants a return. The policy you want instead is to ask for the order number first. The metric checks that phrase, and the example replies in the rows show what a good next question looks like.

With Python 3.12, install Agent Learning Kit in a virtual environment:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7
```

Set `OPENAI_API_KEY` in the shell where you run the script. Save the example as `run_gepa.py` and run `python run_gepa.py`. The local `Contains` metric gives a reply `1` if it includes “order number” (case-insensitive) and `0` otherwise. You do not need Future AGI keys for this example.

<CodeGroup titles={["Python"]}>

```python
from fi.evals.metrics.heuristics.string_metrics import Contains
from fi.opt.base.evaluator import Evaluator
from fi.opt.datamappers import BasicDataMapper
from fi.opt.optimizers import GEPAOptimizer

model = "gpt-4o-mini"
tickets = [
    {"message": "The rain shell is too big. Can I send it back?",
     "expected_reply": "Could you share your order number?"},
    {"message": "I would like to return my unused headlamp.",
     "expected_reply": "What is the order number for your headlamp?"},
]
prompt = (
    "You work at Ridgeline Outfitters. Ask why the customer wants a return. "
    "Reply with just that question. Customer message: {message}"
)
evaluator = Evaluator(metric=Contains(config={"keyword": "order number"}))
mapper = BasicDataMapper(key_map={"response": "generated_output"})

optimizer = GEPAOptimizer(reflection_model=model, generator_model=model)
result = optimizer.optimize(
    evaluator=evaluator,
    data_mapper=mapper,
    dataset=tickets,
    initial_prompts=[prompt],
    max_metric_calls=8,
)
print(f"Score: {result.final_score:.2f}")
template = result.best_generator.get_prompt_template()
print(template)
try:
    first, second = [template.format(message=row["message"]) for row in tickets]
except (KeyError, IndexError, AttributeError, ValueError):
    print("Check the template fields: a new ticket supplies only message.")
else:
    if first == second:
        print("The selected prompt ignores the customer message.")
```

</CodeGroup>

`result` is an `OptimizationResult`. If the run finishes without early stopping, `final_score` is the selected candidate's aggregate validation score. A budgeted search can return the starting prompt if nothing scores better. The script also checks whether changing the ticket changes the text sent to the model. A fixed request for an order number can score `1.00` on both tickets even if the selected template drops `{message}`. Do not use that template for a ticket-specific reply.

## Parameters

| Where | Argument | SDK default | Purpose |
|---|---|---|---|
| `GEPAOptimizer(...)` | `reflection_model` | Required | LiteLLM model identifier for reflection and prompt changes. |
| `GEPAOptimizer(...)` | `generator_model` | `"gpt-4o-mini"` | Model that answers tickets during scoring. Specify it as well as `reflection_model` when using a different provider. |
| `optimize()` | `evaluator`, `data_mapper`, `dataset` | Required | Metric wrapper, evaluator input mapping, and rows used by GEPA. |
| `optimize()` | `initial_prompts` | Required | Nonempty list. Only the first template is used as the seed. |
| `optimize()` | `max_metric_calls` | `150` | Evaluation budget passed to GEPA. Counts scored examples, not prompt variants, reflection calls or tokens. |
| `optimize()` | `early_stopping` | `None` | Optional `EarlyStoppingConfig` checked after a batch is evaluated. |

## Limits and troubleshooting

The optimizer passes the same `dataset` as GEPA's training and validation sets. `final_score` is not a held-out score. Before changing your agent, test the winning template on other tickets, including ones where asking for an order number would be inappropriate.

Passing `initial_prompts=[]` raises `ValueError: Initial prompts list cannot be empty for GEPAOptimizer.` If you get an unchanged template instead, inspect `result.history`: it contains the prompt, average score and per-row evaluation results for each batch. A keyword metric gives feedback about a missing phrase, not the overall helpfulness of the reply.
