Create a [prompt template](/docs/prompt/concepts/understanding-prompts) for a support agent and give it a name you can find again. Start with a description if you need help with the wording, a blank editor if you have it, or a template if your team has a pattern to reuse.

<Prerequisites title="Before you start">
- You need a [role](/docs/roles-and-permissions) of Member or above. Viewers cannot create prompts or use templates.
</Prerequisites>

## Open the prompt directory

1. Open **Prompts** in the left navigation.

   You should see **All Prompts** and **My templates**.

2. Select **Create prompt** in the directory toolbar.

   You should see the **Create a new prompt** modal with three options.

## Pick a starting point

Follow one of the three paths below.

### Generate with AI

Pick this when you don't have the wording yet and want a starting draft to edit.

1. Select **Generate with AI**.

   The platform creates the prompt and opens the editor, with the **Generate a prompt** drawer open on top of it.

2. Describe the job, for example: “Write a support agent that answers customer questions using our returns policy.”
3. Select **Generate**.
4. Review the proposed wording.
5. Select **Continue**.

   You should see the draft in the user message. The system message is still yours to write.

### Start from scratch

Pick this when you already know what the system and user messages should say.

1. Select **Start from scratch**.

   The editor opens empty right away.

2. Enter the system message that sets the support agent's role.
3. Enter the user message that asks the customer's question.

   Both messages are yours to edit; there is no generated draft to accept.

### Start with a template

Pick this when a team pattern for this kind of prompt already exists.

1. Select **Start with a template**.

   The template browser opens instead of the editor. To skip the modal and reach the same browser directly, select **Use template** in the directory toolbar instead.

2. Pick a category from the sidebar or search for a template by name.
3. Open the template preview.
4. Select **Use this template**.

   You should see its content in the new prompt. Editing this prompt doesn't change the base template.

## Name the prompt and reopen it

The generated and blank routes start with `Untitled-1` or the next free number in your organization. The template route starts with `Untitled-1-<template name>`.

1. Select the title in the editor header.
2. Enter a unique name, such as `support-agent` if it isn't already taken.
3. Return to the **Prompts** directory.
4. Open the prompt with that name.

   Check the title in the editor. If the rename didn't take, a blank name gives **Name cannot be empty**; a name already in use is also rejected. For disabled controls or a generation failure, see [Prompt troubleshooting](/docs/prompt/troubleshooting).

## Create a template from code

The [prompts SDK reference](/docs/sdk/reference/prompts) distinguishes `client.prompts.create` in Python and TypeScript (create a named template in the current workspace) from `client.prompts.generate` (draft wording from a description). The MCP tool listed for creation is `create_prompt_template`.
