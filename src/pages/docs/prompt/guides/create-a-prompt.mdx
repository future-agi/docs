---
title: "Create a prompt"
description: "Get from the Prompts directory to a named, open editor."
---

Every prompt starts in the same place: the Prompts directory, one modal, and a choice of how you want the editor to open. This guide covers all three.

<Steps>
  <Step title="Open Prompts">
    In the left navigation, click **Prompts**. You land in the directory, rooted at **All Prompts** and **My templates**.
  </Step>
  <Step title="Click Create prompt">
    In the directory toolbar, click **Create prompt**. This opens the **Create a new prompt** modal.
  </Step>
  <Step title="Pick how you want to start">
    Choose one of three options: **Generate with AI**, **Start from scratch**, or **Start with a template**.
  </Step>
</Steps>

## Generate with AI

Type a plain-language description of what the prompt should do, for example "write a support agent that answers customer questions using our returns policy." The platform generates the system and user content from that statement and opens the editor with it filled in.

## Start from scratch

The editor opens empty. There's no generated or templated content to review here: you write the system and user messages yourself.

## Start with a template

The template browser opens instead of the editor. Pick a category from the sidebar or search by name, open a template to preview it, then click **Use this template** to load its content into a new prompt. To skip the modal entirely, click **Use template** directly in the directory toolbar. It opens the same browser.

## Rename it

Whichever route you took, the new prompt opens named **Untitled-1** (or the next free number in your organization). Rename it before anything else: click the title in the editor header and type a name, for example `support-agent`.

<Note>
Leaving the name empty shows **"Name cannot be empty"** and the rename doesn't go through. A name another prompt in your organization already uses is accepted here, but rejected the first time you run the prompt.
</Note>
