When a [prompt library](/docs/prompt) is hard to scan, group templates by team, task or product. Move `support-agent` into a folder, then use the breadcrumbs to find it in its new location.

<Prerequisites title="Before you start">
- An editable template, such as `support-agent` from [Create a prompt](/docs/prompt/guides/create-a-prompt). Sample prompts have no row menu, regardless of your role.
- A [workspace role](/docs/roles-and-permissions) that can edit prompts. For a Viewer, **New Folder** is disabled and the row menu for **Move**, **Rename** and **Delete** does not appear.
</Prerequisites>

## Create a destination folder

1. Open **Prompts** in the left navigation.
2. Click **New Folder** in the left tree.
3. Enter a name in **Create new folder**.

   A folder name already in use in this workspace is rejected.

4. Click **Create**.

   You should now be inside the new folder.

## Move the template

1. Click **All Prompts** in the breadcrumbs.
2. Open the three-dot menu on the `support-agent` row.
3. Select **Move**.

   The dialog title identifies the template: **Move "support-agent"**.

4. Open **Select folder**.
5. Choose the destination folder.

   Once a prompt is filed, the dropdown can move it to another folder but cannot return it to an unfiled state.

6. Click **Move**.

   The prompt moves immediately.

7. Open the destination folder to check for the `support-agent` row.

## Rename a folder or prompt

1. Open the row menu for the folder or prompt.
2. Select **Rename**.
3. Enter the new name.
4. Click **Save**.

   If the change is rejected, check for a name already used in the workspace. Prompt names and folder names must be unique.

## Delete a folder or prompt

<Warning>
Deleting a folder deletes every prompt and [prompt version](/docs/prompt/concepts/versions-and-labels) inside it. Move anything you still need out first.
</Warning>

1. Open the row menu for the item you intend to remove.
2. Select **Delete**.
3. Confirm **Delete** in **Delete folder** or **Delete prompt**.

## Find a prompt later

| Directory control | Use it to |
| --- | --- |
| All Prompts | Return to every prompt and folder in the workspace. It is a top-level entry in the left tree, so you don't have to click back through each folder you opened. |
| My templates | Jump to the prompts you've saved as reusable templates. It is the other top-level entry in the left tree. |
| Sort | Order the current view by **Name** or **Last modified**. |
| Search | Use **Search in prompts** under **All Prompts**, or **Search in templates** under **My templates**. |

Create, rename and delete folders in the dashboard directory. The [platform SDK reference](/docs/sdk/reference/prompts#promptsupdate) lists `prompt_folder` on prompt-template creation and updates in Python and TypeScript. That field belongs to a template; it is not an operation for creating, renaming or deleting a folder.
