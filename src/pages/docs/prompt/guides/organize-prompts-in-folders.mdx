---
title: "Organize prompts in folders"
description: "Group prompts into folders, move, rename, and delete them, and find any prompt fast as your library grows."
---

Once a prompt library grows past a handful of templates, a flat list stops working. Folders let you group prompts by team, task type, or project, and the workbench's search and sort controls help you find one fast when you can't remember which folder it's in.

<Steps>
  <Step title="Create a folder">
    In the left sidebar, click **New Folder**. In the **Create new folder** modal, enter a name and click **Create**. You land inside the new folder.

    <Warning>
      Folder names must be unique within your workspace. If another folder already has that name, the create fails.
    </Warning>
  </Step>
  <Step title="Move a prompt into a folder">
    Open a prompt's row menu and select **Move**. The modal opens titled **Move** with the prompt's name, and a **Select folder** dropdown. Pick a destination and click **Move**. The prompt moves immediately.
  </Step>
  <Step title="Rename a folder or a prompt">
    Open the row menu for a folder or a prompt and select **Rename**. Update the name and click **Save**.
  </Step>
  <Step title="Delete a folder or a prompt">
    Open the row menu and select **Delete**. Confirm in the dialog.

    <Warning>
      Deleting a folder deletes every prompt and prompt version inside it. There's no partial delete, so move anything you still need out first.
    </Warning>
  </Step>
</Steps>

## Find a prompt

As the library grows, use the workbench's own navigation instead of scrolling the tree:

- **Search bar**: filter the list by prompt name as you type.
- **All Prompts** and **My templates**: breadcrumb roots at the top of the tree. **All Prompts** shows everything in the workspace; **My templates** scopes the view to prompts you created.
- **Sort**: sort the current view by **Name** or **Last modified**.

<Note>
  New Folder, Move, Rename, and Delete are role-gated. If your role doesn't have permission, the controls appear disabled.
</Note>
