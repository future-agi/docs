---
title: "Commit & compare versions"
description: "Turn a draft into a version you can point to, then compare up to three side by side"
---

A prompt starts out as a draft you're still editing. Committing turns that draft into a version you can point to, one that sticks around after you move on. This guide covers the two ways to commit, setting an already-committed version as default on its own, and comparing versions once you have more than one.

## Commit a draft

Commit stays disabled until you've run the prompt at least once. Hover the greyed-out button and the tooltip tells you why: **"Please run the prompt before saving and committing."**

Once you've run it, commit from either place:

- The **Commit** button in the editor header
- **Save and commit** in the more-actions menu

Both open the same **Commit changes to prompt** dialog. Write a **Commit message** describing what changed, then choose how to save it:

- **Commit**: saves the version as is
- **Commit and set as a default version**: saves the version and also makes it the [default](/docs/prompt/concepts/versions-and-labels)

## Set an existing version as default

You don't have to decide at commit time. Open the more-actions menu on a version you've already committed and choose **Set as default**. It's disabled the same way Commit is, while the version is still a draft, with its own tooltip: **"Please run the prompt before setting it as default."**

## Compare versions

Select the versions you want to look at together and open the comparison. You can also have it re-run each one, so you're comparing fresh output instead of just the saved text.

<Note>
Three is the hard cap. Try to add a fourth and it's rejected outright: **"Maximum of 3 versions are allowed."** Pick your three deliberately rather than adding versions as you go.
</Note>

## Promoting to Production

Comparing tells you which version you want live. Making it live isn't a commit or compare action, it's a labeling action: you point the Production label at the version you picked. That's covered in [Versions & Labels](/docs/prompt/concepts/versions-and-labels), and today the way to actually reassign a label is through the [Prompt Workbench SDK](/docs/prompt/features/sdk).
