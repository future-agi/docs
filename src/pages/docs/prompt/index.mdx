## What is Prompt?

A prompt template is a named, versioned object that lives on the platform, not a string hardcoded in your application. The editor is where you compose it, run it, score it, and watch how it performs in production.

Prompt connects outward to the rest of the platform:

- Run a prompt against [Dataset](/docs/dataset/features/run-prompt) rows to generate outputs at scale
- Score its outputs with [Evaluations](/docs/evaluation)
- Simulate a prompt against test conversations from the editor's [Simulation tab](/docs/simulation/features/prompt-simulation)
- Read its production metrics from [Observe](/docs/observe) traces
