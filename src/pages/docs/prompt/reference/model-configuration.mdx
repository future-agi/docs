<Note>
  This page covers the fields on a [prompt template](/docs/prompt/concepts/understanding-prompts)'s model configuration and the limits that apply when you save or run one. For which models are available in your workspace, see [AI Providers](/docs/admin-settings/ai-providers) in Admin & Settings.
</Note>

## Generation parameters

| Field | Type | Valid range | Default |
|---|---|---|---|
| `temperature` | number | 0.0 to 2.0 | Unset, provider default |
| `frequency_penalty` | number | -2.0 to 2.0 | Unset, provider default |
| `presence_penalty` | number | -2.0 to 2.0 | Unset, provider default |
| `top_p` | number | 0.0 to 1.0 | Unset, provider default |
| `max_tokens` | integer | 1 to 65536 | Unset, provider default |

A value outside its range is rejected.

## Output and tool settings

| Field | Valid values | Default |
|---|---|---|
| `output_format` | `array`, `string`, `number`, `object`, `audio`, `image` | `string` |
| `tool_choice` | `auto`, `required`, or unset | Unset |
| `tools` | A list of tool IDs | Unset |
| `response_format` | A JSON schema object, a string, or the ID of a saved [response schema](#response-schemas) | Unset |

<Note>
  `tools` and `response_format` are checked against what actually exists in your workspace. An ID that doesn't resolve to a real tool or response schema is rejected, not silently dropped.
</Note>

## Structural limits

| Item | Limit |
|---|---|
| Messages | An ordered list of `{role, content}` objects. `role` must be `system`, `user`, or `assistant`; `content` must be a string. Any other role is rejected |
| Prompt template name | Up to 2000 characters |
| Base template name | Up to 255 characters |
| Folder name | Up to 255 characters |
| Version name | Must match `v` followed by digits, for example `v1`, `v12`. Anything else is rejected |
| Version comparison | Up to 3 versions at once. A fourth is rejected |
| Concurrency | 1 to 10, default 5. A value over 10 is rejected |
| Timeout retry | A model call that times out is retried automatically, up to 10 times, with the delay backing off from 1 second toward a 10 second cap |

## Response schemas

A response schema is a saved shape that `response_format` can point at by ID instead of an inline JSON schema object.

| Field | What it means |
|---|---|
| `schema_type` | `json` or `yaml` |
| Uniqueness | The schema's name is unique within its organization and workspace |
| Referenced by | `response_format`, by the schema's ID |
