## About

This page is the record of every Future AGI feature, flow, API behavior, and SDK package or version that is deprecated or has been removed, newest first. Each entry says what changes, when it takes effect, and what to do about it.

The weekly [release notes](/docs/release-notes) report changes as they ship, including changes that retire nothing but may need action, such as a stricter authentication rule or a new default. Those stay in the release notes, not here. This page keeps every deprecation and removal in one place, so you can check whether anything you rely on is affected without reading every week.

## Lifecycle

Every entry on this page has one of these statuses.

| Status | What it means | What to do |
|---|---|---|
| **Deprecation planned** | A replacement exists or is on the way. The current feature still works. | Plan the move. Nothing breaks yet. |
| **Deprecated** | Still works, but is no longer recommended and will be removed. | Move new work to the replacement and migrate existing use before the removal date. |
| **Removed** | No longer available. Calls or code that use it fail. | Follow the entry's steps to remove or replace it. |

The version listed is the first platform release that includes the change, and the date is that release's date. On a self-hosted deployment, the change takes effect when you upgrade to that version or later.

## RAG prompt optimization

**Status**: Removed in platform v1.59.0, released 2026-11-18.

RAG prompt optimization tuned a RAG prompt template against a knowledge base. It is no longer available.

### What changed

- Starting a RAG prompt optimization now fails with HTTP 400 and the message `RAG prompt optimization is not available.` No optimization is created and no work is scheduled.
- A RAG optimization that was still queued when the change reached your deployment fails with the same message when it runs.
- Only the RAG type is removed. Prompt-template optimization, the other type in the same flow, still runs as before.
- Dataset optimization, run from a dataset's **Optimization** tab, is a separate feature and is not affected.

### What to do

1. Search your scripts and integrations for code that starts a RAG prompt optimization, or for the error message above, and remove those calls.
2. No replacement has been announced for RAG prompt optimization. To improve a prompt column with evals as the judge, dataset optimization runs optimizers such as GEPA over your dataset. See [Run an optimization](/docs/optimization/guides/run-an-optimization).

## `agent-opt` Python package

**Status**: Deprecation planned. No removal date is set yet.

The optimizer engine from the `agent-opt` package now also ships in Agent Learning Kit (`agent-learning-kit` on PyPI), under the same `fi.opt` module path. For example, `fi.opt.optimizers` provides `RandomSearchOptimizer` in both packages.

### What changes

- Nothing breaks today. `agent-opt` keeps working.
- The optimization guides and cookbooks will move their install line from `pip install agent-opt` to `pip install agent-learning-kit`.

### What to do

- Existing projects can keep `agent-opt` for now.
- When you switch, install `agent-learning-kit` in a fresh virtual environment, or uninstall `agent-opt` first. Both packages ship the `fi.opt` modules, so installing one over the other leaves two packages owning the same files.
- This entry gets a date when the deprecation is scheduled. Check back here or in the [release notes](/docs/release-notes) before you upgrade.
