---
title: "Fix with your coding agent"
description: "Let Claude Code, Cursor or Codex fix a failed run, and have Future AGI check the change"
---

You can fix a failed run with your own coding agent instead of an [Epoch](/docs/environments/concepts/epoch) search. Your agent reads what failed, edits your agent's code on your machine, and submits the change. Future AGI checks every fix on cases your agent wasn't given, and sends back the verdict.

<Note>
**Copy for coding agent** shows only when your deployment has turned this feature on. If you don't see it, ask your workspace admin.
</Note>

## Set up

You need the Future AGI CLI, and you can add the MCP server so your coding agent can read the brief as a tool.

1. Install the CLI with `npm i -g @future-agi/cli`, or run it without installing as `npx @future-agi/cli` in place of `fagi`
2. Sign in with `fagi login`
3. Optional: connect the MCP server. Go to **Settings**, then **MCP Server**, and pick your tool. The **Codex** tab gives you the `~/.codex/config.toml` entry (`[mcp_servers.futureagi]` with the server URL) and the command `codex mcp login futureagi`. **IDE & coding agents** further down the page has the steps for Claude Code, Cursor and Codex

## Copy the brief for your agent

Open the failed run's Epoch page and click the **⋯** menu, then **Copy for coding agent**. On an Error Feed issue, use **Copy for coding agent** on the issue's Epoch strip.

<img src="/images/docs/environments/guides/fix-with-your-coding-agent/copy-menu.png" alt="The menu on an Epoch page open on Copy for coding agent, with Copy epoch ID, Download patch and Export epoch below it" style={{ borderRadius: '5px' }} />
*The same button is on the Epoch strip of an Error Feed issue*

Paste what it copied into Claude Code, Cursor or Codex. It holds the setup steps for the CLI and the instructions: read the brief, fix the code, submit it. Your agent then does the work:

```sh
fagi epoch brief --run <run id>
fagi epoch submit --run <run id> --summary "<what you changed and why>"
fagi epoch verdict <attempt id> --wait
```

- `fagi epoch brief` reads what failed in the run. With the MCP server connected, your agent can call the tool `get_epoch_coding_agent_brief` instead
- `fagi epoch submit` sends the change from the current folder. Add `--dir` to point at another folder, and `--summary` to say what you changed
- `fagi epoch verdict --wait` waits for the checks and prints the result

## What Future AGI checks

Future AGI checks every attempt as an Epoch. It runs the checks on the cases your coding agent was given, and on cases it wasn't given. Your agent gets the result back as checks and tiers only, so it can't tune the fix to the cases it never saw.

The change must also leave locked paths alone. A path locked for the run stays locked on every attempt.

## Read the attempt

An attempt opens as an Epoch, headed **Attempt 2 from your coding agent**, with your agent's note and the checks it passed or failed. The Epochs list marks attempts the same way.

<img src="/images/docs/environments/guides/fix-with-your-coding-agent/attempt.png" alt="Epoch 4 headed Attempt 2 from your coding agent, with the agent's note and the checks Change is valid, Target scenarios, Held-back scenarios, Must-pass scenarios and Holds over repeats, where Held-back scenarios failed" style={{ borderRadius: '5px' }} />
*A failed check says which one, so your agent knows what to change*

<img src="/images/docs/environments/guides/fix-with-your-coding-agent/epochs-list.png" alt="The Epochs tab listing Epoch 5, Attempt 3 from your coding agent, Failed, and Epoch 4, Attempt 2 from your coding agent, No safe improvement" style={{ borderRadius: '5px' }} />
*Attempts sit in the same list as the Epochs Future AGI runs itself*

When the checks pass, the Epoch ends **Ready for review**, and you [review it and ship it](/docs/environments/guides/review-an-epoch) like any other. When a check fails, your agent changes the fix and submits it again.

Shipping a change that didn't pass is your decision, in Future AGI. A coding agent can't override a refused change.

## Limits

- A run takes at most 4 attempts
- Each attempt has its own budget
- An attempt that stopped before Future AGI checked the change doesn't count toward the 4. The page says so, and your agent can submit it again

*A stopped attempt doesn't use one of the four*
