## About

An environment lets you test what your agent does, not just what it says. Suppose the Ridgeline Outfitters support agent tells a shopper, “I've started your return.” If you connect the agent's code, you can give it a test order for a rain jacket and check whether it recorded the return. If you connect a Vapi assistant instead, the call uses that assistant's tools. Point them at test records: the environment doesn't make a copy of your order system.

## Choose where to run the test

| If you have… | Use | What you run |
|---|---|---|
| An agent you want to test in the dashboard | **Simulate → Environment** | Connect a GitHub repository, upload code, or connect a hosted assistant. The builder describes the agent in a [contract](/docs/environments/concepts/contracts) and generates [scenarios](/docs/environments/concepts/scenarios-and-trials). Run them and inspect each call. |
| A test you want to keep in your repository and run locally or in CI | [Agent Learning Kit for Python, version 0.3.7](https://pypi.org/project/agent-learning-kit/0.3.7/) | `alk run` reads a local manifest file, not a dashboard environment ID. The starter manifest runs a scripted example; it does not connect to the Ridgeline agent. |
| A test saved in the legacy **Run Simulation** workflow | [Platform SDK simulation reference](/docs/sdk/reference/simulation) or the MCP tool `run_simulation` | Both `client.simulation.tests.run` and `run_simulation` take a saved test's `run_test_id`. The returned `execution_id` identifies that execution. Neither starts a dashboard environment run or an Epoch. |

**Why do I only see Environment?** With the [Python platform client](/docs/sdk/reference#the-client) authenticated to the same organization as the dashboard, check `client.account.whoami().restrict_simulate_to_environments`. If it is `True`, **Environment** is the only item under **Simulate**. If it is `False`, the menu also includes **Scenarios** and **Run Simulation**. This flag controls dashboard access to the legacy pages, not access to their APIs. MCP can still list `run_simulation` when the tool is enabled.

## How Environments connects to other features

- [Evaluations](/docs/environments/guides/add-evaluations) grade calls alongside the scenario's own goals. For the Ridgeline return, a polite reply and a recorded return are two different things to check.
- [Epoch](/docs/environments/guides/run-epoch) can propose a change to an eligible GitHub or uploaded agent, but not to a provider-hosted assistant. On a finished environment run, **Debug failures → Diagnosis → Improve** opens the setup form when Epoch is enabled and the diagnosis finds a problem. You choose the failing cases to fix and the passing cases to protect before starting the Epoch.

Use the dashboard for this workflow. The Python platform SDK (`futureagi` 0.8.0) has no `client.environments` resource, and `fagi` 0.2.2 has no Epoch command.
