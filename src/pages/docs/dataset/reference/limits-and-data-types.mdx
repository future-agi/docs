A lookup page for the numbers and enums referenced elsewhere in the Dataset docs: what each column data type stores, limits on names, rows, columns, and requests, column and cell statuses, and the separate limits and statuses for experiments.

## Column data types

| Type | Stores |
|---|---|
| `text` | A text value |
| `boolean` | True or false |
| `integer` | A whole number |
| `float` | A decimal number |
| `json` | A JSON object |
| `array` | A JSON array |
| `image` | A single image |
| `images` | Multiple images |
| `datetime` | A date and time value |
| `audio` | An audio file |
| `document` | A document file |
| `persona` | A persona definition |
| `others` | A value that doesn't fit any other type |

## Dataset and column limits

| Limit | Value | Applies to |
|---|---|---|
| Dataset name length | 2000 characters, unique within the organization | Every dataset |
| Column name length | 255 characters | Every column you name |
| Blank-grid rows in the dashboard | 0–100; defaults to 0 | Starting with named and typed columns, with optional empty rows |
| Blank-grid columns in the dashboard | 20 | Defining columns in the creation form |
| Manual dataset rows through REST | 100 maximum | Creating a dataset manually; zero rows requires a named column schema |
| Manual dataset columns through REST | 100 | Creating a dataset manually |
| Empty dataset rows | 10 | Creating an empty dataset |
| Empty rows per request | 100 | Adding empty rows to an existing dataset |
| Row duplication | 100 copies | Duplicating a row |
| Bulk delete | 50 items | Deleting datasets in bulk |
| Dataset list page size | 100 datasets | Listing datasets |
| File upload size | 25 MiB (shown as 25 MB in the dashboard) | Uploading a file to create or add to a dataset |
| Dashboard file upload formats | `.csv`, `.json`, `.jsonl` | Creating a dataset or adding rows in the dashboard; Excel files aren't accepted |
| REST file upload formats | `.csv`, `.xls`, `.xlsx`, `.json`, `.jsonl` | Uploading a file through the REST API |

<Note>
  These are per-request, per-object, or dashboard form limits. Plan-level quotas, such as the total rows or datasets your organization can hold, are enforced separately by the usage system and aren't part of this table.
</Note>

## Status values

Column statuses and cell statuses are separate sets, and a column only reaches the ones below.

| Status | Seen on | Meaning |
|---|---|---|
| `Running` | Column | Set when a column starts an async run, such as Run Prompt, an evaluation, or Retrieval |
| `PartialExtracted` | Column | Set when file upload extraction succeeds for some of a column's cells and fails for others |
| `Completed` | Column | The default status for a new column, and set when a column finishes running successfully |
| `Failed` | Column | Set when a column's processing raises an error, for example during a data type conversion |
| `pass` | Cell | Computed successfully (the default) |
| `running` | Cell | Set while a cell is computing |
| `error` | Cell | Set when a cell fails to compute |

## Experiment limits and statuses

[Experiments](/docs/dataset/guides/run-an-experiment) have their own creation limits and execution statuses. These are separate from the column and cell values above.

### Creation limits

| Limit | Value | Applies to |
|---|---|---|
| Experiment name length | 255 characters | Creating an experiment |
| Expanded runs | 12 maximum | The dashboard creation wizard |
| Initial row concurrency | 10 concurrent rows | Dispatch when an experiment is first created |

Each prompt/model pair counts as a separate run, and an agent card counts as one run. For example, two prompt cards with three models each count as six runs. The 12-run limit is a dashboard wizard limit, not a documented REST API maximum.

The creation wizard doesn't offer trial or concurrency controls.

### Statuses and list actions

The experiment list recognizes these statuses. **Rerun Experiment** and **Stop Experiment** depend on the experiment's status, not on the status of an individual column or cell.

| Status value | Displayed as | List action |
|---|---|---|
| `NotStarted` | Not Started | **Stop Experiment** is disabled |
| `Queued` | Queued | **Stop Experiment** |
| `Running` | Running | **Stop Experiment** |
| `Completed` | Completed | **Rerun Experiment** |
| `Cancelled` | Cancelled | **Rerun Experiment** |
| `Failed` | Failed | **Rerun Experiment** |
| `Editing` | Editing | Neither rerun nor stop |
