---
title: "Use splits"
description: "Organize current dataset rows into named subsets, filter by split, and export training files."
---

A **split** is a named subset of a dataset's current rows, such as `edge-cases`, `train`, or `validation`. A row can belong to several splits. Split membership, renames, and deletions save immediately.

## Create a split

<Steps>
  <Step title="Open Manage splits">
    On the dataset's **Data** tab, open the split filter in the toolbar, then click **Manage splits…**.
  </Step>
  <Step title="Name the split">
    Enter a new name, such as `edge-cases`, and click **Create split**. Use lowercase letters, digits, dots, dashes, or underscores, and a name that isn't already used in this dataset.
  </Step>
</Steps>

**Manage splits** lists each split's name, description, color, and row count. You can edit the name or description, or choose a different color, in the same dialog. Each change saves as you make it; **Done** closes the dialog.

## Add or remove a row

Open the row's **Row view**. If you have permission to edit the row, click **+ Split** in its header, then choose a split to add the row to it. Choose a split the row already belongs to to remove that membership. Repeat for any other splits the row belongs in.

The row's split chips show its memberships. Changing one membership doesn't remove the row from its other splits.

## Filter the grid by split

Open the toolbar's split filter and select the splits you want to see. You can search for a split by name.

- Select **No split** to find rows without any split membership.
- Click **Clear** in the filter to remove the split filter.
- Click **Manage splits…** to create or edit splits without leaving the dataset.

Filtering changes which rows you see, not which splits they belong to.

## Delete a split

In **Manage splits**, click the split's delete icon, then confirm with **Delete split**. The split and its memberships are removed immediately. The rows and their cell values stay in the dataset.

## Export training files

Once at least one split exists, **Manage splits** offers **Export as training set…**. Open it to choose splits and prepare files from their current saved rows in **OpenAI fine-tune JSONL (chat messages)** format.

This workflow downloads files; it does not start a fine-tuning job. Use your training provider to run that job separately.

<Note>
The dataset toolbar's **More > Download…** is a separate export workflow. It exports all current rows, regardless of the grid's split filter or selected rows. See [Export a dataset](/docs/dataset/guides/manage-datasets#export-a-dataset) for its formats and options.
</Note>
