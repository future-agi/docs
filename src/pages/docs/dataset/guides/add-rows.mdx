Your [dataset](/docs/dataset/concepts/understanding-datasets) exists, and now you have more examples for it. This guide covers five ways to add them. Whichever you pick, new rows land after the rows already there, in the order you add them. The paths differ in what happens to columns: copying skips unmapped columns, while file and Hugging Face imports create a column for any name the dataset doesn't already have.

<Prerequisites title="Before you start">
- Open the destination dataset, or [create a dataset](/docs/dataset/guides/create-a-dataset) first.
- Wait for any file processing or synthetic generation to finish. **Add Row** is disabled until it does.
</Prerequisites>

## Choose how to append rows

On the dataset's **Data** tab, click **Add Row** to open the drawer, which has a tile for each way to add rows. To duplicate rows you already have, start from the grid instead.

### Enter or duplicate a few rows

Use this for typing in one or two examples by hand.

1. Pick **Add empty row** in the drawer.
2. Choose how many rows to add.

   The picker tops out at 10 at a time. The API accepts up to 100 empty rows per request. The new rows appear at the bottom of the table with empty cells.

3. Double-click a cell to enter a value.
4. Repeat for the remaining cells.

Instead of starting blank, you can duplicate rows you already have:

1. Select the rows in the grid.
2. Click **Duplicate** in the toolbar.
3. Set the number of copies, at most 100.

   Duplicating a row needs update access.

### Copy rows from a dataset or experiment

Use this when the rows you need already exist somewhere else.

1. Select **Add from existing model dataset or experiment**.
2. Pick the source: another dataset, or an [experiment](/docs/dataset/guides/run-an-experiment) snapshot.
3. Map each source column to a column in this dataset.

   Only mapped columns copy over. Anything left unmapped in the source is skipped.

### Import from Hugging Face

Use this to pull in a public dataset instead of typing examples by hand.

1. Select **Import from Hugging Face**.
2. Search for the dataset.
3. Pick the subset.
4. Pick the split, next to the subset.
5. Set how many rows to import.
6. Start the import.

   Each Hugging Face feature is matched to a column by name. A name that doesn't exist yet becomes a new column, backfilled with empty cells on the rows that already existed.

### Import a file

Use this for a CSV, Excel, JSON or JSONL export you already have.

1. Select **Upload a file (JSONl/ JSON/ CSV)**.
2. Upload the file. It can be `.csv`, `.xls`, `.xlsx`, `.json` or `.jsonl`, up to 25 MB.

   Column names in the file are matched to existing columns by name. A name that isn't already a column gets created, backfilled with empty cells on the rows that already existed.

## Append examples from code

Use this when you're scripting the setup or pushing rows from your own pipeline. The examples append two support questions to `support-agent-eval`. Column names must already exist in the dataset, so it needs `user_query`, `response_quality` and `is_helpful`. The [SDK example that creates the dataset](/docs/dataset/guides/create-a-dataset#add-data-using-the-sdk) adds them.

| Setting | What to use | Where to find it |
| --- | --- | --- |
| `FI_API_KEY`, `FI_SECRET_KEY` | Your API key and secret key | [API keys](/docs/admin-settings/api-keys) |
| Dataset name | The dataset to append to, for the Python and TypeScript examples | Dataset list |
| Dataset ID | The same dataset's ID, in place of `<dataset_id>` in the cURL URL | The **Data** tab of a dataset created with **Add data using SDK** shows it |

`<fi_api_key>` and `<fi_secret_key>` are placeholders. If your environment already sets both keys, leave those two lines out, and don't put live keys in source.

<CodeGroup>

```python Python
# pip install futureagi

import os
from fi.datasets import Dataset
from fi.datasets.types import Cell, Row

os.environ["FI_API_KEY"] = "<fi_api_key>"
os.environ["FI_SECRET_KEY"] = "<fi_secret_key>"

dataset = Dataset.get_dataset_config("support-agent-eval")

rows = [
    Row(cells=[
        Cell(column_name="user_query", value="How do I reset my password?"),
        Cell(column_name="response_quality", value=7),
        Cell(column_name="is_helpful", value=True),
    ]),
    Row(cells=[
        Cell(column_name="user_query", value="What's your refund policy?"),
        Cell(column_name="response_quality", value=9),
        Cell(column_name="is_helpful", value=True),
    ]),
]

dataset = dataset.add_rows(rows=rows)
```

```typescript Typescript
import { Dataset, createRow, createCell } from "@future-agi/sdk";

process.env["FI_API_KEY"] = "<fi_api_key>";
process.env["FI_SECRET_KEY"] = "<fi_secret_key>";

async function main() {
  const dataset = await Dataset.open("support-agent-eval", { createIfMissing: false });

  const rows = [
    createRow({
      cells: [
        createCell({ columnName: "user_query", value: "How do I reset my password?" }),
        createCell({ columnName: "response_quality", value: 7 }),
        createCell({ columnName: "is_helpful", value: true }),
      ],
    }),
    createRow({
      cells: [
        createCell({ columnName: "user_query", value: "What's your refund policy?" }),
        createCell({ columnName: "response_quality", value: 9 }),
        createCell({ columnName: "is_helpful", value: true }),
      ],
    }),
  ];

  await dataset.addRows(rows);
}

main();
```

```bash Curl
curl --request POST \
  --url https://api.futureagi.com/model-hub/develops/<dataset_id>/add_rows/ \
  --header 'content-type: application/json' \
  --header 'X-Api-Key: <fi_api_key>' \
  --header 'X-Secret-Key: <fi_secret_key>' \
  --data '{
  "rows": [
    {
      "cells": [
        { "column_name": "user_query", "value": "How do I reset my password?" },
        { "column_name": "response_quality", "value": 7 },
        { "column_name": "is_helpful", "value": true }
      ]
    },
    {
      "cells": [
        { "column_name": "user_query", "value": "What'\''s your refund policy?" },
        { "column_name": "response_quality", "value": 9 },
        { "column_name": "is_helpful", "value": true }
      ]
    }
  ]
}'
```

</CodeGroup>

Open the grid and scroll to the bottom. The password-reset and refund-policy questions should be the last two rows. A `Row` accepts an `order`, but new rows are always appended after the last existing one, whatever order you pass, so it isn't how you control placement. See the [Datasets SDK](/docs/sdk/datasets) page for the full `Dataset` class.

The [MCP server](/docs/falcon-ai/guides/use-the-mcp-server) has the same operation as the `add_dataset_rows` tool, and `get_dataset` reads the rows back. Over REST, [Add Rows from HuggingFace](/docs/api/datasets/add-rows-from-huggingface) imports Hugging Face rows into an existing dataset.

## Troubleshooting

- **Add Row is greyed out:** the dataset is still processing, or synthetic generation hasn't finished. Wait for it to finish.
- **The upload is rejected:** check the file's extension and size against the [dataset limits](/docs/dataset/reference/limits-and-data-types).
- **A copied column is missing:** check its mapping. Only mapped columns copy over.
- **An import created a column you didn't expect:** imports match columns by name, so a file header or feature name that differs from an existing column becomes a new column.
- **A column you expected is gone:** the grid can hide columns. See [dataset troubleshooting](/docs/dataset/troubleshooting).
