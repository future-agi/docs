---
title: "Manage datasets"
description: "Find, duplicate, export, and clean up datasets and their columns once the data is already in"
---

Once a dataset has data in it, the work shifts from adding rows to keeping the table itself in order: finding the right dataset, making a copy, pulling data out, fixing a column, or getting rid of what you no longer need. This guide covers all of that on an existing dataset. For putting data in, see [Create a dataset](/docs/dataset/guides/create-a-dataset), [Add rows](/docs/dataset/guides/add-rows), and [Add columns](/docs/dataset/guides/add-columns).

## Find a dataset in the list

The dataset list shows **Dataset Name**, **Datapoints**, **Experiments**, **Optimizations**, **Derived**, and **Created** for every dataset in the list. Use the search box above the table to filter by name. If nothing matches, the list shows **No datasets found** instead of an empty table.

The list is paginated; see [Limits & Data Types](/docs/dataset/reference/limits-and-data-types) for the page size.

## Act on several datasets at once

Select more than one dataset with the row checkboxes and a bulk action bar appears, showing **{'{n}'} Selected** and four actions: **Duplicate**, **Compare**, **Delete**, and **Cancel**. Duplicate and Delete behave the same as their single-dataset versions below, just applied to every dataset you selected. Compare opens a comparison view across the selected datasets. Cancel clears the selection without doing anything.

## Duplicate a dataset

Click **Duplicate** on a dataset to open the **Duplicate Dataset** dialog. Enter a name for the copy in **Enter Dataset Name**, then click **Create**. The dialog validates the name before it lets you proceed, and a success toast confirms once the copy exists. Click **Cancel** to back out without duplicating anything.

The duplicate is a separate dataset from the moment it's created: editing it doesn't touch the original, and deleting one doesn't touch the other.

## Export a dataset

Click the download icon in the dataset's toolbar to export it. A **Download has been started...** toast appears immediately, followed by **Dataset downloaded successfully** once the file is ready.

## Edit data in the grid

Inside a dataset, the grid supports these changes directly, without leaving the Data tab:

| Action | What it does |
|---|---|
| Rename a column | Changes the column's display name; doesn't touch its data or, for a dynamic column, its producer |
| Change a column's data type | Reinterprets how the column's stored values are treated |
| Edit a cell | Overwrites that one cell's value |
| Delete rows | Removes the selected rows and every cell in them |
| Delete a column | Removes the column and every cell in it |

Editing a cell in a [dynamic column](/docs/dataset/concepts/static-and-dynamic-columns) doesn't stick: the column's producer overwrites it again the next time it runs.

## What deleting actually removes

Deletes here are final: once you delete a row, a column, or a dataset, it's gone. There's no recovery step, so treat every delete as permanent.

<Note>
Deleting a dynamic column also deletes the producer behind it, whether that's a prompt run or an eval, and anything else that was derived from it. It isn't just the column that disappears.
</Note>

Deleting a dataset also deletes its [experiments](/docs/dataset/guides/run-an-experiment). If you still need the results from an experiment, pull them out before you delete the dataset that ran it.

## Delete a dataset

Click **Delete** on one dataset, or select several and click **Delete** in the bulk action bar. The dialog title switches between **Delete Dataset** and **Delete Datasets** depending on how many you selected. Confirm with **Delete**, or back out with **Cancel**. A success toast confirms once it's done.

Bulk delete is capped at 50 datasets per request. Deleting more than that means running the action in batches.

<Note>
Every control on this page, duplicate, export, edit, and delete, is gated on your dataset permission. If you only have view access, they show up disabled rather than doing nothing when clicked.
</Note>
