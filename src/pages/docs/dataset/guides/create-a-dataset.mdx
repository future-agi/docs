A dataset starts as just a name in your organization; everything else comes from how you fill it. Create it in code or in the dashboard, then keep editing its [rows and columns](/docs/dataset/concepts/understanding-datasets).

For dashboard creation, open the dataset list and click **New dataset**. The chooser offers these entries; synthetic generation also depends on your plan:

| Method | Reach for it when |
| --- | --- |
| Upload a file | You already have test cases in a CSV, JSON, or JSONL export |
| Start with a blank grid | You want to define column names, types, and roles before adding rows |
| Copy from another dataset | You want to branch off a dataset or experiment you already have |
| Hugging Face | Disabled |
| Generate synthetic rows | You don't have real data yet, but know the shape of the examples you need |

The SDK is a separate programmatic workflow, not a tile in this chooser.

<Note>Whichever method you pick, the dataset's name must be unique inside your organization. A name that's already taken is rejected. For the full set of dataset and column limits, see [Limits & Data Types](/docs/dataset/reference/limits-and-data-types).</Note>

## Add data using the SDK

For scripting dataset creation, or when you'd rather write rows in code than click through the grid.

Create the dataset directly with the SDK, then add [columns](/docs/dataset/concepts/static-and-dynamic-columns) and rows. The Python and TypeScript examples below each create a new dataset named `support-agent-eval`; choose an unused name before running one. The cURL example only adds columns to an existing dataset, so replace `<dataset_id>` with that dataset's ID.

<CodeGroup>

```python Python
# pip install futureagi

import os
from fi.datasets import Dataset
from fi.datasets.types import Cell, Column, DatasetConfig, DataTypeChoices, Row, SourceChoices
from fi.utils.types import ModelTypes

os.environ["FI_API_KEY"] = "<fi_api_key>"
os.environ["FI_SECRET_KEY"] = "<fi_secret_key>"

# Create a new dataset before adding columns and rows
dataset = Dataset(dataset_config=DatasetConfig(
    name="support-agent-eval",
    model_type=ModelTypes.GENERATIVE_LLM,
)).create()

# Define columns
columns = [
    Column(name="user_query", data_type=DataTypeChoices.TEXT, source=SourceChoices.OTHERS),
    Column(name="response_quality", data_type=DataTypeChoices.INTEGER, source=SourceChoices.OTHERS),
    Column(name="is_helpful", data_type=DataTypeChoices.BOOLEAN, source=SourceChoices.OTHERS),
]

# Define rows
rows = [
    Row(order=1, cells=[
        Cell(column_name="user_query", value="What is machine learning?"),
        Cell(column_name="response_quality", value=8),
        Cell(column_name="is_helpful", value=True),
    ]),
    Row(order=2, cells=[
        Cell(column_name="user_query", value="Explain quantum computing"),
        Cell(column_name="response_quality", value=9),
        Cell(column_name="is_helpful", value=True),
    ]),
]

dataset = dataset.add_columns(columns=columns)
dataset = dataset.add_rows(rows=rows)
```

```typescript Typescript
import { Dataset, DataTypeChoices, ModelTypes, createRow, createCell } from "@future-agi/sdk";

process.env["FI_API_KEY"] = "<fi_api_key>";
process.env["FI_SECRET_KEY"] = "<fi_secret_key>";

async function main() {
  // Create a new dataset before adding columns and rows
  const dataset = await Dataset.createDataset({
    name: "support-agent-eval",
    model_type: ModelTypes.GENERATIVE_LLM,
  });

  // Define columns
  const columns = [
    { name: "user_query", dataType: DataTypeChoices.TEXT },
    { name: "response_quality", dataType: DataTypeChoices.INTEGER },
    { name: "is_helpful", dataType: DataTypeChoices.BOOLEAN },
  ];

  // Define rows
  const rows = [
    createRow({
      cells: [
        createCell({ columnName: "user_query", value: "What is machine learning?" }),
        createCell({ columnName: "response_quality", value: 8 }),
        createCell({ columnName: "is_helpful", value: true }),
      ],
    }),
    createRow({
      cells: [
        createCell({ columnName: "user_query", value: "Explain quantum computing" }),
        createCell({ columnName: "response_quality", value: 9 }),
        createCell({ columnName: "is_helpful", value: true }),
      ],
    }),
  ];

  await dataset.addColumns(columns);
  await dataset.addRows(rows);
}

main();
```

```bash Curl
curl --request POST \
  --url https://api.futureagi.com/model-hub/develops/<dataset_id>/add_columns/ \
  --header 'X-Api-Key: <fi_api_key>' \
  --header 'X-Secret-Key: <fi_secret_key>' \
  --header 'content-type: application/json' \

      {"name": "user_query", "data_type": "text"},
      {"name": "response_quality", "data_type": "integer"},
      {"name": "is_helpful", "data_type": "boolean"}
    ]
  }'
```

## Upload a file

For bringing in test cases you already have as a file, instead of typing them in.

In the Add dataset panel, pick **Upload a file** and name the dataset. Drop or browse to your file: accepted dashboard formats are `.csv`, `.json`, and `.jsonl`, up to 25 MiB (shown as 25 MB). The dataset appears on your list right away. Future AGI processes the file in the background with a visible progress state until it's done.

Excel files aren't accepted by the dashboard. Export them to CSV, JSON, or JSONL first, or use the REST upload API, which also accepts `.xls` and `.xlsx`. See [upload formats](/docs/dataset/reference/limits-and-data-types#dataset-and-column-limits) for the separate dashboard and REST contracts.

## Create synthetic data

For when you don't have real data yet, but know the shape of the examples you need.

In the Add dataset panel, pick **Generate synthetic rows** and name the dataset. From there, Future AGI walks you through describing the schema and generates rows for you. See [Synthetic Data](/docs/dataset/concepts/synthetic-data) if you want to regenerate later.

## Add a dataset manually

Use **Start with a blank grid** when you know the schema you want, even if you don't have examples yet.

<Steps>
  <Step title="Name the dataset">
    In the Add dataset panel, pick **Start with a blank grid** and enter a dataset name.
  </Step>
  <Step title="Define the columns">
    Give each column a unique, non-empty name, choose its type, and assign its role: **Input**, **Expected**, or **Metadata**. Use **Add column** to add more, up to 20 columns in this form.

    The type picker offers `text`, `integer`, `float`, `boolean`, `json`, `array`, and `datetime`.
  </Step>
  <Step title="Choose the starting rows">
    **Blank rows** defaults to **0**. Keep it at zero to create only the schema, or choose up to 100 empty rows to fill in now.
  </Step>
  <Step title="Create the dataset">
    Click **Create dataset**. Future AGI saves the column names, types, roles, and column order along with the dataset.
  </Step>
</Steps>

A zero-row dataset is ready for you to [add rows](/docs/dataset/guides/add-rows) later. For example, define `user_query` as Text with the Input role, `expected_answer` as Text with the Expected role, and `category` as Text with the Metadata role before importing any examples.

## Import from Hugging Face

<Note>
Hugging Face imports are disabled in the dashboard because imported cells can remain blank. The chooser may list **Hugging Face**, but it cannot start an import. Use **Upload a file** or **Copy from another dataset** instead. This restriction also applies when adding rows to an existing dataset.

The REST API still has a separate `/model-hub/develops/create-dataset-from-huggingface/` route. This dashboard restriction does not mean that route has been removed.
</Note>

## Add from an existing dataset or experiment

For branching off a dataset or experiment you already have.

In the Add dataset panel, pick **Copy from another dataset** and choose the dataset or experiment you want to copy from. Choose whether to bring over **Import Data** or **Import data and prompt configuration**, then select which columns to include. Name the new dataset to finish.
