---
title: "Create a dataset"
description: "Six ways to get a dataset into your organization, from a single upload to a script that pushes rows through the SDK."
---

A dataset starts as just a name in your organization; everything else comes from how you fill it. Future AGI gives you six ways to do that, each landing you on the same [dataset](/docs/dataset/concepts/understanding-datasets) table of rows and columns you can keep editing afterward.

Every method starts the same way: from the dataset list, click **Add Dataset**. That opens a panel with six tiles:

| Method | Reach for it when |
| --- | --- |
| Add data using SDK | You're scripting the setup or pushing rows from your own pipeline |
| Upload a file | You already have test cases in a CSV, Excel, or JSON export |
| Create synthetic data | You don't have real data yet, but know the shape of the examples you need |
| Add a dataset manually | You're hand-building a small set and want an empty grid to fill in |
| Import from Hugging Face | The data you need already exists as a public Hugging Face dataset |
| Add from an existing dataset or experiment | You want to branch off a dataset or experiment snapshot you already have |

<Note>Whichever method you pick, the dataset's name must be unique inside your organization. A name that's already taken is rejected.</Note>

## Add data using the SDK

For scripting dataset creation, or when you'd rather write rows in code than click through the grid.

<Steps>
  <Step title="Choose Add data using SDK">
    In the Add dataset panel, pick **Add data using SDK** and give the dataset a name.
  </Step>
  <Step title="Land on the SDK snippet">
    Future AGI creates an empty dataset and drops you on its Data tab, which shows the dataset's name, ID, API key, and secret key alongside a ready-to-run code snippet.
  </Step>
  <Step title="Run it to add columns and rows">
    Copy the snippet and run it against your dataset.

    ```python
    # pip install futureagi

    import os
    from fi.datasets import Dataset
    from fi.datasets.types import (
        Cell,
        Column,
        DatasetConfig,
        DataTypeChoices,
        ModelTypes,
        Row,
        SourceChoices,
    )

    os.environ["FI_API_KEY"] = "<fi_api_key>"
    os.environ["FI_SECRET_KEY"] = "<fi_secret_key>"

    # Get the dataset you just created
    config = DatasetConfig(name="support-agent-eval", model_type=ModelTypes.GENERATIVE_LLM)
    dataset = Dataset(dataset_config=config)
    dataset = Dataset.get_dataset_config("support-agent-eval")

    # Define columns
    columns = [
        Column(name="user_query", data_type=DataTypeChoices.TEXT, source=SourceChoices.OTHERS),
        Column(name="response_quality", data_type=DataTypeChoices.INTEGER, source=SourceChoices.OTHERS),
        Column(name="is_helpful", data_type=DataTypeChoices.BOOLEAN, source=SourceChoices.OTHERS),
    ]

    # Define rows
    rows = [
        Row(order=1, cells=[
            Cell(column_name="user_query", value="What is machine learning?"),
            Cell(column_name="response_quality", value=8),
            Cell(column_name="is_helpful", value=True),
        ]),
        Row(order=2, cells=[
            Cell(column_name="user_query", value="Explain quantum computing"),
            Cell(column_name="response_quality", value=9),
            Cell(column_name="is_helpful", value=True),
        ]),
    ]

    dataset = dataset.add_columns(columns=columns)
    dataset = dataset.add_rows(rows=rows)
    ```

    See [/docs/sdk/datasets](/docs/sdk/datasets) for the full `Dataset` reference.
  </Step>
</Steps>

**Limit:** the dataset itself starts empty. If you set an initial row count yourself when calling the creation endpoint directly, Future AGI creates at most 10 rows to start; add the rest through the snippet above.

## Upload a file

For bringing in test cases you already have as a file, instead of typing them in.

<Steps>
  <Step title="Choose Upload a file">
    In the Add dataset panel, pick **Upload a file (JSON, CSV)**. Naming it is optional; Future AGI falls back to the file name.
  </Step>
  <Step title="Drop or browse to your file">
    Accepted formats are `.csv`, `.xls`, `.xlsx`, `.json`, and `.jsonl`, up to 25 MB.
  </Step>
  <Step title="Watch it fill in">
    The dataset appears on your list right away and processes in the background, moving through queued, processing, and creating-cells states before landing on completed (or failed, if something's wrong with the file). You don't need to wait on the page for it to finish.
  </Step>
</Steps>

**Limit:** 25 MB per file, restricted to the five extensions above; processing happens in the background rather than instantly.

## Create synthetic data

For when you don't have real data yet, but know the shape of the examples you need.

<Steps>
  <Step title="Choose Create Synthetic Data">
    In the Add dataset panel, pick **Create Synthetic Data** and name the dataset.
  </Step>
  <Step title="Describe what you want generated">
    Add a description of the dataset, and optionally an objective and a pattern (style, tone, or behavioral traits), plus a knowledge base to ground the generation in.
  </Step>
  <Step title="Define the columns">
    For each column, set a name, a data type, and a description of what values should land in it. Column names in the same request can't repeat.
  </Step>
  <Step title="Set the row count and generate">
    Choose how many rows to generate (at least 10) and start the run. Generation happens as a background job. Future AGI drops you on the dataset while rows fill in, and you can reopen the generation config later to edit it and regenerate. See [Synthetic Data](/docs/dataset/concepts/synthetic-data) for how that config is stored and reused.
  </Step>
</Steps>

**Limit:** at least 10 rows per generation request; column names can't repeat within the same request.

## Add a dataset manually

For hand-building a small dataset from scratch when you already know its shape.

<Steps>
  <Step title="Choose Add datasets Manually">
    In the Add dataset panel, pick **Add datasets Manually**.
  </Step>
  <Step title="Set its size">
    Name the dataset and choose how many rows and how many columns to start with, up to 100 of each.
  </Step>
  <Step title="Open the empty grid">
    Future AGI creates the dataset with that many empty rows and columns, ready for you to fill in on the Data tab.
  </Step>
</Steps>

**Limit:** up to 100 rows and 100 columns per manually created dataset.

## Import from Hugging Face

For pulling in a public dataset instead of typing test cases by hand.

<Steps>
  <Step title="Choose Import from HuggingFace">
    In the Add dataset panel, pick **Import from HuggingFace**.
  </Step>
  <Step title="Search and select a dataset">
    Search by name and pick the one you want from the results.
  </Step>
  <Step title="Pick a subset, split, and row count">
    Choose the subset and split you want, and optionally cap how many rows to import. Leave the row count unset to import the whole split.
  </Step>
  <Step title="Name and import">
    Name the new dataset and start the import.
  </Step>
</Steps>

## Add from an existing dataset or experiment

For branching off a dataset or experiment snapshot you already have, keeping only the columns you need.

<Steps>
  <Step title="Choose Add from existing model dataset or experiment">
    In the Add dataset panel, pick **Add from existing model dataset or experiment** and name the new dataset.
  </Step>
  <Step title="Pick the source">
    Choose the dataset or experiment snapshot you want to copy from.
  </Step>
  <Step title="Map the columns">
    Pick which columns to bring over, and rename them if you want. Two columns can't map to the same new name.
  </Step>
</Steps>

**Limit:** two columns in one request can't share the same mapped name.
