## About

The v1.59.1 platform MCP server has **111 tools in 14 groups** before filtering. If you want to inspect a Ridgeline Outfitters support trace, for example, use `get_trace` from the `observability` group. Use `tools/list` on your own connection to check whether you can call it.

This is the catalog for `https://api.futureagi.com/mcp`, not the CLI command list. Falcon uses the same contracts for catalog-backed actions, but its native helpers and [external connectors](/docs/falcon-ai/concepts/mcp-connectors) are not part of this list. [Gateway MCP federation](/docs/command-center/features/mcp-a2a) exposes tools from servers registered with a gateway, not this release catalog.

## Check your connection

1. [Connect your IDE to the platform MCP server](/docs/falcon-ai/guides/use-the-mcp-server), or use a workspace API key pair with the example below. Use credentials for the workspace that contains the trace.
2. List tools on **that connection**. You see a tool only if its API route is available on the deployment, its group is enabled on the connection, and the individual tool is not disabled. With OAuth, its group must also be in the token's grant. An empty list is possible.
3. Check the tool's `inputSchema` and `annotations` before calling it. Seeing a tool does not grant workspace write access or access to a particular resource. Enabling a group does not expand an existing OAuth grant.

### Example: find the support project

Set `FI_API_KEY` and `FI_SECRET_KEY` in your environment. On a self-hosted deployment, also set `FI_BASE_URL` to your API origin. These examples check whether `list_projects` is visible before searching for projects whose names contain `Ridgeline`.

- **Python**: install the SDK with `python -m pip install mcp==1.30.0`.
- **TypeScript**: install the SDK with `npm install @modelcontextprotocol/sdk@1.26.0`. Save the example as `projects.mts` and run `node projects.mts` with Node.js 22.18 or later.
- **cURL**: use Bash, cURL and `jq`. This version returns the first page only.

<CodeGroup titles={["Python", "TypeScript", "cURL"]}>

```python
import asyncio
import os

import httpx
from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


async def main():
    base = os.getenv("FI_BASE_URL", "https://api.futureagi.com").rstrip("/")
    headers = {"X-Api-Key": os.environ["FI_API_KEY"],
               "X-Secret-Key": os.environ["FI_SECRET_KEY"]}
    async with httpx.AsyncClient(headers=headers, timeout=60) as http:
        async with streamable_http_client(f"{base}/mcp", http_client=http) as streams:
            async with ClientSession(streams[0], streams[1]) as client:
                await client.initialize()
                tools = {t.name: t for t in (await client.list_tools()).tools}
                print(f"{len(tools)} tools visible on this connection")
                if "list_projects" not in tools:
                    print("list_projects is not available on this connection")
                    return
                print("Page size:", tools["list_projects"].inputSchema["properties"]["page_size"])
                page = 0
                while True:
                    reply = await client.call_tool("list_projects", {
                        "name": "Ridgeline", "page_number": page, "page_size": 2,
                    })
                    data = reply.structuredContent
                    if reply.isError:
                        raise RuntimeError(data["error"]["code"])
                    print([(p["name"], p["id"]) for p in data["projects"]])
                    page += 1
                    if not data["projects"] or page * 2 >= data["total_count"]:
                        break


asyncio.run(main())
```

```typescript
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const base = process.env.FI_BASE_URL ?? "https://api.futureagi.com";
const client = new Client({ name: "ridgeline-support", version: "1.0.0" });
const transport = new StreamableHTTPClientTransport(new URL("/mcp", base), {
  requestInit: { headers: { "X-Api-Key": process.env.FI_API_KEY!,
                            "X-Secret-Key": process.env.FI_SECRET_KEY! } },
});
try {
  await client.connect(transport);
  const { tools } = await client.listTools();
  console.log(`${tools.length} tools visible on this connection`);
  if (!tools.some(tool => tool.name === "list_projects")) {
    console.log("list_projects is not available on this connection");
  } else {
    for (let page = 0; ; page++) {
      const reply = await client.callTool({ name: "list_projects", arguments: {
        name: "Ridgeline", page_number: page, page_size: 2,
      } });
      if (reply.isError) throw new Error("list_projects returned a tool error");
      const data = reply.structuredContent as {projects: {name: string; id: string}[]; total_count: number};
      console.log(data.projects.map(p => [p.name, p.id]));
      if (!data.projects.length || (page + 1) * 2 >= data.total_count) break;
    }
  }
} finally {
  await client.close();
}
```

`list_projects` starts at page `0`. Its page size defaults to `20` and accepts integers from `1` to `100`. A result of `[]` means there were no matching projects on that page, not that the tool was unavailable. Other tools use different pagination arguments; use the entry for the tool you call.

## Read a preview or retrieve the full value

Tool **result data** has a **64 KiB (65,536-byte) ceiling** after serialization to UTF-8 JSON. This is not a limit on `tools/list`. For long strings under fields such as `input`, `output`, `messages`, `content`, `metadata`, `config` or `transcript`, MCP keeps the first **2,000 characters** and appends `… [truncated]`. This also applies to strings nested under those fields. It does not shorten every string, discard rows to make a page fit, or shorten pagination cursors.

| What you receive | What to do |
| --- | --- |
| Success with `_mcp.truncated: true` and `_mcp.fields` | The page is valid. `fields` lists paths to shortened strings (up to 100 paths), not missing rows. Continue with the returned pagination values, or read the resource through authenticated REST for its full content. |
| `isError: true` with `HTTP_413` | The read result is still too large or too deeply nested. Reduce `page_size`, `limit` or the time range if the tool supports it. If one resource is too large, use its REST read endpoint. |
| A successful write with a short `_mcp` receipt | The operation already succeeded. The receipt can include an `id`, a field ending in `_id`, or `status`. **Do not repeat the write** to recover its response. Read back the resource instead. |

If `get_trace` returns `HTTP_413` for a long Ridgeline support conversation, read one span instead. Call `list_spans` with the same `project_id` and `page_size: 1`. Use the row's `span_id` as the `id` for `get_span` and supply the `project_id` too. If the result has `_mcp.fields`, pick the string you need. For example, `/observation_span/input/intermediate_steps/1/1` identifies a string inside the span's input. If `_mcp.fields` is absent, there is no shortened field listed to recover.

Set `SPAN_ID` and `PROJECT_ID` to the same IDs and `MCP_FIELD` to the path you picked. Fetch the span over REST using credentials for the same workspace. The command prints each matching path as a JSON array of keys and indexes, and its full character count. It does not log the conversation. Matching actual paths matters because `_mcp.fields` does not escape `/` inside key names.

```bash
set -eo pipefail
curl --silent --show-error --fail --get \
  "${FI_BASE_URL:-https://api.futureagi.com}/tracer/observation-span/${SPAN_ID:?Set SPAN_ID}/" \
  --data-urlencode "project_id=${PROJECT_ID:?Set PROJECT_ID}" \
  --header "X-Api-Key: ${FI_API_KEY:?Set FI_API_KEY}" \
  --header "X-Secret-Key: ${FI_SECRET_KEY:?Set FI_SECRET_KEY}" \
  | jq -e --arg field "${MCP_FIELD:?Set MCP_FIELD}" '
      .result | paths(strings) as $p
      | select(("/" + ($p | map(tostring) | join("/"))) == $field)
      | {path: $p, characters: (getpath($p) | length)}'
```

## Tool groups

Open a tool for its REST operation and inputs. The **effect** describes what a call does, not who may call it. **Read** does not edit the data being queried; it may still create or cancel a personal SQL job. **Write** changes a resource or starts work. **Destructive** identifies writes that can delete data. **External** marks calls annotated `openWorldHint: true`, such as a prompt run that can incur provider charges. The idempotent hint tells you whether the catalog expects repeating the same arguments to have no additional effect; it is not a reason to retry a successful write.

The **workspace gate** is the initial access check. *Access* requires membership or organization-wide access; a Workspace Viewer can pass this check. *Write* requires a Workspace Member or Workspace Admin, or an organization Owner or Admin. The underlying API can still restrict an operation by queue role, project, ownership or entitlement. In particular, `get_prompt_template` requires write access even though it uses GET: opening a template can create a draft. `get_annotation_item_detail` also requires write access, even when you omit `reserve`. In the other direction, `query_dashboard_metrics` and `query_dashboard_widget` read data but use POST and require write access.

Argument names below use dots for nested fields, `[]` for array elements and `.*` for the value of each key in a map. A nested field marked required is required **inside its parent**, not when you omit an optional parent. A `default` in the table comes from the tool schema. Unlisted top-level argument names are rejected. Send JSON values of the stated types; for example, send `2`, not `"2"`, for an integer.

## Errors

| Signal | Meaning and next action |
| --- | --- |
| HTTP `401` on the MCP request | The connection did not authenticate. Reconnect via OAuth or check that your API key pair is active and supports platform access. |
| Tool error `FORBIDDEN` | The route is unavailable, the tool or group is disabled, or the group is outside the OAuth grant. Compare `tools/list` with the group above. Reauthorize if the OAuth grant is missing the group. |
| Tool error `HTTP_403` | The API denied the operation in this workspace. Check the workspace gate and your access to the specific resource. |
| Tool error `HTTP_400` | Check the required fields, accepted values and bounds in `inputSchema`. For example, `list_projects` rejects `page_size: 101` before reading projects. The underlying API can also reject invalid combinations. |
| Tool error `RATE_LIMITED` | The organization reached its MCP call limit. Wait before making another call. |
| Tool error `NOT_FOUND` | The server does not recognize the tool name. Check discovery rather than copying a CLI command or a Falcon-native helper name. |
