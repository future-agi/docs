When an [MCP connector](/docs/falcon-ai/concepts/mcp-connectors) discovers tools, every tool it finds is allowed by default. Limit Falcon AI to the tools it needs in [workspace settings](/docs/admin-settings), then reload the page to confirm the selection holds.

<Prerequisites title="Before you start">
- [Connect an MCP server](/docs/falcon-ai/guides/connect-mcp-server), authenticate it and run discovery.
- To try switching one tool off, choose a connector with at least two discovered tools. At least one tool must stay allowed.
</Prerequisites>

## Select a connector

1. Open **Settings**.
2. Choose **Falcon AI Connectors**.
3. Select the connector in the list on the left.

   At the bottom of its detail pane, **Discovered Tools** lists the name, server-supplied description and switch for each tool. The heading counts discovered tools, not allowed tools.

## Restrict the tool list

1. Switch off one tool you do not want Falcon AI to call.

   The selection saves immediately. There is no confirmation or submit button.

<img src="/images/docs/falcon-ai/guides/choose-connector-tools.png" alt="A connected connector's Discovered Tools section listing three tools, the first two switched on and the third switched off" style={{ borderRadius: '5px' }} />

*Three tools were discovered. Two are allowed and one is off; the heading still counts all three.*

2. Reload the page.
3. Check the same connector's **Discovered Tools** list.

   The tool you disabled should still be off. You cannot turn off the last allowed tool.

<Note>
The exact message for the last tool is: "At least one tool must stay allowed for this connector."
</Note>

## If the list is empty or saving reports unknown tools

- **No rows:** The message is "No tools discovered yet. Click Discover Tools or Re-authenticate to fetch available tools." That is expected on a connector you've just added. Run **Discover Tools** to populate the list.
- **Unknown tools:** The name being saved is not in the stored discovery list. Saving does not query the remote server, so a tool disappearing remotely does not by itself cause this error.

<Warning>
Every successful discovery replaces the previous selection and enables all returned tools. OAuth reauthentication can also trigger discovery. Reapply your restrictions before using the connector again.
</Warning>

To recover from a stale discovery list:

1. Run **Discover Tools** on the connector.
2. Review the refreshed list.
3. Switch off each tool that should not be allowed.

## Find connectors from chat

1. Open **+** in the [chat input](/docs/falcon-ai/guides/chat-with-falcon-ai).
2. Choose **Connectors**.

   The submenu lists the workspace's connectors and their connected state, or says "No connectors configured" if the list is empty.

3. Select **Manage connectors** to return to the settings page.

## Verify an allowed tool in chat

1. Ask a read-only question that one of the allowed tools can answer.
2. If Falcon AI uses a tool, open its tool card.

   Check the tool name and result against the question. A reply without a tool card doesn't confirm that the tool ran.
