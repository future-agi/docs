[Falcon AI](/docs/falcon-ai) is the AI copilot built into the Future AGI dashboard, reachable from any page you're on. Ask it what went wrong with a [trace](/docs/observe/concepts/traces) while the request is still on screen, then use the context chip and the tool result to check that the answer is about the right request.

<Prerequisites title="Before you start">
- For the trace walkthrough, open a project with a failing request in [Observe](/docs/observe).
</Prerequisites>

## Ask a question and send it

1. Open the failing trace's detail page.
2. Press `⌘K` (Mac) or `Ctrl+K` (Windows/Linux) to open the side panel.

   You can also click the floating **Falcon AI (⌘K)** button at the bottom right of any dashboard page.

3. Check the context chip before sending.

   On a trace detail page, look for that trace's ID in the input; on the project list shown below, the header says **Tracing**, which identifies the area, not an individual trace.

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/open-shortcut-panel.png" alt="The Falcon AI side panel open over the Tracing project list, with a Tracing chip in the panel header and the project table still visible beside it" style={{ borderRadius: '5px' }} />

4. Type the question “What went wrong with this trace?” in the input.
5. Click **Send**.

   Enter also sends; Shift+Enter adds a newline. **Send** stays inactive until the input has text or an attachment.

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/ask-question-send.png" alt="The Falcon AI input with a question typed in and the Send button active" style={{ borderRadius: '5px' }} />

*The send control becomes active when the input has a question. This screenshot shows a separate, workspace-level dataset question.*

6. Open the tool card if Falcon AI used a tool.

   A running card says **Running...**. Once complete, its collapsed view shows the tool name and the first line of the result.

7. Compare **Full output** with the answer.

   Look for the record from the trace you opened. A card's **Result** is only a summary; **Full output** shows the returned data, including a table when the tool returns rows.

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/tool-card-parameters-result.png" alt="An open tool call card for list_scenarios, showing its Parameters JSON, its Result line, and the Full output table beneath" style={{ borderRadius: '5px' }} />

*This example card is for `list_scenarios`, not a trace lookup. The description explains the tool; expand **Parameters** to see the JSON it received. Calls without arguments omit that section.*

The answer streams while the input is disabled. Click **Stop** to interrupt it without losing text or tool cards already returned.

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/stop-mid-response.png" alt="Falcon AI streaming a response with the Stop button showing in place of Send" style={{ borderRadius: '5px' }} />

## Correct the context and retry

Falcon AI defaults to **Auto**, which reads the page you're on to work out what you're asking about. When **Auto** picks the wrong area, set the context yourself before you send the question.

1. Open the context selector in the chat input.
2. Choose **Tracing** if **Auto** picked the wrong area.

   The tick marks the active choice. The other options are **Datasets**, **Evaluations**, **Experiments**, **Agents** and **Prompts**.

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/context-selector.png" alt="The context selector open, listing Auto, Datasets, Evaluations, Tracing, Experiments, Agents, and Prompts" style={{ borderRadius: '5px' }} />

3. Enter the question again.
4. Click **Send**.

## Start a conversation from a quick action

For a full-page chat, click **Falcon AI** in the navigation sidebar. At `/dashboard/falcon-ai`, saved conversations appear on the left and chat opens in the center. Opening the full page closes the side panel.

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/open-full-page.png" alt="The Falcon AI full page with the Falcon AI nav item selected in the sidebar, three past conversations listed on the left, and an answer in the center" style={{ borderRadius: '5px' }} />

A fresh chat says “How can I help?” and “Ask about your data, evaluations, experiments, traces, and more.” Choose a quick action to prefill the input, or type a question instead. You can edit the prefilled text before sending it.

| Quick action | What it starts |
| --- | --- |
| Analyse my error feed | A request to analyze issues in [Error Feed](/docs/error-feed). |
| Create an Imagine view | A request to create a view. |
| Build a dataset | A request to build a [dataset](/docs/dataset). |
| Create an evaluation | A request to create an [evaluation](/docs/evaluation). |
| Run simulation for my agent | A request about running your agent in a [simulation environment](/docs/environments). |

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/empty-state-quick-actions.png" alt="Falcon AI's empty state with the How can I help heading, five quick-action chips below it, and a row of skill chips just above the input" style={{ borderRadius: '5px' }} />

*These five quick actions disappear after the first message. The chips directly above the input are shortcuts to workspace [skills](/docs/falcon-ai/concepts/skills).*

## Attach a file

1. Click **+** (tooltip: **More**) beside the input.
2. Choose **Attach files**.
3. Select a file up to 10 MB.

   You can also drag it onto the input; the paperclip beside the menu is labeled **Attach file**.

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/attach-file.png" alt="The plus menu open above the input, listing Attach files and Connectors" style={{ borderRadius: '5px' }} />

Falcon AI reads attachments alongside your message. Supported files include plain text, CSV, HTML, Markdown, JSON, PDF, Excel (`.xlsx`), Word (`.docx`), and PNG, JPEG, GIF or WebP images. The menu says **Uploading...** during upload; if nothing appears above the input, check the size. Files over 10 MB are dropped without a message.

The same menu includes **Connectors**, which is where you reach [MCP connectors](/docs/falcon-ai/concepts/mcp-connectors) without leaving the chat.

## Copy or rate the answer

After streaming finishes, choose **Copy** (two pages), **Good response** (thumbs up), or **Bad response** (thumbs down) below the answer. These icon buttons don't appear mid-turn.

<img src="/images/docs/falcon-ai/guides/chat-with-falcon-ai/copy-rate-response.png" alt="An assistant message with the copy, thumbs up, and thumbs down icon buttons beneath it" style={{ borderRadius: '5px' }} />

## Check cost and limits

Each turn costs one [credit](/docs/billing). The limit is ten messages per minute, counting chat messages, response ratings and **Stop** clicks together, so a burst of rapid follow-ups can reach it. Past the limit, the next send fails inline.
