If you ask Falcon AI to compare scores every week, save the comparison as a [skill](/docs/falcon-ai/concepts/skills). Anyone in your [workspace](/docs/admin-settings/workspace-management) can then start the same review with a slash command.

<Prerequisites title="Before you start">
- For the weekly review example, use a workspace with [evaluation](/docs/evaluation) scores from both seven-day periods you want to compare.
</Prerequisites>

## Open the editor

1. Open the Falcon AI full page.
2. Select **Customize** in the left rail.

   The panel opens on **Skills** and lists the skills in your workspace, with a search field for finding one by name. The other section is for [connectors](/docs/falcon-ai/concepts/mcp-connectors).

<img src="/images/docs/falcon-ai/guides/create-skill.png" alt="The Customize panel with Skills selected in its nav, the workspace skills listed in the next column each tagged SYS, and Create Skill at the bottom of that column" style={{ borderRadius: '5px' }} />

3. Select **Create Skill** at the bottom of the list.

   The editor has four fields; the **SYS** tags in the list mark skills that shipped with Falcon AI.

If you're already in a conversation, **Skills > Create Skill** in the chat header opens a separate dialog. It has an **Icon** field for an MDI icon name such as `mdi:bug`. This sets the icon in the list and picker. Its button is **Create** rather than **Save**.

## Write the weekly review

The instructions are the prompt Falcon AI follows when the skill runs. The example below asks it to compare each [dataset](/docs/dataset) against its own baseline. Describe the workflow and the reasoning, not a rigid script of commands:

- **Workflow:** "Compare this week's scores against last week's, and flag any metric that dropped by more than 5%."
- **Script:** "Call the scores endpoint for this week, call it again for last week, then subtract."

1. Enter `Weekly Eval Regression Review` in **Name**.

   The name appears in the Skills list, is required and can be up to 100 characters.

2. In **Description**, enter `Comparing this week's evaluation scores against last week's and flagging anything that dropped`.

   This optional text appears in the skill picker.

3. Paste the comparison rule into **Instructions**, which is required:

   ```
   Pull the evaluation scores for every dataset in this workspace from the last 7 days, then pull the same metrics for the 7 days before that as a baseline. Compare the two periods per dataset and per metric, and treat any metric that dropped by more than 5% as a regression worth flagging. Present the findings as a table with columns for Dataset, Metric, This Week, Last Week, and Change, with the biggest drops listed first. If nothing regressed, say so plainly instead of returning an empty table.
   ```

4. Enter `weekly eval review` in **Trigger phrases**.
5. Press **Enter** to add the phrase.

   At least one phrase is required; add `check eval regressions` the same way for another example of how someone might ask.

## Save and run the review

1. Select **Save**.

   The button reads **Saving...** while the editor stores the skill.

2. In a conversation, type `/` in the chat input.
3. Choose **Weekly Eval Regression Review** from the list to run it.

Read the response against your instructions: look for Dataset, Metric, This Week, Last Week and Change, with the biggest drops first, or a statement that nothing regressed.

## If the editor won't save

<div class="sdk-ref-table max-sm:[&_td]:px-1.5! max-sm:[&_th]:px-1.5!">

| Message or symptom | What to change |
| --- | --- |
| “Name is required” | Enter a name. |
| The name is rejected | Another skill already uses that name. Choose a different one. |
| “Instructions are required” | Describe the workflow Falcon AI should follow. |
| “At least one trigger phrase is required” | Enter a phrase and press **Enter** to add it to the list. |

</div>

## Maintain a skill

1. Open the skill from **Customize > Skills**.
2. Change the field you want to update.
3. Select **Save**.

For a shipped skill, use **Duplicate** to make an editable copy you can rename. **Delete** is available only for custom skills and removes the skill from the workspace entirely.
