Instead of switching between the dashboard and your editor, connect your coding assistant to Future AGI and describe what you want in tools like Claude, Cursor, or VS Code. You can ask about [traces](/docs/observe/concepts/traces), run [evaluations](/docs/evaluation), manage [datasets](/docs/dataset), [generate synthetic data](/docs/quickstart/generate-synthetic-data), or apply [guardrails](/docs/protect).

The server is built on the [Model Context Protocol](https://modelcontextprotocol.io/introduction) (MCP), a standard that connects AI models to external tools and services. This guide adds the server to your client, authorizes it, and checks the connection with a prompt that only reads data: listing your projects.

<Prerequisites title="Before you start">
- A Future AGI account.
- An MCP client, such as one of the clients in the tabs below. The connection uses OAuth 2.0, so you don't need an API key.
</Prerequisites>

## Connect your client

The server address is the same for every client:

```
https://api.futureagi.com/mcp
```

1. Select your client in the tabs below.
2. Add the server using the configuration in that tab.
3. Restart the client if you edited its configuration file.

<MCPIDETabs />

In Claude Code, `claude mcp list` now shows `futureagi` with `! Needs authentication`. In the other clients, the assistant lists `futureagi` as an available MCP server once it reconnects. That's expected: the OAuth handshake happens on the first tool call.

## Authorize the connection

1. Ask your assistant: “List my Future AGI projects.”

   The first tool call opens the consent screen in your browser.

2. Review the permission groups.
3. Click **Authorize**.

   You should see the connection confirmed in the browser tab and your project list in the assistant. The token is cached, so you won't see the consent screen again from this client.

You can revoke access at any time from **Settings > MCP Server**. That page is visible to Owners and Admins only.

## Troubleshooting

- **The consent screen never opens.** Copy the URL the client prints and open it yourself.
- **`claude mcp list` still shows `Needs authentication`.** The handshake only happens on a tool call. Ask for the project list again, then recheck `claude mcp list`.

## Try a workspace task

Once the project list comes back, describe what you want in plain language:

- **Run evaluations:** evaluate single inputs or batches, on local datapoints or large datasets.
- **Build and observe your agents:** add observability and evaluations while you build and deploy agents.
- **Manage datasets:** upload, evaluate and download datasets, and find insights.
- **Add protection rules:** apply toxicity detection, prompt injection protection, and other guardrails.
- **Generate synthetic data:** describe your dataset and objective.

The [MCP server blog post](https://futureagi.com/blogs/model-context-protocol-mcp-2025) has detailed use cases.
