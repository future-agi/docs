---
title: "Together AI Integration with Future AGI for LLM Tracing"
description: "Integrate Together AI with Future AGI observability. Trace inference calls to Together AI models using the traceAI-openai compatible package."
---

Trace Together AI calls made through the OpenAI client in Future AGI.

Calls to `api.together.ai` can be labeled **OpenAI** in the provider field. Do not rely on that field to separate Together AI usage in reports.

## 1. Installation
Install the traceAI OpenAI package.

```bash
pip install traceAI-openai
```

---

## 2. Set Environment Variables

Set your Together AI and Future AGI credentials.

```python
import os

os.environ["TOGETHER_API_KEY"] = "your-together-api-key"
os.environ["FI_API_KEY"] = "your-futureagi-api-key"
os.environ["FI_SECRET_KEY"] = "your-futureagi-secret-key"
```

---

## 3. Initialize Trace Provider

Set up the trace provider to create a new project in FutureAGI, establish telemetry data pipelines.

```python
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType

trace_provider = register(
    project_type=ProjectType.OBSERVE,
    project_name="togetherai_project",
)
```

---

## 4. Instrument your Project

The OpenAI instrumentor can send request messages, responses and provider error details to Future AGI. To hide input and output values and messages, set `FI_HIDE_INPUTS=true` and `FI_HIDE_OUTPUTS=true` before initialization; see [mask span attributes](/docs/sdk/tracing/mask-span-attributes). These switches are not a general scrubber for custom attributes or all exception text. Keep secrets out of request data and error messages.

Instrument the OpenAI client before making Together AI calls.

```python
from traceai_openai import OpenAIInstrumentor

OpenAIInstrumentor().instrument(tracer_provider=trace_provider)
```

---

## 5. Interact with Together AI

Create an OpenAI client pointed at Together AI and send a chat request.

```python
import openai

client = openai.OpenAI(
  api_key=os.environ.get("TOGETHER_API_KEY"),
  base_url="https://api.together.ai/v1",
)

try:
    response = client.chat.completions.create(
        model="openai/gpt-oss-120b",
        messages=[
            {"role": "system", "content": "You are a travel agent. Be descriptive and helpful."},
            {"role": "user", "content": "Tell me the top 3 things to do in San Francisco"},
        ],
    )
    print(response.choices[0].message.content)
finally:
    trace_provider.shutdown()
```

In Future AGI, open the `togetherai_project` project to inspect the trace.
