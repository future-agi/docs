## About

Trace a question from Ridgeline Outfitters' returns assistant to Together AI with the OpenAI Python client. The span identifies the service receiving the call, not the author of the model.

## Configure the endpoint

Choose a chat model available to your Together account. This setup does not instrument an existing `together.Together` client. For the SDK example, use `openai/gpt-oss-120b` if your account has access.

Use Python 3.10 to 3.13. Set the provider credential and model ID for inference, and a separate Future AGI key pair for trace export. If you self-host Future AGI, set `FI_BASE_URL` to your collector origin.

```bash
pip install --upgrade "traceAI-openai>=0.1.11" "fi-instrumentation-otel>=1.2.2"
```

```sh
export TOGETHER_API_KEY="YOUR_PROVIDER_KEY"
export TOGETHER_MODEL="openai/gpt-oss-120b"
export FI_API_KEY="YOUR_FUTURE_AGI_API_KEY"
export FI_SECRET_KEY="YOUR_FUTURE_AGI_SECRET_KEY"
```

## Send the return question

Save this as `returns.py` and run `python returns.py`:

```python
import os

from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from openai import OpenAI
from traceai_openai import OpenAIInstrumentor

provider = register(project_type=ProjectType.OBSERVE, project_name="ridgeline-returns")
OpenAIInstrumentor().instrument(tracer_provider=provider)
try:
    with OpenAI(base_url="https://api.together.ai/v1", api_key=os.environ["TOGETHER_API_KEY"]) as client:
        result = client.chat.completions.create(
            model=os.environ["TOGETHER_MODEL"],
            messages=[{"role": "user", "content": "We accept unused packs within 30 days. Can I return an unused pack on day 12?"}],
        )
        print(result.choices[0].message.content)
finally:
    provider.force_flush()
    provider.shutdown()
```

In **Observe**, open `ridgeline-returns` and select the `ChatCompletion` span. Look for `gen_ai.provider.name=together`. A successful non-streamed call shows the model returned by the service, which can differ from the requested ID in `gen_ai.request.parameters`.

## Limits and troubleshooting

- The older `api.together.xyz` hostname is not the recognized Together endpoint. Upgrading the adapter affects new spans, not traces already stored.
- A stream or failed chat records the requested model. Missing usage means the endpoint did not report a count. See the [shared streaming example](/docs/integrations/traceai/openai#send-a-request).
- An unknown proxy hostname keeps `openai`. If you get an answer but no span, check the Future AGI credentials, collector destination and shutdown, not the provider key.
- Request and response content can reach Future AGI. Input/output masking alone does not remove all request parameters, tool definitions or error details.
