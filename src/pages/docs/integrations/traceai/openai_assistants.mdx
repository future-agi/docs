## About

The OpenAI Assistants API was sunset on 26 August 2026 and is no longer available. There is no supported Future AGI setup for it. Do not look here for setup steps. This page has none.

Alpha. This page is a read of OpenAI's migration guide, not a live call. No request to OpenAI was made to write it.

OpenAI's instruction on the migration guide (retrieved 2026-10-15): "The Assistants API was officially sunset on August 26, 2026, and is no longer available. Use the Responses API for new integrations."

Source: [OpenAI Assistants migration guide](https://developers.openai.com/api/docs/assistants/migration)

## Trace Responses instead

Responses tracing is covered by the existing OpenAI instrumentor. Follow [OpenAI tracing](/docs/integrations/traceai/openai) for chat and Responses calls.

## A different product

[OpenAI Agents](/docs/integrations/traceai/openai_agents) is the Agents SDK. It is a different product and not a drop-in replacement for Assistants.

## What this page does not include

- No setup steps.
- No sample that calls the retired API.
- No polling loop.
- No migration script.
- No package.
- No claim that the generic OpenAI request instrumentation is Assistants support. It is not.

## What to do if you still have Assistants state

Follow OpenAI's migration guide. This page does not run that migration for you.
