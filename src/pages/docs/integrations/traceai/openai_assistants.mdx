---
title: "OpenAI Assistants API is not a supported tracing path"
description: "The OpenAI Assistants API was sunset on 26 August 2026 and is no longer available. This page has no setup steps. Use the Responses API instead."
---

The OpenAI Assistants API was sunset on 26 August 2026 and is no longer available. For new integrations, use the Responses API; follow [OpenAI's migration guide](https://developers.openai.com/api/docs/assistants/migration) to migrate existing Assistants state.

## Trace OpenAI calls

Follow [OpenAI tracing](/docs/integrations/traceai/openai) to instrument OpenAI calls. The [OpenAI Agents SDK](/docs/integrations/traceai/openai_agents) is a separate product, not a drop-in replacement for Assistants.
