## About

To trace a Gemini request, match the traceAI adapter to the **Google package your code imports**, not just to the model name. For example, if the Ridgeline Outfitters support agent streams a reply with `@google/genai`, use `@traceai/google-genai-sdk`. The similarly named `@traceai/google-genai` will not trace that client.

## Choose your adapter

Use a modern client for a new application. If you're instrumenting an existing application, you don't have to migrate it first.

| Google SDK in your application | Install this adapter | Calls it traces |
| --- | --- | --- |
| Node.js: `@google/genai` | `@traceai/google-genai-sdk` | `models.generateContent`, `generateContentStream`, chats through `sendMessage` and `sendMessageStream`, and `models.embedContent`. Also supports Interactions and image/video requests as described below. |
| Python: `from google import genai` (`google-genai`) | `traceAI-google-genai` | `generate_content` and `generate_content_stream` on `client.models` and `client.aio.models`. |
| Node.js, legacy: `@google/generative-ai` | `@traceai/google-genai` | `GenerativeModel.generateContent`, `embedContent` and `batchEmbedContents`. Not streaming, `ChatSession` methods or `countTokens`. |
| Python, legacy: `import google.generativeai as genai` (`google-generativeai`) | `traceAI-google-generativeai` | `GenerativeModel.generate_content`, chat turns and `embed_content`, including their async forms. Generation and chat also support `stream=True`. Not `count_tokens`. |

## Set your credentials and model

Run the examples on your server, not in a browser bundle. Set these environment variables in the shell or secret manager used by your process:

| Variable | Value |
| --- | --- |
| `FI_API_KEY`, `FI_SECRET_KEY` | Your [Future AGI API key and secret key](/docs/admin-settings/api-keys), used to export traces. |
| `GOOGLE_API_KEY` | A Gemini Developer API key, used for model requests. For a modern Python client that uses Google Cloud credentials instead, see [Vertex AI](/docs/integrations/traceai/vertexai). |
| `GOOGLE_MODEL` | The ID of a Gemini text-generation model available to your Google account. |

Prompts and response text can appear in traces. To hide them, set `FI_HIDE_INPUTS=true` and `FI_HIDE_OUTPUTS=true` before initializing tracing. Review [field-specific masking](/docs/sdk/tracing/mask-span-attributes) for configuration, vectors and other fields; the two switches are not a filter for arbitrary custom attributes or your application logs.

## Trace a modern client

Install the packages for **one** runtime. For Node.js, use Node 20 or later with `@google/genai` 1.33.0 or later in the 1.x or 2.x series. For the current Python SDK and adapter, use Python 3.11 to 3.13.

<CodeGroup titles={["Node.js", "Python"]}>
```bash
npm install @google/genai@2.32.0 @traceai/google-genai-sdk @traceai/fi-core
```
```bash
python -m pip install google-genai traceAI-google-genai
```
</CodeGroup>

The support agent drafts a care tip, then streams a shorter version. Save the Node example as `care.mjs` and run `node care.mjs`, or save the Python example as `care.py` and run `python care.py`.

<CodeGroup titles={["Node.js", "Python"]}>
```javascript
import { GoogleGenAI } from "@google/genai";
import { ProjectType, register } from "@traceai/fi-core";
import { instrumentGoogleGenAI } from "@traceai/google-genai-sdk";

const provider = register({ projectName: "ridgeline-support", projectType: ProjectType.OBSERVE });
const ai = new GoogleGenAI({ apiKey: process.env.GOOGLE_API_KEY });
const tracing = instrumentGoogleGenAI(ai, { tracerProvider: provider });
const model = process.env.GOOGLE_MODEL;

try {
  const draft = await ai.models.generateContent({
    model, contents: "How should a Ridgeline Outfitters customer store a wet tent?",
  });
  console.log(draft.text);
  const stream = await ai.models.generateContentStream({
    model, contents: `Shorten this care tip to one sentence: ${draft.text}`,
  });
  for await (const chunk of stream) process.stdout.write(chunk.text ?? "");
  console.log();
} finally {
  tracing.dispose();
  await provider.forceFlush();
  await provider.shutdown();
}
```
```python
import os
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from google import genai
from traceai_google_genai import GoogleGenAIInstrumentor

provider = register(project_name="ridgeline-support", project_type=ProjectType.OBSERVE)
GoogleGenAIInstrumentor().instrument(tracer_provider=provider)
client = genai.Client(api_key=os.environ["GOOGLE_API_KEY"])
model = os.environ["GOOGLE_MODEL"]

try:
    draft = client.models.generate_content(
        model=model, contents="How should a Ridgeline Outfitters customer store a wet tent?"
    )
    print(draft.text)
    stream = client.models.generate_content_stream(
        model=model, contents=f"Shorten this care tip to one sentence: {draft.text}"
    )
    for chunk in stream:
        print(chunk.text or "", end="", flush=True)
    print()
finally:
    provider.force_flush()
    provider.shutdown()
```
</CodeGroup>

### Trace a Node.js Interaction instead

If your agent uses the Interactions API, instrument the same `GoogleGenAI` instance that calls `interactions.create`. The adapter also traces `get`, `cancel` and `delete` when your SDK exposes them. Save this as `interaction.mjs` and run `node interaction.mjs` with a model that supports Interactions.

```javascript
import { GoogleGenAI } from "@google/genai";
import { register, ProjectType } from "@traceai/fi-core";
import { instrumentGoogleGenAI } from "@traceai/google-genai-sdk";

const provider = register({ projectName: "ridgeline-support", projectType: ProjectType.OBSERVE });
const ai = new GoogleGenAI({ apiKey: process.env.GOOGLE_API_KEY });
const tracing = instrumentGoogleGenAI(ai, { tracerProvider: provider });
try {
  const reply = await ai.interactions.create({
    model: process.env.GOOGLE_MODEL,
    input: "Give a Ridgeline Outfitters customer one tip for drying a tent before storage.",
  });
  console.log(reply.id, reply.status);
} finally {
  tracing.dispose();
  await provider.forceFlush();
  await provider.shutdown();
}
```

A background Interaction span measures submission; a later `get` measures your explicit poll, not the time the model spent working remotely. The adapter does not poll for you. Likewise, `models.generateVideos` measures submission. `models.generateImages` and `models.editImage` are traced on backends that support them. Media bytes, file URLs and embedding vectors are not copied by this Node adapter.

## Trace an existing legacy client

Keep the legacy adapter if your agent still uses the corresponding legacy Google SDK. Install only the pair for your runtime:

<CodeGroup titles={["Python", "Node.js"]}>
```bash
python -m pip install 'google-generativeai==0.8.6' traceAI-google-generativeai
```
```bash
npm install @google/generative-ai@0.24.1 @traceai/google-genai @traceai/fi-core
```
</CodeGroup>

Save the Python example as `legacy_care.py` and run `python legacy_care.py`, or save the Node example as `legacy-care.cjs` and run `node legacy-care.cjs`. The Python example checks for a blocked prompt before reading the answer. The Node example calls the model directly because the legacy Node adapter does not trace chat sessions.

<CodeGroup titles={["Python", "Node.js"]}>
```python
import os
import google.generativeai as genai
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from traceai_google_generativeai import GoogleGenerativeAIInstrumentor

provider = register(project_name="ridgeline-support", project_type=ProjectType.OBSERVE)
GoogleGenerativeAIInstrumentor().instrument(tracer_provider=provider)
genai.configure(api_key=os.environ["GOOGLE_API_KEY"])
model = genai.GenerativeModel(os.environ["GOOGLE_MODEL"])

try:
    reply = model.generate_content("How should a Ridgeline Outfitters customer store a wet tent?")
    if reply.prompt_feedback.block_reason:
        print("Prompt blocked:", reply.prompt_feedback.block_reason.name)
    elif reply.candidates:
        for part in reply.candidates[0].content.parts:
            if part.text:
                print(part.text)
finally:
    provider.force_flush()
    provider.shutdown()
```
```javascript
const google = require("@google/generative-ai");
const { register, ProjectType } = require("@traceai/fi-core");
const { GoogleGenAIInstrumentation } = require("@traceai/google-genai");

async function main() {
  const provider = register({ projectName: "ridgeline-support", projectType: ProjectType.OBSERVE });
  const tracing = new GoogleGenAIInstrumentation();
  tracing.setTracerProvider(provider);
  tracing.manuallyInstrument(google);
  try {
    const ai = new google.GoogleGenerativeAI(process.env.GOOGLE_API_KEY);
    const model = ai.getGenerativeModel({ model: process.env.GOOGLE_MODEL });
    const reply = await model.generateContent("How should a Ridgeline Outfitters customer store a wet tent?");
    console.log(reply.response.text());
  } finally {
    await provider.shutdown();
  }
}
main().catch(() => { process.exitCode = 1; console.error("Generation or trace export failed."); });
```
</CodeGroup>

## Inspect the result

Open **Tracing** under **Observe** and select `ridgeline-support`. The modern Node example makes two calls without a shared parent span, so look for two traces: `google.genai.models.generateContent` for the draft and `google.genai.models.generateContentStream` for the shorter reply. Open the streaming trace to see one span for the whole reply, not one per chunk. Check the model and token counts if Google returned usage. With output capture enabled, the streamed text can appear as separate message parts in that span even though your terminal prints one continuous reply.

![In ridgeline-support, one Gemini streaming span shows a tent-drying reply in three message parts, with 54 prompt tokens and 20 completion tokens.](/images/docs/integrations/traceai/google-genai/streamed-tent-care-reply.png)

| Call or response | What to look for |
| --- | --- |
| A modern Node stream | Consume it with `for await` or close the iterator if you stop early. If the SDK stream exposes `pipeTo`, `pipeThrough` or `tee`, using one of those methods records only request timing (`google.genai.stream_capture=request_only`), not the streamed reply. |
| Legacy Python chat or streaming | `start_chat().send_message` calls the model underneath, so you get one model span per turn with the prior conversation as input. For `stream=True`, iterate to the end (`async for` after awaiting an async call) for the aggregated reply and time to first token. |
| A legacy Python response with no text | Check `gen_ai.response.block_reason` for a blocked prompt and `gen_ai.response.finish_reasons` for candidate stop reasons. A provider exception is different: it marks the span as an error and is re-raised to your application. |
| Legacy Python images or embeddings | An inline blob contributes at most its MIME type and byte count, never its contents. Masking can also redact that note. Embeddings carry input text and the returned dimension count, not vector values. The legacy Node adapter can record vector values. Set `FI_HIDE_EMBEDDING_VECTORS=true` before initializing it to exclude them. |

If no span appears, check the Google import against the table first. In modern Node, instrument each client you actually call; in legacy Python, call `genai.embed_content` via the module or import the function **after** instrumentation. A reference imported earlier still calls the original function. Flush before a short-lived process exits.
