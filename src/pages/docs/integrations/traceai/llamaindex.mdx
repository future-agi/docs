Set up your environment variables to authenticate with FutureAGI.

<CodeGroup titles={["Python", "JS/TS"]}>

```python Python
import os

os.environ["FI_API_KEY"] = "your-futureagi-api-key"
os.environ["FI_SECRET_KEY"] = "your-futureagi-secret-key"
os.environ["OPENAI_API_KEY"] = "your-openai-api-key"
```

```typescript JS/TS
process.env.FI_API_KEY = "your-futureagi-api-key";
process.env.FI_SECRET_KEY = "your-futureagi-secret-key";
process.env.OPENAI_API_KEY = "your-openai-api-key";
```

## 3. Initialize Trace Provider
Set up the trace provider to create a new project in FutureAGI, establish telemetry data pipelines.

<CodeGroup titles={["Python", "JS/TS"]}>

```python Python
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType

trace_provider = register(
    project_type=ProjectType.OBSERVE,
    project_name="llamaindex_project",
)
```

```typescript JS/TS
import { register, ProjectType } from "@traceai/fi-core";

const tracerProvider = register({
  projectType: ProjectType.OBSERVE,
  projectName: "llamaindex_project",
});
```

</CodeGroup>

## 4. Instrument your Project
Initialize the Llama Index instrumentor to enable automatic tracing. This step ensures that all interactions with the Llama Index are tracked and monitored.

In JS/TS, pass every LlamaIndex provider package you use (the LLM classes live there) and instrument before you create any LLM. Instances created earlier are not traced.

<CodeGroup titles={["Python", "JS/TS"]}>

```python Python
from traceai_llamaindex import LlamaIndexInstrumentor

LlamaIndexInstrumentor().instrument(tracer_provider=trace_provider)
```

```typescript JS/TS
import * as LlamaIndex from "llamaindex";
import * as LlamaIndexOpenAI from "@llamaindex/openai";
import { LlamaIndexInstrumentation } from "@traceai/llamaindex";

new LlamaIndexInstrumentation({}).manuallyInstrument(LlamaIndex, LlamaIndexOpenAI);
```

</CodeGroup>

## 5. Create Llama Index Components
Set up your Llama Index components as you normally would. Our Instrumentor will automatically trace and send the telemetry data to our platform.

### Agent

```python
import asyncio

from llama_index.core.agent.workflow import FunctionAgent
from llama_index.core.tools import FunctionTool
from llama_index.llms.openai import OpenAI

def multiply(a: int, b: int) -> int:
    """Multiply two integers and return the result."""
    return a * b

def add(a: int, b: int) -> int:
    """Add two integers and return the result."""
    return a + b

agent = FunctionAgent(
    tools=[FunctionTool.from_defaults(fn=multiply), FunctionTool.from_defaults(fn=add)],
    llm=OpenAI(model="gpt-4o-mini"),
)

async def main():
    response = await agent.run("What is (121 * 3) + 42?")
    print(response)

if __name__ == "__main__":
    asyncio.run(main())
```

### Query Engine

<CodeGroup titles={["Python", "JS/TS"]}>

```python Python
from llama_index.core import Document, Settings, VectorStoreIndex
from llama_index.embeddings.openai import OpenAIEmbedding
from llama_index.llms.openai import OpenAI

Settings.llm = OpenAI(model="gpt-4o-mini")
Settings.embed_model = OpenAIEmbedding(model="text-embedding-3-small")

documents = [
    Document(text="Orders can be returned within 30 days of delivery for a full refund."),
    Document(text="Defective products can be exchanged within 90 days of delivery."),
]
index = VectorStoreIndex.from_documents(documents)
query_engine = index.as_query_engine()

response = query_engine.query("How long do I have to return an order?")
print(response)
```

```typescript JS/TS
import { Document, Settings, VectorStoreIndex } from "llamaindex";
import { OpenAI, OpenAIEmbedding } from "@llamaindex/openai";

Settings.llm = new OpenAI({ model: "gpt-4o-mini" });
Settings.embedModel = new OpenAIEmbedding({ model: "text-embedding-3-small" });

const documents = [
  new Document({ text: "Orders can be returned within 30 days of delivery for a full refund." }),
  new Document({ text: "Defective products can be exchanged within 90 days of delivery." }),
];
const index = await VectorStoreIndex.fromDocuments(documents);
const queryEngine = index.asQueryEngine();

const response = await queryEngine.query({ query: "How long do I have to return an order?" });
console.log(response.toString());
```
