## Spring AI compatibility

<Warning>
The traceAI wrapper compiled against Spring AI `1.0.0-M4` is not a supported integration path for Spring AI `1.1.x`; it can fail with a `NoSuchMethodError` involving `Message.getContent()`. The M4 compilation target is not a tested support range. Do not install this wrapper for Spring AI 1.1 or downgrade to M4 as a workaround.
</Warning>

For Spring AI 1.1, use the [Spring AI 1.1 observability guide](https://docs.spring.io/spring-ai/reference/1.1/observability/index.html). For Spring Boot 3.5, use the matching [Spring Boot tracing guide](https://docs.spring.io/spring-boot/3.5/reference/actuator/tracing.html) to configure OpenTelemetry and an OTLP exporter.

Native observations may not include the same traceAI attributes, token counts or cost fields across providers. Do not enable sensitive prompt or completion logging to work around wrapper compatibility.
