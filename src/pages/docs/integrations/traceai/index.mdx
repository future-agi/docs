## About

A customer asks Ridgeline Outfitters how to dry a rain shell. A model span tells you what the model answered. An agent trace also tells you whether the agent looked up the care instructions before answering. Choose the adapter for the operation you want to see, not just the model provider you use.

## Choose a tracing path

| Your application | What creates the spans | Start here |
| --- | --- | --- |
| Pydantic AI, Python | The adapter wraps agent runs and their model and tool calls. The run stays open while you consume a stream. | [Stream a Pydantic AI run](#pydantic-ai) |
| Agno, Python | OpenInference-based Agno wrappers trace the framework's own model, tool and retrieval operations. | [Trace an Agno agent](#agno) |
| Strands, Python or TypeScript | Strands creates the spans. A wrapped exporter maps the native tree without creating a second one. | [Export native Strands spans](#strands) |
| Cohere, Python or TypeScript | A client instrumentor traces chat, streaming chat, embeddings and reranking, not your surrounding agent. | [Trace a Cohere client](#cohere) |
| LangChainGo | One callback handler tracks the components you attach it to. Each concurrent run needs its own context. | [Trace two chains](#langchaingo) |
| Bedrock Runtime or Anthropic Messages, Go | An AWS client wrapper or Anthropic client middleware traces each model call, not each streamed event. | [Bedrock Runtime](#bedrock-runtime-for-go) or [Anthropic Messages](#anthropic-messages-for-go) |

To trace supported calls at startup instead of attaching wrappers or callbacks, use a zero-code agent:

## Set up the examples

1. Set `FI_API_KEY` and `FI_SECRET_KEY` in your server process. An organization owner, organization admin or workspace admin can find the **API Key** and **Secret Key** on the [Keys page](https://app.futureagi.com/dashboard/keys). All examples send traces to the `ridgeline-framework-tracing` Observe project. Keep credentials out of source and span attributes.
2. Choose **one** section below. Use a fresh Python virtual environment, Node project or Go module for that example. Each program owns its provider and shuts it down on exit. In a service, initialize once and shut down only after in-flight calls finish.
3. The Pydantic AI example runs locally without model credentials. The others make provider calls: supply the credentials and model access specified in that section. Future AGI keys authenticate trace export, not model calls.

{/* MEDIA: Keys page showing the API Key and Secret Key column labels with all credential values concealed. */}

If you self-host, set `FI_BASE_URL` to your platform API origin. If the trace collector uses a different origin, set `FI_TRACES_URL` to that origin. Do not append `/tracer/v1/traces` to either variable. In the Go and Strands Node examples, an explicit `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT` overrides both and must include the full path. The hosted traces endpoint is `https://api.futureagi.com/tracer/v1/traces`.

## Pydantic AI

Install the full `pydantic-ai` distribution, not just `pydantic-ai-slim`. The instrumentor checks for `pydantic-ai`. This example uses Python 3.12 and Pydantic AI's local `TestModel` to compare a complete answer with one you stop reading.

```bash
python -m pip install 'traceai-pydantic-ai==0.2.0' 'pydantic-ai==1.107.0'
```

Save as `rain_shell.py` and run `python rain_shell.py`.

```python
import asyncio

from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from pydantic_ai import Agent
from pydantic_ai.models.test import TestModel
from traceai_pydantic_ai import PydanticAIInstrumentor

provider = register(project_name="ridgeline-framework-tracing", project_type=ProjectType.OBSERVE, verbose=False)
tracing = PydanticAIInstrumentor()
tracing.instrument(tracer_provider=provider)
agent = Agent(TestModel(custom_output_text="Air dry the shell away from direct heat."))


async def answer(stop_early=False):
    async with agent.run_stream("How should I dry my rain shell?") as result:
        async for text in result.stream_text(delta=True, debounce_by=None):
            print(text, end="")
            if stop_early:
                break
    print()


async def main():
    await answer()
    await answer(stop_early=True)


try:
    asyncio.run(main())
finally:
    tracing.uninstrument()
    provider.force_flush()
    provider.shutdown()
```

Look for two `pydantic_ai.agent.run_stream` roots, each with a model request beneath it. The run takes its input from the prompt. On exit from `async with`, the adapter records `output.value` for a fully consumed answer. The second run has an input but **no final output**; the first chunk is not the answer. An exception escaping the context marks the span as an error without suppressing the exception. Set `FI_HIDE_INPUTS=true` and `FI_HIDE_OUTPUTS=true` before instrumentation to hide content without changing what your application receives.

## Agno

Use Python 3.10 or later and Agno 2.7.2 or later. Set `OPENAI_API_KEY` to your provider key and `OPENAI_MODEL` to a chat model that supports tools. The [complete Agno program](/examples/observe/framework-tracing/agno_example.py) defines `lookup_care`, streams the reply and closes the iterator even if the consumer stops. Run it with:

```bash
python -m pip install 'traceai-agno[agno]==0.2.3' 'agno==2.7.2' openai
curl -fsSLO https://docs.futureagi.com/examples/observe/framework-tracing/agno_example.py
python agno_example.py
```

`configure_agno_tracing` installs one set of OpenInference-based wrappers. If the model calls the tool, the agent run contains a model span, `lookup_care`, and another model span for the reply. `Knowledge.search` and `Knowledge.asearch` can add a retriever span. Don't also call `agno.tracing.setup_tracing` or instrument the same model separately. The model spans already report Agno's model name and token counts using OpenInference attributes.

| Who owns the tracer provider? | How to configure and stop tracing |
| --- | --- |
| The adapter, as in the example | Pass `otlp_endpoint`, both authentication headers and `project_name`. `tracing.uninstrument()` removes the wrappers and shuts down the provider it created. It does not replace the process-wide provider. |
| Your application | Configure the exporter and project on your provider. With `fi_instrumentation.register`, select `semantic_convention=SemanticConvention.OPENINFERENCE` from `fi_instrumentation.otel`. Pass `tracer_provider=provider` to `configure_agno_tracing` instead of endpoint options. After runs finish, call `tracing.uninstrument()`; flush and shut down the borrowed provider yourself when the application exits. |

The example uses OpenInference's `TraceConfig(hide_inputs=True, hide_outputs=True)`. This also hides tool arguments and retrieved content. FI and OpenInference hide flags both apply: a hide flag in either takes precedence. Closing a started stream early ends the affected stream span as an error; draining it allows the final response and reported usage to arrive.

## Strands

Install the provider **before you create an agent**. Both examples ask the agent to call `lookup_care`. Strands owns the agent, loop, model and tool spans. The adapter wraps the exporter, not `Agent` or the model client. Set `OPENAI_API_KEY` to your provider key and `OPENAI_MODEL` to a chat model with tool support.

<Tabs>
  <Tab title="Python">
    Use Python 3.10 or later and `strands-agents>=1.24.0`. The [Python program](/examples/observe/framework-tracing/strands_example.py) passes `StrandsSpanExporter(HTTPSpanExporter())` to `register` and sets the global tracer provider. Do not also attach a lifecycle callback or call `StrandsTelemetry.setup_otlp_exporter()` for these spans.

    ```bash
    python -m pip install 'traceai-strands==0.1.2' 'strands-agents[otel,openai]==1.63.0'
    curl -fsSLO https://docs.futureagi.com/examples/observe/framework-tracing/strands_example.py
    python strands_example.py
    ```

    For `Agent.stream_async()`, read the iterator to exhaustion if you need complete model usage. With Strands 1.63.0, an early `aclose()` can leave native model and event-loop spans unfinished. Close abandoned iterators to release resources, but flushing the exporter cannot recover a span that Strands never ended.
  </Tab>
  <Tab title="TypeScript / Node.js">
    Use Node.js 22 or later and `@strands-agents/sdk` 1.23.x. The [Node ESM program](/examples/observe/framework-tracing/strands_example.mjs) installs `StrandsSpanProcessor` around a batch processor with `StrandsSpanExporter`. `NodeTracerProvider.register()` propagates the parent across `await`. Do not add the legacy method wrapper or a second raw exporter.

    ```bash
    npm init -y
    npm install @traceai/strands@0.1.3 @strands-agents/sdk@1.23.0 openai@6.45.0 \
      @opentelemetry/api@1.9.0 @opentelemetry/sdk-trace-node@2.8.0 \
      @opentelemetry/sdk-trace-base@2.8.0 @opentelemetry/sdk-metrics@2.8.0 \
      @opentelemetry/resources@2.8.0 @opentelemetry/exporter-trace-otlp-http@0.219.0
    curl -fsSLO https://docs.futureagi.com/examples/observe/framework-tracing/strands_example.mjs
    node strands_example.mjs
    ```

    Consume `agent.stream()` to the end for completion telemetry. An early iterator return without a known outcome is `UNSET`, not success. The adapter marks known cancellations and failed tool results as errors. Shut down the provider after consumption.
  </Tab>
</Tabs>

For a tool-assisted answer, expand the agent: the first loop cycle contains a model call and the tool call; the second contains the model's reply. **Count tokens on model spans only.** The adapter removes repeated usage from the enclosing agent and loop spans. By default the wrapped exporter omits prompts, replies and tool payloads. Keep sensitive text out of span names and resource metadata; the wrapper is not a privacy filter for another exporter.

## Cohere

Choose the client **for your language**. The Python adapter instruments `cohere.Client` and `cohere.AsyncClient`; don't substitute `ClientV2` just because your TypeScript application uses `CohereClientV2`. Both examples set vector hiding before creating the client. Supply `COHERE_API_KEY` for a Cohere account with access to `embed-english-v3.0`.

<Tabs>
  <Tab title="Python">
    The [Python embedding program](/examples/observe/framework-tracing/cohere_example.py) calls `CohereInstrumentor().instrument(tracer_provider=provider, config=...)` and embeds one care instruction with `embedding_types=["int8"]`. Use Python 3.10 through 3.13. The adapter requires Cohere 5.0.0 or later; these commands use 5.21.1.

    ```bash
    python -m pip install 'traceai-cohere==0.1.3' 'cohere==5.21.1'
    curl -fsSLO https://docs.futureagi.com/examples/observe/framework-tracing/cohere_example.py
    python cohere_example.py
    ```

    Your application receives the typed vector. The `cohere.embed` span reports the vector count and dimensions, not the values, with `hide_embedding_vectors=True`. With `AsyncClient.chat_stream`, use `async for` on the iterator and `await stream.aclose()` if you stop early. The span covers iteration and records provider usage when the terminal response supplies it.
  </Tab>
  <Tab title="TypeScript / Node.js">
    Use Node.js 22 for these commands. The adapter supports `cohere-ai` 7.x or 8.x; for the v2 example use 8.3.0 and set `COHERE_MODEL` to a chat model you can use. The [Node ESM program](/examples/observe/framework-tracing/cohere_example.mjs) calls `setTracerProvider` and `manuallyInstrument(Cohere)` **before** constructing `CohereClientV2`, which binds its methods in the constructor.

    ```bash
    npm init -y
    npm install @traceai/cohere@0.1.2 @traceai/fi-core@1.4.1 cohere-ai@8.3.0
    curl -fsSLO https://docs.futureagi.com/examples/observe/framework-tracing/cohere_example.mjs
    node cohere_example.mjs
    ```

    Expect one `Cohere Chat Stream` span for the whole `chatStream()` iterator and one `Cohere Embed` span. The adapter records final usage when supplied, not a running count per chunk. Breaking from the loop or aborting the controller marks the stream cancelled with status unset; EOF without a terminal event is an error. `hideEmbeddingVectors: true` excludes vector attributes and the raw embedding response.
  </Tab>
</Tabs>

Typed embeddings may contain `float`, `int8`, `uint8`, `binary` or `ubinary`. These are alternative representations of the same inputs, not additional documents. Hiding inputs and hiding vectors are separate controls; enable both if neither search text nor its vector belongs in traces.

## LangChainGo

Use Go 1.26 or later with LangChainGo v0.1.15 or later. Set `OPENAI_API_KEY` and `OPENAI_MODEL`. The [chain program](/examples/observe/framework-tracing/langchaingo.go) sends two care questions concurrently. The [exporter](/examples/observe/framework-tracing/export.go) adds both FI headers and the Observe project resource to the uncompressed OTLP/HTTP request.

```bash
mkdir ridgeline-chains && cd ridgeline-chains
go mod init example.com/ridgeline/chains
base=https://docs.futureagi.com/examples/observe/framework-tracing
curl -fsSLO "$base/export.go" && curl -fsSLO "$base/langchaingo.go"
go get github.com/future-agi/traceAI/go/langchaingo@v0.1.0
go mod tidy
FI_HIDE_INPUTS=true FI_HIDE_OUTPUTS=true go run .
```

Create `h := lc.NewHandler(lc.WithTracerProvider(tp), lc.WithModel(modelID))`. Attach `openai.WithCallback(h)` to the model and `chains.WithCallback(h)` to the chain. Pass the handler to each tool or retriever that accepts callbacks. For an embedder there is no callback: use `h.WrapEmbedder(embedder)` instead. Set `OPENAI_EMBEDDING_MODEL` to an embedding model you can use to run the example's optional `EmbedQuery`. It creates a separate `langchaingo.embed_query` span with dimensions, not the vector. `EmbedDocuments` records the number of inputs.

Each invocation creates `runCtx := lc.ContextWithRun(ctx)`, passes it through `chains.Run`, and defers `h.EndRun(runCtx)`. Expect **two traces**, each a `langchaingo.chain` with its own `langchaingo.chat` child. Reusing a run context across goroutines can attach one request's operations to the other. `EndRun` closes unmatched callback spans; shutting down the provider after both goroutines finish flushes them.

The legacy `HandleLLMStart` and the agent action/finish callbacks lack matching span boundaries. Use a model that emits the generate-content start/end pair for response and usage details. A retriever that fails without an end callback needs `EndRun` for cleanup. The adapter does not infer missing usage or preserve partial model output on error.

## Bedrock Runtime for Go

Use Go 1.26 or later and AWS SDK for Go v2 `service/bedrockruntime` v1.63.9 or later. Configure AWS credentials, `AWS_REGION`, and `BEDROCK_MODEL_ID` for a model or inference profile you can invoke. The [Bedrock program](/examples/observe/framework-tracing/bedrock.go) asks the same care question twice: once with `Converse` and once with `ConverseStream`.

```bash
mkdir ridgeline-bedrock && cd ridgeline-bedrock
go mod init example.com/ridgeline/bedrock
base=https://docs.futureagi.com/examples/observe/framework-tracing
curl -fsSLO "$base/export.go" && curl -fsSLO "$base/bedrock.go"
go get github.com/future-agi/traceAI/go/bedrock@v0.1.1
go mod tidy
FI_HIDE_INPUTS=true FI_HIDE_OUTPUTS=true go run .
```

Wrap the configured AWS client with `bedrock.NewClient(awsClient, bedrock.WithTracerProvider(tp))`. `bedrock.ContextWithSessionID` links calls to an opaque session without making one the parent of the other. Expect two LLM spans: `bedrock.Converse` and `bedrock.ConverseStream`.

Read `response.GetStream()` **on the wrapper's response**, defer `stream.Close()`, range over `stream.Events()` and check `stream.Err()`. The span ends on completion, error, cancellation or close, not at the first headers. An early close sets `traceai.stream.closed_early=true`; counts may be absent if usage metadata never arrived. Set the content flags before constructing the wrapper; those flags do not change what AWS returns to your code.

## Anthropic Messages for Go

Use Go 1.26 or later and `anthropic-sdk-go` v1.82.0 or later. Set `ANTHROPIC_API_KEY` to your provider key and `ANTHROPIC_MODEL` to a Messages model you can use. The [Messages program](/examples/observe/framework-tracing/anthropic.go) streams a single reply and prints the final output token count.

```bash
mkdir ridgeline-messages && cd ridgeline-messages
go mod init example.com/ridgeline/messages
base=https://docs.futureagi.com/examples/observe/framework-tracing
curl -fsSLO "$base/export.go" && curl -fsSLO "$base/anthropic.go"
go get github.com/future-agi/traceAI/go/anthropic@v0.1.0
go mod tidy
FI_HIDE_INPUTS=true FI_HIDE_OUTPUTS=true go run .
```

Register the provider with `otel.SetTracerProvider(tp)` and add `option.WithMiddleware(traceaianthropic.Middleware())` when constructing the client. For `Messages.New` and `Messages.NewStreaming`, the middleware enriches the recording SDK span `anthropic.messages.create`. With native SDK tracing disabled it creates its own span per HTTP attempt. Tool requests are attributes of the model span, not spans for executing your tool.

Defer `stream.Close()` as soon as you have the stream. Accumulate `stream.Current()` while `stream.Next()` is true and check `stream.Err()` before using final usage. A premature end, error event or cancelled context can produce an error span. Leave the SDK's own `ANTHROPIC_OPEN_TELEMETRY_TRACES_CONTENT_MODE` unset when hiding content: FI hide flags control what the middleware adds, not content independently emitted by the SDK.

## Verify a trace

In the sidebar under **OBSERVE**, open **Tracing**. Select `ridgeline-framework-tracing` in the **Project** column, then open the trace for the operation you ran. For an agent or chain, expand the root and select a model call. For a direct model or embedding call, select the root itself. Compare the child operations and model usage with the expectations above. A stream is one operation, not a span per token.

{/* MEDIA: Observe trace for the Ridgeline Strands agent expanded to show the two model calls and lookup_care, with one model span selected and its token counts visible. */}

| Symptom | What to check |
| --- | --- |
| The app got a reply, but no trace appeared | Verify both FI keys, the collector destination and the project. Finish or close streams before flushing. Flush on application shutdown even on the error path. |
| Duplicate model spans or inflated usage | Use one tracing path for each operation. Don't add a second model wrapper or export both native and adapted copies of the same Strands tree. |
| Missing response or usage on an interrupted request | Compare with a run consumed to completion. A flush exports finished spans; it cannot recover unsent provider usage or infer an unread answer. |
| The tree is present but message content isn't | Check the adapter's capture default and the process's privacy settings. Hiding content should not remove the framework's parent-child relationships. |
