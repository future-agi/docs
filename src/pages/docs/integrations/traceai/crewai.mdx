Trace CrewAI crew and task execution in **Observe**. This example runs one writing task without external tools.

## Install

Use Python 3.10–3.12, as required by the [traceAI-crewai package](https://pypi.org/pypi/traceAI-crewai/0.1.8/json).

```bash
pip install 'traceAI-crewai==0.1.8' 'crewai>=0.41.1'
```

---

## Set credentials and capture preferences

Set credentials in your shell, then run the Python blocks below in one script. Choose an OpenAI model available to your account.

```bash
export OPENAI_API_KEY="your-openai-api-key"
export OPENAI_MODEL="your-available-openai-model"
export FI_API_KEY="your-futureagi-api-key"
export FI_SECRET_KEY="your-futureagi-secret-key"
```

Tracing can export task inputs, outputs and tool data to Future AGI. To hide input and output values and messages, set `FI_HIDE_INPUTS=true` and `FI_HIDE_OUTPUTS=true` before initializing instrumentation. See [mask span attributes](/docs/sdk/tracing/mask-span-attributes) for controls. These switches are not a general scrubber for custom attributes or exception text; keep secrets out of task data and error messages.

---

## Register the trace provider

Name the Observe project that will receive spans.

```python
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType

trace_provider = register(
    project_type=ProjectType.OBSERVE,
    project_name="crewai_project",
)
```

---

## Instrument CrewAI

Initialize the instrumentor before running the crew.

```python   
from traceai_crewai import CrewAIInstrumentor

CrewAIInstrumentor().instrument(tracer_provider=trace_provider)
```

---

## Run a crew

```python
import os
from crewai import LLM, Agent, Crew, Task

def story_example():
    llm = LLM(model=os.environ["OPENAI_MODEL"])

    writer = Agent(
        role="Writer",
        goal="Write creative stories",
        backstory="You are a creative writer with a passion for storytelling",
        allow_delegation=False,
        llm=llm,
    )

    writing_task = Task(
        description="Write a short story about a magical forest",
        agent=writer,
        expected_output="A short story about a magical forest",
    )

    crew = Crew(agents=[writer], tasks=[writing_task])

    # Execute the crew
    result = crew.kickoff()
    print(result)

if __name__ == "__main__":
    try:
        story_example()
    finally:
        trace_provider.shutdown()  # Send pending spans before this script exits.
```

## View the trace

In Future AGI, open **Observe** and select the project configured above to inspect the trace.
