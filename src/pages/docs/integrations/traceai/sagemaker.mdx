## About

When your application calls a model hosted on SageMaker, traceAI records one LLM span per Runtime request. For a Ridgeline Outfitters support agent, a streaming span measures how long it took to read a reply about a tent. An asynchronous span measures only how long SageMaker took to accept the question, not how long the model took to answer it.

## 1. Install the adapter and configure access

Choose the SDK your application already uses. For Python, use Python 3.10 through 3.13 and boto3 1.34.0 or later. For Node.js, use the AWS SDK for JavaScript v3 (`>=3.693.0`, below v4).

<CodeGroup titles={["Python", "Node.js"]}>

```bash Python
python -m pip install traceAI-sagemaker==0.1.0 fi-instrumentation-otel==1.5.1 'boto3>=1.34.0'
```

```bash Node.js
npm install @traceai/sagemaker@0.1.0 @traceai/fi-core@1.4.1 '@aws-sdk/client-sagemaker-runtime@^3.693.0'
```

</CodeGroup>

Set `FI_API_KEY` and `FI_SECRET_KEY` in the application's environment using your [Future AGI API keys](/docs/admin-settings/api-keys). Separately, configure AWS credentials with permission to invoke your endpoint. Replace the region and endpoint name below with your own. The example assumes a model that accepts a Hugging Face text-generation payload (`inputs` and `parameters`); use your model's request format if it differs.

```bash
export AWS_REGION=us-east-1
export SAGEMAKER_ENDPOINT=ridgeline-gear-support
```

JSON and text bodies can appear in traces by default. To keep customer questions and replies out of traces, set `FI_HIDE_INPUTS=true` and `FI_HIDE_OUTPUTS=true` in the environment **before** starting the application. These settings affect telemetry, not the request sent to SageMaker.

## 2. Instrument the client and invoke the endpoint

Save one of the scripts below. Run `python ridgeline.py` or `node ridgeline.cjs` for a blocking request. In Python, create the `sagemaker-runtime` client **after** calling `instrument()`. In Node.js, pass the AWS SDK module that supplies your client to `manuallyInstrument()`.

<CodeGroup titles={["Python", "Node.js"]}>

```python Python
# ridgeline.py
import json
import os
import sys
from contextlib import closing

import boto3
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from traceai_sagemaker import SageMakerInstrumentor

mode = sys.argv[1] if len(sys.argv) > 1 else "blocking"
provider = register(project_name="ridgeline-sagemaker", project_type=ProjectType.OBSERVE,
                    verbose=False)
SageMakerInstrumentor().instrument(tracer_provider=provider)
client = boto3.client("sagemaker-runtime", region_name=os.environ["AWS_REGION"])
request = {"EndpointName": os.environ["SAGEMAKER_ENDPOINT"], "ContentType": "application/json"}
payload = {"inputs": "How should I store my tent after a rainy trip?",
           "parameters": {"max_new_tokens": 64}}

try:
    if mode == "blocking":
        reply = client.invoke_endpoint(**request, Body=json.dumps(payload))
        with closing(reply["Body"]) as body:
            print(body.read().decode("utf-8"))
    elif mode == "stream":
        reply = client.invoke_endpoint_with_response_stream(
            **request, Body=json.dumps({**payload, "stream": True}))
        with closing(reply["Body"]) as events:
            for event in events:
                if "PayloadPart" in event:
                    sys.stdout.buffer.write(event["PayloadPart"]["Bytes"])
                    sys.stdout.buffer.flush()
    elif mode == "async":
        receipt = client.invoke_endpoint_async(**request, InputLocation=os.environ["S3_INPUT_URI"])
        print(receipt["InferenceId"], receipt["OutputLocation"])
    else:
        raise SystemExit("Choose blocking, stream or async")
finally:
    provider.shutdown()
```

```javascript Node.js
// ridgeline.cjs
const { register, ProjectType } = require("@traceai/fi-core");
const { SageMakerInstrumentation } = require("@traceai/sagemaker");
const sdk = require("@aws-sdk/client-sagemaker-runtime");

async function main(mode) {
  const provider = register({ projectName: "ridgeline-sagemaker", projectType: ProjectType.OBSERVE });
  const adapter = new SageMakerInstrumentation();
  adapter.setTracerProvider(provider);
  adapter.manuallyInstrument(sdk);
  const client = new sdk.SageMakerRuntimeClient({ region: process.env.AWS_REGION });
  const request = { EndpointName: process.env.SAGEMAKER_ENDPOINT, ContentType: "application/json" };
  const payload = { inputs: "How should I store my tent after a rainy trip?", parameters: { max_new_tokens: 64 } };

  try {
    if (mode === "blocking") {
      const reply = await client.send(new sdk.InvokeEndpointCommand({ ...request, Body: JSON.stringify(payload) }));
      console.log(new TextDecoder().decode(reply.Body));
    } else if (mode === "stream") {
      const reply = await client.send(new sdk.InvokeEndpointWithResponseStreamCommand({
        ...request, Body: JSON.stringify({ ...payload, stream: true }),
      }));
      for await (const event of reply.Body) {
        if (event.PayloadPart?.Bytes) process.stdout.write(event.PayloadPart.Bytes);
      }
    } else if (mode === "async") {
      const receipt = await client.send(new sdk.InvokeEndpointAsyncCommand({
        ...request, InputLocation: process.env.S3_INPUT_URI,
      }));
      console.log(receipt.InferenceId, receipt.OutputLocation);
    } else {
      throw new Error("Choose blocking, stream or async");
    }
  } finally {
    client.destroy();
    await provider.shutdown();
  }
}

main(process.argv[2] ?? "blocking").catch(error => { console.error(error.name); process.exitCode = 1; });
```

</CodeGroup>

## 3. Compare streaming with asynchronous inference

| Mode | How to run it | When the span ends |
| --- | --- | --- |
| Blocking | Use the script without an argument on a real-time endpoint. | `sagemaker.invoke_endpoint` ends when the call returns a response or raises an error. You can still read the returned body. |
| Stream | Point `SAGEMAKER_ENDPOINT` at a streaming-capable endpoint and run `python ridgeline.py stream` or `node ridgeline.cjs stream`. | `sagemaker.invoke_endpoint_with_response_stream` stays open while you read events. It ends on exhaustion, error or early close. |
| Async | Put the same JSON input in an S3 object readable by the endpoint. Set `S3_INPUT_URI` to its `s3://` URI, set `SAGEMAKER_ENDPOINT` to your **asynchronous inference** endpoint, then run `python ridgeline.py async` or `node ridgeline.cjs async`. | `sagemaker.invoke_endpoint_async` ends at submission. On success, the script prints the inference ID and S3 output location. Look there for the eventual result; the adapter does not fetch it or add it to the span. |

For example, if `S3_INPUT_URI` is `s3://ridgeline-support/requests/tent-storage.json`, the contents of `tent-storage.json` are the model input, not the AWS request envelope:

```json
{"inputs": "How should I store my tent after a rainy trip?", "parameters": {"max_new_tokens": 64}}
```

## 4. Inspect the span

In **Observe > Tracing**, open `ridgeline-sagemaker` and select the trace for your call. Compare these attributes:

| Attribute | What to look for |
| --- | --- |
| `gen_ai.provider.name` | `aws.sagemaker` for all three calls. |
| `gen_ai.request.model`, `aws.sagemaker.endpoint_name` | The **endpoint name**, such as `ridgeline-gear-support`, not necessarily the deployed model's name. `gen_ai.response.model` is separate and appears if the response supplies a recognized model identifier. |
| `aws.sagemaker.target_variant`, `aws.sagemaker.invoked_variant` | The variant you requested and the one SageMaker reports using. `aws.sagemaker.inference_component` identifies the component if you specify one. |
| `gen_ai.usage.input_tokens`, `gen_ai.usage.output_tokens` | Counts extracted from the model's response, when available. A submission receipt has no model output to measure. |
| `aws.sagemaker.inference_id` | For an async request, match this to `InferenceId` on the receipt, not to the generated reply. |

## Body ownership, missing fields and errors

- **Read the response once, as usual.** For blocking JSON or text responses, the Python adapter reads the network body and gives you a new readable `StreamingBody` containing the same bytes. For blocking JavaScript requests, the SDK has already read the body when `send()` resolves; the adapter leaves it in place. Binary bytes are not captured as text; the span can carry a type and size instead.
- **Consume the stream before shutting down tracing.** The adapter forwards each event unchanged, including `PayloadPart.Bytes`. It joins supported JSON lines and SSE `data:` lines for the trace; it does not drain the stream for you. If you stop early, close the Python body or break out of the JavaScript `for await` loop. `aws.sagemaker.stream.incomplete=true` means the consumer stopped before exhaustion. In JavaScript, `gen_ai.server.time_to_first_token` measures milliseconds to the first `PayloadPart`, not the duration of the full stream.
- **Missing counts do not mean zero tokens.** The adapter extracts counts from recognized responses, for example `usage` in an OpenAI-compatible response or `details.generated_tokens` in a Hugging Face TGI response. It also recognizes Anthropic-style and Bedrock-style responses. A custom JSON schema can yield output without counts; tracing does not require your model to return usage.
- **Mask both directions for sensitive traffic.** A model can echo the prompt in its reply. In Python, hide sampling parameters separately with `FI_HIDE_LLM_INVOCATION_PARAMETERS=true` if they contain sensitive values, such as stop strings. An unrecognized JSON response can be recorded as the whole decoded body if output capture is enabled. In JavaScript, input masking also suppresses request parameters and prevents the whole unrecognized JSON response from being recorded. Keep endpoint names, variant names and inference IDs free of customer data: they are metadata, not body text.
- **On a failed call or stream**, inspect `error.type`. The adapter records the error type rather than its message and passes the exception back to your application. Check your application's AWS error handling for details.
