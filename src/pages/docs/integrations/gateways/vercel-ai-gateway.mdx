## About

Trace a question from Ridgeline Outfitters' returns assistant to Vercel AI Gateway with the OpenAI Python client. The span identifies the service your client called, not the author of the model.

This is a client span, not a [Vercel Trace Drain](https://vercel.com/docs/ai-gateway/observability-and-spend/trace-drains). Client spans can include prompts and answers. Drain traces omit prompt and answer content. For JavaScript applications using the Vercel AI SDK rather than the OpenAI SDK, use the [Vercel AI SDK integration](/docs/integrations/traceai/vercel).

## Configure the endpoint

Choose a `provider/model` ID from the gateway model list. To see the catalog without making a model call, run:

```bash
curl --fail --silent --show-error https://ai-gateway.vercel.sh/v1/models
```

The OpenAI client sends the AI Gateway key to Vercel as a Bearer token. Future AGI authenticates the trace export separately with `X-Api-Key` and `X-Secret-Key`.

Use Python 3.10 to 3.13. Set the provider credential and model ID for inference, and a separate Future AGI key pair for trace export. If you self-host Future AGI, set `FI_BASE_URL` to the platform API origin. If the collector has a separate origin, set `FI_TRACES_URL` to that origin.

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install 'traceAI-openai==0.1.16' 'fi-instrumentation-otel==1.5.1' 'openai==3.57.0'
export AI_GATEWAY_API_KEY="YOUR_PROVIDER_KEY"
export AI_GATEWAY_MODEL="openai/gpt-4o-mini"
export FI_API_KEY="YOUR_FUTURE_AGI_API_KEY"
export FI_SECRET_KEY="YOUR_FUTURE_AGI_SECRET_KEY"
export FI_TRACES_URL="https://api.futureagi.com"  # use your collector origin if self-hosted
```

## Check the trace destination without calling a model

Save this as `gateway_tracing.py`. Run `python gateway_tracing.py` to send a single span to `ridgeline-returns`. You can open the printed trace ID in Observe before spending anything on inference. This checks the Future AGI destination, **not** your Vercel key.

```python
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from traceai_openai import OpenAIInstrumentor


def configure_tracing():
    provider = register(project_type=ProjectType.OBSERVE, project_name="ridgeline-returns", verbose=False)
    OpenAIInstrumentor().instrument(tracer_provider=provider)
    return provider


if __name__ == "__main__":
    provider = configure_tracing()
    try:
        with provider.get_tracer("gateway").start_as_current_span("Check Vercel trace export") as span:
            print(f"{span.get_span_context().trace_id:032x}")
    finally:
        provider.shutdown()
```

## Send the return question

Save this as `returns.py` alongside `gateway_tracing.py` and run `python returns.py` with an active Vercel AI Gateway key:

```python
import os

from openai import OpenAI
from gateway_tracing import configure_tracing

provider = configure_tracing()
try:
    with OpenAI(base_url="https://ai-gateway.vercel.sh/v1", api_key=os.environ["AI_GATEWAY_API_KEY"]) as client:
        result = client.chat.completions.create(
            model=os.environ["AI_GATEWAY_MODEL"],
            messages=[{"role": "user", "content": "We accept unused packs within 30 days. Can I return an unused pack on day 12?"}],
        )
        print(result.choices[0].message.content)
finally:
    provider.force_flush()
    provider.shutdown()
```

Under **Observe**, open **Tracing** and select `ridgeline-returns`. Open the trace, select `ChatCompletion` and switch **Preview** to **JSON**. Look for `gen_ai.provider.name=vercel`. A successful non-streamed call shows the model returned by the service, which can differ from the requested ID in `gen_ai.request.parameters`.

## Limits and troubleshooting

- For a gateway `401`, check `AI_GATEWAY_API_KEY`. This example supplies that key explicitly; it does not load a Vercel OIDC token. An unknown model calls for a current ID from the gateway’s list; a path error calls for `/v1` once, not twice. The trace does not split out fallback providers, internal retries or Vercel charges.
- A stream or failed chat records the requested model. If the `gen_ai.usage.*` attributes are absent, the endpoint did not report a count, even if the token chips show `0`. See the [shared streaming example](/docs/integrations/traceai/openai#send-a-request).
- An unknown proxy hostname keeps `openai`. If you get an answer but no span, check the Future AGI credentials, collector destination and shutdown, not the provider key.
- To group multiple calls from the same return conversation, wrap the calls in `with using_session("returns-42")` after importing `using_session` from `fi_instrumentation`. This sets `session.id` on the client spans, not a Vercel routing header.
- Prompts, answers and tool arguments can reach Future AGI. Before starting the process, set `FI_HIDE_INPUTS=true`, `FI_HIDE_OUTPUTS=true` and `FI_HIDE_LLM_INVOCATION_PARAMETERS=true` to hide those fields. Input hiding masks standard tool definitions, not session IDs. Use `FI_HIDE_ERROR_DETAILS=true` to suppress span error messages and stack traces independently; input or output hiding enables it by default. These switches do not change what Vercel receives.
