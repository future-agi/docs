## About

Trace a question from Ridgeline Outfitters' returns assistant to Vercel AI Gateway with the OpenAI Python client. The span identifies the service receiving the call, not the author of the model.

This is a client span, not a [Vercel Trace Drain](https://vercel.com/docs/ai-gateway/observability-and-spend/trace-drains). It can include the prompts and answers seen by the SDK. For JavaScript applications using the Vercel AI SDK rather than the OpenAI SDK, use the [Vercel AI SDK integration](/docs/integrations/traceai/vercel).

## Configure the endpoint

Choose a `provider/model` ID from the gateway model list (`GET https://ai-gateway.vercel.sh/v1/models`). The OpenAI client sends the AI Gateway key to Vercel as a Bearer token. Future AGI authenticates the trace export separately with `X-Api-Key` and `X-Secret-Key`.

Use Python 3.10 to 3.13. Set the provider credential and model ID for inference, and a separate Future AGI key pair for trace export. If you self-host Future AGI, set `FI_BASE_URL` to your collector origin.

```bash
python -m pip install 'traceAI-openai==0.1.16' 'fi-instrumentation-otel==1.5.1' 'openai==3.57.0'
export AI_GATEWAY_API_KEY="YOUR_PROVIDER_KEY"
export AI_GATEWAY_MODEL="YOUR_CHAT_MODEL_ID"
export FI_API_KEY="YOUR_FUTURE_AGI_API_KEY"
export FI_SECRET_KEY="YOUR_FUTURE_AGI_SECRET_KEY"
```

## Send the return question

Save this as `returns.py` and run `python returns.py`:

```python
import os

from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from openai import OpenAI
from traceai_openai import OpenAIInstrumentor

provider = register(project_type=ProjectType.OBSERVE, project_name="ridgeline-returns")
OpenAIInstrumentor().instrument(tracer_provider=provider)
try:
    with OpenAI(base_url="https://ai-gateway.vercel.sh/v1", api_key=os.environ["AI_GATEWAY_API_KEY"]) as client:
        result = client.chat.completions.create(
            model=os.environ["AI_GATEWAY_MODEL"],
            messages=[{"role": "user", "content": "We accept unused packs within 30 days. Can I return an unused pack on day 12?"}],
        )
        print(result.choices[0].message.content)
finally:
    provider.force_flush()
    provider.shutdown()
```

In **Observe**, open `ridgeline-returns` and select the `ChatCompletion` span. Look for `gen_ai.provider.name=vercel`. A successful non-streamed call shows the model returned by the service, which can differ from the requested ID in `gen_ai.request.parameters`.

## Limits and troubleshooting

- A gateway `401` points to the gateway credential. If you also use Vercel OIDC, check for a stale API key: the gateway gives a configured key precedence. An unknown model calls for a current ID from the gateway’s list; a path error calls for `/v1` once, not twice. The trace does not split out fallback providers, internal retries or Vercel charges.
- A stream or failed chat records the requested model. Missing usage means the endpoint did not report a count. See the [shared streaming example](/docs/integrations/traceai/openai#send-a-request).
- An unknown proxy hostname keeps `openai`. If you get an answer but no span, check the Future AGI credentials, collector destination and shutdown, not the provider key.
- To group multiple calls from the same return conversation, wrap the calls in `with using_session("returns-42")` after importing `using_session` from `fi_instrumentation`. This sets `session.id` on the client spans, not a Vercel routing header.
- Prompts, answers and tool arguments can reach Future AGI. Before starting the process, set `FI_HIDE_INPUTS=true`, `FI_HIDE_OUTPUTS=true` and `FI_HIDE_LLM_INVOCATION_PARAMETERS=true` to hide those fields. Review tool definitions, session IDs and provider error text separately. These switches do not change what Vercel receives.
