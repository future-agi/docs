Trace Gemini calls made with the Google Gen AI SDK (`google-genai`) in Future AGI with `traceAI-google-genai`.

- With a Gemini API key, follow the [Google GenAI setup guide](/docs/integrations/traceai/google_genai) for package versions, content-capture controls, streaming and async requests, and the captured attributes.
- On Vertex AI with Google Cloud credentials, follow the [Vertex AI guide](/docs/integrations/traceai/vertexai), which uses the same instrumentor.
