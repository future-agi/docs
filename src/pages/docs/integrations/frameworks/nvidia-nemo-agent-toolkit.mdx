## Current status

**The Future AGI exporter for NVIDIA NeMo Agent Toolkit is not available in a published NVIDIA package.** This is a status page, not an installation guide.

On 2026-10-29, PyPI listed `nvidia-nat` and `nvidia-nat-opentelemetry` **1.9.0**. The published `nvidia-nat-opentelemetry` wheel contains no `futureagi` exporter. Adding `_type: futureagi` to a stock installation does not install that exporter.

The implementation is proposed in [Future AGI's toolkit fork PR #1](https://github.com/future-agi/NeMo-Agent-Toolkit/pull/1), at commit `16c1295c51b3f76a5d85d3ff59f55f21ab5ea23e`. That source branch is separate from NVIDIA's published distribution and is not a supported customer installation path.

## Release requirement

A setup guide requires a published distribution containing the exporter and validation of that exact installation and workflow. A fork checkout or an editable package is not a substitute for that release. This page offers no hosted, self-hosted, `nat serve`, or `nat eval` setup.

The repository's calculator workflow and script are development fixtures for the proposal, not a released integration recipe.
