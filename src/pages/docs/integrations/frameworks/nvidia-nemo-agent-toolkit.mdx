---
title: "NVIDIA NeMo Agent Toolkit"
description: "Availability of the Future AGI exporter for NVIDIA NeMo Agent Toolkit."
---

The Future AGI exporter is not available in the published `nvidia-nat-opentelemetry` 1.9.0 package. Adding `_type: futureagi` to that installation does not install the exporter.

## Related guides

- [NVIDIA NeMo Agent Toolkit source](https://github.com/NVIDIA/NeMo-Agent-Toolkit)
- [Published OpenTelemetry package](https://pypi.org/project/nvidia-nat-opentelemetry/1.9.0/)
- [LangChain tracing](/docs/integrations/traceai/langchain) for applications that run LangChain directly, outside the toolkit.
