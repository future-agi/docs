## About

Trace a question from Ridgeline Outfitters' returns assistant to Novita AI with the OpenAI Python client. The span identifies the service receiving the call, not the author of the model.

## Configure the endpoint

Choose a chat model in Novita’s Model Hub and allow enough output tokens for its answer. The example sends `max_tokens=128`. For tool calls, choose a model with function calling.

Use Python 3.10 to 3.13. Set the provider credential and model ID for inference, and a separate Future AGI key pair for trace export. If you self-host Future AGI, set `FI_BASE_URL` to your collector origin.

```bash
python -m pip install 'traceAI-openai==0.1.16' 'fi-instrumentation-otel==1.5.1' 'openai==3.57.0'
export NOVITA_API_KEY="YOUR_NOVITA_API_KEY"
export NOVITA_MODEL="YOUR_CHAT_MODEL_ID"
export FI_API_KEY="YOUR_FUTURE_AGI_API_KEY"
export FI_SECRET_KEY="YOUR_FUTURE_AGI_SECRET_KEY"
```

## Send the return question

Save this as `returns.py` and run `python returns.py`:

```python
import os

from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from openai import OpenAI
from traceai_openai import OpenAIInstrumentor

provider = register(project_type=ProjectType.OBSERVE, project_name="ridgeline-returns")
OpenAIInstrumentor().instrument(tracer_provider=provider)
try:
    with OpenAI(base_url="https://api.novita.ai/openai/v1", api_key=os.environ["NOVITA_API_KEY"]) as client:
        result = client.chat.completions.create(
            model=os.environ["NOVITA_MODEL"],
            max_tokens=128,
            messages=[{"role": "user", "content": "We accept unused packs within 30 days. Can I return an unused pack on day 12?"}],
        )
        print(result.choices[0].message.content)
finally:
    provider.force_flush()
    provider.shutdown()
```

Open **Observe**, choose `ridgeline-returns` and select the `ChatCompletion` span. Look for `gen_ai.provider.name=novita`. A successful non-streamed call shows the model returned by the service, which can differ from the requested ID in `gen_ai.request.parameters`.

## Limits and troubleshooting

- For a path error, use `https://api.novita.ai/openai/v1` as the SDK base. Some Novita examples use `https://api.novita.ai/openai`; this chat recipe includes `/v1` once. For a model-not-found response, check the exact model ID in the Model Hub. See [Novita error codes](https://docs.novita.ai/guides/error).
- A stream or failed chat records the requested model. Missing usage means the endpoint did not report a count. See the [shared streaming example](/docs/integrations/traceai/openai#send-a-request).
- An unknown proxy hostname keeps `openai`. If you get an answer but no span, check the Future AGI credentials, collector destination and shutdown, not the provider key.
- Use data approved for tracing. Request, response and error content can reach Future AGI. Set `FI_HIDE_INPUTS=true`, `FI_HIDE_OUTPUTS=true` and `FI_HIDE_LLM_INVOCATION_PARAMETERS=true` before starting the process to hide those fields. These switches are not a general scrubber for tool definitions or error messages.
