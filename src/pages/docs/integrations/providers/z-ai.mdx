## About

Trace a question from Ridgeline Outfitters' returns assistant to Z.ai with the OpenAI Python client. The span identifies the service your client called, not the author of the model.

## Configure the endpoint

Use a [general platform API key](https://z.ai/manage-apikey/apikey-list) and a model available on that platform. A Coding Plan uses a [different endpoint configuration](https://docs.z.ai/devpack/quick-start). This recipe wraps `openai.OpenAI`, not `ZaiClient`.

Use Python 3.10 to 3.13. Set the provider credential and model ID for inference, and a separate Future AGI key pair for trace export. If you self-host Future AGI, set `FI_BASE_URL` to the platform API origin. If the collector has a separate origin, set `FI_TRACES_URL` to that origin.

```bash
python -m pip install 'traceAI-openai==0.1.16' 'fi-instrumentation-otel==1.5.1' 'openai==3.57.0'
export ZAI_API_KEY="YOUR_ZAI_API_KEY"
export ZAI_MODEL="YOUR_CHAT_MODEL_ID"
export FI_API_KEY="YOUR_FUTURE_AGI_API_KEY"
export FI_SECRET_KEY="YOUR_FUTURE_AGI_SECRET_KEY"
```

## Send the return question

Save this as `returns.py` and run `python returns.py`:

```python
import os

from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from openai import OpenAI
from traceai_openai import OpenAIInstrumentor

provider = register(project_type=ProjectType.OBSERVE, project_name="ridgeline-returns")
OpenAIInstrumentor().instrument(tracer_provider=provider)
try:
    with OpenAI(base_url="https://api.z.ai/api/paas/v4/", api_key=os.environ["ZAI_API_KEY"]) as client:
        result = client.chat.completions.create(
            model=os.environ["ZAI_MODEL"],
            messages=[{"role": "user", "content": "We accept unused packs within 30 days. Can I return an unused pack on day 12?"}],
        )
        print(result.choices[0].message.content)
finally:
    provider.force_flush()
    provider.shutdown()
```

Under **Observe**, open **Tracing** and select `ridgeline-returns`. Open the trace and select `ChatCompletion`. In **Preview**, select **JSON** next to **Markdown**. The OpenAI example below shows where to find the control.

![ChatCompletion span for an OpenAI call, with the JSON button to the right of Markdown in Preview.](/images/docs/integrations/z-ai-trace-view.png)

In your Z.ai trace, check that `gen_ai.provider.name` is `zai`. A successful non-streamed call shows the model returned by the service, which can differ from the requested ID in `gen_ai.request.parameters`.

## Limits and troubleshooting

- If Z.ai rejects the request, check the key type and model access before changing the trace collector configuration.
- A stream or failed chat records the requested model. If the `gen_ai.usage.*` attributes are absent, the endpoint did not report a count, even if the token chips show `0`. See the [shared streaming example](/docs/integrations/traceai/openai#send-a-request).
- An unknown proxy hostname keeps `openai`. If you get an answer but no span, check the Future AGI credentials, collector destination and shutdown, not the provider key.
- Use data approved for tracing. Request, response and error content can reach Future AGI. Set `FI_HIDE_INPUTS=true`, `FI_HIDE_OUTPUTS=true` and `FI_HIDE_LLM_INVOCATION_PARAMETERS=true` before starting the process to hide those fields. Trace masking does not change what you send to Z.ai. Input hiding masks standard tool definitions. To suppress span error messages and stack traces independently, set `FI_HIDE_ERROR_DETAILS=true`; this is already the default when input or output hiding is on. Custom attributes and application logs need their own review.
