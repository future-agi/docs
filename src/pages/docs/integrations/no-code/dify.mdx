## Current status

**There is no released Future AGI tracing provider for Dify covered by this page.** This is a status notice, not a customer setup guide.

The proposed provider lives in [Future AGI's Dify fork PR #1](https://github.com/future-agi/dify/pull/1), at commit `91fd3ed2b11bbcf9f1382f101ac127d6777bb2b0`. It adds `api/providers/trace/trace-futureagi` to the source tree. That package is absent from the upstream Dify `1.17.1` release tree. On 2026-10-29, PyPI had no `dify-trace-futureagi` distribution.

A fork branch is not a published Dify release or a separately installable provider. This page does not offer Dify Cloud, stock Docker images, custom fork images, or source-deployment setup instructions.

## Release requirement

A setup guide requires a released Dify distribution or provider that contains the integration, followed by validation of its exact installation, Monitoring configuration, export, and privacy behavior. Until then, the fork remains development work rather than a supported installation path.

Adding a traceAI package to Dify does not install this proposed provider or its Monitoring settings.
