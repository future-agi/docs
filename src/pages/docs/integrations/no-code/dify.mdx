---
title: "Dify tracing support"
description: "Learn about the current status of Dify tracing with Future AGI."
---

Dify 1.17.1 does not include a Future AGI tracing provider. This guide does not offer a supported Dify-to-Future AGI tracing setup. Adding a traceAI package to Dify does not install a Dify provider or its Monitoring settings.

For applications whose model-calling code you control, see the [traceAI integrations](/docs/integrations/traceai).
