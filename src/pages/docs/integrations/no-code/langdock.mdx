---
title: "Langdock tracing support"
description: "Learn about the current status of Langdock tracing with Future AGI."
---

Future AGI does not currently support a direct Langdock tracing setup. Langdock's tracing configuration is for Langfuse; it does not provide the Future AGI collector settings required by this guide.

Do not enter Future AGI credentials or a Future AGI collector URL in Langdock's Langfuse settings. If you have changed the **Tracing cloud URL**, restore it to your Langfuse host.

For Langdock's agent logging settings, see [Langdock agent configuration](https://docs.langdock.com/en/using-langdock/agents/configuration).
