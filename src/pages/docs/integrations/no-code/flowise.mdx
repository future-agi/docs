---
title: "Flowise tracing support"
description: "Learn about the retirement of Flowise tracing with Future AGI."
---

Future AGI has retired its Flowise integration. The upstream [FlowiseAI/Flowise repository](https://github.com/FlowiseAI/Flowise) is archived. There is no supported Flowise-to-Future AGI tracing setup, including fork-based installations.

Installing a traceAI package in Flowise does not add a supported tracing provider.

For applications whose model-calling code you control, see the [traceAI integrations](/docs/integrations/traceai).
