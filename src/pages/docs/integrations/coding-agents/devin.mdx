## About

Future AGI has no integration for hosted Devin sessions: sessions that run in Cognition's cloud and are started from the Devin web app, Slack, Linear, an automation, or the Devin API.

Cognition does not export a session's steps or tool calls to an endpoint you configure. Every documented surface either starts Devin, sends a notification or a chat reply, or has to be called with a Devin API key. Future AGI does not hold Devin credentials and does not poll Devin, so there is nothing to configure on the Future AGI side.

This was last checked against [docs.devin.ai](https://docs.devin.ai) on 2026-10-15.

This page is only about hosted Devin. Devin Desktop runs two local agents, Cascade and Devin Local, on your machine. Cascade has [hooks](https://docs.devin.ai/desktop/cascade/hooks). Tracing Devin Desktop is a separate setup from hosted Devin and is not described on this page.

## What Devin exposes today

| Surface | Direction | Why it is not a session trace export |
| --- | --- | --- |
| [Automations](https://docs.devin.ai/product-guides/automations), including the **Webhook** trigger | Inbound to Devin | A webhook trigger is a URL that other systems call to *start* a Devin session; the request body becomes part of the prompt. The **Email notification** action sends an email when an automation runs. Neither sends the session's steps anywhere. |
| [Slack](https://docs.devin.ai/integrations/slack) and [Microsoft Teams](https://docs.devin.ai/integrations/microsoft-teams) | Devin posts to a chat thread | Devin replies in the thread with updates and questions for the people in it. These are chat messages in a workspace you connected, not spans sent to an endpoint you choose. |
| [Session Insights](https://docs.devin.ai/product-guides/session-insights) and its [API](https://docs.devin.ai/api-reference/v3/sessions/get-organizations-session-insights) | You call Devin | An after-the-fact analysis of a finished session: category, languages, tools used, a timeline of key events, and suggestions. It is a summary you request, not a span tree. |
| [Sessions API](https://docs.devin.ai/api-reference/v3/sessions/get-enterprise-session-messages) (session status, messages, attachments) | You call Devin | Pull only, with a Devin API key. There is no callback when a session changes. |
| [Audit logs API](https://docs.devin.ai/api-reference/v3/audit-logs/enterprise-audit-logs) | You call Devin | Enterprise admin actions such as `create_session` and `send_message`. No tool calls or turns. |
| [Devin MCP server](https://docs.devin.ai/work-with-devin/devin-mcp): `devin_session_search`, `devin_session_interact`, `devin_session_events` | An MCP client calls Devin | Lets an agent or IDE list sessions and read their events. It is an API an MCP client pulls from, not a push. |
| [Devin SDK](https://docs.devin.ai/sdk) (`@cognition-ai/sdk`, beta): [`session.events()`](https://docs.devin.ai/sdk/guides/watching-sessions) and [OpenTelemetry tracing](https://docs.devin.ai/sdk/guides/tracing) | Your process connects to Devin | A TypeScript library. A process you run, holding your Devin API key, creates or attaches to sessions and receives their events live. See [Devin SDK tracing](#devin-sdk-tracing-untested) below. |

No OTLP endpoint, outbound webhook for session events, or hook that runs for cloud sessions is documented.

## Why there is no Future AGI integration

A trace integration needs the app to send events while the session runs. Hosted Devin sends none. Everything above is either a trigger into Devin, a message to people, or data that has to be fetched from Devin with your Devin API key. Building on that would mean Future AGI storing Devin keys and polling Devin's API. That would be a different product: a delayed import of summaries, not a trace of the session as it ran.

What a hosted Devin session would show in Future AGI today: nothing. Session span, turns, tool names, tool arguments, model, tokens, cost, and errors are all unavailable through Future AGI.

## What you can do instead

### Devin SDK tracing (untested)

If you drive or watch Devin sessions from your own TypeScript code with the [Devin SDK](https://docs.devin.ai/sdk), the SDK can record them as OpenTelemetry spans. Cognition documents the setup in its [tracing guide](https://docs.devin.ai/sdk/guides/tracing): the SDK creates spans through `@opentelemetry/api`, and your app chooses the tracer provider and exporter.

Future AGI has not tested this path, does not publish a recipe for it, and does not support it as an integration yet. For how plain OpenTelemetry spans reach Future AGI in general, see [Instrument and Verify](/docs/cookbook/quickstart/instrument-and-verify).

Before you rely on it, note what Cognition documents about this path:

- **Content is recorded by default.** The SDK records the prompt, the final reply, and every tool call's input and output, which can include repository code. Set `recordContent: false` unless you want that text in your trace backend. With it, the SDK keeps timing, token usage, cost, model and tool names.
- It runs in your process, with your Devin API key, and only sees events while that process is attached. History replayed when you attach or reload a session is not exported.
- Each Devin turn is its own trace unless you pass a `parent` span, so one Devin session arrives as several traces.
- Cloud sessions report turns and tool calls, but not per-request token usage or cost.
- The SDK is beta (`0.0.1-beta.N` prereleases) and its API can change between releases.

### Other options

- **Cascade in Devin Desktop.** Cascade runs locally and has [hooks](https://docs.devin.ai/desktop/cascade/hooks). Tracing it is a separate setup from hosted Devin and is not described on this page.
- **Devin Local and Devin CLI.** These local agents have [lifecycle hooks](https://docs.devin.ai/cli/extensibility/hooks/lifecycle-hooks). Future AGI does not ship a recipe for them yet.
- **Devin's own analytics.** For a review of a finished session, use [Session Insights](https://docs.devin.ai/product-guides/session-insights) in Devin.

## Privacy

Hosted Devin sends nothing to Future AGI, and Future AGI never asks for a Devin API key, so no Devin session content reaches Future AGI from hosted Devin.

The Devin SDK tracing path above is different: you run it and choose where it exports, and it records prompt, reply and tool text by default. Set `recordContent: false` to leave that text out.

## What would change this

This page will be revised, and an integration considered, if either happens:

- Cognition documents a server-side export of hosted session activity: an OTLP destination, an outbound webhook per session event, or hooks that run for cloud sessions.
- Future AGI tests the Devin SDK tracing path end to end and publishes it as a supported recipe.
