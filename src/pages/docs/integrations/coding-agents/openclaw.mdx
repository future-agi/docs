---
title: "OpenClaw agent tracing with Future AGI"
description: "Set up local OpenClaw tracing with one command, then inspect model requests, tool calls, token usage and errors in Future AGI."
---

Trace local OpenClaw model requests and tools in Future AGI using OpenClaw's official [`diagnostics-otel` plugin](https://docs.openclaw.ai/gateway/opentelemetry) and the maintained `@traceai/openclaw` integration. No collector or copied instrumentation scripts are required.

Use **OpenClaw 2026.10.5**, **Node 24.16+ in the 24.x line**, and macOS or Linux. Configure your agent and model provider in OpenClaw first. This launcher supports local `agent` turns, not an existing Gateway, channels, TUI, Control UI or `agent exec`.

## 1. Get your Future AGI keys

Create an API key and secret key in [Settings → Keys](https://app.futureagi.com/dashboard/keys). Setup asks for both with hidden terminal input. Do not paste them into an agent conversation.

## 2. Set up tracing

```bash
npx @traceai/agents setup openclaw --project coding-agents
```

Setup validates your credentials, saves a private configuration and uses OpenClaw's own installer to add the official diagnostics plugin and a lifecycle-only flush plugin. Review the native source and capability prompts. Setup never accepts those prompts or grants conversation-access hooks for you. Existing plugin allowlists, model configuration and unrelated settings are preserved.

**Content capture is on by default.** Messages and tool results can include file contents or secrets that the agent reads. For structure and usage without content, use:

```bash
npx @traceai/agents setup openclaw --project coding-agents --no-capture-content
```

## 3. Run a local turn

```bash
npx @traceai/agents run openclaw -- agent --local --agent main \
  --session-id readme-review --message "Read README.md and summarize the project."
```

Replace `main` with your configured agent ID if needed. Reuse `--session-id` for subsequent turns in that conversation. If you omit it, each invocation starts a new session.

Open **Observe** in [Future AGI](https://app.futureagi.com), select **coding-agents**, and open an `openclaw.harness.run` trace to inspect its model requests and tool calls. The launcher exports spans during the run and flushes at shutdown.

Use the launcher for traced runs. An ordinary `openclaw` launch is not redirected to Future AGI, and setup does not restart or take ownership of a running Gateway.

## What you see

| Native span | What it shows |
| --- | --- |
| `openclaw.harness.run` and `openclaw.run` | Native run boundaries, model/provider and outcome. |
| `openclaw.model.call` | Model request input/output, model/provider, input/output/cache tokens, time to first byte and error status. |
| `openclaw.tool.execution` | Tool name, input/output and error status, with native parent relationships. |
| `openclaw.context.assembled` | Native context-assembly timing. |

Content appears only when OpenClaw exposes it and your privacy settings permit it. Trace and span IDs, ancestry and timings come from the official plugin; the integration does not instrument the model twice. An opaque session identifier groups invocations that use the same explicit session ID.

### Retries and usage

A retry can produce several native run traces for one user prompt. The integration keeps those roots separate rather than inventing a common parent. Root spans can report completion even when a model attempt failed; inspect `openclaw.model.call` and `openclaw.tool.execution` error status.

The `openclaw.model.usage` rollup repeats request usage and is suppressed, so it does not double-count model calls or tokens. Only model-request spans contribute token usage; counts are not assigned to failed attempts or opaque external-harness turns.

OpenClaw exports cost estimates as metrics, not model-call trace attributes. Metrics are disabled here, so no cost is invented. The native system prompt and external-harness internals are not available as content. Subagent and compaction visibility is limited to what the official diagnostics plugin emits.

## Configuration

Credentials are stored in the shared Future AGI configuration directory with file mode `0600`. Preferences are stored in `futureagi.json` beside OpenClaw's host config. `OPENCLAW_STATE_DIR` and `OPENCLAW_CONFIG_PATH` are respected. This package does not read `.env` files, shell profiles or keychains.

| Setting | Effect |
| --- | --- |
| `FI_API_KEY` and `FI_SECRET_KEY` | A complete environment pair overrides saved credentials. |
| `FI_PROJECT_NAME` | Destination project name. |
| `FI_AGENT_CAPTURE_CONTENT=false` | Exclude captured messages, tool content and error messages. |
| `FI_HIDE_INPUTS=true` or `FI_HIDE_OUTPUTS=true` | Apply stricter input/output privacy. |
| `FI_HIDE_ERROR_DETAILS=true` | Keep error status without its message. |
| `FI_AGENT_ENABLED=false` | Stop collection/export while the agent continues to run. |
| `FI_USER_ID` | Set your own user identifier; otherwise use a saved opaque ID. |
| `FI_BASE_URL` | Self-hosted API origin. |
| `FI_OTLP_ENDPOINT` | Exact trace URL; takes precedence over `FI_BASE_URL`. |
| `FI_AGENT_CONFIG_DIR` | Override the shared protected configuration directory. |

The Cloud destination is `https://api.futureagi.com/tracer/v1/traces`. The integration sends all three required headers: `X-Api-Key`, `X-Secret-Key` and `X-Project-Name`. Resources include `project_name` and `project_type=observe`. Metrics and logs stay off.

### Per-project configuration

Configure and run with the same project directory:

```bash
npx @traceai/agents setup openclaw --scope project --project-dir /path/to/repo --project my-project
npx @traceai/agents run openclaw --project-dir /path/to/repo -- agent --local --agent main --message "Summarize README.md"
```

The repository gets `.futureagi/agents.json`, not credentials. It cannot silently raise your content-capture setting or redirect saved credentials to a new destination.

## Status and controls

```bash
npx @traceai/agents status openclaw --check
npx @traceai/agents doctor openclaw
npx @traceai/agents disable openclaw
npx @traceai/agents enable openclaw
npx @traceai/agents uninstall openclaw
```

Status distinguishes plugin registration, observed exports and credential acceptance. A successful export request does not by itself verify that a trace rendered in the product. Fresh installs report activation unobserved until data is exported.

Disable works without credentials or network and fences already-running exporters and queued work. Data already accepted by a server cannot be recalled. Uninstall restores only unchanged settings owned by the integration; shared native plugins remain installed but do not export through Future AGI without the launcher.

## Privacy and delivery

The integration removes host/process metadata, arbitrary attributes, event payloads and tool definitions. Each captured content field is limited to 20,000 characters, known Future AGI credentials are removed, and best-effort redaction is applied. Turn content capture off for sensitive work: arbitrary application secrets cannot be reliably recognized.

Environment-supplied Future AGI keys are removed before the model/tool runtime starts. Programs running as your OS user can still access the protected credential store. OpenClaw's own environment and access policies still apply.

Export runs in the agent process with a bounded memory queue and timeout. There is no background daemon, local receiver or model proxy. Telemetry failure must not fail a model/tool call. Interrupting the process can lose queued spans; delivery is not exactly-once.

## Troubleshooting

**Setup returns `TRUST_REQUIRED`.** Complete OpenClaw's interactive source and capability review for the lifecycle plugin, then rerun setup. Enabling a plugin does not authorize conversation-access hooks.

**Setup reports an existing exporter or preload.** Do not run two tracing routes together. Keep the existing route or explicitly remove it before setting up this integration; setup does not disable it for you.

**Registered, but no exports.** Use `run openclaw -- agent --local ...`, not `agent exec` or an existing Gateway. Check your agent/provider configuration with OpenClaw, then run `doctor openclaw`.

**Unsupported host version.** Use OpenClaw 2026.10.5 with Node 24.16+ in the 24.x line. Check both `openclaw --version` and `node --version`.

**Destination is not approved.** Run setup for the intended project and endpoint. Editing a repository setting cannot redirect saved credentials.

**Registration was modified.** Inspect your host-config changes. Update/uninstall will not overwrite settings changed since installation.

**Content is missing.** Check Future AGI privacy settings and OpenClaw's own permissions. Some surfaces, including the system prompt and external-harness internals, are not exposed by the official plugin.
