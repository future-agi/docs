description: "Set up Future AGI tracing for GitHub Copilot CLI with one command, then explore model calls and tools grouped by conversation."
---

See each Copilot turn, model call, and tool call in Future AGI, grouped by conversation. The maintained `@traceai/agents` launcher uses Copilot's native telemetry; you do not need a copied script, shell function, or background service.

## Prerequisites

- Node.js **22.16+ on 22.x**, or **24.x**, on macOS or Linux with `mkfifo` available.
- GitHub Copilot CLI **1.0.106** on your `PATH`: `npm install -g @github/copilot@1.0.106`.
- Copilot's normal login or BYOK model configuration. The integration does not supply model access or change your organization's Copilot policies.

This guide covers the local **Copilot CLI**, not VS Code Copilot Chat, inline completions, or GitHub's hosted coding agent.

## Quick start

<Steps>
<Step title="Get your Future AGI keys">

Create an API key and secret key on the [Future AGI keys page](https://app.futureagi.com/dashboard/keys). Setup asks for them using hidden terminal entry. Do not paste keys into Copilot or pass them as command-line arguments.

</Step>
<Step title="Set up tracing">

```bash
npx @traceai/agents setup copilot --project coding-agents
```

Setup validates the destination with an empty authenticated OTLP request and saves owner-only configuration files (`0600`). It leaves Copilot's provider settings, permissions, repository hooks, and your shell profile unchanged.

<Note>
Content capture is **on by default**. Prompts, model responses, and tool input/output can include source code and secrets the agent reads. To keep only structure and usage, add `--no-capture-content` to the setup command.
</Note>

</Step>
<Step title="Run Copilot and open the trace">

From your project directory, start a traced session:

```bash
npx @traceai/agents run copilot
```

Ask Copilot to list the top-level files and summarize the project's purpose. Keep its normal permission prompts and approve only the access you intend.

Open [Future AGI](https://app.futureagi.com), select the `coding-agents` project in **Observe**, and expand the latest `invoke_agent` trace. Its `chat` and `execute_tool` children show model requests and tool calls. Turns from the same conversation share `session.id` for session grouping.

</Step>
</Steps>

Start traced sessions through `run copilot`; plain `copilot` does not activate this integration. Pass Copilot arguments after `--`. If you prefer a global install, `npm install -g @traceai/agents` provides the equivalent `fi-agent` command.

## Configuration

Environment variables override saved configuration. Supply both credential variables together; one alone is rejected.

| Setting | Purpose |
| --- | --- |
| `FI_API_KEY`, `FI_SECRET_KEY` | Override saved credentials without placing them in command arguments. |
| `FI_PROJECT_NAME` | Override the project; rerun setup to approve a changed destination when using saved credentials. |
| `FI_BASE_URL` | Self-hosted origin, such as `https://your-futureagi.example`. |
| `FI_OTLP_ENDPOINT` | Exact OTLP trace URL; takes precedence over `FI_BASE_URL`. |
| `FI_AGENT_CAPTURE_CONTENT=false` | Capture only structure and usage for this process. |
| `FI_AGENT_ENABLED=false` | Kill switch: disable Future AGI export for this process. |
| `FI_HIDE_INPUTS=true`, `FI_HIDE_OUTPUTS=true` | Omit input or output content. |
| `FI_HIDE_ERROR_DETAILS=true` | Omit error details and failed-tool output while retaining failure status and exit code. |
| `FI_USER_ID` | Set a user identifier; otherwise setup generates one. |
| `OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf` | Use protobuf instead of the default `http/json`; `OTEL_EXPORTER_OTLP_TRACES_PROTOCOL` takes precedence. |

Cloud uses `https://api.futureagi.com/tracer/v1/traces`. For self-hosting, run setup with `--base-url https://your-futureagi.example`. The launcher does not use inherited `OTEL_EXPORTER_OTLP_*` destinations or authentication headers.

### Per-project settings

Run setup inside the repository:

```bash
npx @traceai/agents setup copilot --scope project --project my-project
npx @traceai/agents run copilot
```

The repository gets `.copilot/futureagi.json`; credentials remain in your protected user store. Repeating project-scoped setup preserves its destination, project, and content preference unless you explicitly change them.

Run from that repository, or use `run copilot --project-dir /path/to/project`. Use `--project-dir` instead of Copilot's `-C` flag so the tracing configuration and working directory agree. Repository settings cannot redirect saved or environment-supplied credentials to an unapproved endpoint, or raise capture above your user-level privacy setting. Approve changes through setup rather than editing the repository's transport settings.

## Status and controls

```bash
npx @traceai/agents status copilot --check
npx @traceai/agents disable copilot
npx @traceai/agents enable copilot
npx @traceai/agents uninstall copilot
```

Status shows the resolved destination, project, privacy policy, host version, launcher registration, and recent accepted/dropped export counts. `--check` performs a fresh connection check; `--json` provides machine-readable output. Transport acceptance does not prove that a trace is already visible in the UI.

Disabling drops queued spans from active launchers. Re-enabling does not revive those queues; start a new session to resume tracing. Uninstall disables tracing and removes launcher registration without changing Copilot settings or deleting shared credentials.

## Privacy and trace details

The launcher reads native spans through a private named pipe, preserves their IDs and parent relationships, filters content, and exports directly to Future AGI. It writes no raw telemetry file. Its in-memory queue is bounded; failed exports do not block Copilot, and dropped spans are reported in status.

Content is limited to 20,000 characters per field. Known Future AGI credentials are redacted, and unknown native attributes are dropped. Redaction is best effort, not a guarantee that arbitrary secrets in source files are removed. Use structure-only mode for sensitive repositories.

The launcher removes Future AGI credentials and inherited OTLP headers from Copilot's environment. This is not a security sandbox: tools you authorize still run as your user and can read files accessible to you. Copilot controls its own session history and logs.

- Model requests contribute token, cache, and reasoning counts when Copilot provides them. Parent aggregate counters are diagnostic only, so they do not double session totals.
- Tool failures retain error status and native exit codes even when error details are hidden.
- Native subagent ancestry and compaction markers are preserved when emitted. Missing spans and usage are not estimated.
- Native billing multipliers are not converted into dollar costs.
- `session.id` groups conversation turns; `user.id` and the `observe` project type support user attribution.

## Troubleshooting

| Symptom | What to do |
| --- | --- |
| Unsupported host version | Check `copilot --version` reports `1.0.106`. The launcher disables auto-update for its invocations to keep the telemetry format consistent. |
| No traces appear | Start through `run copilot`, then run `status copilot --check`. Remove `COPILOT_OFFLINE=true` when you want telemetry. |
| Keys rejected or revoked | Run `npx @traceai/agents setup copilot --replace-credentials` for hidden replacement-key entry. Keep `--scope project` for a project profile. Headless runs must supply a new `FI_API_KEY` and `FI_SECRET_KEY` environment pair. Old settings remain unchanged until the new keys validate. |
| Destination not approved | Rerun setup for the selected scope and destination. A repository file or credential pair alone cannot approve a repository-controlled endpoint. Copilot continues without tracing. |
| Prompts are visible unexpectedly | Content is on by default. Rerun setup with `--no-capture-content`, or set `FI_AGENT_CAPTURE_CONTENT=false` for the next process. |
| A field is missing | Check content/privacy settings and whether Copilot emits the field. Oversized native records can be dropped. Token counts do not require content capture. |
| BYOK fails | Check Copilot's provider settings and your organization's policy; tracing does not change model access. |
