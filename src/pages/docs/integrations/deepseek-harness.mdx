---
title: "DeepSeek Harness tracing"
description: "Future AGI does not currently support tracing DeepSeek Harness (dsh)."
---

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`) is a coding-agent harness. **Future AGI does not currently support tracing it.**

This is separate from the DeepSeek chat API. If your application calls DeepSeek models directly, see the model instrumentors under [traceAI](/docs/integrations/traceai).

<Warning>
A third-party `dsh` tracing plugin can export local paths, host names, and raw error text even when message content capture is off. Review its data handling before using it with sensitive projects. It is not supported by Future AGI.
</Warning>
