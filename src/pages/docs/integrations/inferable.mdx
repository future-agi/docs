---
title: "Inferable tracing support"
description: "Learn about the current status of Inferable tracing with Future AGI."
---

Future AGI does not currently support tracing Inferable runs and tool calls. Inferable's Langfuse integration does not export OTLP traces to Future AGI, so do not enter Future AGI credentials or the Future AGI collector URL in its Langfuse settings.

Inferable's **send message payloads** setting sends prompts and tool arguments to the configured Langfuse host. Enable it only if you intend to share that content with that host.

If your application calls model providers directly, see the [traceAI integrations](/docs/integrations/traceai) for provider-level tracing. Those instrumentors do not capture Inferable's own runs and tool calls.
