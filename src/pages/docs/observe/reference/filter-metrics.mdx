---
title: "Filter metrics"
description: "The metrics and fields you can filter, sort, and aggregate the trace table on."
---

These are the metrics and fields Observe exposes for filtering, sorting, and aggregation, the vocabulary behind the [filter syntax](/docs/observe/reference/trace-filter-syntax).

- **Timing**: latency, duration, start and end time
- **Cost and usage**: total tokens, prompt and completion tokens, cost
- **Status**: OK or error
- **Identity**: model, span kind, project, session, user
- **Quality**: eval scores and pass or fail

For the operators and grammar that combine these, see [filter syntax](/docs/observe/reference/trace-filter-syntax).
