---
title: "Span attributes"
description: "The standardized attribute keys a span carries, from OpenTelemetry basics to traceAI's LLM conventions."
---

Every span carries key-value attributes. Some come straight from [OpenTelemetry](https://opentelemetry.io/) (name, status, timing, parent), and traceAI adds LLM-specific keys on top: the span kind, the prompt and completion, the model, token counts, and cost.

- **Core (OpenTelemetry)**: name, kind, status, start and end time, parent span ID, trace ID
- **LLM (traceAI)**: model, input messages, output messages, prompt and completion tokens, cost
- **Retrieval**: query, retrieved documents and their scores
- **Grouping**: session.id, user.id, tags

Which attributes matter depends on the span's kind, see [Span types](/docs/observe/reference/span-types).
