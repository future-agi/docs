---
title: "Reranker"
description: "What a reranker span captures: documents reordered by relevance."
---

A reranker span records retrieved documents being reordered by relevance to the query, so you can see which ones survived and in what order.

For the full set of keys any span carries, see [Span attributes](/docs/observe/reference/span-attributes). For the other kinds, see [Span types](/docs/observe/reference/span-types).
