---
title: "Chain"
description: "What a chain span captures: a group of steps run as one unit."
---

A chain span groups a sequence of steps as one unit. It holds the child spans it runs in order, so a multi-step flow reads as a single node in the trace.

For the full set of keys any span carries, see [Span attributes](/docs/observe/reference/span-attributes). For the other kinds, see [Span types](/docs/observe/reference/span-types).
