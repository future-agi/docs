---
title: "Span types"
description: "The kinds of operation a span can represent in Observe, and what each one captures."
---

Every span carries a `kind` that says what the operation was. Observe uses that kind to label the span, pick its icon, and surface the fields that matter for it. These are the span types traceAI emits.

| Type | What it represents |
|---|---|
| [LLM](/docs/observe/reference/span-types/llm) | A single model call: prompt in, completion out |
| [Tool](/docs/observe/reference/span-types/tool) | A function or tool the model invoked |
| [Retriever](/docs/observe/reference/span-types/retriever) | A lookup against a vector store or index |
| [Embedding](/docs/observe/reference/span-types/embedding) | Text turned into vectors |
| [Reranker](/docs/observe/reference/span-types/reranker) | Retrieved documents reordered by relevance |
| [Agent](/docs/observe/reference/span-types/agent) | A top-level step that coordinates others |
| [Chain](/docs/observe/reference/span-types/chain) | A group of steps run as one unit |
| [Guardrail](/docs/observe/reference/span-types/guardrail) | A safety or policy check on an input or output |
| [Evaluator](/docs/observe/reference/span-types/evaluator) | An eval that scores a span or trace |

For the attributes a span carries regardless of type, see [Span attributes](/docs/observe/reference/span-attributes).
