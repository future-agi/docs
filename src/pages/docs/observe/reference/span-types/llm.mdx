---
title: "LLM"
description: "What an LLM span captures: model, prompt, completion, tokens, and cost."
---

An LLM span records one model call. It carries the model name, the prompt messages sent, the completion returned, the token counts, and the cost.

For the full set of keys any span carries, see [Span attributes](/docs/observe/reference/span-attributes). For the other kinds, see [Span types](/docs/observe/reference/span-types).
