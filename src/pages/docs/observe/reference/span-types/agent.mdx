---
title: "Agent"
description: "What an agent span captures: a top-level step coordinating other spans."
---

An agent span is a top-level step where an agent plans and coordinates the work beneath it. It holds the child spans, the tool calls, retrievals, and model calls, that it set off.

For the full set of keys any span carries, see [Span attributes](/docs/observe/reference/span-attributes). For the other kinds, see [Span types](/docs/observe/reference/span-types).
