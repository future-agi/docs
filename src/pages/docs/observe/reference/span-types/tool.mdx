---
title: "Tool"
description: "What a tool span captures: the tool name, its arguments, and its result."
---

A tool span records a function or tool the model chose to call. It carries the tool name, the arguments it was given, and the result it returned.

For the full set of keys any span carries, see [Span attributes](/docs/observe/reference/span-attributes). For the other kinds, see [Span types](/docs/observe/reference/span-types).
