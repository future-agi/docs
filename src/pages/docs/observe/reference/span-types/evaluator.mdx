---
title: "Evaluator"
description: "What an evaluator span captures: an eval score on a span or trace."
---

An evaluator span records an eval scoring a span or trace on a metric. It carries the metric and the score it produced.

For the full set of keys any span carries, see [Span attributes](/docs/observe/reference/span-attributes). For the other kinds, see [Span types](/docs/observe/reference/span-types).
