---
title: "Retriever"
description: "What a retriever span captures: the query and the documents it returned."
---

A retriever span records a lookup against a vector store or search index. It carries the query and the documents it returned, so you can see what context was pulled into the prompt.

For the full set of keys any span carries, see [Span attributes](/docs/observe/reference/span-attributes). For the other kinds, see [Span types](/docs/observe/reference/span-types).
