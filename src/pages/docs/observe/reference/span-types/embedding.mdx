---
title: "Embedding"
description: "What an embedding span captures: the input text and the embedding model."
---

An embedding span records text being turned into vectors. It carries the input text and the embedding model used.

For the full set of keys any span carries, see [Span attributes](/docs/observe/reference/span-attributes). For the other kinds, see [Span types](/docs/observe/reference/span-types).
