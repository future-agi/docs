## Getting started

Observe shows you what your AI application actually did in production — every request, replayable, with quality, cost, and latency attached. The fastest way in is to send one trace and watch it land. This page is the on-ramp: the five-minute quick start, the concepts the rest of Observe is built on, and the integration guide for whatever framework you already run.

Once traces are flowing, the same data drives everything else in Observe: you debug a single bad answer in the [trace explorer](/docs/observe/features/llm-tracing), watch cost and latency trends on [dashboards](/docs/observe/features/dashboard), score quality with [trace evals](/docs/observe/features/evals), and get paged when a metric slips with [alerts](/docs/observe/features/alerts). You instrument once, and every view reads the same underlying traces.

There are three ways to start, depending on where you are:

- **New to Observe?** Run the [quick start](/docs/observe/quickstart) — install, register a project, send one request, and confirm it lands, in about five minutes.
- **Already on a framework?** Skip the manual setup and add its instrumentor below — one line and your existing calls are traced.
- **Want the mental model first?** Read the [observability model](/docs/observe/concepts/observability-model) to see how traces, spans, sessions, and evals relate before you wire anything up.
