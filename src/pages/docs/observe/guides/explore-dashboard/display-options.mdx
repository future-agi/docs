The graph above the trace table defaults to latency and traffic over time. That doesn't tell you where a support request calls a tool, or which step runs most often. Display options control how the [trace explorer](/docs/observe/guides/explore-dashboard) looks: which primary view sits above the table, which columns are visible and in what order, and how rows are grouped.

<Prerequisites title="Before you start">
- A project with recorded [traces](/docs/observe/concepts/traces). This guide uses the `support-agent` project from the [Observing a LangGraph agent](/docs/cookbook/observe-langgraph-agent-and-obtain-insights) cookbook.
</Prerequisites>

## Open the Display menu

Click **Display** at the top right of the trace explorer. One menu holds the primary view, row height, columns, metrics, and grouping.

![The Display menu open over the trace table, with view tabs on top and sections for rows, columns, metrics, group, and settings.](/images/docs/observe/display-menu.png)

## Switch the primary view

The tabs at the top of the menu swap the graph above the table between three views of the same traces:

- **Graph View**: the default latency and traffic time series
- **Agent Graph**: your agent's structure as a node graph
- **Agent Path**: span flow as a Sankey diagram, sized by span count

![Display menu with the Graph View, Agent Graph, and Agent Path tabs at the top.](/images/docs/observe/display-view-switcher.png)

1. Choose **Agent Graph**.

   Agent Graph draws the nodes the way your agent runs them. Here `support_turn` leads into `LangGraph`, which branches into the agent with its model calls, and into the tools, `search_help_center` and `lookup_order`.

   ![Agent Graph view showing support_turn branching into LangGraph, agent, tools, ChatOpenAI, and VectorStoreRetriever nodes.](/images/docs/observe/display-agent-graph.png)

2. Switch to **Agent Path**.

   Agent Path shows the same run as flow, with each node's span count, so you can see where calls concentrate. In this screenshot, five `support_turn` [spans](/docs/observe/concepts/spans) lead to nine `ChatOpenAI` spans and three `VectorStoreRetriever` spans. These are span counts, not nine separate requests.

   ![Agent Path Sankey diagram showing span flow from support_turn through LangGraph, agent, tools, and the LLM and retriever spans with span counts.](/images/docs/observe/display-agent-path.png)

3. Choose **Graph View** to go back to the default time series.

## Choose your columns

1. Under **Columns**, open **View columns** and show or hide any column.
2. Use **Add custom columns** to surface a span attribute as its own column.
3. Reorder the columns so the fields you care about come first.
4. Click **Autosize columns** to fit them to their content.

## Group the rows

1. Under **Group**, find **Group traces by**.
2. Set it to group by span.

   Repeated spans fold into one group instead of filling separate rows.

3. Set it back to trace to read the table one request per row again.

## Row height, metrics, and defaults

The rest of the menu tunes the table at a glance:

- **Row height** trades density for readability, from Short to taller rows
- **Metrics** (Errors, Non annotated) overlay counts so problem rows stand out
- **Set default for everyone** saves the current layout as your team's default

**Set default for everyone** changes what the whole team sees, so use it only when you mean to change the shared default. To keep a layout for yourself alongside a filter, save it as a [view](/docs/observe/guides/explore-dashboard/views).
