---
title: "Display options"
description: "Choose which columns show, how rows are grouped, and how the trace table is laid out."
---

Display options control how the trace table looks: which columns are visible, how they are ordered, and how rows are grouped. Tune them on the `self-improving-agent` project from the [quickstart](/docs/observe/quickstart) so the table shows what you care about.

## In this guide

- Show, hide, and reorder columns
- Group rows and adjust density
- Save your layout as part of a view
