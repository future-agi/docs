title: "Filter traces by model, status, or eval score"
description: "Use Basic filters to find failed calls on one model, then use Query to find low context adherence and inspect the answer against its source."
page-type: "feature-guide"
---

A request can finish successfully and still return the wrong answer. Use the [trace table](/docs/observe/guides/explore-dashboard) to find failed model calls by status, or use a [context adherence](/docs/evaluation/builtin/context-adherence) score to find answers that disregard retrieved evidence.

<Prerequisites title="Before you start">
- A project with traced traffic. The example uses the [LangGraph support agent](/docs/cookbook/observe-langgraph-agent-and-obtain-insights).
- To filter by score, run the [eval task](/docs/observe/guides/setup-evals) on the turns you want to inspect. You do not need scores for the model and status filters.
</Prerequisites>

## Choose a filter mode

1. Open the project’s trace table.
2. Click **Filter** at the top right.

<img src="/images/docs/observe/filters-open-panel.png" alt="Observe trace table with the Filter button highlighted at the top right" style={{ borderRadius: '5px' }} />

<div class="sdk-ref-table max-sm:[&_td]:px-1.5! max-sm:[&_th]:px-1.5!">

| Mode | When to use it |
|---|---|
| **AI search** | Describe the slice in plain English, for example “errors on gpt-4o today”, and Observe builds the filter. |
| **Basic** | Choose a property, condition and value. Extra conditions apply together with `AND`. |
| **Query** | Write an expression directly, including conditions that Basic cannot express. |

</div>

## Find failed requests on one model

1. Select **Basic**.
2. Choose **Model** as the first property.

   The property picker groups fields under **System**, **Evals**, **Annotations** and **Attributes**, so you can filter on anything the SDK recorded, not just the visible columns.

<img src="/images/docs/observe/filters-pick-property.png" alt="Basic filter builder with the property search open, showing Model and related model attributes grouped by System and Attributes" style={{ borderRadius: '5px' }} />

3. Choose **equals**.
4. Select `gpt-4o-mini` from the recorded models. You can select more than one model if needed.

   The values are the models your traces ran on. Every support-agent turn ran on `gpt-4o-mini`.

<img src="/images/docs/observe/filters-pick-value.png" alt="Basic filter builder with Model equals and the value dropdown showing gpt-4o-mini as a multi-select option" style={{ borderRadius: '5px' }} />

5. Click **Add filter**.
6. Select **Status**.
7. Choose the equality condition.
8. Select `ERROR`.

   Only failed `gpt-4o-mini` requests match. The five visible `support_turn` rows in the screenshot have status `OK`; none of those five would survive the added status condition.

## Find answers that ignored the policy

1. Switch to **Query**.
2. Enter one expression from the examples below. Copy only the expression to the left of `#`, not the explanation.

```text
scores.context_adherence < 0.8                          # ungrounded answers
user.id = cust_42                                       # one customer's traces
fi.span.kind = LLM AND scores.context_adherence < 0.8   # low-adherence LLM spans
```

   Query accepts `=`, `!=`, `>`, `<` and `contains`. The last expression is the one the cookbook uses to surface its single ungrounded turn.

3. Inspect the input and retrieved policy on a matching turn.

   In the support-agent example, look for “My order was a final sale. Can I still get a refund?” The policy rules out a refund; compare it with the actual reply rather than treating a low score as proof.

The middle expression follows one [user](/docs/observe/concepts/users) across conversations. Open **Sessions** to read a whole [conversation](/docs/observe/concepts/sessions) in order.

## If no rows match

1. Widen the time window to include a known request.
2. Check the case of each attribute key and value. Use `ERROR` for status and the model name as the SDK reported it.
3. Try one condition alone before adding `AND`.
