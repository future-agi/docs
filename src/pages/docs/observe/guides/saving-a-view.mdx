---
title: "Saving a view"
description: "Save a filtered trace table as a view so you can return to it in one click."
---

Once you have filtered the trace table down to something useful, save it as a view so you and your team can jump back to it without rebuilding the filters each time. This guide saves a view on the `self-improving-agent` project from the [quickstart](/docs/observe/quickstart).

## In this guide

- Filter the trace table to the traces you want, see [Using Filters](/docs/observe/guides/using-filters)
- Save the current filters as a named view
- Switch between saved views
- Share a view with your team
