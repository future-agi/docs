---
title: "Using Filters"
description: "Narrow the trace table to exactly the traces you want by status, model, time, and more."
---

Filters cut a busy trace table down to the traces you actually care about, whether that is failed requests, one model, a time window, or a single conversation. This guide filters the `self-improving-agent` project from the [quickstart](/docs/observe/quickstart).

## In this guide

- Filter the trace table by status, model, latency, cost, and time
- Combine conditions to narrow the results further
- Filter by session and user to follow one conversation or customer

For the full set of fields and operators, see [Filter syntax](/docs/observe/reference/trace-filter-syntax).
