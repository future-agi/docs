---
title: "Manage versions"
description: "Browse an agent's version history from the Changelog tab."
---

The Changelog tab lets you look back through an agent's version history without disturbing whatever you're currently building, and preview any version on a read-only canvas.

## Open the Changelog tab

From the agent list, open the agent whose history you want to review. It opens on the **Agent Builder** tab, with **Changelog** and **Executions** alongside it across the top; switch to **Changelog** and the view splits into a version list on the left and a canvas preview on the right.

## Read the version list

Each entry in the list carries its version number and the [commit message](/docs/agent-playground/guides/build-workflow) you wrote when you saved it, so you can tell what changed without opening anything. Version numbers only increase with each save, so the entry with the highest number is the newest. You can also remove a version from this list when you no longer need it.

<Note>
An agent always keeps at least one version, so the last one can't be removed.
</Note>

## Preview a version

Click any entry in the list and its graph renders on the right, exactly as it looked the moment you saved it. This preview is read-only, draft included. Editing only happens on a [draft](/docs/agent-playground/concepts/versions-and-execution), marked with the Draft badge, back in Agent Builder.
