To check when a node changed, look up its [saved version](/docs/agent-playground/concepts/versions-and-execution) by commit message. The changelog opens a read-only copy of the graph, so you can compare two saves without changing your draft.

<Prerequisites title="Before you start">
- Open an existing agent, such as Invoice Triage. If you need one, [create an agent](/docs/agent-playground/guides/create-agent) first.
- Have a saved change you can recognize. If the change is still on the draft, save it as described below.
</Prerequisites>

## Find the save

1. Open the agent from the agent list.
2. Select **Changelog** beside **Agent Builder** and **Executions**.

   You should see a version list on the left and a canvas preview on the right.

3. Select the entry whose commit message describes the change you want to inspect.

   Each entry carries its version number and the commit message you wrote when you saved it, for example version 6 with the message "Add duplicate invoice check," so you can tell what changed without opening anything. Version numbers only increase with each save, so the entry with the highest number is the newest.

## Compare the graphs

1. Find the changed node in the preview on the right.

   The graph renders exactly as it looked the moment you saved it.

2. Select the version before it in the list.

   You should see the graph as it looked at that earlier save. This preview is read-only, draft included. Editing only happens on a draft, marked with the **Draft** badge, back in **Agent Builder**.

## If the change isn't listed

1. Return to **Agent Builder**.
2. Check that the draft contains your change.
3. Select **Save Agent**.
4. Enter a description of the change in **Commit Message**.
5. Select **Save**.
6. Reopen **Changelog**.

   You should see the new message on the entry with the highest version number.

If the graph contains a cycle or a node is left unconfigured, **Save Agent** shows the error instead of opening the dialog. Fix the graph, then save again.
