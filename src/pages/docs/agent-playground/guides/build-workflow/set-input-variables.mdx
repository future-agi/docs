A workflow won't start while one of its input variables is blank. Fill each one in the **Variables** drawer before you run, or supply the missing value there when the builder holds a run for you. The example fills the invoice text an LLM Prompt node classifies.

<Prerequisites title="Before you start">
- A workflow with an LLM Prompt node on the canvas. If it has none, [add a node to the canvas](/docs/agent-playground/guides/build-workflow) first.
- A configured node with a saved prompt input. [Configure an LLM Prompt node](/docs/agent-playground/guides/build-workflow/configure-an-llm-prompt-node) covers this next stage. Save both the node and the agent so the drawer reflects the change.
</Prerequisites>

Only inputs without an incoming connection are [the agent's own inputs](/docs/agent-playground/concepts/understanding-agent-playground#what-isnt-connected-becomes-the-agents-own-input-or-output). A value that comes from another node won't have a field in this drawer.

## Save values before a run

1. In the builder, select **Add input variables** at the top right of the canvas.

   The drawer opens with **Variables** and “Define values for your prompt variables”. Each field sits below its variable name.

2. Give the first listed variable a concrete value.

   If your prompt asks for the invoice text to classify, enter the actual invoice, such as “Invoice #4521 from Acme Supplies, $2,400 due in 30 days.”

3. Fill in every other listed variable. A run needs all of them, with none left blank.

![The Variables drawer lists eight prompt variables in double braces, with a filled value below each name.](/images/docs/agent-playground/guides/build-workflow/set-input-variables.png)

4. Select **Save**.

   This stores the values. When no run is waiting, saving them does not start a run.

## Resume a run held for a missing input

1. Select **Run Agent Workflow** with a required input still empty.

   The warning reads “Fill in all variables before running”. The builder opens **Variables** and holds the run.

2. Fill in the missing field with the value the node should receive.
3. Select **Save & Run Workflow** once every field has a value.

   Unlike **Save**, this starts the waiting run. The run panel opens at the bottom of the builder.

4. Select the LLM Prompt node in the run panel.

   Compare its input with the invoice text you supplied. The run panel lists each node by name and shows what it received and what it returned.

## Troubleshoot the drawer

- **A variable is missing.** The drawer reads the saved workflow. Save the node, then save the agent and reopen **Variables**. If the input has an incoming connection, its value comes from the connected node instead.
- **You closed the drawer with an unsaved edit.** The **Unsaved Changes** dialog asks “You have unsaved changes. Are you sure you want to close without saving?” Choose **Discard Changes** to lose the edit, or cancel to return to the drawer.

This procedure sets values in the builder drawer. The workflow guides do not document an equivalent SDK, `fagi`, or MCP operation for saving drawer values.
