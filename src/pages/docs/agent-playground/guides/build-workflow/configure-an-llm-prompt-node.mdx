On Invoice Triage, the router takes the classifier's output as its input, so changing the classifier's [prompt](/docs/prompt/concepts/understanding-prompts) or its [version](/docs/prompt/concepts/versions-and-labels) can change what the router receives. This guide walks the LLM Prompt node's form in the node drawer from top to bottom, where each choice sets up the next: name, version, model, then save. It ends by checking the handoff in a run.

<Prerequisites title="Before you start">
- A workflow with an LLM Prompt node already on the canvas; see [Build a workflow](/docs/agent-playground/guides/build-workflow) to add one first. To check the handoff, connect its output to the router's input.
</Prerequisites>

## Configure the classifier

1. Click the LLM Prompt node on the canvas.

   Its drawer opens with the node's own configuration form.

   ![Prompt drawer with Prompt Name, the version selector and Draft badge, Select Model, and the System and User messages.](/images/docs/agent-playground/guides/build-workflow/configure-an-llm-prompt-node.png)

2. Type a **Prompt Name**. It is required and sits at the top of the form.

   Typing here sets this node's name: what you type is lowercased, every character other than `a`-`z`, `0`-`9`, and `_` is replaced with an underscore, and leading underscores are stripped.

3. Pick a version from the select beside **Prompt Name**.

   Its options are labeled with the version, uppercased. When the selected version hasn't been saved yet, a **Draft** badge appears beside the select, not on the option inside the dropdown. Not every version can be used here: the builder supports only prompts with a text-based [output format](/docs/prompt/reference/model-configuration#output-and-tool-settings).

4. Choose which LLM this node uses in the model picker.

   The model picker is also what unblocks the **Tools** button beside it: **Tools** stays disabled until a model is chosen, and hovering it before then shows why, "Select a model first".

5. Check the `{{variable}}` placeholders in the prompt's messages against the inputs you wired.

   The node's inputs are generated from the prompt's [variables](/docs/prompt/concepts/understanding-prompts#variables), and those placeholder names become the node's input names. Swapping the prompt text or picking a different version changes that set of placeholders, so it also changes the set of inputs the node exposes. See [Limits & rules](/docs/agent-playground/reference/limits-and-rules) for naming restrictions.

6. Click **Save prompt**, at the bottom of the form.

   On a successful save, the drawer closes.

<Note>
Picking a different version of the prompt can change what this node returns: the output shape downstream nodes expect may shift, since the node's response follows the response format set on the linked version.
</Note>

## Check the handoff

1. Click **Save Agent** to save the workflow.
2. Give every [input variable](/docs/agent-playground/guides/build-workflow/set-input-variables) a value, including the invoice text to classify.
3. Press **Run Agent Workflow**.
4. Click the classifier in the run panel to see the output it handed off.
5. Click the router and compare its input with that output.

   The router's input is the same value the classifier handed off. If the classifier failed, the nodes downstream of it are marked skipped rather than running.

## If the drawer won't save

- **The format isn't supported.** The form shows "This prompt uses an unsupported output format. Only text-based prompts are supported in the agent builder." While that alert shows, the model picker, the **Tools** control, and **Save prompt** are all disabled. Pick a version with a text-based output format.
- **The name is taken.** A name that already belongs to another node on the canvas is refused with "A node with this name already exists". Pick a different name and try again.
- **The save failed.** A toast reads "Failed to save prompt" and the form stays open so you can retry.
- **You closed the drawer with a change unsaved.** A dialog titled "Unsaved Changes" asks "You have unsaved changes. Are you sure you want to discard them?" Confirm with **Discard** to drop the edits, or back out of the dialog to go save first.
