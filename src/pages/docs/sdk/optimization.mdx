## About

Ridgeline Outfitters wants its support agent to return a queue name, not a reply to the customer. With Agent Learning Kit, you can try different examples in the routing prompt and choose the prompt that produces the most correct labels.

## 1. Install Agent Learning Kit

Use Python 3.10 or later. Install the kit in a fresh virtual environment. It includes the prompt optimizers.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7
python -c "from fi.alk.optimize import BayesianSearchOptimizer; print(BayesianSearchOptimizer.__name__)"
```

The last command should print `BayesianSearchOptimizer`. The public import path is `fi.alk.optimize`. If your code already imports `BayesianSearchOptimizer` from `fi.opt.optimizers`, that import still works with the kit.

## 2. Run a two-trial search

Set `OPENROUTER_API_KEY` in the shell where you run Python. The `Equals` metric runs locally and does not need Future AGI credentials.

<Warning>
  Each trial makes one OpenRouter model call per ticket. Each call sends the ticket and any labeled example selected for that trial. OpenRouter bills these calls. Use synthetic tickets when trying it.
</Warning>

Each row contains a customer message and the queue that should handle it. Each trial selects zero or one labeled ticket to prepend to the prompt. Both trials can select the same number of tickets. For each trial it asks the model to classify every row, then scores each response against that row's `queue`.

<CodeGroup titles={["Python"]}>
```python
from fi.alk.optimize import BasicDataMapper, BayesianSearchOptimizer, Evaluator
from fi.evals.metrics import Equals

tickets = [
    {"message": "My tent hasn't arrived. Where is the parcel?", "queue": "shipping"},
    {"message": "These boots are too small. Can I send them back?", "queue": "returns"},
    {"message": "The buckle broke on my new pack. Is it covered?", "queue": "warranty"},
]
prompt = (
    "Route this outdoor-gear support ticket. Reply with just shipping, returns, or warranty.\n"
    "Ticket: {message}\nQueue:"
)

optimizer = BayesianSearchOptimizer(
    inference_model_name="openrouter/openai/gpt-4o-mini",
    n_trials=2,
    min_examples=0,
    max_examples=1,
    example_template="Ticket: {message}\nQueue: {queue}",
    few_shot_position="prepend",
)
result = optimizer.optimize(
    dataset=tickets,
    initial_prompts=[prompt],
    data_mapper=BasicDataMapper(
        key_map={"response": "generated_output", "expected_response": "queue"}
    ),
    evaluator=Evaluator(metric=Equals()),
)

for trial, entry in enumerate(result.history, start=1):
    print(f"Trial {trial}: {entry.average_score:.1%} correct")
print(f"Best: {result.final_score:.1%} correct")
print(result.best_generator.get_prompt_template())
```
</CodeGroup>

## 3. Interpret the result

`final_score` is the highest trial average. On these three tickets, two correct labels would give a score of `66.7%`. The final line prints the winning template, including any example the optimizer selected. It keeps the `{message}` placeholder so you can use it with a new ticket.

- **A reasonable answer scores zero:** `Equals` ignores case by default, but compares the whole response. `returns` matches the expected label; `Send this to returns.` does not.
- **Every answer scores zero:** Check the provider credentials and look for generation errors. A failed model call can produce an empty string that the metric then scores as incorrect. Also check the mapper: `generated_output` means the model's answer, while `queue` names a field in each row.
- **A perfect score on these rows:** The search draws its examples from the same rows it scores. Check the winning template against tickets you kept out of the search before using it to route customers.

## Choose a prompt optimizer

Import these classes from `fi.alk.optimize`. Each link describes the algorithm and its arguments. To check the arguments for your installed version, run `help(BayesianSearchOptimizer)` in Python after importing the class.

| Class | What it changes |
| --- | --- |
| [`BayesianSearchOptimizer`](/docs/optimization/reference/optimizers/bayesian-search) | Selects labeled examples to include alongside your instructions. |
| [`RandomSearchOptimizer`](/docs/optimization/reference/optimizers/random-search) | Asks a teacher model for variations of your starting prompt and scores them. |
| [`MetaPromptOptimizer`](/docs/optimization/reference/optimizers/meta-prompt) | Uses a teacher model to rewrite the prompt based on its performance. |
| [`ProTeGi`](/docs/optimization/reference/optimizers/protegi) | Turns critiques of failed examples into candidate instructions. |
| [`PromptWizardOptimizer`](/docs/optimization/reference/optimizers/promptwizard) | Mutates, critiques, and refines instructions over several stages. |
| [`GEPAOptimizer`](/docs/optimization/reference/optimizers/gepa) | Uses evaluator feedback and a reflection model to evolve candidate prompts. |
