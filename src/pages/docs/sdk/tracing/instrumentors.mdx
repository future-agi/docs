## About

Choose the package for the library you want to trace. Many Python instrumentors wrap client methods, but some frameworks already emit spans. Use the [framework tracing guide](/docs/integrations/traceai) to choose between a wrapper, a callback and a native exporter.

## Cleanup

Finish in-flight calls and close any streams before you remove instrumentation. Removing a wrapper stops it from tracing future calls; it does not necessarily shut down the provider. For example, `configure_agno_tracing` shuts down a provider it created when you call `uninstrument()`, but leaves a provider you supplied running. Flush and shut down an application-owned provider at application exit, not after each request.

## Other languages

| Language | Choose a tracing path |
| --- | --- |
| TypeScript | Use the [Strands native exporter](/docs/integrations/traceai#strands) for agent and tool spans, or [instrument the Cohere SDK](/docs/integrations/traceai#cohere) before constructing clients. For supported calls that you want to trace at process startup, see [zero-code Node.js](/docs/integrations/traceai/auto). |
| Go | Attach a [LangChainGo callback](/docs/integrations/traceai#langchaingo) to trace a chain. To trace model calls directly, use the [Bedrock Runtime wrapper](/docs/integrations/traceai#bedrock-runtime-for-go) or [Anthropic Messages middleware](/docs/integrations/traceai#anthropic-messages-for-go). |
| Java | Choose a [Java integration](/docs/integrations/traceai/java) for your provider or framework, such as the [OpenAI client wrapper](/docs/integrations/traceai/java/openai). |
| C# | Use the [.NET SDK](https://github.com/future-agi/traceAI/blob/76093670c1d41b442e458acd70b93bdaafafcb75/csharp/src/FIInstrumentation/README.md) to create spans yourself, or see the [.NET startup hook](https://github.com/future-agi/traceAI/blob/76093670c1d41b442e458acd70b93bdaafafcb75/docs/auto-tracing/dotnet.md) for automatic capture. |
