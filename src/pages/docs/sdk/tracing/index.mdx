## Quick example

Choose one language and start in an empty directory. Set `FI_API_KEY` and `FI_SECRET_KEY` to your [Future AGI key pair](/docs/admin-settings/api-keys). The Python, TypeScript and Java examples also need `OPENAI_API_KEY`: each makes a real model request about a Ridgeline Outfitters return. The C# example traces a local policy lookup without a model provider. Use synthetic inputs; a trace can contain your prompt and response.

The shell commands below use Bash. For a self-hosted deployment, replace the hosted collector origin with your OTLP/HTTP collector origin, without `/tracer/v1/traces`.

<Tabs>
  <Tab title="Python">

    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install fi-instrumentation-otel==1.5.1 traceAI-openai==0.1.16 openai==3.57.0
    export FI_TRACES_URL=https://api.futureagi.com
    ```

    Save this as `returns.py` and run `python returns.py`:

    ```python
    from fi_instrumentation import register
    from fi_instrumentation.fi_types import ProjectType
    from openai import OpenAI
    from traceai_openai import OpenAIInstrumentor

    provider = register(project_name="ridgeline-python", project_type=ProjectType.OBSERVE, verbose=False)
    OpenAIInstrumentor().instrument(tracer_provider=provider)
    try:
        with OpenAI() as client:
            reply = client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[{"role": "user", "content": "Unused packs can be returned within 30 days. Is day 12 within the window?"}],
            )
            print(reply.choices[0].message.content)
    finally:
        provider.shutdown()
    ```
  </Tab>
  <Tab title="TypeScript">

    Use Node.js 22.18 or later:

    ```bash
    npm install @traceai/openai@0.1.18 @traceai/fi-core@1.4.1 openai@7.47.0
    export FI_TRACES_URL=https://api.futureagi.com
    ```

    Save this as `returns.mts` and run `node returns.mts`. Attach the instrumentor to the same OpenAI client class you instantiate:

    ```typescript
    import { register, ProjectType } from "@traceai/fi-core";
    import { OpenAIInstrumentation } from "@traceai/openai";
    import OpenAI from "openai";

    const provider = register({ projectName: "ridgeline-node", projectType: ProjectType.OBSERVE });
    const adapter = new OpenAIInstrumentation({});
    adapter.setTracerProvider(provider);
    adapter.manuallyInstrument(OpenAI);
    try {
      const client = new OpenAI();
      const reply = await client.chat.completions.create({
        model: "gpt-4o-mini",
        messages: [{role: "user", content: "Unused packs can be returned within 30 days. Is day 12 within the window?"}],
      });
      console.log(reply.choices[0].message.content);
    } finally {
      adapter.disable();
      await provider.shutdown();
    }
    ```

  <Tab title="Java">

    Use a JDK (17 or 21) and Maven. Save this as `pom.xml`. The adapter wraps the OpenAI Java client version shown here. For [Spring AI](/docs/integrations/traceai/spring-boot), use native observations instead.

    ```xml
    <project xmlns="http://maven.apache.org/POM/4.0.0">
      <modelVersion>4.0.0</modelVersion>
      <groupId>example.ridgeline</groupId><artifactId>returns</artifactId><version>1.0</version>
      <properties><maven.compiler.source>17</maven.compiler.source><maven.compiler.target>17</maven.compiler.target></properties>
      <dependencies>
        <dependency>
          <groupId>com.futureagi</groupId><artifactId>traceai-java-openai</artifactId><version>1.4.1</version>
        </dependency>
        <dependency>
          <groupId>com.openai</groupId><artifactId>openai-java</artifactId><version>0.8.0</version>
        </dependency>
      </dependencies>
    </project>
    ```

    Save `src/main/java/Returns.java`:

    ```java
    import ai.traceai.TraceAI;
    import ai.traceai.openai.TracedOpenAIClient;
    import com.openai.client.okhttp.OpenAIOkHttpClient;
    import com.openai.models.ChatCompletionCreateParams;
    import com.openai.models.ChatCompletionMessageParam;
    import com.openai.models.ChatCompletionUserMessageParam;

    public class Returns {
        public static void main(String[] args) {
            TraceAI.initFromEnvironment();
            try {
                var builder = OpenAIOkHttpClient.builder().fromEnv();
                String base = System.getenv("OPENAI_BASE_URL");
                if (base != null && !base.isBlank()) builder.baseUrl(base);
                var client = new TracedOpenAIClient(builder.build());
                var user = ChatCompletionUserMessageParam.builder()
                    .role(ChatCompletionUserMessageParam.Role.USER)
                    .content(ChatCompletionUserMessageParam.Content.ofTextContent(
                        "Unused packs can be returned within 30 days. Is day 12 within the window?"))
                    .build();
                var request = ChatCompletionCreateParams.builder().model("gpt-4o-mini")
                    .addMessage(ChatCompletionMessageParam.ofChatCompletionUserMessageParam(user)).build();
                System.out.println(client.createChatCompletion(request).choices().get(0).message().content().orElse(""));
            } finally {
                TraceAI.shutdown();
            }
        }
    }
    ```

    Run from the directory containing `pom.xml`. The Java SDK uses `FI_BASE_URL` for the collector:

    ```bash
    FI_PROJECT_NAME=ridgeline-java FI_BASE_URL=https://api.futureagi.com mvn -q compile org.codehaus.mojo:exec-maven-plugin:3.5.0:java -Dexec.mainClass=Returns
    ```
  </Tab>
  <Tab title="C#">

    With the .NET 10 SDK, create a console project and add the tracer:

    ```bash
    dotnet new console -o ReturnsApp --framework net10.0
    dotnet add ReturnsApp package fi-instrumentation-otel --version 1.0.0
    export FI_TRACES_URL=https://api.futureagi.com
    ```

    Replace `ReturnsApp/Program.cs` with this example and run `dotnet run --project ReturnsApp`. The tool span records the local lookup's input and output:

    ```csharp
    using FIInstrumentation;
    using FIInstrumentation.Types;

    var tracer = TraceAI.Register(options => {
        options.ProjectName = "ridgeline-dotnet";
        options.ProjectType = ProjectType.Observe;
        options.Endpoint = Environment.GetEnvironmentVariable("FI_TRACES_URL");
    });
    try {
        var window = tracer.Tool("lookup-return-window", span => {
            const string item = "unused pack";
            var windows = new Dictionary<string, int> { ["unused pack"] = 30 };
            span.SetInput(item);
            span.SetOutput(windows[item]);
            return windows[item];
        });
        Console.WriteLine($"Return window: {window} days");
    } finally {
        TraceAI.Shutdown();
    }
    ```
  </Tab>

## Find your trace

Open **Observe → Tracing** and select the project from your example. In `ridgeline-python`, `ridgeline-node`, or `ridgeline-java`, open the model span and inspect the prompt, response, and token usage returned by the provider. In `ridgeline-dotnet`, open `lookup-return-window` to see the 30-day result. Register the provider once per application process and shut it down only when that process is done tracing.
