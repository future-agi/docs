Creates an OpenTelemetry tracer provider configured to export spans to your Future AGI dashboard.

<Tabs>
  <Tab title="Python">
    ```python
    from fi_instrumentation import register, Transport
    from fi_instrumentation.fi_types import ProjectType

    trace_provider = register(
        project_name="my-project",
        project_type=ProjectType.OBSERVE,
        transport=Transport.HTTP,
        batch=True,
        verbose=True,
    )
    ```

    | Parameter | Type | Default | Description |
    |-----------|------|---------|-------------|
    | `project_name` | str / None | `FI_PROJECT_NAME` env var | Project identifier in the dashboard |
    | `project_type` | ProjectType | `EXPERIMENT` | `EXPERIMENT` (dev, supports eval tags) or `OBSERVE` (production) |
    | `project_version_name` | str / None | None | Version label (EXPERIMENT only) |
    | `eval_tags` | list / None | None | Evaluation configs for automated span scoring (EXPERIMENT only) |
    | `metadata` | dict / None | None | Custom metadata attached to all spans |
    | `batch` | bool | True | True = BatchSpanProcessor, False = SimpleSpanProcessor |
    | `set_global_tracer_provider` | bool | False | Register as the global OpenTelemetry default |
    | `headers` | dict / None | None | Custom HTTP headers (auto-populated from API keys if not set) |
    | `verbose` | bool | True | Print configuration details on startup |
    | `transport` | Transport | `HTTP` | `HTTP` or `GRPC` |
    | `semantic_convention` | SemanticConvention | `FI` | Resource metadata describing the convention emitted by the application or instrumentor; does not convert span attributes |

    **Returns:** `TracerProvider` - pass this to `.instrument(tracer_provider=...)` on any instrumentor.
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { register, ProjectType, Transport } from "@traceai/fi-core";

    const tracerProvider = register({
      projectName: "my-project",
      projectType: ProjectType.OBSERVE,
      transport: Transport.HTTP,
      batch: true,
      verbose: true,
    });
    ```

    | Parameter | Type | Default | Description |
    |-----------|------|---------|-------------|
    | `projectName` | string | `FI_PROJECT_NAME` env var | Project identifier |
    | `projectType` | ProjectType | `EXPERIMENT` | `EXPERIMENT` or `OBSERVE` |
    | `projectVersionName` | string | undefined | Version label (EXPERIMENT only) |
    | `evalTags` | EvalTag[] | undefined | Evaluation configs (EXPERIMENT only) |
    | `sessionName` | string | undefined | Session name (OBSERVE only) |
    | `metadata` | Record | undefined | Custom metadata |
    | `batch` | boolean | false | Use batch span processor |
    | `setGlobalTracerProvider` | boolean | true | Register as global provider |
    | `headers` | FIHeaders | undefined | Custom HTTP headers |
    | `verbose` | boolean | false | Verbose logging |
    | `endpoint` | string | `FI_BASE_URL` | Custom endpoint |
    | `transport` | Transport | `HTTP` | `HTTP` or `GRPC` |
    | `sampler` | Sampler | undefined (OpenTelemetry environment/default) | Optional OpenTelemetry head sampler. See [Sampling](#sampling) |

    **Returns:** `FITracerProvider`

    TypeScript accepts `sampler?: Sampler` and forwards it to the OpenTelemetry provider. Alternatively, leave it unset to use the standard `OTEL_TRACES_SAMPLER` and `OTEL_TRACES_SAMPLER_ARG` environment variables (see [Sampling](#sampling)). Call `await tracerProvider.forceFlush()` before a short-lived process ends.

## ProjectType

| Value | Use for |
|-------|---------|
| `EXPERIMENT` | Development and testing. Supports eval tags and version names. |
| `OBSERVE` | Production monitoring. No eval tags, no version names. |

## SemanticConvention (Python)

Python's `semantic_convention` option records a `semantic_convention` attribute on the provider's resource. It identifies the convention your application or instrumentor actually emits; it does **not** rewrite, rename, or add span attributes. TypeScript `register()` does not expose this option.

Import `SemanticConvention` from `fi_instrumentation` and select the value that describes your emitted spans:

| Value | Resource value | Convention described |
|-------|----------------|----------------------|
| `OTEL_GENAI` | `otel_genai` | OpenTelemetry GenAI |
| `FI` | `fi` | Future AGI native convention (default) |
| `OPENINFERENCE` | `openinference` | OpenInference |
| `OPENLLMETRY` | `openllmetry` | OpenLLMetry |

<Note>
  Passing `semantic_convention=SemanticConvention.OTEL_GENAI` does not make an instrumentor emit GenAI attributes. Configure the application or instrumentor itself to emit the attributes required by your downstream tools.
</Note>

## Sampling

Pass an OpenTelemetry sampler to TypeScript `register()`. For example, record new root traces and respect an existing parent's sampling decision:

```typescript
import { register, ProjectType } from "@traceai/fi-core";
import { AlwaysOnSampler, ParentBasedSampler } from "@opentelemetry/sdk-trace-base";

const tracerProvider = register({
  projectName: "my-project",
  projectType: ProjectType.OBSERVE,
  sampler: new ParentBasedSampler({ root: new AlwaysOnSampler() }),
});
```

To configure sampling through the environment instead, omit `sampler`. Set these variables before creating the provider to sample approximately 10% of new root traces while respecting an existing parent's sampling decision:

```bash
export OTEL_TRACES_SAMPLER=parentbased_traceidratio
export OTEL_TRACES_SAMPLER_ARG=0.1
```
