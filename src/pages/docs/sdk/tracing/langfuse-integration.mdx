title: "Attach Future AGI scores to Langfuse spans"
description: "Run a hosted evaluation of a support reply and attach its score to the Langfuse observation that contains the reply."
---

## When to use this integration

If you already trace your application in Langfuse, you can use a Future AGI template to score an individual reply. This example records a return-policy question and its answer on a Langfuse observation, then requests a toxicity score for **the answer**. A toxicity pass doesn't mean the answer matches your return policy.

## Install the clients

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7 langfuse==4.15.0
```

If your application already uses Langfuse 5.x, downgrade it to a 4.15.x release or lower (this page pins 4.15.0) to use this integration. Langfuse 4.16.0 and later, including every 5.x release, require OpenTelemetry API 1.45 or later, while agent-learning-kit 0.3.7 depends on `google-adk` 2.7.1, which allows OpenTelemetry API 1.42.1 at most, so pip cannot install them together.

Set `FI_API_KEY` and `FI_SECRET_KEY` from your [workspace API keys](/docs/admin-settings/api-keys). Set `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, and `LANGFUSE_HOST` for the Langfuse project where you want the score. The host is the base URL for your project region or self-hosted instance, not a trace URL. Both your application and the Future AGI server must be able to reach it.

This integration sends your Langfuse public key, secret key, and host, along with the evaluation inputs and observation identifiers, to Future AGI, which stores them with the evaluation request so it can deliver the score later. Use it only if your project permits that access.

## Choose the evaluation input

Run the Python blocks in order in the same Python session. The `toxicity` template has one required field, `output`, so pass the agent's reply as `output`.

```python
import os
from fi.evals import Evaluator
from langfuse import Langfuse

evaluator = Evaluator()

question = "Can I return unworn boots?"
reply = "Yes. Bring your receipt and the unworn boots within 30 days of purchase."
```

## Request the score inside an observation

`platform="langfuse"` tells the evaluator to submit a configuration for background scoring. Call it **inside** the observation to capture its trace ID and span ID. `custom_eval_name` is the score label you'll look for in Langfuse. `turing_flash` is a hosted Future AGI evaluator, so each request uses [AI credits](/docs/billing/concepts/what-you-are-billed-for) from your organization's plan.

```python
langfuse = Langfuse(base_url=os.environ["LANGFUSE_HOST"])
try:
    with langfuse.start_as_current_observation(
        name="support-reply", input={"question": question}, output={"reply": reply}
    ) as span:
        ack = evaluator.evaluate(
            eval_templates="toxicity",
            inputs={"output": reply},
            model_name="turing_flash",
            custom_eval_name="reply-toxicity",
            platform="langfuse",
        )
        if not ack or not ack.get("status"):
            raise RuntimeError("Future AGI did not accept the score request")
        print("Request accepted for trace", span.trace_id, "observation", span.id)
finally:
    langfuse.flush()
```

The acknowledgment means Future AGI accepted the configuration, **not** that Langfuse received a score. In your Langfuse project, open the printed trace, select `support-reply`, and look for `reply-toxicity` on that observation. Future AGI picks up new requests every 30 seconds and then runs the evaluation, so the score shows up shortly after, not at the moment you get the acknowledgment. For this binary template, `1` means the reply passed the toxicity check (not toxic) and `0` means it failed (toxic). If no score appears after a few minutes, check that your organization has AI credits left, then check the Langfuse project keys and host used by both clients; don't treat a missing score as zero.
