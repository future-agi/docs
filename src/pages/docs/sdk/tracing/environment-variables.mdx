---
title: "Environment variables"
description: "Environment variables that configure traceAI tracing."
---

The traceAI SDKs use `FI_*` environment variables for authentication and tracing configuration. Support varies by language and integration; native OpenTelemetry exporters do not read these variables automatically. In particular, the [Genkit Go adapter supports only three privacy switches](#genkit-go-privacy), not the granular controls in this reference.

| Variable | Purpose | Default |
|----------|---------|---------|
| `FI_API_KEY` | Authentication | required |
| `FI_SECRET_KEY` | Authentication | required |
| `FI_BASE_URL` | HTTP collector endpoint | `https://api.futureagi.com` |
| `FI_GRPC_URL` | gRPC collector endpoint | `https://grpc.futureagi.com` |
| `FI_PROJECT_NAME` | Default project name | None |
| `FI_PROJECT_VERSION_NAME` | Default version | None |
| `FI_HIDE_INPUTS` | Redact inputs | False |
| `FI_HIDE_OUTPUTS` | Redact outputs | False |
| `FI_HIDE_INPUT_MESSAGES` | Redact input messages | False |
| `FI_HIDE_OUTPUT_MESSAGES` | Redact output messages | False |
| `FI_HIDE_INPUT_IMAGES` | Redact input images | False |
| `FI_HIDE_INPUT_TEXT` | Redact input text | False |
| `FI_HIDE_OUTPUT_TEXT` | Redact output text | False |
| `FI_HIDE_EMBEDDING_VECTORS` | Redact embedding vectors | False |
| `FI_HIDE_LLM_INVOCATION_PARAMETERS` | Redact model parameters | False |
| `FI_BASE64_IMAGE_MAX_LENGTH` | Max base64 image chars | 32000 |
| `FI_PII_REDACTION` | Auto-mask PII (Python) | False |
| `FI_HIDE_ERROR_DETAILS` | Remove error text from exported spans | Integration-specific; see below for Genkit Go |

## Genkit Go privacy

The [Genkit Go integration](/docs/integrations/traceai/genkit-go) uses `github.com/future-agi/traceAI/go/genkit` to filter native `otelgenai` spans. Its `ConfigFromEnv()` reads only these three privacy switches, once when the exporter is constructed:

| Variable | Effect when true | Default |
|----------|------------------|---------|
| `FI_HIDE_INPUTS` | Remove input messages, system instructions, stop sequences, and action inputs | False |
| `FI_HIDE_OUTPUTS` | Remove output messages and action outputs | False |
| `FI_HIDE_ERROR_DETAILS` | Remove span status descriptions and error/exception text | True when either coarse hide switch is true; otherwise False |

Granular privacy flags, including `FI_HIDE_INPUT_MESSAGES`, `FI_HIDE_OUTPUT_MESSAGES`, `FI_HIDE_INPUT_IMAGES`, `FI_HIDE_INPUT_TEXT`, `FI_HIDE_OUTPUT_TEXT`, `FI_HIDE_EMBEDDING_VECTORS`, and `FI_HIDE_LLM_INVOCATION_PARAMETERS`, have no effect in this adapter. They also do not enable the default error redaction. Use `FI_HIDE_INPUTS` and `FI_HIDE_OUTPUTS` to hide messages, including system instructions on the input side.

Keep `FI_HIDE_ERROR_DETAILS=true` when enabling message capture. Explicitly setting it to `false` overrides the default even when a coarse hide switch is true, so error text can expose prompts or responses. These switches filter exported spans, not application console output, logs, custom attributes, span names, or resource attributes. Keep Genkit's `CaptureActionIO: false` and avoid additional unwrapped exporters.

The guide maps `FI_API_KEY`, `FI_SECRET_KEY`, and `FI_PROJECT_NAME` in application code. Configure its OTLP HTTP endpoint with `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT`, not `FI_BASE_URL`.
