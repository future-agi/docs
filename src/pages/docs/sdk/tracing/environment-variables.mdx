---
title: "Environment variables"
description: "Environment variables that configure traceAI tracing."
---


traceAI SDKs share the following environment-variable names. Support varies by SDK and integration; native OpenTelemetry integrations use the controls documented in their integration guide.

| Variable | Purpose | Default |
|----------|---------|---------|
| `FI_API_KEY` | Authentication | required |
| `FI_SECRET_KEY` | Authentication | required |
| `FI_BASE_URL` | HTTP collector endpoint | `https://api.futureagi.com` |
| `FI_GRPC_URL` | gRPC collector endpoint | `https://grpc.futureagi.com` |
| `FI_PROJECT_NAME` | Default project name | None |
| `FI_PROJECT_VERSION_NAME` | Default version | None |
| `FI_HIDE_INPUTS` | Redact inputs | False |
| `FI_HIDE_OUTPUTS` | Redact outputs | False |
| `FI_HIDE_INPUT_MESSAGES` | Redact input messages | False |
| `FI_HIDE_OUTPUT_MESSAGES` | Redact output messages | False |
| `FI_HIDE_INPUT_IMAGES` | Redact input images | False |
| `FI_HIDE_INPUT_TEXT` | Redact input text | False |
| `FI_HIDE_OUTPUT_TEXT` | Redact output text | False |
| `FI_HIDE_EMBEDDING_VECTORS` | Redact embedding vectors | False |
| `FI_HIDE_LLM_INVOCATION_PARAMETERS` | Redact model parameters | False |
| `FI_BASE64_IMAGE_MAX_LENGTH` | Max base64 image chars | 32000 |
| `FI_PII_REDACTION` | Auto-mask PII (Python) | False |
| `FI_HIDE_ERROR_DETAILS` | Hide error messages and stack traces on supported traceAI spans. Use Python `fi-instrumentation-otel` 1.2.3 or later or TypeScript `@traceai/fi-core` 1.1.1 or later. See [Errors and privacy](/docs/sdk/tracing/trace-config#errors-and-privacy) | When unset, derived from the resolved input/output content flags in code or the environment; see below |

For Python and TypeScript, `FI_HIDE_ERROR_DETAILS` defaults to true when any of `hide_inputs`, `hide_outputs`, `hide_input_messages`, `hide_output_messages`, `hide_input_text`, or `hide_output_text` is true (camelCase in TypeScript). These flags can come from code or their `FI_` environment variables. Otherwise, it defaults to false. Image-only, embedding-vector, invocation-parameter, and PII masking do not enable it. An explicit error-details setting in code takes precedence over `FI_HIDE_ERROR_DETAILS`; an explicit environment value takes precedence over the derived default.
