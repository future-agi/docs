- **Python:** evals, tracing, datasets, prompts, optimization, simulation
- **TypeScript:** evals, tracing, datasets, prompts

Future AGI is a set of packages that evaluate LLM outputs, trace calls across your stack, optimize prompts, and load-test voice agents. Install what you need, skip what you don't.

## Quickstart

<Tabs>
  <Tab title="Python">
    Start in a fresh virtual environment. Install `agent-learning-kit` and use its `fi.alk.evals` module. Existing `from fi.evals import evaluate` code also works with this package.

    ```bash
    python -m venv .venv-evals
    source .venv-evals/bin/activate  # Windows PowerShell: .venv-evals\Scripts\Activate.ps1
    python -m pip install agent-learning-kit==0.3.7
    ```

    Try a local check. It needs no API key:

    ```python
    from fi.alk import evals

    result = evals.evaluate("contains", output="Hello world", keyword="Hello")
    print(result.passed)  # True
    ```

    For a hosted template, see [Cloud evals](/docs/sdk/evals/cloud-evals). For tracing setup, see [Tracing](/docs/sdk/tracing).
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @future-agi/ai-evaluation
    ```

    ```bash
    export FI_API_KEY="your-api-key"
    export FI_SECRET_KEY="your-secret-key"
    ```

    ```typescript
    import { Evaluator, Tone } from "@future-agi/ai-evaluation";

    const evaluator = new Evaluator();

    const result = await evaluator.evaluate({
      evalTemplates: [new Tone()],
      inputs: [{
        query: "Write a professional email",
        response: "Dear Sir/Madam, I hope this message finds you well..."
      }],
      modelName: "turing_flash"
    });

    console.log(result);
    ```

    Want tracing too?

    ```bash
    npm install @traceai/fi-core @traceai/openai
    ```
  </Tab>
  <Tab title="Java">
    Java support covers tracing only. 25+ instrumentors including Spring AI and LangChain4j.

    ```xml
    <!-- Maven — add the JitPack repository -->
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>

    <dependency>
        <groupId>com.github.future-agi.traceAI</groupId>
        <artifactId>traceai-java-openai</artifactId>
        <version>LATEST</version>
    </dependency>
    ```

    See the [Tracing docs](/docs/sdk/tracing) for setup instructions.
  </Tab>
  <Tab title="C#">
    C# support covers tracing only.

    ```bash
    dotnet add package fi-instrumentation-otel
    ```

    See the [Tracing docs](/docs/sdk/tracing) for setup instructions.
  </Tab>
</Tabs>

<AccordionGroup>
  <Accordion title="Getting an error? Check these common issues">
    **`ModuleNotFoundError: No module named 'fi.evals'`** — Activate the eval environment and run `python -m pip install agent-learning-kit==0.3.7` with the same Python interpreter you use for the example.

    **Authentication error on a Turing eval** — Set both `FI_API_KEY` and `FI_SECRET_KEY`. Local string checks do not read these keys.
  </Accordion>
</AccordionGroup>

## Packages

### Python

Choose the package for the task:

| Package | Install | What it does | Python |
|---------|---------|--------------|--------|
| **futureagi** | `pip install futureagi` | Datasets, prompt versioning, knowledge bases | 3.9+ |
| **agent-learning-kit** | `python -m pip install agent-learning-kit==0.3.7` | Local evaluation metrics and hosted Turing evaluations | 3.10+ |
| **fi-instrumentation-otel** | `pip install fi-instrumentation-otel` | OpenTelemetry tracing for AI apps | 3.9+ |
| **traceai-\*** | `pip install traceAI-openai` | Auto-instrumentation for 45+ frameworks | 3.9+ |

For new Python optimization and simulation projects, the kit also provides
`fi.alk.optimize` and `fi.alk.simulate`. Existing projects pinned to `agent-opt`
or `agent-simulate` should keep their own environment when porting; don't install
the kit over either distribution. The kit's extras are not a one-for-one match
for all legacy integrations.

<Note>
  Use separate virtual environments for Agent Learning Kit and the `futureagi` platform SDK. Their current wheels install different code at some of the same `fi/` paths. For example, installing the kit after `futureagi==0.7.0` can break `from fi import Client`. Installing the packages in the other order is not a fix. Don't add the legacy `ai-evaluation` wheel to the kit environment either.
</Note>

### TypeScript

| Package | Install | What it does |
|---------|---------|--------------|
| **@future-agi/sdk** | `npm install @future-agi/sdk` | Datasets, prompt versioning, knowledge bases |
| **@future-agi/ai-evaluation** | `npm install @future-agi/ai-evaluation` | Eval metrics and guardrails |
| **@traceai/fi-core** | `npm install @traceai/fi-core` | Tracing core |
| **@traceai/openai** | `npm install @traceai/openai` | Framework instrumentors (40+) |

### Java and C#

Tracing only. Java has 25+ instrumentors (Maven via JitPack, group ID `com.github.future-agi.traceAI`). C# has a single NuGet package (`fi-instrumentation-otel`). See the [Tracing reference](/docs/sdk/tracing) for details.
