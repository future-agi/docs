## Quickstart

<Tabs>
  <Tab title="Python">
    ```bash
    pip install ai-evaluation
    ```

    Requires Python 3.10+. This also installs `futureagi` ([datasets](/docs/sdk/datasets), [prompts](/docs/sdk/datasets), [knowledge bases](/docs/sdk/knowledgebase)) automatically.

    ```bash
    export FI_API_KEY="your-api-key"
    export FI_SECRET_KEY="your-secret-key"
    ```

    ```python
    from fi.evals import evaluate

    # Local metric — no API key needed
    result = evaluate("contains", output="Hello world", keyword="Hello")
    print(result.score)    # 1.0
    print(result.passed)   # True

    # Cloud metric — needs FI_API_KEY and FI_SECRET_KEY
    result = evaluate("toxicity", output="Hello world", model="turing_flash")
    print(result.score)    # 1.0
    print(result.passed)   # True
    ```

    Want tracing too? Add the instrumentor for your provider:

    ```bash
    pip install fi-instrumentation-otel traceAI-openai
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @future-agi/ai-evaluation
    ```

    ```bash
    export FI_API_KEY="your-api-key"
    export FI_SECRET_KEY="your-secret-key"
    ```

    ```typescript
    import { Evaluator, Tone } from "@future-agi/ai-evaluation";

    const evaluator = new Evaluator();

    const result = await evaluator.evaluate({
      evalTemplates: [new Tone()],
      inputs: [{
        query: "Write a professional email",
        response: "Dear Sir/Madam, I hope this message finds you well..."
      }],
      modelName: "turing_flash"
    });

    console.log(result);
    ```

    Want tracing too?

    ```bash
    npm install @traceai/fi-core @traceai/openai
    ```
  </Tab>

    ```bash
    pip install ai-evaluation
    ```

    **`AuthenticationError`** — Both `FI_API_KEY` and `FI_SECRET_KEY` must be set. The API key alone is not enough.

    **`Python version error`** — `ai-evaluation` requires Python 3.10+. Check with `python --version`.

## Call the gateway from Python

`futureagi` 0.7.0 and later include `fi.gateway`, an OpenAI-compatible client for the [Agent Command Center](/docs/command-center) gateway. Calls go through the providers, routing, caching and guardrails configured for your organization.

```bash
pip install --upgrade "futureagi>=0.7.0"
```

The gateway authenticates with its own [virtual keys](/docs/command-center/concepts/virtual-keys) (`sk-agentcc-...`, from **Settings > API Keys**), not with `FI_API_KEY` and `FI_SECRET_KEY`:

```bash
export FI_GATEWAY_API_KEY="sk-agentcc-your-api-key-here"
# Optional. Defaults to https://gateway.futureagi.com; set it for a self-hosted gateway.
export FI_GATEWAY_URL="https://gateway.futureagi.com"
```

```python
from fi.gateway import Gateway

gw = Gateway()  # reads FI_GATEWAY_API_KEY and FI_GATEWAY_URL

reply = gw.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
)

print(reply.choices[0].message.content)  # Paris
print(reply.usage.total_tokens)

meta = reply.agentcc  # what the gateway did with the request
print(meta.provider, meta.model_used, meta.latency_ms, meta.cost, meta.cache_status)
```

`create()` returns a `ChatCompletion` with the same fields as an OpenAI response (`id`, `model`, `choices`, `usage`). `reply.agentcc` adds the gateway's metadata, read from its `x-agentcc-*` response headers:

| Field | What it holds |
|-------|---------------|
| `request_id`, `trace_id` | IDs to find the request in the gateway's request logs |
| `provider`, `model_used` | The provider and model that served the call, which can differ from `model` after routing or a fallback |
| `latency_ms`, `cost` | Gateway latency in milliseconds and the call's cost |
| `cache_status` | The gateway cache's result for the call, from the `x-agentcc-cache` header |
| `guardrail_triggered`, `fallback_used` | Whether a guardrail fired, and whether a fallback model answered |

- `AsyncGateway` is the async version: `async with AsyncGateway() as gw: ...`
- `Gateway(session_id="checkout-flow")` groups calls into one gateway session.
- An error response raises a typed exception such as `fi.gateway.AuthenticationError` or `fi.gateway.RateLimitError`, both subclasses of `fi.gateway.APIStatusError`.
- Code written for the `agentcc` package keeps working with a changed import: `from fi.gateway import AgentCC`. `AGENTCC_API_KEY` and `AGENTCC_BASE_URL` are still read when the `FI_GATEWAY_*` variables are unset.
- Managing gateways (listing them, reading their config, request logs, sessions and analytics) is a platform API on `fi.Client().gateway`. See the [Gateway SDK reference](/docs/sdk/reference/gateway).

To configure what the gateway does with these calls, see [routing](/docs/command-center/features/routing), [caching](/docs/command-center/features/caching) and [guardrails](/docs/command-center/features/guardrails). The [gateway endpoints](/docs/command-center/api/endpoints) page lists every request the gateway accepts.

## Packages

### Python

Six packages, each installable independently:

| Package | Install | What it does | Python |
|---------|---------|--------------|--------|
| **futureagi** | `pip install futureagi` | Datasets, prompt versioning, knowledge bases, [gateway client](#call-the-gateway-from-python) | 3.9+ |
| **ai-evaluation** | `pip install ai-evaluation` | 76+ local metrics + 100+ cloud templates, guardrails, streaming eval | 3.10+ |
| **fi-instrumentation-otel** | `pip install fi-instrumentation-otel` | OpenTelemetry tracing for AI apps | 3.9+ |
| **traceai-\*** | `pip install traceAI-openai` | Auto-instrumentation for 45+ frameworks | 3.9+ |
| **agent-opt** | `pip install agent-opt` | Prompt optimization (6 algorithms) | 3.10+ |
| **agent-simulate** | `pip install agent-simulate` | Simulate voice AI agents at scale | 3.10+ |

```
futureagi                    ← standalone base layer
  └── ai-evaluation          ← installs futureagi automatically
        └── agent-opt        ← installs ai-evaluation automatically

fi-instrumentation-otel      ← standalone tracing layer
  ├── traceai-*              ← each installs fi-instrumentation-otel
  └── agent-simulate         ← installs fi-instrumentation-otel
```

<Tip>
  You don't need to install dependencies manually. `pip install ai-evaluation` gives you `futureagi` too. `pip install traceAI-openai` gives you `fi-instrumentation-otel` too.
</Tip>

### TypeScript

| Package | Install | What it does |
|---------|---------|--------------|
| **@future-agi/sdk** | `npm install @future-agi/sdk` | Datasets, prompt versioning, knowledge bases |
| **@future-agi/ai-evaluation** | `npm install @future-agi/ai-evaluation` | Eval metrics and guardrails |
| **@traceai/fi-core** | `npm install @traceai/fi-core` | Tracing core |
| **@traceai/openai** | `npm install @traceai/openai` | Framework instrumentors (40+) |

### Java and C#

Tracing only. Java has 25+ instrumentors (Maven via JitPack, group ID `com.github.future-agi.traceAI`). C# has a single NuGet package (`fi-instrumentation-otel`). See the [Tracing reference](/docs/sdk/tracing) for details.
