title: "Core SDKs"
description: "Choose the Python SDK for datasets, prompt optimization, simulation, knowledge bases, or Protect."
---

Use the platform SDK (`futureagi`) to manage datasets and knowledge bases. Use Agent Learning Kit for optimization, simulation, and Protect. Both Python packages install modules under `fi`, so keep them in separate virtual environments.

## Datasets

To create and version datasets, install the platform SDK in its own environment:

```bash
python3.12 -m venv .venv-platform
.venv-platform/bin/python -m pip install futureagi
```

**Full reference:** [Datasets SDK](/docs/sdk/datasets)

## Prompt Optimization

Install Agent Learning Kit in a second environment:

```bash
python3.12 -m venv .venv-alk
.venv-alk/bin/python -m pip install agent-learning-kit==0.3.7
```

Use `BayesianSearchOptimizer` from `fi.alk.optimize` to select few-shot examples, or `MetaPromptOptimizer` to rewrite instructions based on how candidate prompts score.

**Full reference:** [Prompt Optimization SDK](/docs/sdk/optimization)

## Simulation Testing

Use `TestRunner` from `fi.alk.simulate` in the Agent Learning Kit environment to simulate local text conversations. For voice agents, follow the SDK reference to set up LiveKit. For hosted runs, use [Environments](/docs/environments).

**Full reference:** [Simulation SDK](/docs/sdk/simulate)

## Knowledge Base

Use `fi.kb` in the platform SDK environment to upload documents to a knowledge base.

**Full reference:** [Knowledge Base SDK](/docs/sdk/knowledgebase)

## Protect

Use `Protect` from `fi.evals.protect` in the Agent Learning Kit environment to check messages against the rules in your Protect configuration.

**Full reference:** [Protect SDK](/docs/sdk/protect)
