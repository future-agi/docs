## Python

Install Agent Learning Kit in a fresh virtual environment. You can run both local and hosted evaluations with `fi.alk.evals`.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7
```

To check whether a support reply mentions the return window, save this as `local_check.py` and run `python local_check.py`. The `contains` metric runs locally without credentials.

```python
from fi.alk import evals

reply = "You can return unworn boots within 30 days."
result = evals.evaluate("contains", output=reply, keyword="30 days")
print(result.passed)  # True
```

To check the same reply for toxicity with a hosted template, set `FI_API_KEY` and `FI_SECRET_KEY` from your [workspace API keys](/docs/admin-settings/api-keys). Save this as `hosted_check.py` and run `python hosted_check.py`. It prints the score, the reason, and the evaluation ID you can use to retrieve the result.

```python
from fi.alk import evals

reply = "You can return unworn boots within 30 days."
result = evals.evaluate("toxicity", output=reply, model="turing_flash")
if result.status != "completed" or result.score is None:
    raise RuntimeError(result.error or "No toxicity score returned")
print(result.score, result.reason)
print(result.metadata["eval_id"])
```

## Optional extras (Python)

The base install is enough for both examples. If you need extra dependencies, install them in the **same kit environment**:

| Feature | Install |
|---------|---------|
| NLI models | `python -m pip install "agent-learning-kit[nli]==0.3.7"` |
| Sentence embeddings | `python -m pip install "agent-learning-kit[embeddings]==0.3.7"` |
| ChromaDB feedback storage | `python -m pip install "agent-learning-kit[feedback]==0.3.7"` |

For Celery, Ray, or Temporal, follow the [distributed backend recipes](/docs/sdk/evals/distributed). Version 0.3.7 does not provide extras with those names.
