## Python

In a fresh environment, install `agent-learning-kit` for new local and hosted evaluations. The kit replaces the legacy `ai-evaluation` distribution. Use `fi.alk.evals` for new code; existing `from fi.evals import evaluate` imports still work. See the [SDK quickstart](/docs/sdk#quickstart) for virtual environment setup.

```bash
python -m pip install agent-learning-kit==0.3.7
```

```python
from fi.alk import evals

result = evals.evaluate("contains", output="Hello world", keyword="Hello")
print(result.passed)  # True
```

For a cloud template, set `FI_API_KEY` and `FI_SECRET_KEY`, then pass a Turing model:

```python
result = evals.evaluate("toxicity", output="Hello world", model="turing_flash")
print(result.score, result.reason)
```

## Optional extras (Python)

The base install is enough for the two examples above. For a feature with extra dependencies, select it in the **same kit environment**:

| Feature | Install |
|---------|---------|
| NLI models | `python -m pip install "agent-learning-kit[nli]==0.3.7"` |
| Sentence embeddings | `python -m pip install "agent-learning-kit[embeddings]==0.3.7"` |
| ChromaDB feedback storage | `python -m pip install "agent-learning-kit[feedback]==0.3.7"` |

The [distributed backend recipes](/docs/sdk/evals/distributed) use legacy `ai-evaluation` extras. The kit does not publish `celery`, `ray`, or `temporal` extras in 0.3.7.
