description: "Run your Python agent through a conversation and check its answer against a shipping policy"
---

Can your order assistant give a customer the right shipping day? Run one customer question through your own Python code, read both sides of the conversation, and add a check you can repeat whenever the agent changes.

<Note>
Install ALK with the [Agent Learning Kit quickstart](/docs/sdk/agent-learning-kit) and keep that Python environment active. The example runs locally with a built-in simulated customer and needs no API keys.
</Note>

## Give ALK an agent to call

Create `order_test.py` and add the following code. ALK calls the agent's asynchronous `call` method with the conversation so far. Read the latest message and return an `AgentResponse` containing the reply.

```python
import asyncio

from fi.alk import simulate
from fi.simulate.agent.wrapper import AgentInput, AgentResponse


class OrderAgent:
    async def call(self, request: AgentInput) -> AgentResponse:
        question = request.messages[-1]["content"]
        if "A-104" in question:
            return AgentResponse(content="Order A-104 ships Friday.")
        return AgentResponse(content="Which order do you mean?")
```

To test an existing agent, put its call inside this method and return its reply in `content`. If your agent uses a model provider, its usual credentials and charges apply.

## Describe one customer's question

Append this block to the same file. The scenario describes Morgan's situation and what they want to learn. The chat environment allows one exchange, so the report captures the first answer a customer would get.

```python
case = simulate.Persona(
    persona={"name": "Morgan"},
    situation="Ask when order A-104 will ship.",
    outcome="Learn the shipping day.",
)
spec = simulate.SimulationSpec(
    run_id="order-status",
    environment=simulate.EnvironmentSpec(
        adapter="chat",
        world_kind="conversation",
        config={"min_turns": 1, "max_turns": 1},
    ),
    target=simulate.AgentEndpointSpec(adapter="callable"),
    simulator=simulate.SimulatorPolicySpec(adapter="synthetic_user"),
    scenario=simulate.Scenario(name="shipping-day", dataset=[case]),
)
```

`callable` tells the runner to use the Python agent you pass to it. The built-in `synthetic_user` turns Morgan's situation and desired outcome into the opening message. Keep the expected shipping day out of Morgan's instructions so the agent has to supply it.

## Run the conversation and check the answer

Append the final block. The report holds one test case for Morgan. Print its transcript so you can see what prompted the reply, then check the agent's message against the expected shipping day.

```python
report = asyncio.run(simulate.SimulationRunner().run(spec, target=OrderAgent()))
result = report.test_cases[0].result
print(report.status.value)
print(result.transcript)
assert result.messages[-1]["content"] == "Order A-104 ships Friday."
```

Run `python order_test.py`. The example prints:

```text
completed
User: My name is Morgan. Ask when order A-104 will ship. I want this outcome: Learn the shipping day.
Agent: Order A-104 ships Friday.
```

Change `Friday` to `Monday` in the agent's reply, leave the assertion as written, and run the file again. The status still reads `completed` because the conversation ran to the end. This time the transcript shows the wrong day and Python raises `AssertionError`. That distinction matters when you use the test to decide whether an agent change is safe to ship.
