In [Simulate an agent](/docs/sdk/agent-learning-kit/simulate-an-agent), ALK's built-in chat environment manages the conversation. Write a plugin when your test needs its own rules for what happens in a turn. Here the environment asks about one order, the target looks up its shipping status, and ALK records the exchange.

<Note>
Use the virtual environment and local settings from the [ALK quickstart](/docs/sdk/agent-learning-kit). This example uses an in-memory order and needs no provider account or Docker service. To generate scenarios from an agent's source, follow [Author an environment](/docs/sdk/agent-learning-kit/author-an-environment).
</Note>

## Define the interaction

Save this as `order_world.py`. The target owns the order data. The environment decides which question to ask, calls the target, and returns one test case with the conversation it observed.

```python
import asyncio

from fi.alk import simulate
from fi.simulate.environments.base import EnvironmentManifest


class OrderAgent:
    async def reply(self, order_id):
        orders = {"A-104": "packed"}
        return f"Order {order_id} is {orders[order_id]}."


@simulate.register_environment("order_status")
class OrderEnvironment:
    manifest = EnvironmentManifest(name="order_status", world_kinds=["orders"])

    async def run(self, spec, *, target, **kwargs):
        question = "Where is order A-104?"
        answer = await target.reply("A-104")
        case = simulate.TestCaseResult(
            persona=spec.scenario.dataset[0],
            transcript=f"Customer: {question}\nAgent: {answer}",
            messages=[
                {"role": "user", "content": question},
                {"role": "assistant", "content": answer},
            ],
        )
        return simulate.TestReport(results=[case])
```

Importing the class registers the name `order_status` in the current Python process. A script that runs the test in a new process must import the plugin there too.

## Select the environment and run one case

Append the following to the same file. The environment's `adapter` selects the registered class. The `target` argument to `run` supplies the actual agent instance.

```python
spec = simulate.SimulationSpec(
    run_id="order-demo",
    environment=simulate.EnvironmentSpec(adapter="order_status", world_kind="orders"),
    target=simulate.AgentEndpointSpec(adapter="callable"),
    simulator=simulate.SimulatorPolicySpec(adapter="synthetic_user"),
    scenario=simulate.Scenario(
        name="order lookup",
        dataset=[
            simulate.Persona(
                persona={"name": "Morgan"},
                situation="Ask where order A-104 is.",
                outcome="Receive the current order status.",
            )
        ],
    ),
)

report = asyncio.run(simulate.SimulationRunner().run(spec, target=OrderAgent()))
case = report.test_cases[0].result
print(case.transcript)
assert case.messages[-1]["content"] == "Order A-104 is packed."
```

Run `python order_world.py`. The runner converts the plugin's `TestReport` into a simulation report. The assertion checks the reply recorded in that report.

```text
Customer: Where is order A-104?
Agent: Order A-104 is packed.
```

Try changing the order status to `shipped` while leaving the assertion unchanged. The transcript shows the new reply, and the assertion fails. For a suite of checks on responses, follow [Evaluate responses](/docs/sdk/agent-learning-kit/evaluate-responses).
