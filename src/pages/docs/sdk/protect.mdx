title: "Protect: AI Input and Output Guardrails SDK Module"
description: "Check a message for toxicity, bias, prompt injection, or privacy violations before you forward it."
---

Protect checks the text you pass to it. Your application decides whether to send that text to an LLM or show its reply to a customer. For the full platform guide, see [Protect docs](/docs/protect).

## Quick example

Set `FI_API_KEY` and `FI_SECRET_KEY` from your [workspace API keys](/docs/admin-settings/api-keys). Install the kit in a fresh environment:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7 openai
```

Run the Python blocks in order in the same Python session. Start by checking a rude draft reply before it reaches a customer. `Protect()` reads the two credentials from your environment.

```python
from fi.evals import Protect

protect = Protect()
result = protect.protect(
    inputs="Only an idiot would buy boots in the wrong size. Figure it out yourself.",
    protect_rules=[{"metric": "toxicity"}],
    action="Hold this reply for review.",
    reason=True,
)
print(result["status"], result["failed_rule"], result["messages"])
```

When the toxicity rule flags the draft, the output is:

```text
failed ['toxicity'] Hold this reply for review.
```

A processing-error message instead of your configured action is **not** a toxicity verdict. Withhold the reply and check that your deployment can run the selected Protect model. The standard client does not accept a model override. If you want to select a Turing model explicitly for a single hosted metric, see the [evaluation example](/docs/sdk/list/evaluation).

## `protect()` method

| Parameter | Default | Description |
|-----------|---------|-------------|
| `inputs` | Required | For a text check, pass a nonempty string. |
| `protect_rules` | `None` | Standard mode requires a nonempty list of rules. |
| `action` | `"Response cannot be generated as the input fails the checks"` | Default message to return when a rule triggers. |
| `reason` | `False` | Request a reason for a triggered rule. |
| `timeout` | `30000` | Time budget for rule checks, in milliseconds. Incomplete checks are not approvals. |
| `use_flash` | `False` | Use a binary harmful/not harmful classifier instead of the individual rules. |

### Rule structure

Each standard rule names a `metric`: `toxicity`, `bias_detection`, `prompt_injection`, or `data_privacy_compliance`. You can override the default action for a rule. For example, check customer questions for prompt injection, and check draft replies for toxicity and privacy:

```python
input_rules = [{"metric": "prompt_injection", "action": "Hold this question for review."}]
output_rules = [
    {"metric": "toxicity"},
    {"metric": "data_privacy_compliance", "action": "Hold this reply for a privacy review."},
]
```

### Return value

For a single text in standard mode:

| Field | Meaning |
|-------|---------|
| `status` | `"passed"` or `"failed"`. A pass alone does not mean every rule completed. |
| `completed_rules`, `uncompleted_rules` | Lists of rule names. Check these before forwarding a message. |
| `failed_rule` | List of rules reported as failed, not a single name. A request error can also fail a check. |
| `messages` | The input on a pass; a rule action or processing-error message on a failure. |
| `reasons` | List of explanations when available. Use `status` and the rule lists for branching, not this text. |
| `time_taken` | Elapsed time in seconds. |

## Common patterns

### Check before sending to an LLM

Set `OPENAI_API_KEY` for this example. Only send the question when all requested checks have completed and passed. Keep the generated reply private until its own checks finish.

```python
from openai import OpenAI


def cleared(result, rules):
    return (
        result["status"] == "passed"
        and not result["uncompleted_rules"]
        and set(result["completed_rules"]) == {rule["metric"] for rule in rules}
    )


question = "How do I find the care label on my hiking jacket?"
input_result = protect.protect(inputs=question, protect_rules=input_rules)
reply = None
if cleared(input_result, input_rules):
    response = OpenAI().chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": question}],
    )
    reply = response.choices[0].message.content
else:
    print("Question withheld.")
```

### Check the LLM output before returning it to the customer

Check the generated reply, not the original question. If a rule fails, a check is incomplete, or the model gave no reply, return a fallback rather than the unchecked text.

```python
if reply and reply.strip():
    output_result = protect.protect(inputs=reply, protect_rules=output_rules, reason=True)
    if cleared(output_result, output_rules):
        print(reply)
    else:
        print("Reply withheld for review.")
else:
    print("No reply to send.")
```
