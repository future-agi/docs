<TLDR>
- Install `agent-learning-kit` to run open-source agent workflows directly.
- Start with a credential-free simulation that writes a local artifact.
- Use released Future AGI clients for their documented resources. Use the dashboard for Environment jobs and results.
</TLDR>

Agent Learning Kit (ALK) is an open-source Python toolkit for testing and improving AI agents. It supports evaluation, simulation, red teaming, and optimization. You start ALK from your Python environment. A workflow can use subprocesses, containers, local services, or model providers. Direct ALK workflows write local artifacts or CI output by default.

ALK is separate from the generated Future AGI platform client. ALK does not create or wait for platform Environment jobs. Use the Future AGI dashboard to create and monitor those jobs until a released client includes Environment operations. Future AGI can run ALK in hosted workers. A hosted ALK run can send events and artifacts to an existing platform run.

## Choose ALK or a platform client

| Goal | Use | Where the work runs | Where results go |
| --- | --- | --- | --- |
| Evaluate or simulate an agent directly | `agent-learning-kit` | Your environment and selected runtimes | Local artifacts by default |
| Author an environment against ALK contracts | `agent-learning-kit` | Your environment and selected runtimes | Local artifacts by default |
| Manage platform datasets, prompts, and knowledge bases | `futureagi` or `@future-agi/sdk` | Future AGI | Future AGI platform |
| Create and monitor Environment jobs | Future AGI dashboard | Future AGI hosted workers | Future AGI dashboard |
| Run an existing platform chat simulation with an agent callback | `agent-simulate` | Your callback and Future AGI | Future AGI platform |

## Install ALK

ALK requires Python 3.10 or later.

```bash
pip install agent-learning-kit
```

Confirm that the CLI is installed:

```bash
agent-learn --help
```

## Run the credential-free quickstart

Create a project in an empty directory:

```bash
agent-learn init . --preset run
agent-learn run manifests/run.json --output artifacts/run.json
```

The command writes `artifacts/run.json`. The scaffold uses a scripted agent, so the run does not require a model provider or a Future AGI account.

<Note>
The first run proves that ALK can load a manifest, run a scripted simulation, and write an artifact. It does not test your own agent.
</Note>

## Use hosted Future AGI workflows

Use a released platform client only for resources documented for the version you installed. The released clients manage resources such as datasets, prompts, and knowledge bases. Use the Future AGI dashboard to create and monitor Environment jobs until a released client includes Environment operations.

ALK may run inside Future AGI's hosted workers, but those worker entry points are internal. Do not call them as a platform API.
