<TLDR>
- 16 string check metrics (binary 0/1): contains, equals, regex, length, email/link detection
- 7 similarity metrics: compare n-grams, retrieved items, character edits, numbers, or embeddings
- `embedding_similarity` and `semantic_list_contains` use the optional `embeddings` extra and download a public model on first use.
</TLDR>

Use these metrics to check a Ridgeline Outfitters support reply without calling an LLM. For example, you can require a return label to be mentioned without requiring an exact sentence. Install the kit in a Python 3.12 virtual environment:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install agent-learning-kit==0.3.7
```

Run the Python examples in order in the same session up to `embedding_similarity`. The two embedding metrics have an additional install step.

```python
from fi.evals import evaluate

result = evaluate("contains", output="Your return label is ready.", keyword="return label")
print(result.score)    # 1.0
print(result.passed)   # True
print(result.reason)   # Keyword 'return label' found
```

## String Check Metrics

A score of `1.0` means the check passed; `0.0` means it failed.

| Metric | What it checks |
|--------|---------------|
| `contains` | Output contains a keyword |
| `contains_all` | Output contains every keyword in a list |
| `contains_any` | Output contains at least one keyword from a list |
| `contains_none` | Output contains none of the forbidden keywords |
| `contains_email` | Output contains an email address |
| `contains_link` | Output contains a URL |
| `contains_valid_link` | The first URL-like match returns HTTP 2xx to a HEAD request |
| `is_email` | Entire output matches an email-address pattern |
| `one_line` | Output has no internal newline after trimming |
| `equals` | Matches `expected_output` (case-insensitive by default) |
| `starts_with` | Output starts with a given string |
| `ends_with` | Output ends with a given string |
| `regex` | Output matches a regular expression |
| `length_less_than` | Output is under a maximum character count |
| `length_greater_than` | Output exceeds a minimum character count |
| `length_between` | Output length is within a range |

### contains

Output contains a keyword. Pass the keyword as a kwarg.

```python
result = evaluate("contains", output="Contact our support team.", keyword="support")
print(result.score)  # 1.0
print(result.reason)  # Keyword 'support' found
```

### contains_all

Output contains every keyword in the list. Fails if any keyword is missing.

```python
result = evaluate(
    "contains_all",
    output="Order shipped, delivered Friday.",
    config={"keywords": ["shipped", "delivered", "Friday"]},
)
print(result.score)  # 1.0
print(result.reason)  # All 3 keywords found.
```

### contains_any

Output contains at least one keyword from the list.

```python
result = evaluate(
    "contains_any",
    output="Pay via credit card or PayPal.",
    config={"keywords": ["credit card", "PayPal", "bank transfer"]},
)
print(result.score)  # 1.0
print(result.reason)  # Found keywords: credit card, PayPal
```

### contains_none

Output contains none of the forbidden keywords.

```python
result = evaluate(
    "contains_none",
    output="Your return label is ready.",
    config={"keywords": ["guaranteed", "nonrefundable"]},
)
print(result.score)  # 1.0
print(result.reason)  # No forbidden keywords found.
```

### contains_email

Output contains at least one email address.

```python
result = evaluate("contains_email", output="Reach us at support@example.com")
print(result.score)  # 1.0
```

### contains_link

Output contains at least one URL.

```python
result = evaluate("contains_link", output="Visit https://docs.futureagi.com for details.")
print(result.score)  # 1.0
```

### contains_valid_link

The first URL-like match must respond to an HTTP HEAD request with a 2xx status within five seconds. Redirects are not followed. Use this on trusted links only; unlike `contains_link`, it contacts the destination.

```python
result = evaluate("contains_valid_link", output="More info at https://example.com/")
print(result.score)  # 1.0
```

### is_email

Checks the shape of the entire string, not whether the mailbox exists.

```python
result = evaluate("is_email", output="user@example.com")
print(result.score)  # 1.0

result = evaluate("is_email", output="Contact user@example.com")
print(result.score)  # 0.0 (not just an email)
```

### one_line

Checks for internal `\n` characters after stripping leading and trailing whitespace.

```python
result = evaluate("one_line", output="Your order has shipped.")
print(result.score)  # 1.0
```

### equals

Case is ignored by default. Set `case_sensitive` to require the exact capitalization, for example when you compare an order code.

```python
result = evaluate("equals", output="rl-42", expected_output="RL-42")
print(result.score)  # 1.0

result = evaluate("equals", output="rl-42", expected_output="RL-42", config={"case_sensitive": True})
print(result.score)  # 0.0
```

### starts_with

Output begins with the given string.

```python
result = evaluate("starts_with", output="Summary: The refund was approved.", keyword="Summary:")
print(result.score)  # 1.0
```

### ends_with

Output ends with the given string.

```python
result = evaluate("ends_with", output="Thank you for your patience.", keyword="patience.")
print(result.score)  # 1.0
```

### regex

Searches for the pattern anywhere in the output. Pass the pattern via `config`.

```python
result = evaluate("regex", output="Order #12345 confirmed.", config={"pattern": r"#\d+"})
print(result.score)  # 1.0
print(result.reason)  # Regex pattern '#\d+' found in response.
```

### length_less_than

Output is under a maximum character count.

```python
result = evaluate("length_less_than", output="Yes.", config={"max_length": 100})
print(result.score)  # 1.0
print(result.reason)  # Length 4 < 100
```

### length_greater_than

Output exceeds a minimum character count.

```python
result = evaluate("length_greater_than", output="Item packed", config={"min_length": 5})
print(result.score)  # 1.0
print(result.reason)  # Length 11 > 5
```

### length_between

Output length falls within an inclusive range.

```python
result = evaluate("length_between", output="Ready", config={"min_length": 3, "max_length": 10})
print(result.score)  # 1.0
print(result.reason)  # Length 5 is between [3, 10]
```

## Similarity Metrics

Pass a reference with `expected_output`. Most of these metrics return a graded score; `semantic_list_contains` returns a binary score after applying a similarity threshold.

| Metric | What it measures |
|--------|-----------------|
| `bleu_score` | N-gram precision between output and expected |
| `rouge_score` | ROUGE F-measure (combines precision and recall) |
| `recall_score` | Fraction of distinct reference items retrieved |
| `levenshtein_similarity` | One minus normalized character edit distance |
| `numeric_similarity` | Numeric value proximity |
| `embedding_similarity` | Similarity between two text embeddings |
| `semantic_list_contains` | Thresholded similarity to a list of reference phrases |

### bleu_score

BLEU score between output and expected. Measures n-gram precision. Commonly used for translation and summarization.

```python
reply = "Your return label is ready."
reference = "Your return label is now ready."
result = evaluate("bleu_score", output=reply, expected_output=reference)
print(round(result.score, 3))  # 0.579
```

### rouge_score

The score is the F-measure, not recall alone. The default `rouge1` uses unigrams. Use `rouge2` for bigrams or `rougeL` for longest common subsequence.

```python
result = evaluate("rouge_score", output=reply, expected_output=reference)
print(round(result.score, 3))  # 0.909

result = evaluate("rouge_score", output=reply, expected_output=reference, config={"rouge_type": "rougeL"})
print(round(result.score, 3))  # 0.909
```

### recall_score

Item recall, not word recall: a plain sentence counts as one item. Use a JSON list string as the output when your agent returns several SKUs. Extra SKUs do not reduce recall.

```python
result = evaluate("recall_score", output='["PACK-12", "TENT-8"]', expected_output=["PACK-12", "BOOT-4"])
print(result.score)  # 0.5 (one of two reference SKUs found)
```

### levenshtein_similarity

One minus the edit distance divided by the longer string length. By default, comparison ignores case and strips ASCII punctuation.

```python
result = evaluate("levenshtein_similarity", output="boots", expected_output="boot")
print(result.score)  # 0.8
```

### numeric_similarity

Compares the first number in each string, relative to the larger absolute value. This does not convert units.

```python
result = evaluate("numeric_similarity", output="102", expected_output="100")
print(round(result.score, 3))  # 0.98
```

### embedding_similarity

Compare the embeddings of two full replies when the wording can differ. The default is cosine similarity, which can range from -1 to 1. `euclidean` and `manhattan` convert distance to similarity using `1 / (1 + distance)`.

Exit Python and install the `embeddings` extra in the same virtual environment. For kit 0.3.7 on Python 3.12, pin NumPy to `1.26.4` so both embedding metrics return numeric scores. On CPU-only Linux, install the CPU build of PyTorch first to avoid downloading GPU libraries:

```bash
python -m pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install "agent-learning-kit[embeddings]==0.3.7" numpy==1.26.4
```

On other platforms, install the extra with the second command after choosing a compatible PyTorch build. The default model (`sentence-transformers/all-MiniLM-L6-v2`) needs a network connection on first use. Subsequent calls can reuse the cached weights. Start a fresh Python session for the next two examples.

```python
from fi.evals import evaluate

reply = "Your return label is ready."
reference = "Your return label is now ready."
result = evaluate("embedding_similarity", output=reply, expected_output=reference)
print(round(result.score, 3))  # 0.973 (cosine)

result = evaluate(
    "embedding_similarity", output=reply, expected_output=reference,
    config={"similarity_method": "euclidean"},
)
print(round(result.score, 3))  # 0.81
```

### semantic_list_contains

Compare the whole reply to each reference phrase, not to substrings of the reply. By default, one phrase at or above the threshold (0.7) is enough. Pass `match_all=True` inside `config` to require all phrases to match.

```python
result = evaluate(
    "semantic_list_contains",
    output="Your return label is ready.",
    expected_output=["Your return label is now ready.", "The tent is out of stock."],
    config={"similarity_threshold": 0.7},
)
print(result.score)  # 1.0
```
