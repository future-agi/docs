## Configuration fields

Most fields below apply to every check in both the [first-party](#first-party-checks) and [provider-backed](#provider-backed-checks) tables above; a provider-backed check additionally exposes Provider Settings for connecting to its external provider. Confidence Threshold appears on every check except `futureagi-eval` and `presidio-pii`.

A check is configured from one of two dialogs: the per-check dialog covered under [Rules dialog](#rules-dialog), and the guardrail-level dialog covered under [Overview dialog](#overview-dialog). The two expose different fields: the Rules dialog sets Mask, a Confidence Threshold, or a provider connection; the Overview dialog sets Stage.

### Rules dialog

| Field | Values | Default |
|---|---|---|
| Enabled | Toggle | |
| Action | Block, Warn, Mask, Log | Block |
| Confidence Threshold | Slider from 0.0 to 1.0, marked at 0.0 / 0.5 / 1.0 | 0.8 |
| Provider Settings (provider-backed checks only) | Connection to the check's external provider | |

### Overview dialog

| Field | Values | Default |
|---|---|---|
| Action | Block, Warn, Log | Block |
| Stage | pre, post, both | pre |
| Threshold | Numeric (optional) | |

The Overview dialog does not expose Mask.

### Pipeline settings

These apply to the check pipeline as a whole, not to an individual check.

| Field | Values | Default |
|---|---|---|
| Mode | Parallel, Sequential | Parallel |
| Fail Open | Toggle | On |
| Timeout | Milliseconds | 5000 ms |

## Response statuses

A gateway call's response status only changes when a check blocks or warns.

| Status | Meaning |
|---|---|
| `403` | Blocked |
| `446` | Blocked |
| `246` | Warned |

<Note>Both `403` and `446` indicate a blocked call. The condition that selects one over the other isn't documented here, so treat both as blocked when writing code that branches on status.</Note>
