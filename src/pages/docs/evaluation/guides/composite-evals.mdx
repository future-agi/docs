---
title: "Build a composite evals"
description: "Combine several evals into one score you can gate on"
---

A [composite eval](/docs/evaluation/concepts/composite-evals) runs several child evals against the same input, then combines their scores into one number with an aggregation function. This guide builds one from the eval builder, combining the built-in `completeness`, `context_adherence`, and `conversation_coherence` evals with a weighted average.

## Open the eval builder

On the Evals list, click **Create evals** at the top right.

<img src="/images/docs/evaluation/guides/composite-evals/open-builder.png" alt="Evaluations list page with the Create evals button highlighted at the top right" style={{ borderRadius: '5px' }} />
*Start from Create evals on the Evals list*

## Switch to Composite

The eval builder opens on **Single**. Click **Composite** next to it.

<img src="/images/docs/evaluation/guides/composite-evals/composite-mode.png" alt="Eval details page with the Single and Composite toggle, Composite tab highlighted" style={{ borderRadius: '5px' }} />
*The Single / Composite toggle sits at the top right of Eval details*

## Configure the composite

Under **Composite Configuration**, set:

- **Name**: a unique identifier, lowercase letters, numbers, hyphens, and underscores only
- **Description**: what the composite evaluates
- **Child evaluation type**: the output type every child must share, `Pass / Fail`, `Score`, `Choices`, or `Code`, so their scores are comparable. This locks once you add the first child
- **Aggregate child eval scores**: on by default, combines children into one composite score. Turn it off to run the children independently with no combined score
- **Aggregation function**: `Weighted Average`, `Average`, `Minimum (safety gate)`, `Maximum`, or `Pass Rate`

This example uses `Score` as the child type and leaves **Weighted Average** as the aggregation function.

<img src="/images/docs/evaluation/guides/composite-evals/configure.png" alt="Composite Configuration panel with name response_quality_check, a description, Score selected as the child evaluation type, and Weighted Average as the aggregation function" style={{ borderRadius: '5px' }} />
*Name the composite, pick the child type, and choose how children combine*

## Add child evaluations

Under **Children**, click **Add evaluation**. A drawer opens to **Select Evaluation**, showing only evals that match the child type you picked. Search for one and click **Add** on its row, then confirm on the eval's configuration screen by clicking **Add to Composite**. Repeat for each child.

<img src="/images/docs/evaluation/guides/composite-evals/add-child.png" alt="Select Evaluation drawer searched for completeness, with an Add button on the completeness row and its Single, Agent, and Percentage columns" style={{ borderRadius: '5px' }} />
*Search the library and add each child one at a time*

This example adds `completeness`, `context_adherence`, and `conversation_coherence`.

<img src="/images/docs/evaluation/guides/composite-evals/children-added.png" alt="Composite Configuration with three children listed, completeness, context_adherence, and conversation_coherence, each with a Weight input" style={{ borderRadius: '5px' }} />
*All three children now list under Children, each with its own Weight field*

## Set weights

When the aggregation function is **Weighted Average**, every child gets a **Weight** field, from 0.0 to 10.0, defaulting to 1.0. A child you care about more gets a higher weight; the other four aggregation functions ignore weights entirely. This example weights `completeness` at 2 and leaves the other two children at 1.

<img src="/images/docs/evaluation/guides/composite-evals/weights.png" alt="Children list with completeness weight set to 2 and context_adherence and conversation_coherence still at the default weight of 1" style={{ borderRadius: '5px' }} />
*completeness now counts twice as much as the other two children in the weighted average*

## Save

Click **Save Evaluation**. The composite is created and opens on its own detail page, ready to attach to a dataset, a trace, or run from the SDK, the same way as any other eval template.

<img src="/images/docs/evaluation/guides/composite-evals/saved.png" alt="Saved composite evaluation detail page for response_quality_check showing its three children and weighted average aggregation" style={{ borderRadius: '5px' }} />
*The saved composite behaves like any other eval template*
