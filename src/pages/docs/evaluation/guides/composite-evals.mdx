title: "Build a composite eval"
description: "Combine task completion and human escalation into one weighted score, check which inputs the children use, and test the composite before saving."

If a support conversation needs both [task completion](/docs/evaluation/builtin/customer-agent-task-completion) and [appropriate human escalation](/docs/evaluation/builtin/customer-agent-human-escalation), score the same conversation with both checks. A [composite eval](/docs/evaluation/concepts/composite-evals) runs several child evals against the same input, then combines their scores into one number with an aggregation function. This guide builds one called `customer_evals_composite` that counts completion twice as much as escalation.

## Choose the output and aggregation

1. From the Evals list, click **Create evals**.

<img src="/images/docs/evaluation/guides/composite-evals/open-builder.png" alt="Evaluations list page with the Create evals button highlighted at the top right" style={{ borderRadius: '5px' }} />

2. Switch **Eval details** from **Single** to **Composite**.

<img src="/images/docs/evaluation/guides/composite-evals/switch-composite.png" alt="Create evaluation page with the Single and Composite toggle at the top of Eval details, Single currently selected" style={{ borderRadius: '5px' }} />

3. Under **Name**, enter `customer_evals_composite`.

   Use a unique name containing only lowercase letters, numbers, hyphens and underscores.

4. In **Description**, describe what the two checks evaluate.
5. Set **Child evaluation type** to **Pass / Fail**.

   All children must share an [output type](/docs/evaluation/reference/output-types); the other options are **Score**, **Choices** and **Code**. The type locks when you add the first child.

6. Keep **Aggregate child eval scores** on.

   It is on by default and combines the children into one composite score. Turn it off only if you want the child results side by side without a parent score.

7. Use **Weighted Average** for **Aggregation function**.

   This is how the child scores combine. The other four [aggregation functions](/docs/evaluation/concepts/composite-evals#aggregation-functions) ignore weights.

<img src="/images/docs/evaluation/guides/composite-evals/configure.png" alt="Composite Configuration panel with name customer_evals_composite, Pass / Fail selected as the child evaluation type, Aggregate child eval scores checked, and Weighted Average as the aggregation function" style={{ borderRadius: '5px' }} />

## Add the children

1. Under **Children**, click **Add evaluation**.
2. Search for `customer` in **Select Evaluation**.

<img src="/images/docs/evaluation/guides/composite-evals/add-child-search.png" alt="Select Evaluation drawer searched for customer, showing customer_agent_task_completion and customer_agent_human_escalation with an Add button on each row" style={{ borderRadius: '5px' }} />

3. Click **Add** on `customer_agent_task_completion`.

   You should see the child under **Children**. Its required variables, `agent_prompt` and `conversation`, appear in **Test Data** mapped by name.

<img src="/images/docs/evaluation/guides/composite-evals/child-added.png" alt="Children section showing customer_agent_task_completion added with weight 1, and the Test Data panel now listing agent_prompt and conversation mapped by name" style={{ borderRadius: '5px' }} />

4. Click **Add evaluation** again.
5. Click **Add** on `customer_agent_human_escalation`.

   An existing child shows **Added**. If you cannot find a child in the drawer, check its output type: the drawer lists only children that match the type you selected.

<img src="/images/docs/evaluation/guides/composite-evals/add-second-child.png" alt="Select Evaluation drawer with customer_agent_task_completion showing Added and customer_agent_human_escalation showing Add" style={{ borderRadius: '5px' }} />

6. Set **Weight** for task completion to `2`.

   Leave escalation at its default of `1`. Weights range from `0.0` to `10.0`, and a child you care about more gets a higher weight. The parent score is twice the normalized completion score plus the normalized escalation score, divided by three.

<img src="/images/docs/evaluation/guides/composite-evals/set-weights.png" alt="Children list with customer_agent_task_completion weight set to 2 and customer_agent_human_escalation at the default weight of 1, next to the Test Evaluation and Save Evaluation buttons" style={{ borderRadius: '5px' }} />

## Test and save

1. Choose a source in **Test Data**: a [dataset](/docs/dataset), a [trace](/docs/observe/concepts/traces), a [simulation](/docs/environments) or manual input.
2. Supply the required variables for the children.
3. Click **Test Evaluation**.
4. Compare the parent score with the weighted child results for that input.
5. Click **Save Evaluation** when the combination matches your intent.

   The composite is now an [eval template](/docs/evaluation/concepts/eval-templates) you can attach to data or run from the SDK.
