When an eval's completion rate dips or its volume drops, use its **Usage** tab to see how the eval has performed over time and open the runs behind the change. A summary and chart sit at the top, and the full evaluation log runs below.

<Prerequisites title="Before you start">
- An eval with runs recorded in the period you want to investigate.
</Prerequisites>

## Select the eval and time range

1. Open the [Evaluations list](/docs/evaluation/guides/explore-playground).
2. Select the eval you want to inspect.

<img src="/images/docs/evaluation/explore-playground/test-an-eval/select-eval.png" alt="The Evaluations list, searched for hallucination, with a prompt to select the eval you want to open" style={{ borderRadius: '5px' }} />

3. Open **Usage**.
4. Select the time window around the change you want to investigate.

   Choose **30 mins**, **6 hrs**, **Today**, **Yesterday**, **7D**, **30D**, **3M**, **6M**, **12M** or **Custom** for your own dates. The range scopes everything below it: narrow it to a spike, or widen it to watch the long trend.

<img src="/images/docs/evaluation/explore-playground/usage-analytics/usage-tab.png" alt="The eval's Usage tab with a time-range selector, summary stats, a volume and completion-rate chart, and searchable evaluation logs below" style={{ borderRadius: '5px' }} />

The `detect_hallucination` example shows **3M** selected, with **45** runs, **45** successes, **0** errors and a **100%** task completion rate.

## Read the summary and chart

1. Read **Runs**, **Success**, **Errors** and **Task Completion Rate** for the selected range.
2. Compare **Volume**, the number of runs, with **Task Completion Rate** over time on the chart.

   A rate that dips or a volume that drops is your cue to look closer. Narrow the time range to that interval before you open individual runs.

## Find one run

Below the chart, **Evaluation Logs** lists every run the eval scored, one row each: its **Score** and **Result** (passed or failed), the **Input** it saw, the **Reason** for the verdict, the **Source** it ran under, and when it ran.

1. Enter a run ID or a distinctive part of its input, result or reason in **Search**.
2. Open the matching run.
3. Compare its **Input** with the reason to see why it received that **Score** and **Result**.

The result panel below is from a different eval, `is_informal_tone`. The run ID shown starts with `f357ecbe-5ab`. Its **Result** is **Failed** with a **Score** of `0.00`, and the explanation says the output's tone is formal, not casual, pointing to the salutation “To whom it may concern”. The panel also shows the run's **Status**, **Source** and run time.

<img src="/images/docs/evaluation/guides/collect-feedback/playground-add-feedback.png" alt="Selected dataset run beginning f357ecbe-5ab: Status success, Result Failed, score 0.00. The explanation points to the formal salutation." style={{ borderRadius: '5px' }} />

Use **Source** and the run time to tell similar rows apart. In the earlier `detect_hallucination` screenshot, the first two rows start with the same input and both came from **Playground**. One ran at `15 Jul, 23:28` and the other at `17:02`. A source is **Playground**, **Dataset** or **Tracer**, or the name of the project.

If you can't find the run, widen the time range or search by another field.
