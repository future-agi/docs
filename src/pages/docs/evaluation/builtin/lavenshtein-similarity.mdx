---
title: "Levenshtein Similarity"
description: "Calculates edit distance between generated and reference text, scoring similarity by the minimum number of single-character edits required."
---

Levenshtein Similarity measures how close two texts are by counting the character-level edits needed to turn one into the other. Run it when you need a strict, deterministic comparison rather than a meaning-based one.

## What it does

The metric lowercases both strings and removes ASCII punctuation before counting insertions, deletions, and substitutions. The similarity is 1 minus the edit count divided by the longer normalized length (at least 1).

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `expected` | `string` | Reference content for comparison against the model generated output |
| `output` | `string` | Model generated content to be evaluated for similarity |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher score indicates greater similarity |
| Reason | `string` | A plain-language explanation of the similarity assessment |

### Run it from code

Pass the template name and its inputs to `evaluate()`. In Python, `engine="turing"` selects the hosted template. The Python example prints the score, the reason, and the evaluation ID. Here `pack1234` and `pack1235` differ by one character out of eight, so the score is 0.875.

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "levenshtein_similarity",
    expected="PACK-1234",
    output="pack1235",
    engine="turing",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

## When to use

Run Levenshtein Similarity wherever exact character-level fidelity matters more than semantic equivalence.

- Text outputs from spelling correction or OCR, where character-level accuracy is the point
- Deterministic text matching against a fixed reference string
- Regression checks where a changed letter or digit matters even if the texts seem similar

## What to do when Levenshtein Similarity is low

Look for missing characters, swapped digits, or whitespace differences. Case and ASCII punctuation alone do not lower this score.

For meaning-based comparison rather than exact character matching, consider semantic similarity metrics. For texts with similar meaning but different wording, consider ROUGE, BLEU, or Embedding Similarity instead. Remember that this metric measures character-level similarity, not semantic similarity.
