Synthetic Image Evaluator checks whether an image was created by an AI generation model or captured by a camera. Use the score to flag images for review, not as proof of origin.

## What it does

Synthetic Image Evaluator is an LLM-as-Judge eval. It reads an image and scores how confident it is that the image is AI-generated rather than a real photograph.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `image` | `string` | An image the evaluator can read, such as a PNG data URL |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher values indicate greater confidence that the image is AI-generated |
| Reason | `string` | A plain-language explanation of why the image was classified as AI-generated or not |

### Run it from code

Call `evaluate()` with the template name and the eval's required inputs. It returns the score and the reason.

<Note>

Create a Python environment with `python3.12 -m venv .venv`, activate it with `source .venv/bin/activate`, and install the kit with `python -m pip install agent-learning-kit==0.3.7`. Use your own `tent.png`, or generate a simple product icon with Pillow. Run `python -m pip install Pillow`, save this as `make_icon.py`, and run `python make_icon.py`:

Save the Python example as `score.py` and run `python score.py`. It prints the score, the reason, and the evaluation ID. The `model` argument selects the [evaluator model](/docs/evaluation/concepts/evaluator-models), not the tool used to create the image.

<CodeGroup>

```python Python
import base64
from pathlib import Path
from fi.evals import evaluate

encoded = base64.b64encode(Path("tent.png").read_bytes()).decode("ascii")
result = evaluate(
    "synthetic_image_evaluator",
    image=f"data:image/png;base64,{encoded}",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { readFile } from "node:fs/promises";
import { evaluate } from "@future-agi/agent-learning-kit";

  { modelName: "turing_flash" }

console.log(result.eval_results);
```

## When to use

Use Synthetic Image Evaluator to prioritize images for a human provenance check.

- Image pipelines where you want to investigate whether an input image is a real photograph or AI-generated
- Content moderation workflows that treat synthetic and real images differently
- Auditing datasets that mix real and generated images

## What to do when Synthetic Image Evaluator fails

For actual photographs mistakenly identified as synthetic, ensure the image hasn't been heavily processed or filtered, check that it doesn't have unusual artifacts from compression or editing, and consider providing a higher resolution version if available.

For synthetic images that aren't being detected, keep in mind that newer AI generation models are increasingly photorealistic, and images that were post-processed or combined with real photographs can be harder to detect. The evaluation works best with full images rather than small crops or heavily modified versions.
