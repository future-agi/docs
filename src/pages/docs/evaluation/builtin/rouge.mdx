---
title: "ROUGE Score"
description: "Calculates ROUGE-1 token overlap between generated and reference text, commonly used to evaluate summarization quality."
---

ROUGE Score measures how much of a reference text's content is recovered in the generated text. Run it when recall against a reference matters as much as, or more than, precision.

## What it does

ROUGE Score is a statistical metric. It reads the hypothesis and the reference text, then counts shared lowercase, whitespace-separated tokens and reports their F1 score, the harmonic mean of precision and recall.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `reference` | `string` | The reference containing the information to be captured |
| `hypothesis` | `string` | The content to be evaluated for recall against the reference |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher values indicate better token overlap, balancing precision and recall |
| Reason | `string` | A plain-language explanation of the recall evaluation |

### Run it from code

Call `evaluate()` with the template name and the eval's required inputs. It returns the score and the reason.

<Note>
Set `FI_API_KEY` and `FI_SECRET_KEY` for your Future AGI account. In a Python 3.12 virtual environment named `.venv`, run `source .venv/bin/activate` and `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `score.py` and run `python score.py`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "rouge_score",
    reference="lightweight waterproof hiking jacket",
    hypothesis="lightweight breathable hiking jacket",
    engine="turing",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { evaluate } from "@future-agi/agent-learning-kit";

const result = await evaluate(
  "rouge_score",
  {
    reference: "lightweight waterproof hiking jacket",
    hypothesis: "lightweight breathable hiking jacket",
  }
);

console.log(result.eval_results);
```

</CodeGroup>

The two four-word descriptions share three words. Precision and recall are both 0.75, so the ROUGE-1 F1 score is 0.75.

## When to use

Use ROUGE-1 when a reference and a candidate should use similar words. It does not check their order or meaning.

- Summarization tasks, to check whether the model covered the important parts of the source
- Translation quality checks where recall of reference content is the priority

## What to do when ROUGE Score is low

Inspect which reference words are missing and which extra words lower precision. A paraphrase can score poorly even if it is accurate. If matching meaning matters more than matching words, pair ROUGE-1 with a semantic evaluation.
