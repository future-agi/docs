Customer Agent Conversation Quality rates the overall experience of a support interaction rather than any single response. Run it to get a holistic read on how a conversation felt to the customer.

## What it does

Customer Agent Conversation Quality is an LLM-as-Judge eval. It reads the full conversation and scores its overall quality across issue resolution, professional tone, and conversational efficiency.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `conversation` | `string` | The full conversation history between the customer and agent |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `1 / 2 / 3 / 4 / 5` | 1 is very poor and 5 is excellent overall conversation quality |
| Reason | `string` | A plain-language explanation of the conversation quality assessment |

### Run it from code

Set `FI_API_KEY` and `FI_SECRET_KEY` to [your Future AGI credentials](/docs/evaluation/reference/sdk-api). Both examples print the rating, the reason and the evaluation ID. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

- **Python:** Create a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. Save the example as `conversation_quality.py` and run `python conversation_quality.py`.
- **TypeScript:** This example calls the REST API directly from Node.js 22.18 or later. Save it as `conversation_quality.mts` and run `node conversation_quality.mts`.

<CodeGroup>

```python Python
from fi.evals import Evaluator

batch = Evaluator().evaluate(
    eval_templates="customer_agent_conversation_quality",
    inputs={
        "conversation": "Customer: I bought the wrong size hiking boots. Can I exchange them?\nAgent: Yes. If they're unworn, bring them to a Ridgeline Outfitters store within 30 days with your receipt. We can fit you for the next size there.\nCustomer: Great, they're still in the box. Thanks!",
    },
    model_name="turing_flash",
)
result = batch.eval_results[0]
if result.output is None:
    raise RuntimeError(result.reason or "No evaluation result returned")
print(result.output["choice"])
print(result.reason)
print(result.eval_id)
```

```typescript TypeScript
const { FI_API_KEY, FI_SECRET_KEY, FI_BASE_URL = "https://api.futureagi.com" } = process.env;
if (!FI_API_KEY || !FI_SECRET_KEY) throw new Error("Set both Future AGI credentials");

const response = await fetch(new URL("/sdk/api/v1/new-eval/", FI_BASE_URL), {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": FI_API_KEY,
    "X-Secret-Key": FI_SECRET_KEY,
  },
  body: JSON.stringify({
    eval_name: "customer_agent_conversation_quality",
    model: "turing_flash",
    inputs: {
      conversation: "Customer: I bought the wrong size hiking boots. Can I exchange them?\nAgent: Yes. If they're unworn, bring them to a Ridgeline Outfitters store within 30 days with your receipt. We can fit you for the next size there.\nCustomer: Great, they're still in the box. Thanks!",
    },
  }),
});
if (!response.ok) throw new Error(`Evaluation request failed: HTTP ${response.status}`);
const body = await response.json();
const result = body.result?.[0]?.evaluations?.[0];
if (result?.output == null) throw new Error("No evaluation result returned");
console.log(result.output.choice);
console.log(result.reason);
console.log(result.eval_id);
```

## When to use

Run Customer Agent Conversation Quality as a top-line score for customer-facing agent conversations.

- Dashboards and QA sampling, to track overall conversation quality across a support queue
- Comparing agent versions or prompt changes on the full interaction, not just one response
- Flagging low-scoring conversations for deeper review with the more specific customer agent evals

## What to do when Customer Agent Conversation Quality fails

Review the full conversation for unresolved requests, dismissive wording, or avoidable back-and-forth, and identify the specific turns where the agent failed to meet user expectations. Improve response templates for the common customer scenarios that keep scoring low.

Combine this eval with the other customer agent evals, like Query Handling or Context Retention, to pinpoint the specific weakness behind a low score.
