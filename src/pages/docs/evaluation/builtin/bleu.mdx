---
title: "BLEU Score"
description: "Computes n-gram overlap precision between generated output and a reference text, commonly used for translation and summarization quality."
---

BLEU Score measures how many contiguous word sequences (n-grams) in the generated text also appear in the reference text. Run it when you need a fast, established lexical-overlap metric for translation or summarization output.

## What it does

BLEU Score is a statistical metric. It reads the hypothesis and the reference text, then computes a modified n-gram precision, combined across n-gram levels and adjusted by a brevity penalty for outputs shorter than the reference.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `reference` | `string` | The reference (gold) text to compare the output against |
| `hypothesis` | `string` | The model-generated output to be evaluated |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher score indicates greater lexical overlap |
| Reason | `string` | A plain-language explanation of the BLEU score |

### Run it from code

Use `engine="turing"` in Python to run the hosted BLEU-4 template. The inputs are text strings; the evaluator splits them on whitespace.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create a virtual environment with `python3.12 -m venv .venv`, activate it with `source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. The TypeScript tab shows the corresponding SDK call, but the 0.4.0 npm release cannot run it; use the Python example instead.
</Note>

Save the Python example as `score.py` and run `python score.py`. It prints the score, the reason, and the evaluation ID.

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "bleu_score",
    engine="turing",
    reference="Your hiking boots can be returned within thirty days.",
    hypothesis="Your hiking boots can be returned within thirty days with a receipt.",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
console.log(result);
```

## When to use

Run BLEU Score wherever you need a fast, reproducible lexical-overlap check against a fixed reference text.

- Machine translation output, comparing a translated hypothesis against a reference translation
- Summarization quality checks where word choice is expected to closely track the source
- Regression testing on text generation, to catch large lexical drift between runs

## What to do when BLEU Score is low

A correct paraphrase can score poorly if its word sequences differ from the reference. Shorter hypotheses also incur a brevity penalty. The hosted template uses fixed, equally weighted 1- to 4-gram precisions with add-one smoothing for orders present in the hypothesis. A hypothesis shorter than four words has no 4-grams, so even an exact short match can receive a low score.

Read the candidate and reference together. If you care more about preserving meaning than matching wording, pair BLEU with a semantic evaluation rather than treating lexical drift as an error on its own.
