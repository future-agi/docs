title: "Contains Valid Link"
description: "Evaluates whether output text contains at least one valid hyperlink formatted to standard URL conventions."

Contains Valid Link checks whether a response includes at least one properly formatted URL. Run it wherever a response is expected to point users to a link.

## What it does

Contains Valid Link is a deterministic, rule-based eval. The hosted template scans for a valid HTTP or HTTPS link. It checks the URL format, not whether the page exists or is the right destination; it does not make a network request to the link. If the text contains more than 20 HTTP or HTTPS link candidates, the check fails rather than scanning a subset.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `text` | `string` | The content to be assessed for valid hyperlinks |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Pass means the text contains a valid HTTP or HTTPS link within the 20-link limit |
| Reason | `string` | A plain-language explanation of the link validation assessment |

### Run it from code

Use the hosted template for a format-only check. This example passes because the URL is well formed.

<Note>
Set [your Future AGI credentials](/docs/evaluation/reference/sdk-api) (`FI_API_KEY` and `FI_SECRET_KEY`). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then install the Agent Learning Kit with `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `contains_valid_link.py` and run `python contains_valid_link.py`.

For TypeScript, use Node.js 22.18 or later. Run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `contains_valid_link.mts`, and run `node contains_valid_link.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "contains_valid_link",
    engine="turing",
    text="See the Ridgeline returns guide at https://example.com/returns",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(f"Score: {result.score}")
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { Evaluator } from "@future-agi/agent-learning-kit";

const run = await new Evaluator().submit(
  "contains_valid_link",
  {
    text: "See the Ridgeline returns guide at https://example.com/returns"
  }
);

const { result } = await run.wait();
if (result?.output == null) throw new Error("No result returned");
console.log(result.output);
console.log(run.id);
```

## When to use

Run Contains Valid Link wherever a response is supposed to direct the user to a resource.

- Text outputs like support replies or help-center answers that should reference a documentation link
- Content generation tasks where a citation or source link is a required element
- Regression checks after a prompt change, to confirm the model still includes expected links

## What to do when Contains Valid Link fails

If the evaluation fails, review the output text to identify the absence of valid links. Consider revising the content to include appropriate hyperlinks that meet the required standards. Providing clearer instructions or constraints in the input can help prevent this issue in future evaluations.
