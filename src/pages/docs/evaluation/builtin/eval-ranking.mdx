---
title: "Eval Ranking"
description: "Scores an ordered set of retrieved passages against a query and explains which passages help answer it."
---

Eval Ranking helps you inspect an existing retrieval order. It returns one overall score and an explanation, not a reordered list.

## What it does

Eval Ranking is an LLM-as-Ranker eval. It reads the input query and a list of candidate contexts, then considers the relevance and new information each passage adds in that order.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `input` | `string` | The input provided to the model |
| `context` | `string` | JSON-encoded list of candidate passages in retrieval order |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Overall relevance and coverage of the passages, from 0 to 1 |
| Reason | `string` | A plain-language explanation of the ranking assessment |

### Run it from code

Python runs the evaluation and prints its score, reason, and execution ID. TypeScript submits the same evaluation asynchronously and prints its execution ID. To retrieve the result later, call `await evaluator.getEvalResult(run.id)` and check `result.eval_status` for `completed`. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`. Run `python -m pip install agent-learning-kit==0.3.7`, save the example as `score.py`, and run `python score.py`.

For TypeScript, use Node.js 22.18 or later, run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `score.mts`, and run `node score.mts`.
</Note>

<CodeGroup>

```python Python
import json
from fi.evals import evaluate

result = evaluate(
    "eval_ranking",
    input="When can I return unworn boots?",
    context=json.dumps(["Unworn boots can be returned within 30 days of delivery.", "Ridgeline backpacks come with a rain cover."]),
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { Evaluator } from "@future-agi/agent-learning-kit";

const evaluator = new Evaluator();
const run = await evaluator.submit(
  "eval_ranking",
  {
    input: "When can I return unworn boots?",
    context: JSON.stringify(["Unworn boots can be returned within 30 days of delivery.", "Ridgeline backpacks come with a rain cover."]),
  },
  { modelName: "turing_flash" }
);
console.log(run.id);
```

## When to use

Run Eval Ranking wherever you have multiple candidate contexts and need to know which ones are the best match, not just a pass/fail relevance check.

- RAG and retrieval pipelines, to review whether high-ranked chunks address the query before generation
- Custom retrieval evaluation, where ranking criteria are specific to your domain

## What to do when Eval Ranking fails

If the evaluation returns a low ranking score, review the ranking criteria to ensure they're well-defined, relevant, and aligned with the evaluation's objectives, adjusting them for clarity and comprehensiveness where needed.

Analyze the contexts themselves for relevance and suitability, identifying any gaps or inadequacies and refining them to better support the input.
