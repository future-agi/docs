title: "Context Relevance"
description: "Evaluates whether the provided context is sufficient and relevant to answer the query, surfacing weak RAG retrieval."
---

Context Relevance checks whether the context retrieved for a query is actually relevant and sufficient to answer it. Run it to catch weak or off-target retrieval before it produces a bad response.

## What it does

Context Relevance is an LLM-as-Judge eval. It reads the input query and the retrieved context, then scores how relevant and sufficient that context is for answering the query.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `context` | `string` | The context provided to the model |
| `input` | `string` | The input provided to the model |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher scores indicate more relevant context |
| Reason | `string` | A plain-language explanation of the context relevance assessment |

### Run it from code

Score the retrieved passage against the question before generating an answer. Here the passage supplies the deadline the customer needs. Both examples use the hosted [`turing_flash` judge](/docs/evaluation/concepts/evaluator-models).

<Note>
Set [your Future AGI credentials](/docs/evaluation/reference/sdk-api) (`FI_API_KEY` and `FI_SECRET_KEY`). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then install the Agent Learning Kit with `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `context_relevance.py` and run `python context_relevance.py`.

The TypeScript example calls the same evaluation endpoint with Node.js 22.18 or later; no npm package is required. Save it as `context_relevance.mts` and run `node context_relevance.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "context_relevance",
    context="Ridgeline accepts unworn boots for return within 30 days of delivery.",
    input="How long do I have to return unworn boots to Ridgeline?",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(f"Score: {result.score}")
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
const inputs = {
  context: "Ridgeline accepts unworn boots for return within 30 days of delivery.",
  input: "How long do I have to return unworn boots to Ridgeline?",
};
const base = process.env.FI_BASE_URL || "https://api.futureagi.com";
const response = await fetch(`${base}/sdk/api/v1/new-eval/`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": process.env.FI_API_KEY!,
    "X-Secret-Key": process.env.FI_SECRET_KEY!,
  },
  body: JSON.stringify({ eval_name: "context_relevance", inputs, model: "turing_flash" }),
});
if (!response.ok) throw new Error(`Evaluation request failed: ${response.status}`);
const { result } = await response.json();
const row = result[0].evaluations[0];
if (row.output == null) throw new Error("No result returned");
console.log(row.output, row.reason);
console.log(row.eval_id);
```

</CodeGroup>

## When to use

Run Context Relevance wherever a query drives context retrieval and you need to confirm the retrieved material actually supports an answer.

- Support questions where you retrieve a policy before generating an answer
- RAG and retrieval pipelines, to check whether retrieval surfaces chunks that support the query

## What to do when Context Relevance fails

When context relevance is low, the first step is to identify which parts of the context are either irrelevant or insufficient to address the query effectively.

If critical information is missing, additional details should be incorporated to ensure completeness. At the same time, any irrelevant content should be removed or refined to improve focus and alignment with the query.

Implementing mechanisms to enhance context-query alignment can further strengthen relevance, ensuring that only pertinent information is considered. Additionally, optimising context retrieval processes can help prioritise relevant details, improving overall response accuracy and coherence.
