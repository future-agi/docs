---
title: "Detect Hallucination"
description: "Identifies fabricated facts or details a model added that aren't present in the input or provided context."
---

Detect Hallucination checks whether a response contains facts the model made up, information that isn't backed by the input or context it was given. Run it as a direct hallucination check on generated content.

## What it does

Detect Hallucination is an LLM-as-Judge eval. It reads the original input, the context, and the generated output, then returns a pass/fail on whether fabricated content is present.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `output` | `string` | Output generated by the model |
| `context` | `string` | The context provided to the model |
| `input` | `string` | Input provided to the model |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Passed means no hallucination is detected, Failed means hallucination is detected |
| Reason | `string` | A plain-language explanation of the evaluation |

### Run it from code

Python runs the evaluation and prints its score, reason, and execution ID. TypeScript submits the same evaluation asynchronously and prints its execution ID. To retrieve the result later, call `await evaluator.getEvalResult(run.id)` and check `result.eval_status` for `completed`. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`. Run `python -m pip install agent-learning-kit==0.3.7`, save the example as `score.py`, and run `python score.py`.

For TypeScript, use Node.js 22.18 or later, run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `score.mts`, and run `node score.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "detect_hallucination",
    input="When can I return my unworn boots?",
    context="Ridgeline Outfitters accepts returns of unworn boots within 30 days of delivery.",
    output="You can return unworn boots within 30 days of delivery.",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { Evaluator } from "@future-agi/agent-learning-kit";

const evaluator = new Evaluator();
const run = await evaluator.submit(
  "detect_hallucination",
  {
    input: "When can I return my unworn boots?",
    context: "Ridgeline Outfitters accepts returns of unworn boots within 30 days of delivery.",
    output: "You can return unworn boots within 30 days of delivery.",
  },
  { modelName: "turing_flash" }
);
console.log(run.id);
```

## When to use

Run Detect Hallucination wherever fabricated facts would be costly, and you want a direct signal on made-up content rather than a broader adherence score.

- Responses generated from a fixed input or context
- RAG and retrieval pipelines, to catch fabricated details that slipped past retrieval-grounded generation
- Hallucination checks, as a targeted complement to Context Adherence and Groundedness

## What to do when Detect Hallucination fails

If the content is evaluated as containing hallucinations (Failed) and you want to improve it:

- Ensure all claims in your output are explicitly supported by the source material
- Avoid extrapolating or generalizing beyond what is stated in the input
- Remove any specific details that aren't mentioned in the source text
- Use qualifying language (like "may," "could," or "suggests") when necessary
- Stick to paraphrasing rather than adding new information
- Double-check numerical values, dates, and proper nouns against the source
- Consider directly quoting from the source for critical information
