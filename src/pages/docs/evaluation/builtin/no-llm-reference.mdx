---
title: "No LLM Reference"
description: "Detects references to LLM providers or model names in AI responses, flagging mentions like OpenAI, Anthropic, or GPT-4."
---

No LLM Reference checks whether a response accidentally reveals it was generated by an LLM, whether by naming a provider or self-identifying as an AI. Run it to keep AI-generated content free of provider mentions.

## What it does

No LLM Reference is an LLM-as-Judge eval. It reads the generated output and checks it for mentions of LLM providers, products, or AI self-identification.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `output` | `string` | Content to evaluate for LLM reference |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Pass means no LLM reference was detected in the model's output; Fail means one was detected |
| Reason | `string` | A plain-language explanation of why the content was classified as containing or not containing LLM reference |

### Run it from code

The Python example uses Agent Learning Kit; the TypeScript example calls the same hosted template over HTTP. Both use `turing_flash` as the [evaluator model](/docs/evaluation/concepts/evaluator-models). Each prints the result, the reason, and the evaluation ID.

<Note>
Set `FI_API_KEY` and `FI_SECRET_KEY` for your [Future AGI account](/docs/evaluation/reference/sdk-api). For Python, run `python3.12 -m venv .venv`, `source .venv/bin/activate`, and `python -m pip install agent-learning-kit==0.3.7`. Save the example as `score.py` and run `python score.py`. For TypeScript, save the HTTP example as `score.mts` and run `node score.mts` with Node.js 22.18 or newer.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "no_llm_reference",
    model="turing_flash",
    output="As an AI language model, I can explain the Ridgeline return policy.",
)
if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")

print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript (HTTP)
const { FI_BASE_URL = "https://api.futureagi.com", FI_API_KEY, FI_SECRET_KEY } = process.env;
if (!FI_API_KEY || !FI_SECRET_KEY) throw new Error("Set your Future AGI credentials");

const response = await fetch(new URL("/sdk/api/v1/new-eval/", FI_BASE_URL), {
  method: "POST",
  headers: { "Content-Type": "application/json", "X-Api-Key": FI_API_KEY, "X-Secret-Key": FI_SECRET_KEY },
  body: JSON.stringify({
    eval_name: "no_llm_reference",
    model: "turing_flash",
    inputs: {
      output: "As an AI language model, I can explain the Ridgeline return policy.",
    },
  }),
});
if (!response.ok) throw new Error(`Evaluation request failed: HTTP ${response.status}`);
const row = (await response.json()).result?.[0]?.evaluations?.[0];
if (row?.output == null || !row.eval_id) throw new Error("No evaluation result returned");
console.log(row.output);
console.log(row.reason);
console.log(row.eval_id);
```

</CodeGroup>

## When to use

Use No LLM Reference to flag irrelevant self-identification in generated replies, not to suppress required disclosures.

- Text and chat outputs shipped under a brand voice, not an AI persona
- Brand voice reviews where irrelevant self-identification distracts from an answer
- Customer-facing copy, to catch phrases like "As an AI language model..."

## What to do when No LLM Reference fails

This evaluation detects both explicit mentions ("OpenAI", "ChatGPT", "Claude", "Llama") and implicit self-identification ("As an AI language model..."). It covers references to all major LLM providers (OpenAI, Anthropic, Meta, Mistral, DeepSeek, and others), their products, and model names or versions.

A relevant third-person discussion of models, such as a requested comparison, is not the same as an unsolicited self-reference. For comprehensive brand compliance, combine this with other brand-specific evaluations.
