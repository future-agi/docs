---
title: "Contains Code"
description: "Judges whether the output contains recognizable, syntactically valid code rather than prose or pseudocode."
---

Contains Code checks whether a response contains valid code, catching cases where a model was expected to produce code but returned prose instead. Run it wherever code generation is part of the task.

## What it does

Contains Code is an LLM-as-Judge eval. It reads the generated output and judges its structure and syntax. It does not compile or execute the snippet, or verify that it solves the task.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `output` | `string` | The model output to be checked for valid code content |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Pass means the output contains valid code; Fail means it does not |
| Reason | `string` | A plain-language explanation of the code detection assessment |

### Run it from code

Python runs the evaluation and prints its score, reason, and execution ID. TypeScript submits the same evaluation asynchronously and prints its execution ID. To retrieve the result later, call `await evaluator.getEvalResult(run.id)` and check `result.eval_status` for `completed`. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`. Run `python -m pip install agent-learning-kit==0.3.7`, save the example as `score.py`, and run `python score.py`.

For TypeScript, use Node.js 22.18 or later, run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `score.mts`, and run `node score.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "contains_code",
    output="def within_return_window(days_since_delivery):\n    return 0 <= days_since_delivery <= 30",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { Evaluator } from "@future-agi/agent-learning-kit";

const evaluator = new Evaluator();
const run = await evaluator.submit(
  "contains_code",
  {
    output: "def within_return_window(days_since_delivery):\n    return 0 <= days_since_delivery <= 30",
  },
  { modelName: "turing_flash" }
);
console.log(run.id);
```

## When to use

Run Contains Code wherever a task expects a code snippet rather than a natural-language answer.

- Text outputs from code generation or coding-assistant tasks
- Pipelines that parse or execute the model's output downstream, where prose instead of code would break things
- Quality gates for coding agents, before handing output to a compiler or interpreter

## What to do when Contains Code fails

Ensure the code is properly formatted with appropriate indentation and syntax for its language. This evaluation can identify code across common programming languages like Python, JavaScript, and Java.

Mixed content (code with extensive natural language explanations) might yield uncertain results, and code snippets with syntax errors might still be identified as code, since the evaluation focuses on structural patterns rather than correctness.
