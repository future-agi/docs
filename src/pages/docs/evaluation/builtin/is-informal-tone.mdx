title: "Is Informal Tone"
description: "Detects informal or casual language in AI output, including slang, contractions, and emoji."
---

Is Informal Tone flags casual language markers like slang, contractions, and emoji. Run it wherever a response needs to stay formal, or wherever it needs to sound conversational.

## What it does

Is Informal Tone is an LLM-as-Judge eval. It assesses the dominant tone of the output. One contraction in an otherwise formal reply is not enough on its own.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `output` | `string` | The text content to evaluate for informal tone |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Pass means the dominant tone is informal; Fail means there are no clear informal markers (the text may be neutral or formal) |
| Reason | `string` | A plain-language explanation of why the text was classified as formal or informal |

### Run it from code

Pass the template name and its inputs to `evaluate()`. In Python, `model="turing_flash"` selects the hosted judge. The Python example prints the score, the reason, and the evaluation ID.

<Note>
Set `FI_API_KEY` and `FI_SECRET_KEY` for your Future AGI account. In a fresh Python 3.12 virtual environment named `.venv`, run `source .venv/bin/activate`, then `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `score.py` and run `python score.py`. Use Python with the current release: the TypeScript package is not runnable in version 0.4.0.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "is_informal_tone",
    output="Hey, your pack's on its way! Wanna track it? Just hit the link in your shipping email.",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

## When to use

Run Is Informal Tone wherever the formality of the response needs to match a specific brand voice.

- Text and chat outputs where brand voice mandates a formal or casual register
- Customer support responses, to confirm tone matches the audience
- Compliance-sensitive content, where informal language could look unprofessional

## What to do when Is Informal Tone fails

If the content is detected as having an informal tone but formality is required, replace contractions with full forms (for example, "don't" to "do not"), remove slang, colloquialisms, and emoji, and use more professional terminology and phrasing. Maintain a consistent, professional tone throughout and avoid first-person perspective where appropriate.

If the content is detected as formal but informality is desired, incorporate appropriate contractions, use more conversational language, include relatable examples or analogies, and consider a first-person perspective when appropriate.
