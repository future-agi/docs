title: "Customer Agent: Prompt Conformance"
description: "Measures how well the agent adheres to system prompt constraints, including persona, language, and conversation guidelines."

Customer Agent Prompt Conformance checks whether an agent stays within the rules set by its system prompt: persona, tone, language, and topics it should avoid. Run it to catch agents that drift from their configured behavior.

## What it does

Customer Agent Prompt Conformance is an LLM-as-Judge eval. It reads the system prompt and the conversation, then scores how well the agent's responses adhere to the system prompt.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `system_prompt` | `string` | The system prompt defining the agent's persona, constraints, and behavior guidelines |
| `conversation` | `string` | The full conversation history between the customer and agent |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `0.0` to `1.0` | Higher values indicate stronger adherence to the system prompt |
| Reason | `string` | A plain-language explanation of the prompt conformance assessment |

### Run it from code

Set `FI_API_KEY` and `FI_SECRET_KEY` to [your Future AGI credentials](/docs/evaluation/reference/sdk-api). Both examples print the score, the reason and the evaluation ID. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

- **Python:** Create a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. Save the example as `prompt_conformance.py` and run `python prompt_conformance.py`.
- **TypeScript:** This example calls the REST API directly from Node.js 22.18 or later. Save it as `prompt_conformance.mts` and run `node prompt_conformance.mts`.

<CodeGroup>

```python Python
from fi.evals import Evaluator

batch = Evaluator().evaluate(
    eval_templates="customer_agent_prompt_conformance",
    inputs={
        "system_prompt": "You are a Ridgeline Outfitters support agent. Use English, keep your tone professional and do not compare competitors' products.",
        "conversation": "Customer: Is your trail pack better than Summit's?\nAgent: I can describe the Ridgeline pack rather than compare brands. It holds 30 liters and includes a rain cover. What are you looking for on your hike?",
    },
    model_name="turing_flash",
)
result = batch.eval_results[0]
if result.output is None:
    raise RuntimeError(result.reason or "No evaluation result returned")
print(result.output)
print(result.reason)
print(result.eval_id)
```

```typescript TypeScript
const { FI_API_KEY, FI_SECRET_KEY, FI_BASE_URL = "https://api.futureagi.com" } = process.env;
if (!FI_API_KEY || !FI_SECRET_KEY) throw new Error("Set both Future AGI credentials");

const response = await fetch(new URL("/sdk/api/v1/new-eval/", FI_BASE_URL), {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": FI_API_KEY,
    "X-Secret-Key": FI_SECRET_KEY,
  },
  body: JSON.stringify({
    eval_name: "customer_agent_prompt_conformance",
    model: "turing_flash",
    inputs: {
      system_prompt: "You are a Ridgeline Outfitters support agent. Use English, keep your tone professional and do not compare competitors' products.",
      conversation: "Customer: Is your trail pack better than Summit's?\nAgent: I can describe the Ridgeline pack rather than compare brands. It holds 30 liters and includes a rain cover. What are you looking for on your hike?",
    },
  }),
});
if (!response.ok) throw new Error(`Evaluation request failed: HTTP ${response.status}`);
const body = await response.json();
const result = body.result?.[0]?.evaluations?.[0];
if (result?.output == null) throw new Error("No evaluation result returned");
console.log(result.output);
console.log(result.reason);
console.log(result.eval_id);
```

## When to use

Run Customer Agent Prompt Conformance wherever an agent operates under a defined persona or system-level constraints.

- Branded agents with a defined persona, tone, or set of topics to avoid
- Checking whether an agent holds its guardrails under adversarial or off-topic questioning
- Regression testing after a system prompt change, to confirm behavior still matches the new rules

## What to do when Customer Agent Prompt Conformance fails

Review cases where the agent broke persona or violated a stated constraint, and strengthen the system prompt with explicit rules and examples covering those cases. Add guardrails for topics the agent should never discuss.

Test with adversarial prompts that try to break the agent out of its persona, so gaps surface before real users find them.
