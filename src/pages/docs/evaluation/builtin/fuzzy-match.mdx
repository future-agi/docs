---
title: "Fuzzy Match"
description: "Compares output against an expected answer using approximate text matching that tolerates minor wording, spelling, or formatting differences."
---

Fuzzy Match checks whether a response is close enough to an expected answer, even when the wording, spelling, or formatting differs slightly. Run it when you need approximate matching instead of an exact string comparison.

## What it does

Fuzzy Match is a deterministic text comparison. It trims the strings, lowercases them by default, and uses Python’s `difflib.SequenceMatcher` to score matching character sequences. A score of 1 means the normalized strings match.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `expected` | `string` | The expected content for comparison against the model generated output |
| `output` | `string` | The output generated by the model to be evaluated for fuzzy match |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher values indicate better fuzzy match |
| Reason | `string` | A plain-language explanation of the fuzzy match assessment |

### Run it from code

Python runs the evaluation and prints its score, reason, and execution ID. TypeScript submits the same evaluation asynchronously and prints its execution ID. To retrieve the result later, call `await evaluator.getEvalResult(run.id)` and check `result.eval_status` for `completed`.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`. Run `python -m pip install agent-learning-kit==0.3.7`, save the example as `score.py`, and run `python score.py`.

For TypeScript, use Node.js 22.18 or later, run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `score.mts`, and run `node score.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "fuzzy_match",
    expected="Ridgeline Trail Pack",
    output="Ridgeline Trail Pak",
    engine="turing",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { Evaluator } from "@future-agi/agent-learning-kit";

const evaluator = new Evaluator();
const run = await evaluator.submit(
  "fuzzy_match",
  {
    expected: "Ridgeline Trail Pack",
    output: "Ridgeline Trail Pak",
  }
);
console.log(run.id);
```

## When to use

Run Fuzzy Match wherever an exact string comparison would be too strict for the kind of answer you expect.

- Names, product labels, and short strings with small spelling differences
- Answers pulled from different sources that may vary in spelling or formatting
- Quick approximate checks before reaching for a stricter or semantic metric

## What to do when Fuzzy Match fails

Ensure both input texts are properly formatted and contain meaningful content. A paraphrase can score poorly if it uses different characters. Use Embedding Similarity when meaning, rather than spelling, is what matters.

For very short texts (one or two words), results may be less reliable. If you need more precise matching, consider using Levenshtein Similarity instead.
