Groundedness checks whether a response is strictly based on the provided context, with no outside information introduced. Run it wherever an answer must be traceable back to a source.

## What it does

Groundedness is an LLM-as-Judge eval. It reads the original input, the context, and the generated output, then returns a pass/fail on whether the response is fully supported by that context.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `output` | `string` | The output generated by the model |
| `context` | `string` | The context provided to the model |
| `input` | `string` | The input provided to the model |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Passed means the response is fully grounded in the provided context, Failed means the response introduces unsupported information |
| Reason | `string` | A plain-language explanation of the groundedness assessment |

### Run it from code

Python runs the evaluation and prints its score, reason, and execution ID. TypeScript submits the same evaluation asynchronously and prints its execution ID. To retrieve the result later, call `await evaluator.getEvalResult(run.id)` and check `result.eval_status` for `completed`. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`. Run `python -m pip install agent-learning-kit==0.3.7`, save the example as `score.py`, and run `python score.py`.

For TypeScript, use Node.js 22.18 or later, run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `score.mts`, and run `node score.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "groundedness",
    input="What is the return window for unworn boots?",
    context="Ridgeline Outfitters accepts unworn boots within 30 days of delivery.",
    output="Unworn boots can be returned within 30 days of delivery.",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { Evaluator } from "@future-agi/agent-learning-kit";

const evaluator = new Evaluator();
const run = await evaluator.submit(
  "groundedness",
  {
    input: "What is the return window for unworn boots?",
    context: "Ridgeline Outfitters accepts unworn boots within 30 days of delivery.",
    output: "Unworn boots can be returned within 30 days of delivery.",
  },
  { modelName: "turing_flash" }
);
console.log(run.id);
```

## When to use

Run Groundedness wherever an answer needs to be traceable to a source document and any unsupported addition is a problem.

- Text, audio, and chat outputs generated from a fixed context
- RAG and retrieval pipelines, to confirm answers don't extend past the retrieved material
- Hallucination checks, alongside Context Adherence and Detect Hallucination, for a stricter Pass/Fail read on grounding

## What to do when Groundedness fails

Reassess the provided context for completeness and clarity, ensuring it includes all necessary information to support the response.

Examine the response for any elements not supported by the context, and adjust it to improve alignment with the given information.
