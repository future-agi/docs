title: "Cultural Sensitivity"
description: "Analyzes output for cultural appropriateness and inclusive language, flagging biases or insensitive content."
---

Cultural Sensitivity checks whether generated content respects cultural nuances and avoids insensitive framing. Run it wherever output reaches a culturally diverse audience.

## What it does

Cultural Sensitivity is an LLM-as-Judge eval. It reads the output and scores whether it's culturally appropriate.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `output` | `string` | The content to analyse for cultural appropriateness |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Fail means the content shows potential cultural insensitivity |
| Reason | `string` | A plain-language explanation of the cultural sensitivity assessment |

### Run it from code

Evaluate the text your customers will actually see. Here the invitation asks about individual needs instead of assuming shared customs. Both examples use the hosted [`turing_flash` judge](/docs/evaluation/concepts/evaluator-models).

<Note>
Set [your Future AGI credentials](/docs/evaluation/reference/sdk-api) (`FI_API_KEY` and `FI_SECRET_KEY`). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then install the Agent Learning Kit with `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `cultural_sensitivity.py` and run `python cultural_sensitivity.py`.

For TypeScript, use Node.js 22.18 or later. Run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `cultural_sensitivity.mts`, and run `node cultural_sensitivity.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "cultural_sensitivity",
    output="The Ridgeline winter walk is open to everyone. The sign-up form lets you tell us about dietary preferences or dates you cannot attend.",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(f"Score: {result.score}")
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { Evaluator } from "@future-agi/agent-learning-kit";

const run = await new Evaluator().submit(
  "cultural_sensitivity",
  {
    output: "The Ridgeline winter walk is open to everyone. The sign-up form lets you tell us about dietary preferences or dates you cannot attend.",
  },
  { modelName: "turing_flash" }
);

const { result } = await run.wait();
if (result?.output == null) throw new Error("No result returned");
console.log(result.output);
console.log(run.id);
```

</CodeGroup>

## When to use

Run Cultural Sensitivity wherever content reaches an audience spanning multiple cultures or regions.

- Support messages, event notices, and chat replies written for people in different regions
- Localization and marketing content, to catch assumptions that don't translate across cultures
- Safety checks on any surface where inclusive, culturally aware language is a requirement

## What to do when Cultural Sensitivity fails

Read the judge’s reason alongside the original wording. If an invitation assumes every customer celebrates the same holiday, name the event without treating the holiday as universal. For region-specific copy, ask someone familiar with that context to review the revised message.
