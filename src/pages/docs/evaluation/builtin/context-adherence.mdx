---
title: "Context Adherence"
description: "Measures how well a response stays within the provided context, flagging statements not grounded in it to catch hallucination."
---

Context Adherence checks whether a response sticks to the information given in its context, or introduces claims the context doesn't support. Run it to catch hallucination in RAG and grounded-generation pipelines.

## What it does

Context Adherence is an LLM-as-Judge eval. It reads the context and the generated output, then scores how much of the output is actually grounded in that context.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `context` | `string` | The context provided to the model |
| `output` | `string` | The output generated by the model |

### Output

| Field | Type | Description |
| --- | --- | --- |
| `result.score` | `float` (0–1) | Higher scores (closer to 1) indicate stronger adherence to the context |
| `result.reason` | `string` | A plain-language explanation of the score |

### Run it from code

Compare the reply with the return policy. A faithful paraphrase can score well even when the wording differs. Both examples use the hosted [`turing_flash` judge](/docs/evaluation/concepts/evaluator-models).

<Note>
Set [your Future AGI credentials](/docs/evaluation/reference/sdk-api) (`FI_API_KEY` and `FI_SECRET_KEY`). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then install the Agent Learning Kit with `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `context_adherence.py` and run `python context_adherence.py`.

The TypeScript example calls the same evaluation endpoint with Node.js 22.18 or later; no npm package is required. Save it as `context_adherence.mts` and run `node context_adherence.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "context_adherence",
    context="Ridgeline accepts unworn boots for return within 30 days of delivery.",
    output="You can return unworn boots within 30 days of delivery.",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(f"Score: {result.score}")
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
const inputs = {
  context: "Ridgeline accepts unworn boots for return within 30 days of delivery.",
  output: "You can return unworn boots within 30 days of delivery.",
};
const base = process.env.FI_BASE_URL || "https://api.futureagi.com";
const response = await fetch(`${base}/sdk/api/v1/new-eval/`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": process.env.FI_API_KEY!,
    "X-Secret-Key": process.env.FI_SECRET_KEY!,
  },
  body: JSON.stringify({ eval_name: "context_adherence", inputs, model: "turing_flash" }),
});
if (!response.ok) throw new Error(`Evaluation request failed: ${response.status}`);
const { result } = await response.json();
const row = result[0].evaluations[0];
if (row.output == null) throw new Error("No result returned");
console.log(row.output, row.reason);
console.log(row.eval_id);
```

</CodeGroup>

## When to use

Run Context Adherence wherever a response is supposed to be grounded in a specific context and you need to catch claims that aren't.

- Support replies grounded in a product description or policy excerpt
- RAG and retrieval pipelines, to confirm the answer doesn't go beyond the retrieved chunks
- Hallucination checks, where you need to flag statements the context doesn't support

## What to do when Context Adherence fails

When context adherence is low, start by identifying statements that are not supported by the provided context and checking for implicit versus explicit information to assess potential misinterpretations.

Reviewing how the context is processed can help pinpoint inconsistencies. If necessary, expand context coverage to fill in gaps, clarify ambiguous details, and add missing relevant information.

To improve adherence, implement stricter context binding, integrate fact-checking mechanisms, and enhance overall context processing.
