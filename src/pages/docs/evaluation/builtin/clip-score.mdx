CLIP Score measures how well a generated image aligns with the text description it was supposed to depict. Run it to score image-text alignment for individual generations.

## What it does

CLIP Score is a statistical metric. It compares an image against a text description and scores how well the two align, using CLIP embeddings.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `images` | `string` or `list[string]` | Use a PNG data URL for one image, or a URL the evaluator can fetch |
| `text` | `string` or `list[string]` | Text description or list of descriptions to compare against the images |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Score from 0 to 1, where higher values indicate better alignment between the image and text description |
| Reason | `string` | Reports the cosine similarity and the number of pairs compared |

### Run it from code

In Python, select `engine="turing"` to run the hosted template rather than a local metric. The backend embeds the image and description with the same CLIP model, then computes their cosine similarity. Self-hosted deployments need model serving with image-text embeddings enabled.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create a virtual environment with `python3.12 -m venv .venv`, activate it with `source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. The TypeScript tab shows the corresponding SDK call, but the 0.4.0 npm release cannot run it; use the Python example instead.
</Note>

Use your own `tent.png`, or generate a simple product icon with Pillow. Run `python -m pip install Pillow`, save this as `make_icon.py`, and run `python make_icon.py`:

```python
from PIL import Image, ImageDraw

image = Image.new("RGB", (256, 192), "white")
draw = ImageDraw.Draw(image)
draw.polygon([(25, 164), (125, 24), (231, 164)], fill="orange")
draw.polygon([(95, 164), (125, 98), (155, 164)], fill="black")
image.save("tent.png")
```

Save the Python example as `score.py` and run `python score.py`. It prints the score, the reason, and the evaluation ID.

<CodeGroup>

```python Python
import base64
from pathlib import Path

from fi.evals import evaluate

encoded = base64.b64encode(Path("tent.png").read_bytes()).decode("ascii")

result = evaluate(
    "clip_score",
    text="An orange triangular tent icon on a white background.",
    images=f"data:image/png;base64,{encoded}",
    engine="turing",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { readFileSync } from "node:fs";
import { evaluate } from "@future-agi/agent-learning-kit";

const result = await evaluate(
  "clip_score",
  {
    text: "An orange triangular tent icon on a white background.",
    images: `data:image/png;base64,${readFileSync("tent.png").toString("base64")}`
  }
);

console.log(result);
```

## When to use

Run CLIP Score wherever a generated image is meant to depict a specific text prompt and you need a fast alignment check.

- Text-to-image generation pipelines, to score how well output matches the prompt
- Comparing generation models or prompt variants on the same text description
- Filtering or ranking generated images by alignment before human review

## What to do when CLIP Score is low

Make the text description more specific and aligned with the visual content, and check that the image actually depicts what the prompt requested. Avoid overly abstract or ambiguous descriptions.

Ensure the image generation prompt used matches the evaluation text, and consider refining the generation model or prompt engineering.
