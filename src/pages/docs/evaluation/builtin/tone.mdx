title: "Tone"
description: "Analyzes the tone and sentiment of AI content to identify the emotional content of a response."
---

Tone identifies emotions expressed in a response, such as joy, fear, or annoyance. Run it to confirm content matches the communication style your audience expects.

## What it does

Tone is an LLM-as-Judge eval. It reads the generated output and selects the emotion labels supported by the content.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `output` | `string` | Content to evaluate for tone |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `choice` | The selected emotion labels, or neutral for calm, factual content |
| Reason | `string` | A plain-language explanation of the tone evaluation |

### Run it from code

Use `Evaluator.evaluate()` to get the selected labels in `output` rather than a numeric score.

Set `FI_API_KEY` and `FI_SECRET_KEY` for your Future AGI account. In a fresh Python 3.12 virtual environment named `.venv`, run `source .venv/bin/activate`, then `python -m pip install agent-learning-kit==0.3.7`. Save the example as `score.py` and run `python score.py`.

```python
from fi.evals import Evaluator

batch = Evaluator().evaluate(
    eval_templates="tone",
    inputs={"output": "Your replacement tent poles will arrive on Tuesday."},
    model_name="turing_flash",
)
result = batch.eval_results[0]
print(result.output)
print(result.reason)
print(result.eval_id)
```

## When to use

Run Tone wherever the emotional register of a response matters as much as its content.

- Text, audio, and chat outputs where brand voice or emotional register matters
- Safety reviews, to catch responses that read as hostile, dismissive, or overly familiar
- Customer-facing copy, to confirm tone matches the audience and context

## What to do when Tone fails

Adjust the tone of the content to align with the intended emotional context or communication goal, ensuring it's appropriate for the audience and purpose.

Use tone analysis to refine messaging, making it more engaging, professional, or empathetic as needed. Continuously improving tone detection models helps recognize and interpret nuanced emotional expressions, leading to more accurate and context-aware assessments.
