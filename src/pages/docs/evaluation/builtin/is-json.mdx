title: "Is JSON"
description: "Determines whether output text conforms to valid JSON format, catching structural errors that break downstream parsing."

Is JSON checks whether a piece of text is valid JSON, catching structural errors before they break a downstream parser. Run it wherever a model is expected to return structured JSON output.

## What it does

Is JSON is a deterministic, rule-based eval. It parses the entire string with Python's `json.loads`. A pass means the string parsed, not that the payload contains the fields or types your app expects.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `text` | `string` | The provided content to be evaluated for JSON validity |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Pass means the provided content is valid JSON; Fail means it's not |
| Reason | `string` | A plain-language explanation of the evaluation |

### Run it from code

Pass the template name and its inputs to `evaluate()`. In Python, `engine="turing"` selects the hosted template. The Python example prints the score, the reason, and the evaluation ID.

<Note>
Set `FI_API_KEY` and `FI_SECRET_KEY` for your Future AGI account. In a fresh Python 3.12 virtual environment named `.venv`, run `source .venv/bin/activate`, then `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `score.py` and run `python score.py`. Use Python with the current release: the TypeScript package is not runnable in version 0.4.0.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "is_json",
    text='{"item": "trail pack", "in_stock": true}',
    engine="turing",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { evaluate } from "@future-agi/agent-learning-kit";

const result = await evaluate(
  "is_json",
  {
    "text": "{\"item\": \"trail pack\", \"in_stock\": true}"
  }
);

console.log(result.eval_results[0]);
```

</CodeGroup>

## When to use

Run Is JSON wherever downstream code parses the model's output as JSON.

- Text outputs feeding a `json.loads` or `JSON.parse` call in your pipeline
- API responses where the model generates a structured payload
- Regression checks after a prompt change, to confirm formatting instructions still hold

## What to do when Is JSON fails

Identify common structural problems, such as missing commas, misplaced brackets, or incorrect key-value formatting, and correct them. To prevent future errors, implement automated checks within the system to detect and resolve formatting issues before processing.
