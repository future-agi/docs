title: "Customer Agent: Objection Handling"
description: "Monitors the agent's ability to handle customer objections, disinterest, hesitation, or refusals effectively and politely."
---

Customer Agent Objection Handling checks how an agent responds when a customer pushes back, hesitates, or declines an offer. Run it to confirm the agent backs off gracefully instead of pressuring the user.

## What it does

Customer Agent Objection Handling is an LLM-as-Judge eval. It reads the full conversation and scores how well the agent handles objections raised by the customer.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `conversation` | `string` | The full conversation history between the customer and agent |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `never / occasionally / frequently / always` | How consistently the agent acknowledges and respects objections; `always` is best |
| Reason | `string` | A plain-language explanation of the objection handling assessment |

### Run it from code

Set `FI_API_KEY` and `FI_SECRET_KEY` to [your Future AGI credentials](/docs/evaluation/reference/sdk-api). Both examples print the label, the reason and the evaluation ID. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

- **Python:** Create a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. Save the example as `objection_handling.py` and run `python objection_handling.py`.
- **TypeScript:** This example calls the REST API directly from Node.js 22.18 or later. Save it as `objection_handling.mts` and run `node objection_handling.mts`.

<CodeGroup>

```python Python
from fi.evals import Evaluator

batch = Evaluator().evaluate(
    eval_templates="customer_agent_objection_handling",
    inputs={
        "conversation": "Customer: That tent is outside my budget. I don't want to finance it.\nAgent: Understood. Would you like to see tents under your budget, or would you prefer to stop here?\nCustomer: Let's stop here.\nAgent: Of course. Thanks for visiting Ridgeline.",
    },
    model_name="turing_flash",
)
result = batch.eval_results[0]
if result.output is None:
    raise RuntimeError(result.reason or "No evaluation result returned")
print(result.output["choice"])
print(result.reason)
print(result.eval_id)
```

```typescript TypeScript
const { FI_API_KEY, FI_SECRET_KEY, FI_BASE_URL = "https://api.futureagi.com" } = process.env;
if (!FI_API_KEY || !FI_SECRET_KEY) throw new Error("Set both Future AGI credentials");

const response = await fetch(new URL("/sdk/api/v1/new-eval/", FI_BASE_URL), {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": FI_API_KEY,
    "X-Secret-Key": FI_SECRET_KEY,
  },
  body: JSON.stringify({
    eval_name: "customer_agent_objection_handling",
    model: "turing_flash",
    inputs: {
      conversation: "Customer: That tent is outside my budget. I don't want to finance it.\nAgent: Understood. Would you like to see tents under your budget, or would you prefer to stop here?\nCustomer: Let's stop here.\nAgent: Of course. Thanks for visiting Ridgeline.",
    },
  }),
});
if (!response.ok) throw new Error(`Evaluation request failed: HTTP ${response.status}`);
const body = await response.json();
const result = body.result?.[0]?.evaluations?.[0];
if (result?.output == null) throw new Error("No evaluation result returned");
console.log(result.output.choice);
console.log(result.reason);
console.log(result.eval_id);
```

## When to use

Run Customer Agent Objection Handling on agents that make offers, upsells, or requests the customer might decline.

- Sales and upsell flows, to check the agent doesn't push after a clear refusal
- Support conversations where the customer expresses hesitation or frustration
- Reviewing agent scripts for tone when a customer says no

## What to do when Customer Agent Objection Handling fails

Review cases where the agent pushed back after a clear refusal, and train the agent to acknowledge objections empathetically instead of repeating the pitch. Ensure the agent doesn't repeat sales pitches after the user has declined.

Add logic to gracefully close the topic when an objection is firm, so the conversation can move on.
