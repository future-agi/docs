Is Polite checks whether a response maintains a respectful, courteous tone free of rudeness. Run it wherever a response represents your product or brand to a user.

## What it does

Is Polite is an LLM-as-Judge eval. It reads the generated output and checks whether it's respectful and free of impolite language.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `output` | `string` | The response to be evaluated for politeness |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Pass means the response is polite and respectful; Fail means it's not |
| Reason | `string` | A plain-language explanation of the evaluation |

### Run it from code

Pass the template name and its inputs to `evaluate()`. In Python, `model="turing_flash"` selects the hosted judge. The Python example prints the score, the reason, and the evaluation ID.

<Note>
Set `FI_API_KEY` and `FI_SECRET_KEY` for your Future AGI account. In a fresh Python 3.12 virtual environment named `.venv`, run `source .venv/bin/activate`, then `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `score.py` and run `python score.py`. Use Python with the current release: the TypeScript package is not runnable in version 0.4.0.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "is_polite",
    output="Thank you for letting us know about your damaged pack. I'm sorry it arrived that way. May I help you arrange a replacement?",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { evaluate } from "@future-agi/agent-learning-kit";

const result = await evaluate(
  "is_polite",
  {
    "output": "Thank you for letting us know about your damaged pack. I'm sorry it arrived that way. May I help you arrange a replacement?"
  },
  { modelName: "turing_flash" }
);

console.log(result.eval_results[0]);
```

## When to use

Run Is Polite wherever a response needs to stay courteous regardless of what the user says.

- Text and chat outputs delivered directly to end users
- Customer support responses, especially in frustrating or escalated conversations
- Safety reviews, to catch responses that turn curt or dismissive

## What to do when Is Polite fails

Read the reason alongside the reply. If a short answer sounds dismissive, acknowledge the customer’s concern before offering a next step.

Consider cultural context when interpreting results, as politeness norms vary globally.
