---
title: "Customer Agent: Context Retention"
description: "Evaluates if the agent correctly retains and applies context from earlier in the conversation without re-asking for it."
---

Customer Agent Context Retention checks whether an agent remembers what the user already told it, like their name or order number, instead of asking for it again. Run it to catch agents that lose track of earlier turns.

## What it does

Customer Agent Context Retention is an LLM-as-Judge eval. It reads the full conversation and scores how well the agent retains and applies context from earlier turns.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `conversation` | `string` | The full conversation history between the customer and agent |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher values indicate better context retention |
| Reason | `string` | A plain-language explanation of the context retention assessment |

### Run it from code

Give the judge the earlier turn that contains the order number. Without it, the final question would look like a reasonable request for missing information. Both examples use the hosted [`turing_flash` judge](/docs/evaluation/concepts/evaluator-models).

<Note>
Set [your Future AGI credentials](/docs/evaluation/reference/sdk-api) (`FI_API_KEY` and `FI_SECRET_KEY`). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then install the Agent Learning Kit with `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `customer_agent_context_retention.py` and run `python customer_agent_context_retention.py`.

The TypeScript example calls the same evaluation endpoint with Node.js 22.18 or later; no npm package is required. Save it as `customer_agent_context_retention.mts` and run `node customer_agent_context_retention.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "customer_agent_context_retention",
    conversation=(
        "Customer: I need help with Ridgeline order RG-1042.\n"
        "Agent: I have order RG-1042. What would you like to know?\n"
        "Customer: When will my boots arrive?\n"
        "Agent: What is your order number?"
    ),
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(f"Score: {result.score}")
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
const inputs = {
  conversation: [
    "Customer: I need help with Ridgeline order RG-1042.",
    "Agent: I have order RG-1042. What would you like to know?",
    "Customer: When will my boots arrive?",
    "Agent: What is your order number?",
  ].join("\n"),
};
const base = process.env.FI_BASE_URL || "https://api.futureagi.com";
const response = await fetch(`${base}/sdk/api/v1/new-eval/`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": process.env.FI_API_KEY!,
    "X-Secret-Key": process.env.FI_SECRET_KEY!,
  },
  body: JSON.stringify({ eval_name: "customer_agent_context_retention", inputs, model: "turing_flash" }),
});
if (!response.ok) throw new Error(`Evaluation request failed: ${response.status}`);
const { result } = await response.json();
const row = result[0].evaluations[0];
if (row.output == null) throw new Error("No result returned");
console.log(row.output, row.reason);
console.log(row.eval_id);
```

## When to use

Run Customer Agent Context Retention wherever a conversation carries information across turns that the agent needs to keep using.

- Support conversations that open with identifying details, like a name or order number, that later turns depend on
- Long conversations where account details, preferences, or earlier answers need to persist
- Debugging agents that appear to "forget" what the user just said

## What to do when Customer Agent Context Retention fails

Ensure the agent's memory window covers the full conversation length, and add explicit context summarization between turns so key facts aren't dropped. Review cases where the agent re-asks for information already provided to find the pattern behind the loss.

Implement entity tracking to persist key facts, like names and order numbers, across the whole conversation.
