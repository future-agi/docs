title: "Instruction Adherence"
description: "Assesses how closely a response follows prompt instructions, checking task completion and constraint compliance."

Instruction Adherence checks whether a response actually does what the prompt asked, including any constraints on format, length, or content. Run it to catch outputs that miss part of the instruction.

## What it does

Instruction Adherence is an LLM-as-Judge eval. It reads the prompt and the generated output, then scores how closely the output follows the prompt's instructions.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `prompt` | `string` | The input prompt provided to the model |
| `output` | `string` | The output generated by the model |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher scores indicate better adherence to the prompt instructions |
| Reason | `string` | A plain-language explanation of the instruction adherence assessment |

### Run it from code

Pass the task prompt inside `inputs`. The top-level `prompt` argument of `fi.evals.evaluate` is for defining a custom judge, not for sending data to this template.

Python runs the evaluation and prints its score, reason, and execution ID. TypeScript submits the same evaluation asynchronously and prints its execution ID. To retrieve the result later, call `await evaluator.getEvalResult(run.id)` and check `result.eval_status` for `completed`. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`. Run `python -m pip install agent-learning-kit==0.3.7`, save the example as `score.py`, and run `python score.py`.

For TypeScript, use Node.js 22.18 or later, run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `score.mts`, and run `node score.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import Evaluator

batch = Evaluator().evaluate(
    "prompt_instruction_adherence",
    inputs={
        "prompt": "Answer in one sentence and include the phrase \"30 days\".",
        "output": "Return unworn boots within 30 days.",
    },
    model_name="turing_flash",
)
result = batch.eval_results[0]
if result.output is None:
    raise RuntimeError(result.reason or "No score returned")
print(result.output)
print(result.reason)
print(result.eval_id)
```

```typescript TypeScript
import { Evaluator } from "@future-agi/agent-learning-kit";

const evaluator = new Evaluator();
const run = await evaluator.submit(
  "prompt_instruction_adherence",
  {
    prompt: "Answer in one sentence and include the phrase \"30 days\".",
    output: "Return unworn boots within 30 days.",
  },
  { modelName: "turing_flash" }
);
console.log(run.id);
```

## When to use

Run Instruction Adherence wherever a prompt carries specific constraints the response must satisfy.

- Text, audio, and chat outputs generated against a detailed prompt
- Format or length-constrained tasks, where the prompt sets a specific structure to follow
- Support responses that must follow a requested format as well as answer the question

## What to do when Instruction Adherence fails

Identify specific areas where the output deviates from the given instructions. Providing targeted feedback helps refine the content to better align with the prompt.

Reviewing the prompt for clarity and completeness is essential, as ambiguous or vague instructions may contribute to poor adherence. If necessary, adjusting the prompt to offer clearer guidance can improve response accuracy.

Enhancing the model's ability to interpret and follow instructions through fine-tuning or prompt engineering can further strengthen adherence.
