---
title: "Customer Agent: Termination Handling"
description: "Tracks occurrences of the agent freezing, hanging up abruptly, crashing, or cutting off conversations early."
---

Customer Agent Termination Handling checks whether a conversation ends cleanly or cuts off abruptly, before the user's issue was addressed. Run it to catch dropped calls, crashes, and premature endings.

## What it does

Customer Agent Termination Handling is an LLM-as-Judge eval. It reads the full conversation and scores how often termination issues occur.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `conversation` | `string` | The full conversation history between the customer and agent |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `never / occasionally / frequently / always` | How often an abnormal ending occurs; `never` is best |
| Reason | `string` | A plain-language explanation of the termination handling assessment |

### Run it from code

Set `FI_API_KEY` and `FI_SECRET_KEY` to [your Future AGI credentials](/docs/evaluation/reference/sdk-api). Both examples print the label, the reason and the evaluation ID. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

- **Python:** Create a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. Save the example as `termination_handling.py` and run `python termination_handling.py`.
- **TypeScript:** This example calls the REST API directly from Node.js 22.18 or later. Save it as `termination_handling.mts` and run `node termination_handling.mts`.

<CodeGroup>

```python Python
from fi.evals import Evaluator

batch = Evaluator().evaluate(
    eval_templates="customer_agent_termination_handling",
    inputs={
        "conversation": "Customer: Can you check whether my Ridgeline tent has shipped?\nAgent: Sure. What's the order number?\nCustomer: It's RG-48213.\n[Agent ends the call before answering.]",
    },
    model_name="turing_flash",
)
result = batch.eval_results[0]
if result.output is None:
    raise RuntimeError(result.reason or "No evaluation result returned")
print(result.output["choice"])
print(result.reason)
print(result.eval_id)
```

```typescript TypeScript
const { FI_API_KEY, FI_SECRET_KEY, FI_BASE_URL = "https://api.futureagi.com" } = process.env;
if (!FI_API_KEY || !FI_SECRET_KEY) throw new Error("Set both Future AGI credentials");

const response = await fetch(new URL("/sdk/api/v1/new-eval/", FI_BASE_URL), {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": FI_API_KEY,
    "X-Secret-Key": FI_SECRET_KEY,
  },
  body: JSON.stringify({
    eval_name: "customer_agent_termination_handling",
    model: "turing_flash",
    inputs: {
      conversation: "Customer: Can you check whether my Ridgeline tent has shipped?\nAgent: Sure. What's the order number?\nCustomer: It's RG-48213.\n[Agent ends the call before answering.]",
    },
  }),
});
if (!response.ok) throw new Error(`Evaluation request failed: HTTP ${response.status}`);
const body = await response.json();
const result = body.result?.[0]?.evaluations?.[0];
if (result?.output == null) throw new Error("No evaluation result returned");
console.log(result.output.choice);
console.log(result.reason);
console.log(result.eval_id);
```

## When to use

Run Customer Agent Termination Handling on voice and chat agents where a dropped session means a lost or angry customer.

- Voice agents, to catch calls that end abruptly mid-request
- Chat sessions that close before the user's question was resolved
- Post-incident review, to check whether a spike in complaints traces back to abrupt endings

## What to do when Customer Agent Termination Handling fails

Investigate system logs for errors or timeouts around the flagged moments, and add graceful error handling to prevent abrupt disconnections. Implement conversation state persistence so sessions can recover from crashes instead of dropping entirely.

Test edge cases that may trigger unexpected termination before they show up with real users.
