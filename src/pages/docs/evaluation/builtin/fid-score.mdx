---
title: "FID Score"
description: "Computes the Frechet Inception Distance between two sets of images, where lower scores indicate more similar distributions."
---

FID Score measures how close the distribution of generated images is to a set of real reference images. Run it to track the statistical quality of an image generation model across a batch, not just one image at a time.

## What it does

FID Score is a statistical metric. It compares the distribution of a real image set against a generated image set and scores how similar they are.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `real_images` | `string` | JSON-encoded array of at least two reference image URLs or image data URIs |
| `fake_images` | `string` | JSON-encoded array of at least two generated image URLs or image data URIs |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | The hosted template clips the numeric result to the range 0 to 1; this field cannot distinguish distances above 1 |
| Reason | `string` | Reports the measured FID to three decimal places. Compare this distance across runs: lower means more similar distributions |

### Run it from code

Compare two pairs of synthetic fabric swatches: the reference pair is red and blue, while the generated pair is red and green. Serialize each set as a JSON array so both sets belong to one evaluation. Two images per set illustrate the inputs; use much larger, representative samples to compare models.

Python runs the evaluation and prints the clipped score, the reason containing the measured distance, and the execution ID. TypeScript submits the same evaluation asynchronously and prints its execution ID. To retrieve the result later, call `await evaluator.getEvalResult(run.id)` and check `result.eval_status` for `completed`.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`. Run `python -m pip install agent-learning-kit==0.3.7`, save the example as `score.py`, and run `python score.py`.

For TypeScript, use Node.js 22.18 or later, run `npm install @future-agi/agent-learning-kit@0.4.0`, save the example as `score.mts`, and run `node score.mts`.
</Note>

## When to use

Run FID Score wherever you need a distributional check on a batch of generated images, not a single image at a time.

- Evaluating an image generation model's overall output quality against a reference set
- Comparing checkpoints during model training or fine-tuning
- Regression testing a generation pipeline after changes to prompts, sampling, or model version

## What to do when FID Score is high

Increase the diversity and size of both image sets for a more reliable score, and review the generation model for mode collapse or quality issues. Ensure real and generated images are from the same domain and resolution.

Check preprocessing steps, since both sets should be normalized consistently, and consider fine-tuning the generation model on domain-specific data.
