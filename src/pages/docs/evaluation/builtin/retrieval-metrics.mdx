title: "Retrieval Metrics"
description: "Code-based metrics that score retrieval and ranking quality against reference relevant items, no LLM judge."
---

These are code-based (`CustomCodeEval`) metrics for retrieval and RAG pipelines: each one compares retrieved contexts or ranked items against a reference set using exact string matching, then returns a normalized 0-1 score, no LLM judge involved.

## Metrics

| Metric | What it measures | Required inputs | Output |
| --- | --- | --- | --- |
| `non_llm_context_precision` | Fraction of retrieved contexts that exact-match a reference context | `output`, `expected` | score (0-1), higher = better |
| `non_llm_context_recall` | Fraction of reference contexts that were successfully retrieved | `output`, `expected` | score (0-1), higher = better |
| `mean_average_precision` | Average precision at each relevant rank position, rewards relevant items retrieved earlier | `reference`, `hypothesis` | score (0-1), higher = better |

## Run a metric from code

Call `evaluate()` with the template id and the metric's required inputs. For one query, pass each list as a JSON-encoded string rather than a batch of rows. Use unique document IDs in the ranked list.

<Note>
Set `FI_API_KEY` and `FI_SECRET_KEY` for your Future AGI account. In a Python 3.12 virtual environment named `.venv`, run `source .venv/bin/activate` and `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `score.py` and run `python score.py`.
</Note>

<CodeGroup>

```python Python
import json
from fi.evals import evaluate

result = evaluate(
    "mean_average_precision",
    hypothesis=json.dumps(["tent-care", "pack-fit", "returns", "pack-sizing"]),
    reference=json.dumps(["pack-fit", "pack-sizing", "torso-length"]),
    engine="turing",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { evaluate } from "@future-agi/agent-learning-kit";

const result = await evaluate(
  "mean_average_precision",
  {
    hypothesis: JSON.stringify(["tent-care", "pack-fit", "returns", "pack-sizing"]),
    reference: JSON.stringify(["pack-fit", "pack-sizing", "torso-length"]),
  }
);

console.log(result.eval_results);
```

</CodeGroup>

For this query, the relevant items appear at ranks 2 and 4. Precision at each hit is 0.5. Dividing their sum by three reference items gives an average precision of about 0.333. To get mean average precision across queries, average their individual scores.

## When to use

Use these hosted metrics when you have known-relevant items and want to score a retriever without an LLM judge.

- Evaluating a retriever or vector index against a labeled set of relevant contexts, without calling a judge model
- Comparing ranking configurations (chunking, embedding model, top-k) using mean_average_precision, which credits relevant items retrieved earlier
- Tracking precision and recall of retrieved chunks against ground truth as a RAG pipeline changes over time
