Chunk Attribution checks whether the model draws on a specific retrieved chunk when generating a response. Run it to catch cases where retrieval succeeded but the model ignored what it retrieved.

## What it does

Chunk Attribution is an LLM-as-Judge eval. Compare one retrieved chunk with the answer. A distinctive fact or a paraphrase can count as attribution; shared subject matter alone does not. To find which chunks contributed, check each one separately.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `context` | `string` | One retrieved chunk |
| `output` | `string` | The response generated by the language model |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Pass means the answer uses information from this chunk; Fail means the judge found no meaningful contribution |
| Reason | `string` | A plain-language explanation of the evaluation |

### Run it from code

Call `evaluate()` with the template name and the eval's required inputs. It returns the score and the reason.

<Note>
[Set `FI_API_KEY` and `FI_SECRET_KEY`](/docs/evaluation/reference/sdk-api). For Python, create a virtual environment with `python3.12 -m venv .venv`, activate it with `source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. The TypeScript tab shows the corresponding SDK call, but the 0.4.0 npm release cannot run it; use the Python example instead.
</Note>

Save the Python example as `score.py` and run `python score.py`. It prints the score, the reason, and the evaluation ID. The `model` argument selects the [evaluator model](/docs/evaluation/concepts/evaluator-models), not the model that wrote the response.

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "chunk_attribution",
    context="Ridgeline covers return shipping on defective boots within 45 days of delivery.",
    output="If your boots are defective, you have 45 days from delivery to send them back with shipping covered.",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { evaluate } from "@future-agi/agent-learning-kit";

const result = await evaluate(
  "chunk_attribution",
  {
    context: "Ridgeline covers return shipping on defective boots within 45 days of delivery.",
    output: "If your boots are defective, you have 45 days from delivery to send them back with shipping covered."
  },
  { modelName: "turing_flash" }
);

console.log(result);
```

## When to use

Run Chunk Attribution wherever you need a quick, binary check on whether retrieved context is being used at all.

- RAG and retrieval pipelines, as a first-pass sanity check before measuring how well context is used
- Debugging a generator that seems to ignore retrieved documents
- Custom pipelines where you want a Pass/Fail signal rather than a graded score

## What to do when Chunk Attribution fails

- Ensure that the context provided is relevant and sufficiently detailed for the model to utilize effectively. Irrelevant context might be ignored
- Modify the input prompt to explicitly guide the model to use the context, for example "Using the provided documents, answer..."
- Check the retrieval mechanism: is the correct context being retrieved and passed to the generation model
- If the model consistently fails to use context despite relevant information and clear prompts, it may require fine-tuning with examples that emphasize context utilization
