---
title: "Numeric Similarity"
description: "Calculates the normalized numerical difference between a generated value and a reference value, extracted from generated output."
---

Numeric Similarity checks whether a numeric value in the generated output matches a reference value. Run it when the correctness of a specific number matters more than the surrounding wording.

## What it does

Numeric Similarity is a statistical metric. It extracts the first signed integer or decimal from each string. It divides their absolute difference by the largest of the two absolute values and 1, then subtracts that fraction from 1 and floors the score at 0. It does not convert units or check later numbers.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `expected` | `string` | Reference content with the expected numeric value |
| `output` | `string` | Model-generated content containing the numeric prediction |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Similarity from 0 to 1; matching numbers score 1 |
| Reason | `string` | A plain-language explanation of the numeric similarity assessment |

### Run it from code

The Python example uses Agent Learning Kit; the TypeScript example calls the same hosted template over HTTP. Each prints the result, the reason, and the evaluation ID.

<Note>
Set `FI_API_KEY` and `FI_SECRET_KEY` for your [Future AGI account](/docs/evaluation/reference/sdk-api). For Python, run `python3.12 -m venv .venv`, `source .venv/bin/activate`, and `python -m pip install agent-learning-kit==0.3.7`. Save the example as `score.py` and run `python score.py`. For TypeScript, save the HTTP example as `score.mts` and run `node score.mts` with Node.js 22.18 or newer.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "numeric_similarity",
    engine="turing",
    expected="The pack holds 40 liters.",
    output="The pack holds 36 liters.",
)
if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")

print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript (HTTP)
const { FI_BASE_URL = "https://api.futureagi.com", FI_API_KEY, FI_SECRET_KEY } = process.env;
if (!FI_API_KEY || !FI_SECRET_KEY) throw new Error("Set your Future AGI credentials");

const response = await fetch(new URL("/sdk/api/v1/new-eval/", FI_BASE_URL), {
  method: "POST",
  headers: { "Content-Type": "application/json", "X-Api-Key": FI_API_KEY, "X-Secret-Key": FI_SECRET_KEY },
  body: JSON.stringify({
    eval_name: "numeric_similarity",
    inputs: {
      expected: "The pack holds 40 liters.",
      output: "The pack holds 36 liters.",
    },
  }),
});
if (!response.ok) throw new Error(`Evaluation request failed: HTTP ${response.status}`);
const row = (await response.json()).result?.[0]?.evaluations?.[0];
if (row?.output == null || !row.eval_id) throw new Error("No evaluation result returned");
console.log(row.output);
console.log(row.reason);
console.log(row.eval_id);
```

</CodeGroup>

The example scores 0.9: the values differ by 4 liters and the larger value is 40.

## When to use

Run Numeric Similarity wherever the answer hinges on a specific number and lexical or semantic metrics could overlook an outright numeric error.

- Text outputs that report measurements, prices, counts, or dates
- Generated content where numeric correctness needs to be checked explicitly, separate from wording
- Regression checks on numeric fields that a semantic metric would otherwise score as similar despite a wrong value

## What to do when Numeric Similarity is low

Check that the output actually contains an extractable numeric value in a recognizable format; unit mismatches or embedded text around the number can throw off extraction. Confirm the reference value is stated in the same unit and scale as the expected output.

If the model is consistently off by a fixed factor or rounding differently, adjust the prompt or post-processing to normalize units before comparison.
