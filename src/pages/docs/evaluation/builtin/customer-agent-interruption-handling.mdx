---
title: "Customer Agent: Interruption Handling"
description: "Evaluates how well the agent recovers after being interrupted by the user, resuming logically without losing context."
---

Customer Agent Interruption Handling checks whether an agent picks up correctly after the user talks over it or cuts in mid-response, instead of restarting or losing the thread. Run it on voice and chat agents where interruptions are common.

## What it does

Customer Agent Interruption Handling is an LLM-as-Judge eval. It reads the full conversation and scores how well the agent recovers after being interrupted.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `conversation` | `string` | The full conversation history between the customer and agent |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `0.0` to `1.0` | Higher values indicate better interruption handling |
| Reason | `string` | A plain-language explanation of the interruption handling assessment |

### Run it from code

Set `FI_API_KEY` and `FI_SECRET_KEY` to [your Future AGI credentials](/docs/evaluation/reference/sdk-api). Both examples print the score, the reason and the evaluation ID. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

- **Python:** Create a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. Save the example as `interruption_handling.py` and run `python interruption_handling.py`.
- **TypeScript:** This example calls the REST API directly from Node.js 22.18 or later. Save it as `interruption_handling.mts` and run `node interruption_handling.mts`.

<CodeGroup>

```python Python
from fi.evals import Evaluator

batch = Evaluator().evaluate(
    eval_templates="customer_agent_interruption_handling",
    inputs={
        "conversation": "Customer: Can I exchange my boots?\nAgent: Yes. You can mail them back using the...\nCustomer: [interrupts] Actually, can I take them to the store instead?\nAgent: Of course. Bring the unworn boots and your receipt to a Ridgeline store within 30 days.",
    },
    model_name="turing_flash",
)
result = batch.eval_results[0]
if result.output is None:
    raise RuntimeError(result.reason or "No evaluation result returned")
print(result.output)
print(result.reason)
print(result.eval_id)
```

```typescript TypeScript
const { FI_API_KEY, FI_SECRET_KEY, FI_BASE_URL = "https://api.futureagi.com" } = process.env;
if (!FI_API_KEY || !FI_SECRET_KEY) throw new Error("Set both Future AGI credentials");

const response = await fetch(new URL("/sdk/api/v1/new-eval/", FI_BASE_URL), {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": FI_API_KEY,
    "X-Secret-Key": FI_SECRET_KEY,
  },
  body: JSON.stringify({
    eval_name: "customer_agent_interruption_handling",
    model: "turing_flash",
    inputs: {
      conversation: "Customer: Can I exchange my boots?\nAgent: Yes. You can mail them back using the...\nCustomer: [interrupts] Actually, can I take them to the store instead?\nAgent: Of course. Bring the unworn boots and your receipt to a Ridgeline store within 30 days.",
    },
  }),
});
if (!response.ok) throw new Error(`Evaluation request failed: HTTP ${response.status}`);
const body = await response.json();
const result = body.result?.[0]?.evaluations?.[0];
if (result?.output == null) throw new Error("No evaluation result returned");
console.log(result.output);
console.log(result.reason);
console.log(result.eval_id);
```

## When to use

Run Customer Agent Interruption Handling on voice agents and real-time chat where users routinely talk over or cut into a response.

- Voice assistants with barge-in support, to confirm the agent merges interrupted input correctly
- Chat agents where users send follow-up messages before the first response finishes
- Conversations with partial or mid-sentence user input that the agent needs to reconcile

## What to do when Customer Agent Interruption Handling fails

Implement barge-in detection so users can speak over the agent, and make sure the agent doesn't restart from the beginning after an interruption. Test recovery behavior when users provide partial or mid-sentence input.

Add logic to merge interrupted input with the user's subsequent turn instead of treating them as separate requests.
