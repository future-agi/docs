title: "Is Email"

Is Email checks whether a piece of text is a properly formatted email address. Run it wherever a model or user input is expected to produce a valid email.

## What it does

Is Email is a deterministic, rule-based eval using a regex pattern designed for email validation. It trims surrounding whitespace and checks the entire remaining string. It does not check whether the domain exists or the inbox accepts mail.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `text` | `string` | The content to check for email validity |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Pass / Fail` | Pass means the trimmed string matches the pattern; Fail means it does not |
| Reason | `string` | A plain-language explanation of the evaluation |

### Run it from code

Pass the template name and its inputs to `evaluate()`. In Python, `engine="turing"` selects the hosted template. The Python example prints the score, the reason, and the evaluation ID.

<Note>
Set `FI_API_KEY` and `FI_SECRET_KEY` for your Future AGI account. In a fresh Python 3.12 virtual environment named `.venv`, run `source .venv/bin/activate`, then `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `score.py` and run `python score.py`. Use Python with the current release: the TypeScript package is not runnable in version 0.4.0.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "is_email",
    text="returns@example.com",
    engine="turing",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(result.score)
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
import { evaluate } from "@future-agi/agent-learning-kit";

const result = await evaluate(
  "is_email",
  {
    "text": "returns@example.com"
  }
);

console.log(result.eval_results[0]);
```

</CodeGroup>

## When to use

Run Is Email wherever a field or extracted value needs to be a valid email address.

- Text outputs from form-filling or data-extraction agents that populate an email field
- Data validation pipelines, before an extracted address is used to send mail or stored as a record
- Structured extraction tasks, to confirm a parsed field is actually a well-formed email rather than a partial match

## What to do when Is Email fails

Review the input text to identify formatting issues. Common problems include a missing "@" symbol, a missing dot in the domain, or invalid characters.

Consider revising the input to ensure it meets the standard email format.
