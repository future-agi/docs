---
title: "Completeness"
description: "Evaluates whether a response fully addresses every aspect of the input query, flagging gaps in coverage."
---

Completeness checks whether a response covers everything the query asked for, or leaves parts of it unanswered. Run it wherever a partial answer is as bad as a wrong one.

## What it does

Completeness is an LLM-as-Judge eval. It reads the input query and the generated output, then scores how fully the output addresses every aspect of the query.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `input` | `string` | User query provided to the model |
| `output` | `string` | Model generated response |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `score` | Higher scores indicate more complete content relative to the input |
| Reason | `string` | A plain-language explanation of the completeness assessment |

### Run it from code

Call `evaluate()` with the template name and the eval's required inputs. The hosted `turing_flash` judge returns a score and a reason. Here the question asks for both the return window and the condition of the boots.

<Note>
Set [your Future AGI credentials](/docs/evaluation/reference/sdk-api) (`FI_API_KEY` and `FI_SECRET_KEY`). For Python, create and activate a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then install the Agent Learning Kit with `python -m pip install agent-learning-kit==0.3.7`. Save the Python example as `completeness.py` and run `python completeness.py`.

The TypeScript example calls the same evaluation endpoint with Node.js 22.18 or later; no npm package is required. Save it as `completeness.mts` and run `node completeness.mts`.
</Note>

<CodeGroup>

```python Python
from fi.evals import evaluate

result = evaluate(
    "completeness",
    input="How long do I have to return boots, and what condition must they be in?",
    output="Ridgeline Outfitters accepts returns within 30 days. Bring the boots back unworn and in their original box.",
    model="turing_flash",
)

if result.score is None:
    raise RuntimeError(result.error or result.reason or "No score returned")
print(f"Score: {result.score}")
print(result.reason)
print(result.metadata["eval_id"])
```

```typescript TypeScript
const inputs = {
  input: "How long do I have to return boots, and what condition must they be in?",
  output: "Ridgeline Outfitters accepts returns within 30 days. Bring the boots back unworn and in their original box."
};
const base = process.env.FI_BASE_URL || "https://api.futureagi.com";
const response = await fetch(`${base}/sdk/api/v1/new-eval/`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": process.env.FI_API_KEY!,
    "X-Secret-Key": process.env.FI_SECRET_KEY!,
  },
  body: JSON.stringify({ eval_name: "completeness", inputs, model: "turing_flash" }),
});
if (!response.ok) throw new Error(`Evaluation request failed: ${response.status}`);
const { result } = await response.json();
const row = result[0].evaluations[0];
if (row.output == null) throw new Error("No result returned");
console.log(row.output, row.reason);
console.log(row.eval_id);
```

</CodeGroup>

## When to use

Run Completeness wherever a response needs to answer the full question, not just part of it.

- Text, audio, and chat outputs that respond to multi-part or multi-step queries
- RAG answers, to check that each part of the user’s question was addressed (this does not check whether the answer is grounded)
- Support and Q&A flows, where an unanswered sub-question sends the user back for another round

## What to do when Completeness fails

Determine which aspects of the query have not been fully addressed and identify any gaps or incomplete sections that require additional information.

Enhancing the response involves adding missing details to ensure it's comprehensive and refining the content to cover all aspects of the query.

To improve completeness in the long term, implement mechanisms that align responses more closely with query requirements and enhance the response generation process to prioritize completeness.
