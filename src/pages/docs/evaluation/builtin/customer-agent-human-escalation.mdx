title: "Customer Agent: Human Escalation"
description: "Tracks if the agent escalates to a human appropriately based on user frustration, query complexity, or specific keywords."

Customer Agent Human Escalation checks whether an agent hands a conversation off to a human at the right moment, not too early and not too late. Run it to catch missed, premature, or delayed escalations.

## What it does

Customer Agent Human Escalation is an LLM-as-Judge eval. It reads the full conversation and scores whether escalation to a human was handled appropriately.

### Input

| Required Input | Type | Description |
| --- | --- | --- |
| `conversation` | `string` | The full conversation history between the customer and agent |

### Output

| Field | Type | Description |
| --- | --- | --- |
| Result | `Passed` / `Failed` | Pass means the agent escalates at the right time and explains the handoff, or correctly handles the issue without escalating. Fail means it misses, mistimes or fails to explain a needed handoff. |
| Reason | `string` | A plain-language explanation of the escalation handling assessment |

### Run it from code

Set `FI_API_KEY` and `FI_SECRET_KEY` to [your Future AGI credentials](/docs/evaluation/reference/sdk-api). Both examples print the verdict, the reason and the evaluation ID. The [evaluator model](/docs/evaluation/concepts/evaluator-models) is `turing_flash`.

- **Python:** Create a virtual environment with `python3.12 -m venv .venv && source .venv/bin/activate`, then run `python -m pip install agent-learning-kit==0.3.7`. Save the example as `human_escalation.py` and run `python human_escalation.py`.
- **TypeScript:** This example calls the REST API directly from Node.js 22.18 or later. Save it as `human_escalation.mts` and run `node human_escalation.mts`.

<CodeGroup>

```python Python
from fi.evals import Evaluator

batch = Evaluator().evaluate(
    eval_templates="customer_agent_human_escalation",
    inputs={
        "conversation": "Customer: I've contacted Ridgeline twice about a missing tent. Please let me speak to a person.\nAgent: I'm sorry you still don't have your tent. I'll connect you to our order team now and send them the tracking history so you won't need to repeat it.",
    },
    model_name="turing_flash",
)
result = batch.eval_results[0]
if result.output is None:
    raise RuntimeError(result.reason or "No evaluation result returned")
print(result.output)
print(result.reason)
print(result.eval_id)
```

```typescript TypeScript
const { FI_API_KEY, FI_SECRET_KEY, FI_BASE_URL = "https://api.futureagi.com" } = process.env;
if (!FI_API_KEY || !FI_SECRET_KEY) throw new Error("Set both Future AGI credentials");

const response = await fetch(new URL("/sdk/api/v1/new-eval/", FI_BASE_URL), {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-Api-Key": FI_API_KEY,
    "X-Secret-Key": FI_SECRET_KEY,
  },
  body: JSON.stringify({
    eval_name: "customer_agent_human_escalation",
    model: "turing_flash",
    inputs: {
      conversation: "Customer: I've contacted Ridgeline twice about a missing tent. Please let me speak to a person.\nAgent: I'm sorry you still don't have your tent. I'll connect you to our order team now and send them the tracking history so you won't need to repeat it.",
    },
  }),
});
if (!response.ok) throw new Error(`Evaluation request failed: HTTP ${response.status}`);
const body = await response.json();
const result = body.result?.[0]?.evaluations?.[0];
if (result?.output == null) throw new Error("No evaluation result returned");
console.log(result.output);
console.log(result.reason);
console.log(result.eval_id);
```

## When to use

Run Customer Agent Human Escalation wherever an agent has the option to hand off to a human and getting that decision right matters.

- Conversations showing signs of user frustration, to confirm the agent escalates instead of continuing to loop
- Complex queries outside the agent's scope, to check it hands off rather than guessing
- Reviewing escalation triggers for false positives, where the agent escalates too early

## What to do when Customer Agent Human Escalation fails

Define clear escalation triggers, like frustration signals, repeated failures, or specific keywords, and avoid escalating too early before the agent has attempted resolution. Ensure the handoff to a human agent is smooth and carries over conversation context.

Review cases where escalation was needed but the agent continued without escalating, and use those to sharpen the trigger conditions.
