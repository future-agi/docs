When a gateway request returns HTTP 429, waiting a minute helps only if a rate limit was the cause. A budget or an empty key balance needs a different fix.

Rate limiting controls how many requests a key or org can make per minute. Budgets control how much money can be spent per period. Credits give individual keys a prepaid USD balance. All three work together to prevent runaway costs and protect provider quotas.

<Prerequisites title="Before you start">
- Use an [organization](/docs/command-center/admin/organizations) Owner or Admin account to manage keys and budgets.
- For the managed-key requests, use the gateway admin token. All key operations require it in the `Authorization` header.
</Prerequisites>

## Choose the control

- **Prevent abuse**: Cap RPM per key so one user can't monopolize gateway capacity
- **Control spending**: Set monthly budgets per org so teams can't exceed their allocation
- **Reseller billing**: Give each customer key a credit balance that auto-deducts per request
- **Protect provider quotas**: Global RPM limits prevent hitting provider rate limits

Agent Command Center supports rate limits at three levels: global, per-org, and per-key.

<div class="sdk-ref-table">

| Level | Scope | How to set |
|---|---|---|
| **Global** | All requests to the gateway | `config.yaml` |
| **Per-org** | All requests from one organization | Org config via admin API |
| **Per-key** | Requests using a specific [virtual key](/docs/command-center/concepts/virtual-keys) | Key config (requests per minute, RPM, and tokens per minute, TPM) |

</div>

The most restrictive limit applies. If the global limit is 1000 RPM and a key's limit is 100 RPM, that key is capped at 100 RPM.

## Set a rate limit

1. Open **Agent Command Center > Rate Limits** in the Future AGI dashboard.
2. Set the global and per-org limits.
3. For a per-key limit, open **Settings > API Keys**.
4. Set the limit when you create or edit the key.

### Set a per-org limit from code

<Tabs items={["Python (Agent Command Center SDK)", "TypeScript (Agent Command Center SDK)"]}>

<Tab title="Python (Agent Command Center SDK)">

```python
from agentcc import AgentCC

client = AgentCC(
    api_key="sk-agentcc-your-key",
    base_url="https://gateway.futureagi.com",
    control_plane_url="https://api.futureagi.com",
)

# Set per-org rate limits
client.org_configs.create(
    org_id="your-org-id",
    config={
        "rate_limiting": {
            "enabled": True,
            "rpm": 500,     # requests per minute for this org
            "tpm": 100000,  # tokens per minute for this org
        }
    }
)
```

</Tab>

<Tab title="TypeScript (Agent Command Center SDK)">

```typescript

const client = new AgentCC({
    apiKey: "sk-agentcc-your-key",

    controlPlaneUrl: "https://api.futureagi.com",
});

await client.orgConfigs.create({
    orgId: "your-org-id",

```

</Tab>

**Self-hosted config.yaml:**

```yaml
# Global rate limit (all requests)
rate_limiting:
  enabled: true
  global_rpm: 1000

# Per-key limits are set on the key itself
auth:
  keys:
    - name: "limited-key"
      key: "sk-agentcc-..."
      rate_limit_rpm: 100
      rate_limit_tpm: 50000
```

## Read the rate limit headers

When rate limiting is enabled for the key or org, each response includes [rate limit headers](/docs/command-center/api/headers):

<div class="sdk-ref-table">

| Header | Description |
|---|---|
| `X-Ratelimit-Limit-Requests` | Maximum requests allowed per minute |
| `X-Ratelimit-Remaining-Requests` | Requests remaining in the current window |
| `X-Ratelimit-Reset-Requests` | Unix timestamp when the window resets |

</div>

### Error response (429)

When a rate limit is exceeded:

```json
{
  "error": {
    "type": "rate_limit_exceeded",
    "code": "rate_limit_exceeded",
    "message": "Rate limit exceeded. Please retry after the window resets."
  }
}
```

### Retry logic

<Tabs items={["Python (Agent Command Center SDK)", "Python (OpenAI SDK)", "cURL"]}>

<Tab title="Python (Agent Command Center SDK)">

```python
import time
from agentcc import AgentCC, RateLimitError

client = AgentCC(
    api_key="sk-agentcc-your-key",
    base_url="https://gateway.futureagi.com",
)

def call_with_retry(max_retries=3):
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(
                model="gpt-4o",
                messages=[{"role": "user", "content": "Hello"}],
            )
        except RateLimitError:
            if attempt < max_retries - 1:
                time.sleep(2 ** attempt)  # 1s, 2s, 4s
                continue
            raise

result = call_with_retry()
```

</Tab>

## Set a spending budget

Set spending limits per org, per key, per user, or per model. Budgets can be daily, weekly, monthly, or total.

<div class="sdk-ref-table">

| Setting | Description |
|---|---|
| `period` | `daily`, `weekly`, `monthly`, or `total` |
| `limit` | USD amount |
| `action` | `block` (hard limit, reject requests) or `warn` (soft limit, log warning) |

</div>

To set org-level budgets and alerts in the dashboard, open **Agent Command Center > Budgets**.

### Set a budget from code

<Tabs items={["Python (Agent Command Center SDK)", "TypeScript (Agent Command Center SDK)"]}>

<Tab title="Python (Agent Command Center SDK)">

```python
client.org_configs.create(
    org_id="your-org-id",
    config={
        "budgets": {
            "enabled": True,
            "org_budget": {
                "period": "monthly",
                "limit": 500.00,
                "action": "block",
            }
        }
    }
)
```

</Tab>

<Tab title="TypeScript (Agent Command Center SDK)">

```typescript
await client.orgConfigs.create({
    orgId: "your-org-id",
    config: {
        budgets: {
            enabled: true,
            org_budget: {
                period: "monthly",
                limit: 500.00,
                action: "block",
            },
        },
    },
});
```

</Tab>

</Tabs>

**Self-hosted config.yaml:**

```yaml
budgets:
  enabled: true
  org_budget:
    period: monthly
    limit: 500.00
    action: block
```

When a budget is exceeded with `action: block`, new requests return:

```json
{
  "error": {
    "type": "budget_exceeded",
    "code": "rate_limit_exceeded",
    "message": "Organization monthly budget of $500.00 exceeded"
  }
}
```

## Fund a managed key

Managed keys have a USD credit balance that auto-deducts the cost of each request. When credits run out, requests are blocked.

**Create a managed key with credits:**

```bash
curl -X POST https://gateway.futureagi.com/-/keys \
  -H "Authorization: Bearer your-admin-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "customer-key",
    "key_type": "managed",
    "credit_balance": 25.00
  }'
```

**Add more credits:**

```bash
curl -X POST "https://gateway.futureagi.com/-/keys/key_123/credits" \
  -H "Authorization: Bearer your-admin-token" \
  -H "Content-Type: application/json" \
  -d '{"amount": 50.00}'
```

The remaining balance is returned in the `x-agentcc-credits-remaining` response header on every request made with a managed key.

## Decide what to change after a blocked request

<div class="sdk-ref-table">

| What the response tells you | What to do |
| --- | --- |
| The message says `Rate limit exceeded. Please retry after the window resets.` | Wait for the time in `X-Ratelimit-Reset-Requests`, then retry. |
| The message names a budget, such as `Organization monthly budget of $500.00 exceeded` | Increase the budget, or wait for the next period. A budget resets at the start of the next daily, weekly or monthly period, not when the rate window resets. |
| A managed key whose `x-agentcc-credits-remaining` balance has run out | Add credits to that key. |

</div>
