## About

Agent Command Center proxies audio and image requests to any configured provider. The API follows the OpenAI format. These requests are not cached and do not fail over to another provider or model.

The gateway prices a speech request per character of its input text, and a WAV transcription or translation per second of audio, from the model's per-character or per-second price in the gateway's model database. The bundled database has these prices for `tts-1`, `tts-1-hd` and `whisper-1`.

---

## Endpoints

| Method | Path | Description |
|---|---|---|
| POST | `/v1/audio/speech` | Text-to-speech |
| POST | `/v1/audio/speech/stream` | Streaming text-to-speech |
| POST | `/v1/audio/transcriptions` | Speech-to-text |
| POST | `/v1/audio/translations` | Translate audio to English |
| POST | `/v1/images/generations` | Generate images from prompts |

## Text-to-speech

Convert text to spoken audio. The response is raw audio bytes in the requested format.

### Basic usage

<Tabs items={["Agent Command Center SDK", "OpenAI SDK", "cURL"]}>

<Tab title="Python (Agent Command Center SDK)">

```python
from agentcc import AgentCC

client = AgentCC(
    api_key="sk-agentcc-your-key",
    base_url="https://gateway.futureagi.com",
)

audio_bytes = client.audio.speech.create(
    model="tts-1",
    voice="alloy",
    input="Hello! This is a test of text-to-speech through Agent Command Center.",
)

with open("output.mp3", "wb") as f:
    f.write(audio_bytes)
```

</Tab>

<Tab title="Python (OpenAI SDK)">

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.futureagi.com/v1",
    api_key="sk-agentcc-your-key",
)

response = client.audio.speech.create(
    model="tts-1",
    voice="alloy",
    input="Hello! This is a test of text-to-speech through Agent Command Center.",
)

response.stream_to_file("output.mp3")
```

</Tab>

<Tab title="cURL">

```bash
curl -X POST https://gateway.futureagi.com/v1/audio/speech \
  -H "Authorization: Bearer sk-agentcc-your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-1",
    "voice": "alloy",
    "input": "Hello! This is a test of text-to-speech through Agent Command Center."
  }' \
  --output output.mp3
```

</Tab>

</Tabs>

### Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `model` | string | Yes | - | TTS model (`tts-1`, `tts-1-hd`, `gpt-4o-mini-tts`) |
| `input` | string | Yes | - | Text to convert to speech (max 4096 characters) |
| `voice` | string | Yes | - | Voice to use (`alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`) |
| `response_format` | string | No | `mp3` | Output format: `mp3`, `opus`, `aac`, `flac`, `wav`, `pcm` |
| `speed` | float | No | `1.0` | Speed multiplier (0.25 to 4.0) |

### Using `tts-1-hd`

To use OpenAI's `tts-1-hd` text-to-speech model, set `model` to `tts-1-hd`:

```python
audio_bytes = client.audio.speech.create(
    model="tts-1-hd",
    voice="nova",
    input="This sentence is read by tts-1-hd.",
    response_format="flac",
)
```

## Speech-to-text (transcription)

Transcribe audio files to text. Supports mp3, mp4, mpeg, mpga, m4a, wav, and webm formats.

### Basic usage

<Tabs items={["Agent Command Center SDK", "OpenAI SDK", "cURL"]}>

<Tab title="Python (Agent Command Center SDK)">

```python
from agentcc import AgentCC

client = AgentCC(
    api_key="sk-agentcc-your-key",
    base_url="https://gateway.futureagi.com",
)

with open("recording.mp3", "rb") as f:
    transcription = client.audio.transcriptions.create(
        model="whisper-1",
        file=f,
    )

print(transcription.text)
```

</Tab>

<Tab title="Python (OpenAI SDK)">

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.futureagi.com/v1",
    api_key="sk-agentcc-your-key",
)

with open("recording.mp3", "rb") as f:
    transcription = client.audio.transcriptions.create(
        model="whisper-1",
        file=f,
    )

print(transcription.text)
```

</Tab>

<Tab title="cURL">

```bash
curl -X POST https://gateway.futureagi.com/v1/audio/transcriptions \
  -H "Authorization: Bearer sk-agentcc-your-key" \
  -F file=@recording.mp3 \
  -F model=whisper-1
```

</Tab>

</Tabs>

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `file` | file | Yes | Audio file to transcribe |
| `model` | string | Yes | Transcription model (`whisper-1`, `gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) |
| `language` | string | No | ISO-639-1 language code (e.g. `en`, `fr`, `de`). Improves accuracy if you know the language. |
| `prompt` | string | No | Hint text to guide the model's style or continue a previous segment |
| `response_format` | string | No | Output format: `json`, `text`, `srt`, `verbose_json`, `vtt` |
| `temperature` | float | No | Sampling temperature (0 to 1). Lower values are more deterministic. |
| `timestamp_granularities` | string[] | No | `word` and/or `segment` level timestamps (requires `verbose_json` format) |

### Timestamps

Get word-level or segment-level timestamps with `verbose_json`:

```python
with open("recording.mp3", "rb") as f:
    transcription = client.audio.transcriptions.create(
        model="whisper-1",
        file=f,
        response_format="verbose_json",
        timestamp_granularities=["word", "segment"],
    )

for word in transcription.words:
    print(f"[{word.start:.2f}s - {word.end:.2f}s] {word.word}")
```

## Audio translation

## Image generation

Generate images from text prompts. The examples use OpenAI's `gpt-image-2`.

### Basic usage

<Tabs items={["Agent Command Center SDK", "OpenAI SDK", "cURL"]}>

<Tab title="Python (Agent Command Center SDK)">

```python
import base64

from agentcc import AgentCC

client = AgentCC(
    api_key="sk-agentcc-your-key",
    base_url="https://gateway.futureagi.com",
)

response = client.images.generate(
    model="gpt-image-2",
    prompt="A serene mountain lake at dawn, photorealistic",
)

image_bytes = base64.b64decode(response.data[0].b64_json)
print(f"Received {len(image_bytes)} bytes of image data")
```

</Tab>

<Tab title="Python (OpenAI SDK)">

```python
import base64

from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.futureagi.com/v1",
    api_key="sk-agentcc-your-key",
)

response = client.images.generate(
    model="gpt-image-2",
    prompt="A serene mountain lake at dawn, photorealistic",
)

image_bytes = base64.b64decode(response.data[0].b64_json)
print(f"Received {len(image_bytes)} bytes of image data")
```

</Tab>

<Tab title="cURL">

```bash
curl -X POST https://gateway.futureagi.com/v1/images/generations \
  -H "Authorization: Bearer sk-agentcc-your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A serene mountain lake at dawn, photorealistic"
  }'
```

</Tab>

</Tabs>

OpenAI's GPT image models return each image as base64-encoded data in `b64_json`, not as a URL ([OpenAI's Images API reference](https://developers.openai.com/api/reference/resources/images)). The gateway does not forward `output_format`, so the model's default format is returned.

### Parameters

The gateway reads these fields from the request body:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `model` | string | Yes | Image model, for example `gpt-image-2` |
| `prompt` | string | Yes | Text description of the image to generate |
| `n` | integer | No | Number of images to generate |
| `size` | string | No | Image size, for example `1024x1024` |
| `quality` | string | No | Image quality |
| `user` | string | No | An identifier for your end user |
| `style`, `response_format` | string | No | Passed to OpenAI and Azure as given. OpenAI's GPT image models do not support them. |

A request without `model` or `prompt` gets a 400 (`missing_model` or `missing_prompt`). The OpenAI and Azure adapters send the other fields to the provider as given, so for an OpenAI model the values each model accepts, and its defaults, are the ones in [OpenAI's Images API reference](https://developers.openai.com/api/reference/resources/images). The Gemini adapter uses only the prompt, `n` and `size` (as an aspect ratio). Fields not in this table are not sent to any provider.

### Response

```json
{
  "created": 1700000000,
  "data": [
    {
      "b64_json": "..."
    }
  ]
}
```

The response has `created` and, for each image, the `url`, `b64_json` and `revised_prompt` fields the provider returned, each only when it is set. Other fields in the provider's response are not passed on.

<Note>
The gateway reads up to 10 MiB (10,485,760 bytes) of OpenAI's image response. A larger response, such as several large images as base64, is answered with a 502.
</Note>

## Supported models

### Text-to-speech

| Provider | Models | Notes |
|---|---|---|
| OpenAI | `tts-1`, `tts-1-hd` | 6 voices, mp3/opus/aac/flac/wav/pcm |
| OpenAI | `gpt-4o-mini-tts` | Text-to-speech |

### Speech-to-text

| Provider | Models | Notes |
|---|---|---|
| OpenAI | `whisper-1` | 57 languages, timestamps, translation |
| OpenAI | `gpt-4o-transcribe` | Speech-to-text |
| OpenAI | `gpt-4o-mini-transcribe` | Speech-to-text |

### Image generation

| Provider | Models | Notes |
|---|---|---|
| OpenAI | `gpt-image-2`, `gpt-image-2-2026-04-21` | Returns `b64_json` (no URL) |

<Note>
Available models depend on which providers are configured for your organization. Use `GET /v1/models` to see what's available on your key.
</Note>
