## About

Integrations let you connect Future AGI to external platforms. You can import data from other observability tools, export metrics and traces, set up alerting, or archive logs to cloud storage.

Access: Owner and Admin at the organization level. Workspace admins and members can view configured integrations.

## Available Integrations

| Integration | Status | What it does |
|---|---|---|
| [Langfuse](/docs/integrations/import/langfuse) | Available | Import traces, spans, and scores from Langfuse |
| [Datadog](/docs/integrations/export/datadog) | Available | Export Agent Command Center metrics and traces to Datadog APM |
| [PostHog](/docs/integrations/export/posthog) | Available | Export LLM usage events to PostHog analytics |
| [PagerDuty](/docs/integrations/export/pagerduty) | Available | Route alerts to PagerDuty incidents |
| [Mixpanel](/docs/integrations/export/mixpanel) | Available | Export LLM usage events to Mixpanel |
| [Cloud Storage (S3, Azure Blob, GCS)](/docs/integrations/export/cloud-storage) | Available | Archive logs to your cloud storage |
| [Message Queue (SQS, Pub/Sub)](/docs/integrations/export/message-queues) | Available | Stream logs in real-time to a message queue |
| Slack | Available | Send Error Feed alerts to a Slack channel. Selecting Slack opens Slack's authorization page instead of the steps below. On self-hosted Future AGI, first set `SLACK_CLIENT_ID` and `SLACK_CLIENT_SECRET` from your own Slack app |
| [Linear](/docs/error-feed/guides/create-linear-issue) | Available | Turn Error Feed issues into Linear tickets. Enter a Linear personal API key with Issues: Write permission and click **Connect Linear**; there is no sync interval or Save step |
| [LangSmith](/docs/integrations/langsmith) | Available (trace forwarding) | Forward new runs from a LangSmith-traced app to a self-hosted Future AGI. You set this up in your app; importing existing LangSmith runs from **Settings > Integrations** is coming soon |
| [Arize (OpenInference)](/docs/integrations/import/openinference) | Available (OpenInference over OTLP) | Send the OpenInference spans your app emits to Observe. You set this up in your app; importing data stored in Arize from **Settings > Integrations** is coming soon |

## How to Add an Integration

1. Go to **Settings > Integrations**
2. Click **Add Integration**
3. Select the platform you want to connect
4. Enter the required credentials (API key, endpoint, etc.)
5. Configure the sync interval (1 min, 2 min, 5 min, 10 min, 15 min, 30 min)
6. Click **Save**

## Managing Integrations

| Action | How |
|---|---|
| View active connections | All connected integrations are listed on the Integrations page |
| Edit configuration | Click on an integration to update credentials or sync settings |
| View sync history | Each integration shows its last sync time and status |
| Delete | Click delete to remove the integration. This stops all data sync. |

Slack and Linear work differently. Clicking either one opens a dialog with only **Disconnect**, plus **Reconnect Slack** for Slack, and neither has sync history. To change a Linear API key, disconnect Linear and connect it again.

<Warning>
Deleting an integration stops all data sync immediately. Make sure you no longer need the connection before removing it.
</Warning>

## Workspace-Level Integrations

Each workspace can have its own integrations. Go to **Settings > Workspace > [workspace name] > Integrations** to configure workspace-specific connections.
