Integrations connect Future AGI to external platforms. You can import data from other observability tools, export logs and metrics, set up alerting, or archive logs to cloud storage. They don't all connect the same way, so start with what you're connecting: a scheduled import or export, Slack, Linear, or forwarding you set up in your own app.

<Prerequisites title="Before you start">
- Check your [role](/docs/roles-and-permissions). Owners and Admins at the organization level can configure integrations. Workspace admins and members can view configured integrations.
- Each [workspace](/docs/admin-settings/workspace-management) can have its own integrations. For a workspace-specific connection, go to **Settings > Workspace > [workspace name] > Integrations**.
</Prerequisites>

## Connect a scheduled import or export

1. Go to **Settings > Integrations**.
2. Click **Add Integration**.
3. Select the platform you want to connect.
4. Enter the required credentials (API key, endpoint, etc.).

   When connecting Datadog, select your site: **US1**, **US3** or **US5** (United States), **EU1** (Europe), **AP1** (Asia-Pacific) or **US1-FED** (US Government).

5. Configure the sync interval: 1, 2, 5, 10, 15 or 30 minutes.
6. Click **Save**. On the Langfuse and Datadog forms, the button reads **Connect Integration**.

   The connection is now listed on the Integrations page, with its last sync time and status.

## Authorize Slack for alerts

1. On [self-hosted](/docs/self-hosting) Future AGI, first set `SLACK_CLIENT_ID` and `SLACK_CLIENT_SECRET` from your own Slack app.
2. Select **Slack** on the Integrations page.

   Slack's authorization page opens instead of the credential steps above.

3. Complete Slack's authorization.

## Connect Linear for issue creation

1. Select **Linear** on the Integrations page.
2. Enter a Linear personal API key with Issues: Write permission.
3. Click **Connect Linear**.

   There is no sync interval or Save step. With Linear connected, you can turn Error Feed issues into Linear tickets.

## Forward new runs from your app

You set these two up in your app, not in **Settings > Integrations**:

- **LangSmith**: forward new runs from a LangSmith-traced app to a self-hosted Future AGI. Importing existing LangSmith runs from **Settings > Integrations** is coming soon.
- **Arize (OpenInference)**: send the OpenInference spans your app emits to Observe over OTLP. Importing data stored in Arize from **Settings > Integrations** is coming soon.

## Verify the destination

After a sync, check the destination. For Datadog:

1. Open the Datadog connection in Future AGI and check its last sync time and status.
2. In **Datadog > Logs**, search for `source:agentcc`, or filter by a tag such as `model:gpt-4o`.
3. In **Datadog > Metrics Explorer**, search for `agentcc.gateway.requests`.

   Metrics are aggregated over each sync window. The windows overlap, so don't use summed counts as exact usage totals.

The [Datadog verification steps](/docs/integrations/export/datadog#verify-in-datadog) cover these checks, next to the list of what gets exported.

## Manage integrations

<div class="sdk-ref-table max-sm:[&_td]:px-1.5! max-sm:[&_th]:px-1.5!">

| Action | How |
|---|---|
| View active connections | All connected integrations are listed on the Integrations page |
| Edit configuration | Click on an integration to update credentials or sync settings |
| View sync history | Each integration shows its last sync time and status |
| Delete | Click delete to remove the integration. This stops all data sync. |

</div>

Slack and Linear work differently. Clicking either one opens a dialog with only **Disconnect**, plus **Reconnect Slack** for Slack, and neither has sync history. To change a Linear API key, disconnect Linear and connect it again.

<Warning>
Deleting an integration stops all data sync immediately. Make sure you no longer need the connection before removing it.
</Warning>

## Troubleshooting

- **No data arrives from a scheduled connection.** Check the integration's sync history for errors. For Datadog, check that you selected the correct site, and that the gateway received requests in that sync window: metrics are only sent when a window has at least one request.
- **A Langfuse sync reports a credential error.** Check that the host URL matches your project's region, that both keys belong to the source project, and that the key has read access. Then edit the integration to update it.
- **Nothing arrives from LangSmith or Arize.** These forward new runs and spans from your app. They don't import data that already exists there.
- **Slack or Linear stops working.** Use **Reconnect Slack**, or disconnect Linear and connect it again with a valid key.
