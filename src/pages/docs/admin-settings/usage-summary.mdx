## About

The Usage Summary page shows what your organization is consuming and what it costs. The page is headed **Usage & Billing** and opens on the current period.

Access: everyone in the organization. It is available on Future AGI Cloud only.

## How to View Usage

1. Open **Settings > Usage Summary**
2. Pick a time range: **MTD**, **3M**, **6M**, or **12M**
3. Select a product to see its detail below

## What is metered

Usage is broken down by product, each with its own cost for the selected range.

| Product | What it counts |
|---|---|
| Storage | Data held in the platform, reported in GB |
| AI Credits | Credits spent running evaluations and other model calls |
| Gateway Requests | Requests routed through the Agent Command Center gateway |
| Gateway Cache Hits | Gateway requests served from cache |
| Text Simulation | Text simulation runs |
| Voice Simulation | Voice simulation runs |
| Tracing Events | Spans and events ingested by Observe |

<Note>
If you route model traffic through the gateway, that consumption shows up here too, under Gateway Requests and Gateway Cache Hits. You do not need to read gateway analytics separately to know what it cost.
</Note>

## Usage details

Select a product and the page shows two views of it:

- **Daily usage** for that product across the selected range
- **Usage by workspace** for that product, as a table of Workspace, usage, and % of total

The workspace view is what tells you which team drove the spend. It is reporting only. Every workspace bills to the same organization, so there is no separate per-workspace invoice.
