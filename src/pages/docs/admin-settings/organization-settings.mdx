When two-factor authentication (2FA) is left to each member, some accounts stay protected by a password alone. Organization Settings lets an [Owner or Admin](/docs/roles-and-permissions) enforce 2FA for every member and manage the organization's name. Changes here affect all members of the organization.

<Prerequisites title="Before you start">
- Sign in as an Owner or Admin. Only these roles can open Organization Settings.
- Point members to the [personal 2FA setup and recovery codes](/docs/admin-settings/profile-security) instructions, so they know how to enroll.
</Prerequisites>

## What you can set

<div class="sdk-ref-table">

| Setting | Description |
|---------|-------------|
| Organization Name | The display name for your organization. Visible across the platform. |
| Two-Factor Policy | Enforce mandatory 2FA for all organization members. When enabled, members must set up 2FA before they can access the platform. |

</div>

## Require 2FA for all members

1. Open **Settings > Org Settings**.
2. In the **Two-Factor Policy** section, enable the enforcement toggle.

   All members without 2FA will be prompted to set it up on their next login. They need an authenticator app to finish the setup.

<Note>
Enforcing 2FA is recommended for organizations handling sensitive data or operating in regulated industries.
</Note>

This policy covers the whole organization. Each member still enrolls their own authenticator from their profile.

## If a member cannot sign in

A member who has lost their 2FA device can use a saved recovery code. A member who has lost both the device and the recovery codes needs to contact support. Ask members to store recovery codes in a secure location separate from their authenticator device.

## Change the organization name

1. Open **Settings > Org Settings**.
2. Edit the organization name field.
3. Select **Save**.

   The new name is the display name members see across the platform.
