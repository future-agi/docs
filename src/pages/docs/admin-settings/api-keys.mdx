API keys authenticate your application with Future AGI. Each key pair is an API Key (`FI_API_KEY`) and a Secret Key (`FI_SECRET_KEY`), and you need both to use the [Python or TypeScript SDK](/docs/sdk) or the [REST API](/docs/api). The Secret Key is shown only once and deleting a key cuts off every application that uses it, so this guide shows how to create a pair, check which workspace it authenticates, and replace an old key before you delete it.

<Prerequisites title="Before you start">
- You need the organization [Owner role](/docs/roles-and-permissions) to manage keys.
- Sign in with a password or social login. A [SAML session](/docs/release-notes) cannot change API-key settings.
- Have a secret manager or a secure place for environment variables ready. The secret key is shown only once.
</Prerequisites>

## Create a key pair

1. Open **Settings > API Keys** at [https://app.futureagi.com/dashboard/keys](https://app.futureagi.com/dashboard/keys).
2. Click **Add API Key**.
3. Enter a name for the key.
4. Copy the API Key to your secret store.
5. Copy the Secret Key to the same place.

   The Secret Key is only shown once, at creation time. Afterward the keys table shows the API Key, with a copy icon next to it, and masks the Secret Key.

## Configure the application

| Environment variable | What to store | Where to find it |
| --- | --- | --- |
| `FI_API_KEY` | The API Key | The keys table |
| `FI_SECRET_KEY` | The matching Secret Key | Your secret store. It is shown only when you create the key. |

Set both as environment variables in your application. `YOUR_API_KEY` and `YOUR_SECRET_KEY` below are placeholders:

```python
import os
os.environ["FI_API_KEY"] = "YOUR_API_KEY"
os.environ["FI_SECRET_KEY"] = "YOUR_SECRET_KEY"
```

```typescript
process.env.FI_API_KEY = "YOUR_API_KEY";
process.env.FI_SECRET_KEY = "YOUR_SECRET_KEY";
```

<Tip>
Never commit API keys to version control. Use environment variables or a secret manager.
</Tip>

## Verify the pair

1. Load the new pair in the application you want to check.
2. Call [`account.whoami`](/docs/sdk/reference/account) with the Python or TypeScript client.

   It returns the authenticated user, organization and workspace.

3. Compare them with the ones you intended.

   If the workspace is wrong, check which pair the application loaded before you change any other keys.

## Rotate or revoke a key

To rotate a key, replace it in your applications first and delete it last.

1. [Create a new key pair](#create-a-key-pair).
2. Update each application that uses the old pair with the new credentials.
3. [Verify the pair](#verify-the-pair) from each updated application.
4. Click the delete icon on the old key.

<Warning>
Deleting a key is permanent and cannot be undone. It immediately revokes access for any application using it, so update your code before deleting.
</Warning>

## Troubleshooting

- **You lost the Secret Key.** The keys table masks it, so it can't be read back. Check your secret store first. If it isn't there, rotate the key as above instead of deleting one that is still in use.
- **You can't change API-key settings.** Check that you have the Owner role and that you signed in with a password or social login, not SAML.
