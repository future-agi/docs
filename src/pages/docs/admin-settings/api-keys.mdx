## About

API keys authenticate your application with Future AGI. Each key pair consists of an API Key (`FI_API_KEY`) and a Secret Key (`FI_SECRET_KEY`). You need these to use the Python SDK, TypeScript SDK, or REST API.

Access: active organization members (**Owner**, **Admin**, **Member**, and **Viewer**) can create their own personal keys. Sign in interactively with a password or OAuth; API-key authentication and SAML-scoped sessions cannot issue personal keys. Managing other members' keys is restricted to **Owners** and **Admins**.

## How to

<Steps>
  <Step title="Open Keys">
    Open **Keys** under **Build** in the main sidebar, or go directly to [https://app.futureagi.com/dashboard/keys](https://app.futureagi.com/dashboard/keys).
  </Step>
  <Step title="Create a new key">
    Click **Add API Key**. Enter a name for the key.
  </Step>
  <Step title="Copy your keys">
    In **Save your personal key**, copy and securely save both the API Key and Secret Key before closing. Both values are shown only once, in this creation result; you cannot recover them from the key table later.
  </Step>
  <Step title="Use in your application">
    Set them as environment variables.

    ```python
    import os
    os.environ["FI_API_KEY"] = "YOUR_API_KEY"
    os.environ["FI_SECRET_KEY"] = "YOUR_SECRET_KEY"
    ```

    ```typescript
    process.env.FI_API_KEY = "YOUR_API_KEY";
    process.env.FI_SECRET_KEY = "YOUR_SECRET_KEY";
    ```
  </Step>
</Steps>

## Managing Keys

| Action | How |
|--------|-----|
| View keys | Both API Key and Secret Key are masked in existing rows. The table cannot reveal either value. |
| Copy a key pair | Copy both values from the one-time creation result, before closing it. Existing rows do not offer copying of usable credentials. |
| Delete a key | Click the delete icon. This is permanent and cannot be undone. |
| Rotate keys | Delete the old key and create a new one. Update your application with the new credentials. |

<Warning>
Deleting a key immediately revokes access for any application using it. Make sure to update your code before deleting.
</Warning>

<Tip>
Never commit API keys to version control. Use environment variables or a secret manager.
</Tip>
