---
title: "Create your first prompt"
description: "Create and run your first prompt in the Future AGI Prompt Workbench, with versioning built in"
---

A prompt is the instruction you give a model, and getting it right is one of the highest-leverage things you can do for an AI product. The **Prompt Workbench** gives every prompt a versioned home, so you can edit it, compare versions, and reuse it across datasets, simulations, experiments, and the SDK. This page walks you through creating and running your first prompt from scratch

## Prerequisites

- A Future AGI account
- At least one model provider configured (Dashboard → **Settings → AI Providers**) so you can run the prompt

## 1. Open Prompts

In the dashboard, under **Build** in the left nav, click **Prompts**:

![Prompts section in the Future AGI dashboard](/images/docs/get-started/create-your-first-prompt/prompts-list.png)

## 2. Create a new prompt

Click **Create prompt**, then choose **Start from scratch** (the other options are *Generate with AI* and *Start with a template*):

![Create a new prompt modal with Start from scratch selected](/images/docs/get-started/create-your-first-prompt/create-modal.png)

## 3. Name it and pick a model

The prompt opens as **Untitled-1**: click the title and rename it to **Acme Support Assistant**, then click **Select Model** to choose the model it runs on. You can optionally tune parameters like **temperature**, **max tokens**, and **top P**:

![Renaming the prompt and selecting a model](/images/docs/get-started/create-your-first-prompt/select-model.png)

## 4. Write the prompt

The editor has two fields:

- **System** (optional): instructions that shape the model's overall behavior
- **User**: the message that drives the response

Here's a ready-to-use example. Copy each block into the matching field:

**System**

```text
You are a customer support assistant for Acme, a company that makes project-management software.
Answer the customer's question clearly and accurately, in a friendly and professional tone.
Keep your reply under 120 words. If you are unsure of the answer, say so honestly and point the
customer to help@acme.com instead of guessing.
```

**User**

```text
How do I reset my password?
```

## 5. Run it

Click **Run Prompt** in the top-right corner. The model's response appears in the **Output** panel:

![Running the prompt and viewing the output](/images/docs/get-started/create-your-first-prompt/run-prompt.png)

## 6. Save a version

Save the prompt. Every edit creates a new **version**, so you can compare versions, roll back, and deploy a specific one via labels, and reuse the prompt across the rest of the platform

## Verify

Your prompt now appears in the **Prompts** list with its first version, and the **Output** panel shows the model's latest response

Congratulations! You've created your first prompt!🎉

## Troubleshooting

Not getting a response? Try checking these:

- **"API key not configured"**: add a model provider key under **Settings → AI Providers**, then run again
- **Empty output**: check that the **User** field isn't blank before running
