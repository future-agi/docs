<TLDR>
Route an OpenAI SDK request through [Agent Command Center](/docs/command-center) by changing two lines, then find the provider that served it in the [request log](/docs/command-center/features/observability).
</TLDR>

## The problem

An app that calls a model provider directly has no single place to add routing, caching, guardrails or cost tracking. The reply alone also does not tell you which provider served the request, how long it took or what it cost. Agent Command Center is the gateway that adds these to every request.

## What you'll build

An OpenAI-compatible client that sends its requests to the gateway instead of directly to the provider. You change two lines in the OpenAI SDK, `base_url` and `api_key`, and the rest of your code stays the same. This works with any OpenAI-compatible client, and you can switch providers later without touching your code.

You'll:

1. Connect a [provider](/docs/command-center/features/providers) and choose a model to expose.
2. Send a request using the gateway URL and key.
3. Read the provider, latency and available cost for that request.

<Prerequisites title="Before you start">
- A Future AGI account and an API key for the provider you want to connect.
- Python 3.10+. The JS/TS example needs Node.js instead.
</Prerequisites>

## Create the gateway key

1. Create an Agent Command Center API key in **Dashboard > Settings > API Keys**.
2. Copy the value starting with `sk-agentcc-`.

## Connect a provider

The gateway routes each request to a provider you've connected, so add at least one.

1. Open **Agent Command Center > Providers**.

![Providers list in Agent Command Center](/images/docs/get-started/route-your-first-llm-request/list_provider.png)

2. Click **Add provider**.
3. Choose a provider.
4. Enter its API key.
5. Select the model to expose. The request examples use `gpt-4o-mini`.

<div style={{ display: 'flex', gap: '1rem', alignItems: 'flex-start', margin: '1.5rem 0' }}>
  <img src="/images/docs/get-started/route-your-first-llm-request/add_provider_modal.png" alt="Add provider modal in Agent Command Center" style={{ flex: 1, minWidth: 0, maxWidth: 'none', margin: 0 }} />

</div>

6. Save the provider.

   You should see it in the provider list.

## Set your gateway key

Set your Agent Command Center key in your terminal:

```bash
export AGENTCC_API_KEY="sk-agentcc-your-api-key-here"
```

## Send a request

Change two lines, `base_url` and `api_key`, then send a request:

<CodeGroup titles={["Python", "JS/TS"]}>

```python Python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.futureagi.com/v1",   # 1. point at the gateway
    api_key=os.environ["AGENTCC_API_KEY"],          # 2. use your sk-agentcc- key
)

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "How does Future AGI's agentcc gateway reduce LLM call cost by 80%?"}],
)
print(response.choices[0].message.content)
```

```typescript JS/TS
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.futureagi.com/v1",   // 1. point at the gateway
  apiKey: process.env.AGENTCC_API_KEY,            // 2. use your sk-agentcc- key
});

const response = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "What is the capital of France?" }],
});
console.log(response.choices[0].message.content);
```

</CodeGroup>

## Run it

Save the Python example as `gateway.py` and run it:

```bash
python gateway.py
```

You should see the model's reply in the terminal. The request is now flowing through Agent Command Center.

## Find the request in the log

Open your [Future AGI dashboard](https://app.futureagi.com) and go to **Gateway > Request Logs**. Your request appears there with its provider, latency, and cost.

For a programmatic check, every response also carries `x-agentcc-*` [response headers](/docs/command-center/api/headers#response-headers):

```python
resp = client.chat.completions.with_raw_response.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello"}],
)
print("Provider:", resp.headers.get("x-agentcc-provider"))
print("Latency: ", resp.headers.get("x-agentcc-latency-ms"), "ms")
print("Cost:    $", resp.headers.get("x-agentcc-cost"))
```

This check sends a new request, which gets its own log entry. To match one call to its entry:

1. Read `x-agentcc-request-id` from that response's headers.
2. Open **Gateway > Request Logs**.
3. Find the entry with that ID.

   Its provider and latency should match `x-agentcc-provider` and `x-agentcc-latency-ms`. The gateway returns `x-agentcc-cost` only when the model has pricing data, so a missing cost is not a zero cost.

## Switch the requested model

If you have connected the other providers and exposed their models, change the model name. The gateway translates the request to the provider’s format:

```python
client.chat.completions.create(model="claude-sonnet-4-6", messages=[{"role": "user", "content": "Hello"}])
client.chat.completions.create(model="gemini-2.0-flash", messages=[{"role": "user", "content": "Hello"}])
```

## Troubleshooting

- **Authentication error**: confirm your key starts with `sk-agentcc-` (Settings → API Keys)
- **Model or provider error**: make sure that provider is configured in Agent Command Center → Providers
- **Wrong base URL**: it must be `https://gateway.futureagi.com/v1`
