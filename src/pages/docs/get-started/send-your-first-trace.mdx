title: "Send your first trace"
description: "Send your first LLM call into Future AGI with traceAI and see the trace in minutes"
---

Make one OpenAI chat completion and inspect the prompt, reply, and token usage in Future AGI. Pick either the Python or the Node.js example.

[Auto instrumentation](/docs/integrations/traceai) captures supported model calls. You can add [custom spans](/docs/cookbook/quickstart/manual-tracing) for work outside the model, such as looking up an order.

## Prerequisites

- A Future AGI account and your **`FI_API_KEY`** and **`FI_SECRET_KEY`** (Dashboard → Build → Keys)
- Python 3.12 or Node.js 22.18+
- An OpenAI API key

Find both keys at **Dashboard → Build → Keys**. Copy the **API Key** (`FI_API_KEY`) and **Secret Key** (`FI_SECRET_KEY`):

![Future AGI Keys page showing where to copy the API Key (FI_API_KEY) and Secret Key (FI_SECRET_KEY)](/images/docs/get-started/send-your-first-trace/keys-page.png)

## 1. Install traceAI

<CodeGroup titles={["Python", "JS/TS"]}>

```bash Python
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install traceai-openai==0.1.16 fi-instrumentation-otel==1.5.1 openai
```

```bash JS/TS
npm install @traceai/openai@0.1.18 @traceai/fi-core@1.4.1 openai@7.62.0
```

</CodeGroup>

## 2. Set your keys

Environment variables are the same regardless of language. Enter them in your terminal:

```bash
export FI_API_KEY="your-futureagi-api-key"
export FI_SECRET_KEY="your-futureagi-secret-key"
export OPENAI_API_KEY="your-openai-api-key"
export FI_TRACES_URL="https://api.futureagi.com"
```

## 3. Add tracing and make one call

<CodeGroup titles={["Python", "JS/TS"]}>

```python Python
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from traceai_openai import OpenAIInstrumentor
from openai import OpenAI

# Connect to Future AGI and create (or reuse) a project
trace_provider = register(
    project_type=ProjectType.OBSERVE,
    project_name="my-llm-app",
    verbose=False,
)

# Instrument the client before making the request
OpenAIInstrumentor().instrument(tracer_provider=trace_provider)

# Use OpenAI exactly as you normally would
client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Greet a Ridgeline Outfitters customer in one sentence."}],
)
print(response.choices[0].message.content)
trace_provider.shutdown()
```

```typescript JS/TS
import { register, ProjectType } from "@traceai/fi-core";
import { OpenAIInstrumentation } from "@traceai/openai";
import OpenAI from "openai";

const tracerProvider = register({
  projectType: ProjectType.OBSERVE,
  projectName: "my-llm-app",
});

// Attach to the imported SDK rather than relying on module load order.
const instrumentor = new OpenAIInstrumentation();
instrumentor.setTracerProvider(tracerProvider);
instrumentor.manuallyInstrument(OpenAI);

try {
  const client = new OpenAI();
  const response = await client.chat.completions.create({
    model: "gpt-4o-mini",
    messages: [{ role: "user", content: "Greet a Ridgeline Outfitters customer in one sentence." }],
  });
  console.log(response.choices[0].message.content);
} finally {
  await tracerProvider.shutdown();
}
```

</CodeGroup>

Save this as `quickstart.py` (Python) or `quickstart.mts` (JS/TS, an ES module).

## 4. Run it

<CodeGroup titles={["Python", "JS/TS"]}>

```bash Python
python quickstart.py
```

```bash JS/TS
node quickstart.mts
```

</CodeGroup>

You will see the model's reply in your terminal. Shutting down the provider flushes pending spans before the script exits.

## Inspect your trace

Open **Tracing** in the [Future AGI dashboard](https://app.futureagi.com) and select `my-llm-app`.

![Future AGI Tracing tab showing the my-llm-app project](/images/docs/get-started/send-your-first-trace/tracing_home.png)

Open the latest trace and confirm you can see:

- The model and the prompt you sent
- The model's response
- Token usage and call duration

## Troubleshooting

Not seeing your traces? Try checking these:

- **Authentication error**: re-check `FI_API_KEY` and `FI_SECRET_KEY` against Dashboard → Build → Keys
- **No trace in Tracing**: let the script finish. Traces flush as the program exits, so don't stop it early
- **Wrong place**: confirm you're on the **Tracing** tab of the dashboard and in the `my-llm-app` project
