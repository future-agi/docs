<TLDR>
Instrument one OpenAI call in Python or TypeScript, then match its terminal reply with the exported call in [Observe](/docs/observe).
</TLDR>

## The problem

Your script prints a greeting, but the text alone doesn't tell you which prompt produced it, how long the call took or how many tokens it used. To investigate that reply later, you need a [trace](/docs/observe/concepts/traces) for the same request.

## What you'll build

A short script that sends one Ridgeline Outfitters greeting request and exports the model call before the process exits.

<Mermaid chart={`
flowchart LR
    accTitle: Export one OpenAI call
    accDescr: A script asks OpenAI for a Ridgeline greeting. The OpenAI instrumentor records the call, and the tracer provider exports it to the Observe project.
    A["Ridgeline greeting request"] --> B["OpenAI call"] --> C["Instrumentor records span"] --> D["Observe trace"]
`} />

You'll:

1. Set separate credentials for the model provider and the tracing workspace.
2. Attach the [OpenAI instrumentor](/docs/integrations/traceai/openai) before making the call.
3. Flush the trace on exit and compare the reply with its [span](/docs/observe/concepts/spans).

<Prerequisites title="Before you start">
- A Future AGI account and its [API key and secret key](/docs/admin-settings/api-keys).
- Python 3.12 or Node.js 22.18+.
- An OpenAI API key.
</Prerequisites>

## 1. Install traceAI

Choose the commands for one language and use that environment for the rest of the example.

<CodeGroup titles={["Python", "JS/TS"]}>

```bash Python
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install traceai-openai==0.1.16 fi-instrumentation-otel==1.5.1 openai
```

```bash JS/TS
npm install @traceai/openai@0.1.18 @traceai/fi-core@1.4.1 openai@7.62.0
```

</CodeGroup>

## 2. Set your keys

Find both Future AGI keys at **Build > Keys** in the dashboard. Copy the **API Key** (`FI_API_KEY`) and **Secret Key** (`FI_SECRET_KEY`):

![Future AGI Keys page showing where to copy the API Key (FI_API_KEY) and Secret Key (FI_SECRET_KEY)](/images/docs/get-started/send-your-first-trace/keys-page.png)

<div class="sdk-ref-table">

| Variable | What to set | Where to find it |
| --- | --- | --- |
| `FI_API_KEY` | Workspace API key | **Build > Keys** |
| `FI_SECRET_KEY` | Matching secret key | **Build > Keys** |
| `OPENAI_API_KEY` | Key for the model call. It does not export traces | Your OpenAI account |

Environment variables are the same regardless of language. Enter them in your terminal:

```bash
export FI_API_KEY="your-futureagi-api-key"
export FI_SECRET_KEY="your-futureagi-secret-key"
export OPENAI_API_KEY="your-openai-api-key"
export FI_TRACES_URL="https://api.futureagi.com"
```

## 3. Add tracing and make one call

Save the matching example as `quickstart.py` (Python) or `quickstart.mts` (TypeScript, an ES module).

<CodeGroup titles={["Python", "JS/TS"]}>

```python Python
from fi_instrumentation import register
from fi_instrumentation.fi_types import ProjectType
from traceai_openai import OpenAIInstrumentor
from openai import OpenAI

# Connect to Future AGI and create (or reuse) a project
trace_provider = register(
    project_type=ProjectType.OBSERVE,
    project_name="my-llm-app",
    verbose=False,
)

# Instrument the client before making the request
OpenAIInstrumentor().instrument(tracer_provider=trace_provider)

# Use OpenAI exactly as you normally would
client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Greet a Ridgeline Outfitters customer in one sentence."}],
)
print(response.choices[0].message.content)
trace_provider.shutdown()
```

```typescript JS/TS
import { register, ProjectType } from "@traceai/fi-core";
import { OpenAIInstrumentation } from "@traceai/openai";
import OpenAI from "openai";

const tracerProvider = register({
  projectType: ProjectType.OBSERVE,
  projectName: "my-llm-app",
});

// Attach to the imported SDK rather than relying on module load order.
const instrumentor = new OpenAIInstrumentation();
instrumentor.setTracerProvider(tracerProvider);
instrumentor.manuallyInstrument(OpenAI);

try {
  const client = new OpenAI();
  const response = await client.chat.completions.create({
    model: "gpt-4o-mini",
    messages: [{ role: "user", content: "Greet a Ridgeline Outfitters customer in one sentence." }],
  });
  console.log(response.choices[0].message.content);
} finally {
  await tracerProvider.shutdown();
}
```

</CodeGroup>

## 4. Run it

<CodeGroup titles={["Python", "JS/TS"]}>

```bash Python
python quickstart.py
```

```bash JS/TS
node quickstart.mts
```

</CodeGroup>

You will see the model's reply in your terminal. Shutting down the provider flushes pending spans before the script exits.

## Inspect your trace

1. Open **Tracing** in the [Future AGI dashboard](https://app.futureagi.com) and select `my-llm-app`.

   ![Future AGI Tracing tab showing the my-llm-app project](/images/docs/get-started/send-your-first-trace/tracing_home.png)

2. Open the latest trace. Its input should be the Ridgeline prompt from the script.
3. Compare its response with the greeting printed in your terminal.
4. Read the model, token usage and call duration on the span. The scripts print the greeting, not the token counts.

## Troubleshooting

Not seeing your traces? Try checking these:

- **Authentication error**: re-check `FI_API_KEY` and `FI_SECRET_KEY` against **Build > Keys** in the dashboard
- **No trace in Tracing**: let the script finish. Traces flush when the provider shuts down as the program exits, so don't stop it early. If the project stays empty, follow [No traces appear](/docs/observe/troubleshooting/no-traces-appearing).
- **Wrong place**: confirm you're on the **Tracing** tab of the dashboard and in the `my-llm-app` project
