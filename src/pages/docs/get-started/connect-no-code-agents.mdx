---
title: "Connect your no code agent"
description: "Sync your no code agent definition in Future AGI to run simulations"
---

Connect an existing agent from **Agents → Connected agents**, then use an **Environment** to configure and run simulations. This guide starts with a hosted **voice** agent on **Vapi** or **Retell**.

## Prerequisites

- A Future AGI account
- A Vapi **Assistant ID** or Retell **Agent ID**, and the matching provider **API key**
- The contact information required by your chosen voice connection mode

## 1. Open the connection flow

Open **Agents → Connected agents**. In the Agents creation menu, select **Connect agents**. If the list is empty, you can also click **Connect an agent**. Both open the build tab of **Simulate → Environment**.

## 2. Connect your hosted agent

Choose **Hosted platform**, select **Voice** as the agent type, and choose **Vapi** or **Retell**. Enter the provider's agent ID and API key, then complete the contact information and other required fields shown in the form.

Click **Run preflight** and resolve any failed checks. Once the form and preflight allow it, click **Build environment**.

## 3. Run your first simulation

When the environment is ready, review its **Scenarios** and **Evaluations** tabs. Resolve any setup blockers, then click **Run simulation**. Open **Runs** to inspect the results.

<Note>
The older **Agent Definition** wizard and standalone **Run Simulation** flow below are legacy features. They are unavailable to Environments-only organizations. The old Agent Definition list now redirects to **Connected agents**; it is not a sidebar entry. Use the Environment flow above for new connections.
</Note>

## Legacy Agent Definition wizard

The remaining instructions and screenshots apply only if your organization still has access to the legacy **Create new agent definition** page. That wizard has three steps: **Basic Info**, **Configuration**, and **Behaviour**.

![Legacy Agent Simulation welcome screen](/images/docs/get-started/connect-no-code-agents/agent-simulation-welcome.png)

### Add the basic information

On the **Basic Info** step, fill in the basics:

| Field | What you enter |
|-------|----------------|
| **Agent Type** | **Voice** |
| **Agent Name** | A unique, descriptive name (also used as the observability project name) |
| **Language** | One or more languages your agent uses (e.g. English) |

![Basic Info step of the wizard with agent type, agent name, and language fields](/images/docs/get-started/connect-no-code-agents/basic-information.png)

### Configure and connect your agent

On the **Configuration** step, choose the provider and set how Future AGI reaches your agent

Under **Agent Configuration**, **Vapi** and **Retell** are natively supported: select the provider and enter the **Assistant ID** and **API Key**. With those set, use **Sync from provider** to pull the agent's name and system prompt into the form automatically. The right-hand panel lists exactly where to find each value in your provider

Then set **Contact Information**, since voice agents are reached by phone: enter the **country code** and **contact number**, then choose the **connection type**:

- **Inbound**: the agent receives calls
- **Outbound**: the agent places calls (requires the Assistant ID and API Key above)

![Configuration step showing provider, authentication, and contact information fields](/images/docs/get-started/connect-no-code-agents/agent-configuration.png)

<Note>
For **Outbound** agents, both the **Assistant ID** and **API Key** are required. Otherwise saving fails with a validation error
</Note>

### Define behavior and save

On the **Behaviour** step, set how your agent thinks and responds. Add the **system prompt** and, if needed, attach a **Knowledge Base** so evals can check the agent's answers against your real content: FAQs, SOPs, or product docs

Review the **Summary** panel, enter a **commit message** (e.g. "Initial support agent"), and click **Create agent definition**. Future AGI stores this as version **v1**, a snapshot you can run tests against, compare, or roll back to later:

![Behaviour step with the system prompt, knowledge base, commit message, and the configuration summary panel](/images/docs/get-started/connect-no-code-agents/behaviour-and-summary.png)

### Verify the legacy definition

After saving, inspect the definition's version and configuration on its detail page. The old **Agent Definition** list link now opens **Connected agents**.

### Troubleshoot the legacy wizard

Save not going through? Try checking these:

- **Validation error**: for **Outbound** agents, both the **Assistant ID** and **API Key** are required
- **Sync failed**: double-check the API key and Assistant ID match your Vapi or Retell agent
